# 场景化输出模板

场景判定方法见 `post-processing.md` 第一步。所有模板共同要求：
时间戳可溯源、⚠ 低置信内容不作为结论引用、文件头声明生成方式。

## 模板 A：问答体（访谈 / 采访 / 答疑 / 用户调研）

输出文件 `<prefix>.qa.md`。结构：

```markdown
# 访谈问答整理

> 来源：<音频文件名>（时长 hh:mm:ss）
> 说话人：提问者=<S1/姓名>，回答者=<S2/姓名>
> 问答划分依据：声纹分离 + 句式判断 / 仅句式判断（可信度中等）

## 目录
- Q1 [00:03:12] 预算规模问题
- Q2 [00:09:40] 时间表问题

---

## Q1 [00:03:12] 这个方案的预算是多少？

**答**（李工，00:03:18–00:05:02）：

要点：
- 初步估算 300 万左右
- 其中硬件占 60%，明年一季度复核

> 原文摘录：目前初步估算是三百万左右，硬件这块大概占六成……

### Q1.1（追问）[00:05:10] 这个数字包含人力成本吗？
**答**（李工）：不包含，人力另列。
```

规则：
1. **问的识别**：疑问句式（吗/呢/为什么/怎么/多少/能不能/是不是/？结尾），且下一个发言由另一说话人产出较长回应。
2. **答的归属**：取该问题之后、下一个独立问题之前，由回答者产出的全部内容。
3. **追问归并**：同一话题的连续追问作 Qn.1、Qn.2 挂在主问题下，不另立新问。
4. **长答案先要点后原文**：答案超过 150 字时先给 bullet 要点，原文放引用块；短答案直接给原文。
5. **寒暄过滤**：开场寒暄、结尾致谢不进问答体，归入文末"其他内容"一节。
6. **无声纹数据时**：问答对可信度声明必须写"仅句式判断"，且不猜测提问者/回答者身份。

## 模板 B：会议纪要素材（交接 meeting-minutes 技能）

输出文件 `<prefix>.meeting-material.md`，作为 meeting-minutes 技能的输入：

```markdown
# 会议纪要素材
> 本文件为 ASR + LLM 整理的中间素材，非正式纪要

## 会议基本信息（能推断多少写多少，不编造）
- 时间 / 参会人 / 主题

## 议题与讨论（按章节）
### 议题一：<标题> [起始时间戳]
- 讨论要点…
- 分歧点…

## 决议事项
## 行动项（负责人/期限/出处时间戳）
## 待核实事项
```

## 模板 C：讲座 / 培训笔记

输出文件 `<prefix>.notes.md`：

```markdown
# 讲座笔记：<主题>

## 知识大纲（章节树 + 时间戳）
## 核心观点（每条附时间戳）
## 案例与例子
## 讲者推荐/引用的资源
## 现场问答（若有，用模板 A 的单问格式）
```

## 模板 D：语音备忘整理

输出文件 `<prefix>.memo.md`：

```markdown
# 语音备忘整理（<日期>）

## 整理稿（书面化改写，保留原意）
## 待办事项（勾选框列表，含推断出的时间）
- [ ] 明天上午给张总回电话（[00:00:32]）
## 原始转录（折叠保留）
```

备忘场景默认执行口头禅清理与书面化改写（与其他场景相反），因为用户要的是可用的笔记而非存档。

## 模板 E：客服 / 电话记录

输出文件 `<prefix>.call.md`：坐席与客户分列、诉求摘要、承诺事项、
情绪与升级风险标注（仅描述语言表现，不下人格结论）。
