# 变更记录

## 1.2.0（2026-11-10）

- 逻辑与衔接：新增 `references/logic-and-cohesion.md`，据实际运行的立项报告、基金设立报告和汇报提纲提炼论证方法，包括先搭骨架（一句话结论、理由、事实）、总分结构与导语、段落“论点—依据—含义—边界”的写法、七种上下文衔接方式、称谓数字口径分类时间结论六项一致、结论“依据—不足—判断—下一步”的写法、十二种常见逻辑毛病及改法和八项逻辑自查；示例内容均为虚构。
- `SKILL.md` 新增“逻辑硬性规则”八条并写入正文，工作流程增加“搭骨架”步骤；适用范围补充分析材料。
- `references/writing-patterns.md` 总要求增加“逻辑连贯”，成文前自查增加两项逻辑核对；明确分析论证类材料一节收束时可用一句取自本节内容的判断。
- 生成器、版式规则、页码和千位分隔符不变。

## 1.1.0（2026-11-10）

- 公文表述：重写 `references/writing-patterns.md`，按实际运行的请示、报告、批复、函、通知、会议纪要、上会议题、情况说明提炼通用结构、各文种写法、开头和过渡句式、固定结语、口语改书面语对照表及不使用的表达（对话痕迹、连接套话、对比转折句式、后续判断尾巴、空泛拔高、修辞、模糊表达、Markdown符号）和成文前自查；新增 `references/model-texts.md`，收录十类虚构范文和口语改写对照。
- `SKILL.md` 改为中文，写作硬性规则和版式要点全部写入正文，宿主不读取参考文件或不能执行脚本时仍按规则输出；补充事实核对和缺项占位要求。
- 页码由 `-1-` 改为 `- 1 -`（短横线与数字之间各一个半角空格），整体仍为四号宋体、奇右偶左；生成器、烟测和回归测试同步。
- 千位分隔符：规则原已写入文档但生成器未执行，现由生成器对文档规格中的数量自动补齐，年份、日期、文号、电话、代码、标准号等标识保持原样；可用 `"thousands": false` 或 `--no-thousands` 关闭。
- 生成器新增附注 `note` / `--note`（上行文联系人和联系方式），排在成文日期下一行。
- 跨客户端：新增 DeepSeek Harness（`--agent dsh`）和千问办公（`--agent qwenwork`）的安装目录、入口和调用说明。`scripts/skill_portability.py`、`references/agent-compatibility.md` 自本版起由本技能单独维护，退出原共享组。
- 字体文件、字体映射、行距、标题层级、附件说明和落款规则不变。其他技能的页码仍为 `-1-`。
