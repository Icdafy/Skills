# 逻辑与衔接

本文件规定公文和分析类材料的论证方法：全篇怎样搭、段落怎样写、上下文怎样接。方法提炼自实际运行的立项报告、基金设立报告和汇报提纲等长篇论证材料，例子中的单位、项目和数字均为虚构。篇幅超过三段或带有分析、论证、测算内容的材料（报告、请示的理由部分、方案、调研和分析材料、汇报提纲、上会议题）都按本文件成文；一段成文的短公文只需做到第五部分的一致性要求。

判断逻辑是否通顺的标准只有一条：读者不看标题，只读每段第一句，能够复述全文的结论和理由；任意抽出一段，能够说清它回答的是上一段留下的哪个问题。

## 一、先搭骨架再成文

动笔前先写出三样东西，写不出来说明材料还没有想清楚，应当先向用户补问或标出缺口。

1. **一句话结论**。全文要读者接受什么判断或批准什么事项，用一句话写出：`XX公司具备进一步开展投资论证的基础，建议予以立项。`
2. **支撑结论的三至五个理由**。每个理由是一个可以被事实证明或推翻的判断，彼此不重叠、合起来不遗漏。理由之间只用一个标准划分，不混用标准：或按对象（行业、业务、公司、财务、方案），或按时间（近期、中期、长期），或按因果（需求、约束、方案、证据、限制）。
3. **每个理由下的事实**。数据、文件、程序、时间各归其位；找不到事实支撑的理由删去，或改写成"待核实事项"。

骨架确定后，章节顺序就是理由的顺序。常用的顺序有四种，全篇选定一种，不中途更换：

| 顺序 | 用法 | 适用 |
|---|---|---|
| 由面到点 | 行业—产业链—公司—本次事项，每一层结尾落到下一层 | 立项、可研、调研类材料 |
| 由因到果 | 缘由—现状—问题—措施—预期结果 | 请示、方案、整改报告 |
| 由时间 | 已完成—正在推进—下一步；或近期—中期—长期，标明年份 | 进展报告、工作计划 |
| 由重到轻 | 最重要的事项放最前，补充事项放后 | 情况报告、纪要、通知 |

## 二、总分结构与导语

每一章、每一节、每个带小标题的部分，都以一段导语开头。导语做两件事：先给出本部分的结论，再交代下文从哪几个方面展开。下文的小标题必须与导语交代的方面一一对应、顺序相同、数量相同。

- `XX行业正处于由试点验证向规模应用过渡的阶段，下游需求持续释放，政策支持方向明确。以下从市场需求、技术路线、商业化进程和政策支持四方面梳理行业现状。`（随后恰好四个小标题，顺序相同）
- `公司核心技术围绕建模引擎、求解算法、数据接口和行业模型库四个方面展开。`
- `公司主要产品按平台软件、行业解决方案和实施服务三部分列示。平台软件为核心交付内容，行业解决方案为应用延伸方向，实施服务保障项目上线和运维。`

全文的第一部分（概况、摘要或开头段）是全篇的导语，按后文章节的顺序各用一至两句话概括，并以本次事项和结论收尾。后文没有展开的内容不写进概况；概况里的数字、称谓和口径与后文完全一致。

小标题分两类，同一层级只用一类：

- 名称式：`（一）基本信息` `（二）股权变动情况`，用于罗列要素。
- 论点式：`1.下游需求持续释放，市场空间稳步扩大` `2.技术路线逐步收敛，XX成为主流方向`，用于论证。论点式标题本身就是该部分的结论，正文负责证明它，不另起一个不同的结论。

## 三、段落的写法

论证段落按"论点—依据—含义—边界"四步写，一段只证明一个论点。

1. **论点句**放在段首，是一个完整的判断，不用"关于XX方面"这类只报题目不下判断的句子。
2. **依据**紧跟论点：数据写明时点和来源，事实写明主体和时间，程序写明会议和文号。
3. **含义**说明这些依据对本文对象意味着什么，把事实接回主题。常用引出语：`对XX而言，……` `实际意义在于，……` `上述格局的直接含义是，……` `由此，……`
4. **边界**交代该判断成立的条件和尚未验证的部分：`后续转化取决于……` `该测算依赖……两项假设` `具体以……为准` `……尚需在尽调阶段核实`。

示例（虚构）：

```
　　批量化采购改变了配套需求的形态。三家运营单位公布的建设规划合计约2.4万台，单台制造成本较2021年下降约40%。对配套企业而言，需求由一次性研制交付转为多批次、长周期的稳定供货；能够在保证可靠性的同时给出批产价格和交付节拍的供应商，才具备进入采购名录的条件。上述规划为运营单位公开口径，实际采购节奏取决于年度预算和交付能力。
```

四步不必每段齐全：纯陈述段落（工商信息、人员构成、合同清单）写到依据即可；但凡写了判断，就必须有依据和边界。只有论点没有依据的段落删去，只有数据没有含义的段落补上"这说明什么"。

事实型段落按"总括句—分项—必要的说明"写：

```
　　公司共有员工46人，其中全职41人、兼职5人。按部门划分，研发部21人、市场部9人、生产部11人、职能部门5人。研发部人数包含知识产权和综合管理岗位，不等同于直接从事研发的技术人员数量。
```

## 四、上下文的衔接

段与段、节与节之间靠内容衔接，不靠"首先、其次、此外、另外、与此同时"串联。衔接的办法是让后一段的开头接住前一段的结论。

| 衔接方式 | 写法 | 例句 |
|---|---|---|
| 承接上文结论 | 段首复述上段的结论或关键词，再推进一步 | `现有方案尚不能满足上述要求。` `试点进展已同步转化为合同。` |
| 承接图表 | 表前用引导句说明看什么，表后用一句话说出表里得出的结论 | 表前：`各路线主要指标对比如下。` 表后：`上表差异决定了各路线当前的适用范围。` `上表显示，五个环节中有三个已出现上市企业，格局趋于集中。` |
| 由因及果 | 用因果词连接，因果两端都写明 | `由此形成按场景分工的格局：……` `……，因此……` `鉴于……，故……` |
| 转入限制 | 肯定之后交代不足，用"但""同时""仍" | `产品已实现对外销售；但现有合同仍以测试和小批量交付为主，批量销售尚未形成。` |
| 由面到点 | 一层写完，末句落到下一层的对象 | `XX公司处于产业链中游的平台软件环节，并与设备厂商开展联合交付。` |
| 时间推进 | 用明确的时间词起句 | `2026—2027年，……` `本轮融资完成后，……` `立项后，……` |
| 小结收束 | 一节论证完毕，用一句判断收束，判断只取自本节已写的内容 | `总体判断，在需求释放、技术路线收敛和政策支持的共同作用下，……` `整体来看，……` |

衔接时遵守以下规则：

1. **指代清楚**。"上述""该""其""前述"所指的对象必须在紧邻的上文中出现过，且只有一个可能的指代对象；隔了一段以上的，重新写出名称。
2. **因果完整**。写"因此""由此""故"之前，原因必须已经写在纸面上；不把读者不知道的前提当作已知。推理链每一环都写出，不跳步：需求是什么，现有办法为什么不够，新办法靠什么解决，有什么证据，还有什么限制。
3. **先定义后使用**。专门概念、简称、统计口径第一次出现时即界定：`所称长距离作业，指单程50公里以上需返航或单次连续作业2小时以上的任务。`
4. **比较有前提**。比较之前先写明比较的条件和口径：`以相同载重为对比前提，能源价格取2026年6月公开报价。`口径不同的数字不相加、不直接比较，必要时加注：`注：不同分母的占比不可直接相加。`
5. **小结不引入新内容**。小结句、结论段只归纳前文已经论证的内容，不出现前文没有的事实、数字和判断；也不逐条复述前文。
6. **正反并陈**。写优势、进展之后，紧接着写与之对应的限制、风险或待核实事项，放在同一段或紧邻的下一段，不集中堆到文末，也不省略。

## 五、前后一致

全篇核对以下六项，短公文同样适用。

1. **称谓一致**。同一机构、项目、产品全文只用一个简称；简称在首次出现时括注。
2. **数字一致**。同一指标在概况、正文、表格、结论中的数值、单位、时点完全相同；分项之和等于合计，占比之和为100%（因口径或四舍五入不等的加注说明）。
3. **口径一致**。写明数据的统计口径和来源（`按审计报告口径` `据公司介绍` `公开数据显示`），同一处比较只用一种口径；公司提供、未经核实的内容用"据公司介绍""公司预计"标明，与已核实的事实区分。
4. **分类一致**。分类的标准全篇不变，同一层级的各项互不包含。
5. **时间一致**。时点统一写法（`截至2026年6月30日`），先后顺序不倒置，"目前""近期"换成具体时间。
6. **结论与正文一致**。结论的每一个判断都能在正文找到对应的论证；结论的强弱与证据相称，证据写的是"小批量交付"，结论就不写"已形成规模"。

## 六、结论的写法

结论段按"依据—不足—判断—下一步"写，四项齐全，一段完成：

```
　　整体来看，XX公司在建模引擎和行业模型库方面具备自主技术，已在3家头部制造企业完成试点并取得首批订单；但目前收入规模较小，客户集中于单一行业，产品标准化程度和持续盈利能力尚待验证，交付团队扩充进度也将影响项目上线节奏。综合考虑技术积累、客户验证进展和下游应用空间，XX公司具备进一步开展投资论证的基础，建议予以立项。立项后重点围绕订单真实性、收入确认、产品标准化程度和核心人员稳定性开展尽职调查。
```

请示的"请示事项"、报告的结论性判断、方案的预期效果，都按同样的原则：先摆依据，再交代不足或条件，然后给出明确的请求或判断，最后写后续安排。

## 七、常见的逻辑毛病及改法

| 毛病 | 表现 | 改法 |
|---|---|---|
| 导语与正文对不上 | 导语说"从四方面"，下面只有三个小标题，或顺序不同 | 以正文为准改导语，或补齐正文 |
| 段首不下判断 | 段首是"关于市场方面""在技术上"，读完才知道要说什么 | 把结论提到段首 |
| 有数据无含义 | 罗列一串数字后直接换段 | 补一句"对XX而言，……" |
| 有判断无依据 | "市场空间广阔""技术领先"后面没有数字和事实 | 补依据，补不出就删去或改成"据公司介绍" |
| 跳步 | 从"需求增长"直接跳到"公司将受益" | 补出中间环节：需求落在哪个环节，公司是否处在该环节，凭什么能拿到 |
| 指代不明 | "该项目""上述情况"前文有两个可能的对象 | 写出名称 |
| 前后矛盾 | 概况写收入2,000万元，财务部分写1,860万元；前称"行业领先"，后称"尚处验证阶段" | 统一数字和口径；判断按证据强弱重写 |
| 口径混用 | 把不同统计口径的规模相加，把含税与不含税、认缴与实缴放在一起比较 | 分别列示并注明口径 |
| 分类交叉 | 同一层级里既有"按产品"又有"按客户"的分项 | 换成单一标准，另一标准另起一层 |
| 结论越界 | 结论出现正文没有的新事实，或强度超过证据 | 删去新内容，按证据强弱改写 |
| 只说好不说坏 | 优势写了三段，限制一句不提 | 每项优势后补对应的限制或待核事项 |
| 靠连接词硬接 | 段首堆"此外""另外""同时"，段间没有内容联系 | 调整段落顺序，让后段接住前段的结论 |

## 八、成文后的逻辑自查

1. 只读各段首句，能否连成全文的摘要；不能的，改段首句或调整段落顺序。
2. 每一处导语交代的方面，与下文小标题是否数量相同、顺序相同。
3. 每一个判断后面是否有依据，每一组数据后面是否有含义，每一项优势后面是否有限制。
4. "上述""该""其""由此""因此"逐个核对，所指对象和原因是否在上文写明。
5. 同一指标在全文各处的数值、单位、时点是否一致；分项之和是否等于合计。
6. 每张表前是否有引导句，表后是否说明了从表中得出的结论；表内数字与正文是否一致。
7. 结论是否只用到正文已论证的内容，强度是否与证据相称，是否写明下一步。
8. 公司提供的未经核实内容是否已标明来源，是否写明以何者为准。
