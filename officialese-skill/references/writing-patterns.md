# 国企公文写作规范

本文件规定公文的语言、结构和各文种写法。句式和结构提炼自实际运行的国企及区级机关公文（请示、报告、批复、函、通知、会议纪要、上会议题、情况说明），已隐去单位、人名和金额。成文时先定文种和行文方向，再套用对应结构，最后按文末清单自查。配套范文见 `model-texts.md`；篇幅超过三段或带有分析论证的材料，全篇怎样搭、段落怎样写、上下文怎样接，见 `logic-and-cohesion.md`。

## 一、总要求

公文只做三件事：说明依据和缘由，陈述事实和安排，提出明确的请求或要求。正文每一句都应当能归入这三类之一，归不进去的句子删去。

1. 主语是机构，不是个人。自称用"我司""我公司""我局""我方"，对称按行文方向用"贵公司""贵单位"（平行）、"你公司""你单位"（下行）、机关简称（上行，如"区国资局""集团"）。不用"我们""咱们""大家""您""领导"。
2. 事实先于评价。每一处判断后面跟着依据：数据、文件、程序或时间。没有依据的评价句删去。
3. 数字精确、口径完整。金额写清币种和单位，时点写"截至X年X月X日"，上限下限写"不超过""不低于"，构成写"其中"，多项并列写"分别为……、……和……"。四位及以上的数量一律加千位分隔符（`2,400万元`）。
4. 程序交代清楚。已经履行的决策程序、依据的文件和文号、下一步报批环节都写明，例如"本次投资事项已经XX公司党委会及董事会审议通过"。
5. 一文一事，篇幅服从内容。短事短写：转报、印发、备案类公文正文可以只有一段。不为显得完整而补写背景、意义和展望。
6. 语气中性平实。不夸大、不表态式拔高，也不堆砌限定词。写清楚即止，段落写完即收，不加重复前文的总结句和展望句；分析论证类材料一节写完需要收束时，只用一句取自本节内容的判断（`总体判断，……` `整体来看，……`）。
7. 逻辑连贯。先有结论和理由再动笔；每部分以导语开头，交代结论和下文的展开顺序；每段首句下判断，判断后跟依据；后一段的开头接住前一段的结论；称谓、数字、口径全篇一致。具体方法见 `logic-and-cohesion.md`。

## 二、行文方向

起草前先判定行文方向，判定后直接按该口吻成文，不向用户解释判定过程。

| 判定依据 | 上行文 | 平行文 | 下行文 |
|---|---|---|---|
| 用户明示 | 上行文 | 平行文 | 下行文 |
| 文种 | 请示、报告、上会议题 | 函 | 通知、通报、决定、批复、印发类 |
| 关系用语 | 报送、呈报、报批、提请审议 | 商请、函询、函告、不相隶属 | 下发、部署、各部门、各子公司 |

没有任何信号时，按正式书面语成文，不硬套红头格式。

- **上行文**：陈述事实、说明理由、提出请求，把决定权留给上级。用"拟""建议""恳请""提请……审议""请予批复"。不对上级提要求，不出现"各单位要""必须""务必"。请示一文一事；报告不夹带请示事项。
- **平行文**：平等、礼貌、就事论事。用"商请""函询""函告""请予支持""敬请回复为盼"。不用"责成""必须""限期"。
- **下行文**：明确、可执行、可检查。写清责任单位、完成时限、报送渠道。用"现将……通知如下""由……负责""请认真遵照执行"。语气肯定但不喊口号。

## 三、通用结构

标准公文依次为：标题、主送机关、正文、附件说明、发文机关署名、成文日期、附注。

### （一）标题

"发文机关＋关于＋事由＋的＋文种"。发文机关名称较长时单独占一行，"关于……的请示"另起一行。标题只写事由，不写评价和口号；除法规、规章、文件名称加书名号外不用标点。

- `XX公司关于投资XX项目的请示`
- `XX公司关于股权投资基金投后管理情况的报告`
- `XX局关于XX公司投资XX项目的批复`
- `关于认购XX股份有关回购问题的函`
- `XX公司关于印发《2026年制度汇编》的通知`

### （二）主送机关

顶格，后加全角冒号。上行文只写一个主送机关：`区国资局：` `集团：` `董事会：`。下行文可并列：`各部门、子公司：`。

### （三）开头

开头一句交代依据、目的或缘由，随即用过渡句引出正文。不寒暄，不铺垫形势。

| 类型 | 句式 |
|---|---|
| 依据式 | 根据……会议精神／相关规定，……。<br>按照……工作部署，……。<br>为落实《……》（文号）的相关要求，……。 |
| 目的式 | 为深入落实……，做强做优……，现由……。<br>为进一步贯彻……文件精神，着力提升……，……。<br>为加强……管理，健全完善……体系，提升……，……。 |
| 缘由式 | 近期，我司收到……《关于……的函》，拟……。<br>X年X月，……完成……。<br>鉴于……，……。 |
| 引文式（批复、复函） | 你公司《关于……的请示》（文号）已收悉，按照……审议意见，现批复如下：<br>贵公司《关于……的函》收悉。经研究，现函复如下： |
| 转报式 | ……《关于……的请示》已经……第X次常务会议审议通过，现提请……审议。 |

过渡句按文种选用，全篇只用一次：

- 报告：`现将有关情况报告如下：` `现将相关情况汇报如下。` `具体情况如下：`
- 请示：`现就有关事项请示如下：` `现将有关事项请示如下。`
- 通知：`现将有关事项通知如下：` `现印发你们，请认真遵照执行。`
- 批复：`现批复如下：`
- 函：`现就有关事项函告如下：` `现函请贵公司……。`
- 纪要：`现纪要如下：` `经研究，会议决定以下事项：`

### （四）主体

1. **简称**。机构、项目、文件首次出现写全称，后加括注`（以下简称"XX"）`，此后全文只用简称，不来回切换。
2. **层次**。内容少时不分层，直接成段。内容多时用"一、""（一）""1.""（1）"四级标题，层级不跳级、不倒置。一级标题用名词性短语，不带标点：`一、基本情况` `二、政策依据` `三、请示事项`。三级标题可写成"标题句＋句号＋说明"：`1.出资规模。各合伙人实缴规模不超过X亿元，其中我司出资X亿元。`
3. **段内分项**。同一段内并列的几点用"一是……。二是……。三是……。"，每点先写结论性短句，再写具体内容。不用"首先、其次、最后"。
4. **事实陈述**。按"主体＋时间＋事项＋数据"顺序写，一句一个信息点或一组并列信息。
   - `截至X年X月X日，我司X支在管基金均在存续期内，分别为……、……和……。`
   - `基金总规模为6,400万元，A公司出资3,200万元，我司出资3,200万元，注册地拟定于XX区。`
   - `投资总额不超过2,600万元，其中我方出资不超过2,400万元（甲公司出资不超过2,000万元，乙公司出资400万元），丙公司出资200万元。`
   - `本次投资资金来源全部为自有资金。`
5. **程序陈述**。
   - `本项目已经XX公司X年第X次董事会审议通过。`
   - `……已由区财政局报请区政府审议，并原则同意。`
   - `待方案最终确定且符合……相关规定后，履行相关审批手续。`
   - `以上事项报集团审批后执行。`
6. **判断与结论**。判断紧跟事实，用陈述句，一句说完。
   - `基金运营正常，整体风险可控。`
   - `本次投资符合XX公司主责主业范围。`
   - `投资规模占比较低，对公司正常经营及债务履约无不利影响。`
   - `经核查，本次议案的计费标准与《合伙协议》条款相符，未发现损害我方权益的情形。`
7. **责任与要求**（下行文、纪要）。写成"由谁负责＋做什么＋达到什么结果"。
   - `由XX局负责，强化合规性、可行性审查，指导XX公司依法依规依程序做好……工作，确保全流程合法合规、风险可控。`
   - `由XX局牵头，XX街道办事处负责，XX局等单位配合，做好……工作，确保项目顺利推进、按期交付。`
   - `请于X年X月X日前将……报送至XX部。`

### （五）结尾

结语按文种固定，单独成段，前面不加"综上""总之"。

| 文种 | 结语 |
|---|---|
| 请示 | 妥否，请批示。 |
| 报告 | 特此报告。 |
| 函 | 特此致函，敬请回复为盼。／请予支持为盼。／特此函复。 |
| 通知 | 特此通知。（正文已写明执行要求时可不写结语） |
| 批复 | 一般不写结语，批复事项写完即止。 |
| 上会议题 | 现提请董事会审议。／现提请投委会审议。 |

### （六）附件说明、落款与附注

- 附件说明、发文机关署名、成文日期的排法见 `format-rules.md`。
- 上行文在成文日期下一行加附注，写明联系人和联系方式：`（联系人：XXX　联系方式：XXXXXXXXXXX）`。联系人、电话由用户提供，未提供时保留占位并提醒补充。
- 用户未要求时，不编造发文字号、签发人、密级、份号、印发机关和抄送范围。

## 四、各文种写法

### （一）请示

结构：缘由和背景，事项基本情况，依据和可行性（政策依据、决策程序、资金来源、风险），明确的请示事项，结语。

- 开头交代来由后即进入事项，不写形势分析。
- 事项较复杂时分为`一、基本情况` `二、政策依据` `三、请示事项`，或`一、项目基本情况` `二、必要性` `三、风险分析` `四、请示事项`。
- 请示事项必须明确到可以批"同意"或"不同意"：
  - `现提请区政府审议以下事项：一是建议同意XX公司投资认购……的X亿元份额。二是建议由XX公司负责，核定……等核心条款，加强对……运营的监督。`
  - `现向集团申请由我司联合XX公司共同设立……基金，基金规模5,000万元，其中我司出资2,500万元。`
  - `恳请区国资局对我司参与……事项予以审议决策。`
- 可写获批后的履职安排：`如获批准，我司将严格履行出资人职责：一是……。二是……。`
- 结语`妥否，请批示。`后接附件说明、落款、附注。

### （二）报告

结构：依据或缘由，情况（进展、数据、程序），结论性判断，结语。

- 报备类报告写清"做了什么、规模多大、履行了什么程序、符合什么要求"即可，一至三段。
- 情况类报告按"整体情况—分项情况—存在问题—下一步安排"展开，问题和安排有则写、无则不写。
- 报告不提请示事项。需要上级决策的另行请示。
- 结语`特此报告。`

### （三）函

结构：往来背景或缘由，商请、询问或告知的事项，结语。

- 篇幅短，一事一函，通常两至三段。
- 提出请求用`现函请贵公司……` `商请贵单位协助……`，不用命令语气。
- 复函先引来函：`贵公司《关于……的函》收悉。`

### （四）通知

结构：依据或目的，事项安排，执行要求。

- 印发类：`根据……要求，为加强……，健全完善……，特修订完善《……》，经……审议通过，现印发你们，请认真遵照执行。`一段成文。
- 事项类：过渡句后分条写任务，每条写明责任单位、时限、报送方式。

### （五）批复

结构：引述来文，表明态度，提出要求。

- 引文：`你公司《关于……的请示》（文号）已收悉，……现批复如下：`
- 态度明确：`原则同意……。`不同意或需补充的写明事项和理由。
- 要求分条：`请你公司依法依规依程序做好……工作，确保全流程合法合规、风险可控。` `由你公司负责，……，加强……监督，强化风险研判，定期跟踪反馈。`
- 批复事项写完即止。

### （六）会议纪要

公司办公会、投委会类纪要：

1. 标题：`XX公司总经理办公会会议纪要`，下一行`（第X号）`。
2. 要素：`时　间：` `地　点：` `主持人：` `议　题：`各占一行。
3. 导语：`X月X日，公司召开总经理办公会，会议审议了关于……的议题。经研究，会议决定以下事项：`
4. 决定事项逐条写，每条先表态再写内容和后续安排：
   - `一、原则同意……，投资金额不超过2,400万元，其中甲公司出资400万元，乙公司出资不超过2,000万元。具体事宜按照议题所附方案执行。`
   - `二、原则同意……合作方案，并据此开展协议磋商工作。待方案最终确定且符合相关规定后，履行相关审批手续。`
   - 说明理由用`鉴于……，故……。`
5. 文末：`参会人员：` `送：` `发送：`或`抄送：`。

政府、党委类会议纪要按议题分条，每条先写`听取……情况汇报`或`审议并原则同意……《关于……的请示》`，再用`会议指出，……` `会议强调，……` `会议要求，……` `会议确定：（一）……（二）……`展开。"会议指出"写认识和定位，"会议强调""会议要求"写任务和责任单位，"会议确定"写具体决定事项。

纪要只记决定和要求，不记讨论过程和个人发言，不写"大家一致认为""与会人员纷纷表示"。

### （七）上会议题

1. 标题：`审议关于……的议题`。下一行`提交部门：XX部`或`提交子公司：XX公司`。
2. 主送：`董事会：` `投委会：` `总经理办公会：`。
3. 正文：背景和依据，事项具体情况，已履行的程序和核查结论，提请审议的事项。
4. 核查结论：`经核查，……与……条款相符，……符合……约定，未发现损害我方权益的情形。`
5. 结尾：`现提请投委会同意……。`或`现提请董事会审议。`

投委会表决议题、项目退出议题有专门技能时由其负责，本技能只处理一般性上会材料。

### （八）情况说明、方案

- 标题直接写`XX基本情况说明` `XX方案`，不加发文机关和主送机关。
- 用一级标题分块，段落纯陈述，按"设立及管理—规模及出资—投向及项目—现状"之类的客观顺序排列。
- 要素型内容用"名称：……""类型：……"逐项列出，或用三级标题句。
- 不写评价和建议，除非用户要求。

## 五、用语规范

### （一）口语改书面语

| 口语 | 书面语 |
|---|---|
| 已经、还没有 | 已、尚未 |
| 准备、打算、想要 | 拟 |
| 因为、所以 | 因、鉴于；故、据此 |
| 如果、要是、……的话 | 如、若 |
| 和、跟、还有 | 与、及、以及 |
| 都、全都 | 均 |
| 现在、目前为止 | 现、目前、截至目前 |
| 马上、赶紧、尽快 | 及时；于X月X日前 |
| 大概、差不多、左右 | 约（能确定的写确数） |
| 一共、总共、加起来 | 合计、共计、累计 |
| 到……为止 | 截至…… |
| 最多、最少 | 不超过、不低于 |
| 看一下、审一下、过一下 | 审阅、审议、审定 |
| 同意一下、批一下 | 予以批准、予以批复 |
| 告诉、通知一下、问一下 | 告知、函告；函询 |
| 帮忙、配合一下 | 协助、支持、配合 |
| 交、发给、报上去 | 报送、提交、呈报 |
| 找……商量、对接一下 | 商请……；与……对接 |
| 花了、用掉、钱 | 支出、使用；资金、款项 |
| 按……办、照……做 | 按照……执行、遵照执行 |
| 没问题、有问题 | 无异议；存在……问题 |
| 这个、那个、上面说的 | 该、本次、上述 |
| 我们公司、你们公司 | 我司、我公司；贵公司（下行用"你公司"） |
| 开个会、碰一下 | 召开会议、专题研究 |
| 搞、弄、做（泛指） | 写出具体动作：开展、办理、实施、建设、编制 |

### （二）常用规范表述

- 表态：原则同意、同意、不予同意、暂不予……
- 限定：不超过、不低于、原则上、暂定名（以工商核名为准）、具体以……批复为准
- 程序：经……审议通过、报……审批后执行、履行相关审批手续、依法依规依程序
- 风险：风险可控、合法合规、强化风险研判、定期跟踪反馈、确保国有资本安全与增值
- 指代：该公司、该项目、本次投资、上述事项、前述……
- 时间：截至X年X月X日、X年X月、X年第X季度、于X月X日前（不写"近日""前段时间""不久前"）

### （三）不使用的表达

以下表达是口语、宣传腔或机器生成痕迹，公文中不出现。

1. **对话痕迹**：`以下是为您起草的……` `希望对您有帮助` `如需调整请告知` `好的`，以及任何对写作过程的说明。直接输出公文本身。
2. **连接套话**：`首先、其次、再次、最后` `此外、另外、与此同时`（用作段首硬接时） `总之、综上所述、总的来说、总而言之` `值得注意的是、需要指出的是、需要强调的是` `毋庸置疑、众所周知、不言而喻`。并列事项用"一是、二是、三是"或分条，段与段之间靠内容衔接。
3. **对比转折句式**：`不是……而是……` `并非……而是……` `不在于……而在于……` `……而非……` `与其……不如……` `不仅……更……`。直接写肯定判断：`开展……是……的需要` `……有利于……`。
4. **后续判断尾巴**：`需要后续进行判断` `有待进一步研判` `需进一步评估` `仍需持续观察` `后续视情况而定` `具体情况有待确定`。事项未定的，写明由谁、在何时、按何程序确定。
5. **空泛拔高**：`至关重要` `意义深远` `具有里程碑意义` `强有力的支撑` `全方位、多层次、宽领域` `深度赋能` `重要抓手` `注入强劲动力` `开启新篇章` `迈上新台阶`。写具体作用：对什么指标、什么工作有什么影响。
6. **凑数排比**：为了整齐而拼三个近义短语（`更高效、更智能、更便捷`）。并列项各自有实际内容时才并列，两项就写两项。
7. **修辞**：比喻、拟人、设问、反问、感叹句、引号强调、破折号插入说明、省略号。
8. **模糊表达**：`一定程度上` `某种意义上` `或许` `可能会` `相关方面` `有关人员` `近期` `不久` `若干`。写确定的主体、数值和时间；确实无法确定的写"暂定""预计"并说明依据。
9. **情绪和客套**：`非常感谢` `十分荣幸` `深表歉意` `衷心希望` `热烈祝贺`（贺信等礼仪文书除外）。
10. **排版符号**：正文不出现Markdown标记（`#` `*` `-`列表、`>`引用、代码块）、表情符号、英文项目符号。需要强调的内容靠标题层级和句子位置体现，正文不加粗（三级、四级标题句除外）。
