# 国企公文写作模式

Use these patterns to draft concise Chinese SOE officialese. Prefer plain, accountable wording over slogans.

## General Style

- Start with basis or purpose: `为进一步...`, `根据...要求`, `结合...实际`.
- State the action clearly: `现将有关事项通知如下`, `现就有关情况报告如下`, `特请示如下`.
- Use concrete responsibilities: `由...牵头`, `各部门按职责分工落实`, `于...前报送`.
- Use restrained requirement verbs: `请`, `应`, `需`, `严格`, `及时`, `认真`.
- Avoid informal wording such as `大家`, `尽快搞定`, `麻烦`, `非常棒`, `推动一下`.
- Avoid empty intensifiers unless needed: `高度重视`, `扎实推进`, `切实加强` should be supported by concrete measures.

## 通知

Typical structure:

1. Recipient.
2. Purpose or policy basis.
3. Main arrangement.
4. Requirements, deadline, and contact or reporting method.
5. Attachment and signature/date.

Useful sentence frames:

- `为规范...，提升...，现将有关事项通知如下：`
- `请各单位结合实际，认真抓好贯彻落实。`
- `请于X年X月X日前将...报送至...。`

## 请示

Typical structure:

1. Background and need.
2. Requested matter.
3. Basis, feasibility, funds, or risk control.
4. Clear request for approval.

Useful sentence frames:

- `为保障...顺利推进，根据...，拟...。`
- `现就...事项请示如下：`
- `妥否，请批示。`

## 报告

Typical structure:

1. Work background.
2. Progress or main situation.
3. Existing issues.
4. Next steps.

Useful sentence frames:

- `现将有关情况报告如下：`
- `截至目前，...`
- `下一步，我公司将...`

## 函

Typical structure:

1. Reason for correspondence.
2. Matter requiring coordination, confirmation, or reply.
3. Polite closing.

Useful sentence frames:

- `为推进...，现就...函告如下：`
- `请贵单位予以支持为盼。`
- `特此函达。`

## 会议纪要

Typical structure:

1. Meeting time, location, host, participants.
2. Main deliberations.
3. Agreed matters.
4. Tasks, responsible departments, and deadlines.

Useful sentence frames:

- `会议听取了...汇报，研究了...事项。`
- `会议要求，...`
- `会议明确，由...负责，于...前完成。`

## Polishing Checklist

- Replace vague subjects with accountable entities.
- Convert long oral sentences into numbered requirements.
- Remove duplicated adjectives and slogans.
- Confirm every deadline, unit, amount, and attachment name.
- Ensure closing formula matches document type: 通知 uses implementation requirements, 请示 uses `妥否，请批示。`, 函 uses `特此函达。` or support/response wording.
