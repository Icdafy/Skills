# 国企公文写作模式

Use these patterns to draft concise Chinese SOE officialese. Prefer plain, accountable wording over slogans.

## 行文方向识别

Before drafting, detect 行文方向. If detected, write in that tone directly.

Priority order:

1. Explicit user wording: `上行文`, `平行文`, or `下行文`.
2. Document type: 请示/报告 usually means 上行文; 函 usually means 平行文; 通知/通报/决定/批复/印发 usually means 下行文.
3. Relationship wording: 向上级报送/呈报/报批 means 上行文; 商请/函询/同级/不相隶属 means 平行文; 下发/部署/贯彻落实/各单位 means 下行文.
4. If none appears, default to normal formal SOE written style.

When drafting in chat, do not explain this detection unless asked. Produce the official text directly.

## General Style

- Start with basis or purpose: `为进一步...`, `根据...要求`, `结合...实际`.
- State the action clearly: `现将有关事项通知如下`, `现就有关情况报告如下`, `特请示如下`.
- Use concrete responsibilities: `由...牵头`, `各部门按职责分工落实`, `于...前报送`.
- Use restrained requirement verbs: `请`, `应`, `需`, `严格`, `及时`, `认真`.
- Avoid informal wording such as `大家`, `尽快搞定`, `麻烦`, `非常棒`, `推动一下`.
- Avoid empty intensifiers unless needed: `高度重视`, `扎实推进`, `切实加强` should be supported by concrete measures.
- Plain-text body paragraphs and numbered headings should begin with two full-width spaces `　　`.

## 上行文口吻

Use for requests or reports from a lower unit to a higher unit, especially 请示 and 报告.

Tone:

- Respectful, concise, factual, and approval-oriented.
- Avoid instructing the superior unit. Use `拟`, `建议`, `请予审定`, `请予批复`, `请示如下`, `报告如下`.
- Be clear about the requested decision. A 请示 must be one matter per document and should not bury multiple unrelated requests.
- A 报告 should state facts, progress, issues, and next steps; do not attach a hidden approval request inside a 报告.

Useful openings:

- `根据...要求，结合...实际，现将有关情况报告如下：`
- `为保障...顺利推进，拟...，现就有关事项请示如下：`
- `按照...工作安排，我公司对...进行了梳理，现将有关情况报告如下：`

Useful closings:

- 请示: `妥否，请批示。`
- 报批类请示: `以上请示妥否，请予批复。`
- 报告: `特此报告。`

Avoid:

- `各单位要...`, `请你单位抓好落实`, `必须立即...` when addressing a higher unit.
- Casual self-justifying language such as `我们觉得`, `希望领导支持一下`.

## 平行文口吻

Use for communication between equal units or units without direct subordination, especially 函.

Tone:

- Equal, courteous, coordinated, and matter-focused.
- Use `贵单位` for the counterpart when appropriate and `我公司`/`我单位` for the sender.
- Use `商请`, `函询`, `函告`, `请予协助`, `请予支持为盼`, `特此函达`.
- Avoid commands that imply hierarchy, such as `责成`, `必须`, `限期整改` unless there is a legal or contractual basis.

Useful openings:

- `为推进...，现就...事项函告如下：`
- `因...工作需要，现商请贵单位协助办理...事项。`
- `就...有关事宜，我公司函询如下：`

Useful closings:

- `请予支持为盼。`
- `请函复为盼。`
- `特此函达。`

## 下行文口吻

Use for documents from a higher unit to subordinate units, especially 通知, 通报, 决定, 批复, and 印发类 documents.

Tone:

- Clear, directive, executable, and accountable.
- Use `现将...通知如下`, `各单位要...`, `请认真贯彻落实`, `严格按照...执行`, `按时报送...`.
- State responsible departments, deadlines, reporting channels, and inspection requirements where relevant.
- Keep the tone firm but not emotional or slogan-heavy.

Useful openings:

- `为规范...，提升...，现将有关事项通知如下：`
- `根据...要求，现将...印发给你们，请认真贯彻执行。`
- `经研究，现就...工作通知如下：`

Useful closings:

- `请各单位结合实际，认真抓好贯彻落实。`
- `特此通知。`
- `执行过程中如遇问题，请及时向...反馈。`

## 默认书面正式口吻

Use when no 上行文、平行文、下行文 signal appears.

Tone:

- Formal, neutral, concise, and suitable for SOE internal written materials.
- Prefer factual verbs and accountable subjects.
- If the user asks for a制度、方案、说明、纪要, choose the matching structure without forcing a red-head official document frame.

## 通知

Typical structure:

1. Recipient.
2. Purpose or policy basis.
3. Main arrangement.
4. Requirements, deadline, and contact or reporting method.
5. Attachment and signature/date.

Useful sentence frames:

- `为规范...，提升...，现将有关事项通知如下：`
- `请各单位结合实际，认真抓好贯彻落实。`
- `请于X年X月X日前将...报送至...。`

Checks:

- Usually use 下行文口吻.
- Requirements should name the responsible party, deadline, and reporting channel when available.

## 请示

Typical structure:

1. Background and need.
2. Requested matter.
3. Basis, feasibility, funds, or risk control.
4. Clear request for approval.

Useful sentence frames:

- `为保障...顺利推进，根据...，拟...。`
- `现就...事项请示如下：`
- `妥否，请批示。`

Checks:

- Use 上行文口吻.
- Keep one requested matter per document.
- Make the approval point explicit near the end.

## 报告

Typical structure:

1. Work background.
2. Progress or main situation.
3. Existing issues.
4. Next steps.

Useful sentence frames:

- `现将有关情况报告如下：`
- `截至目前，...`
- `下一步，我公司将...`

Checks:

- Use 上行文口吻.
- Report facts and arrangements; do not request approval in disguise.

## 函

Typical structure:

1. Reason for correspondence.
2. Matter requiring coordination, confirmation, or reply.
3. Polite closing.

Useful sentence frames:

- `为推进...，现就...函告如下：`
- `请贵单位予以支持为盼。`
- `特此函达。`

Checks:

- Use 平行文口吻.
- Avoid 下级命令式 verbs unless the user supplies a binding basis.

## 会议纪要

Typical structure:

1. Meeting time, location, host, participants.
2. Main deliberations.
3. Agreed matters.
4. Tasks, responsible departments, and deadlines.

Useful sentence frames:

- `会议听取了...汇报，研究了...事项。`
- `会议要求，...`
- `会议明确，由...负责，于...前完成。`

## Polishing Checklist

- Replace vague subjects with accountable entities.
- Convert long oral sentences into numbered requirements.
- Remove duplicated adjectives and slogans.
- Confirm every deadline, unit, amount, and attachment name.
- Ensure closing formula matches document type and 行文方向: 通知 uses implementation requirements, 请示 uses `妥否，请批示。`, 报告 uses `特此报告。`, 函 uses `特此函达。` or support/response wording.
- Confirm the plain-text indentation rule: body paragraphs and numbered headings begin with `　　`.
