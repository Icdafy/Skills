# 公文范文

以下范文仿照实际运行的国企及区级机关公文的结构、句式和篇幅编写，单位、人名、项目、文号、日期和金额均为虚构。起草时先找到同文种范文，照其结构、句长、用词和详略成文，再替换为用户提供的事实。"XX"表示需由用户材料填入的内容；没有材料支撑的内容不要照抄范文中的数字、文号和程序。

范文侧重各文种的格式和用语；长篇材料的论证结构、段落写法和衔接方式另见 `logic-and-cohesion.md` 中的示例。

范文为纯文本排法：标题不缩进，主送机关顶格，正文段落和各级标题以两个全角空格开头。

## 十一、改写对照

用户给的是口语或提纲时，按下例的方式改写：保留全部事实，补齐主体、时间、数量和程序，删去语气词和评价。

口语原文：

```
我们公司想跟C集团一起搞个基金，大概6000多万，一家出一半，董事会已经过了，跟您报告一下。这个基金主要投高端装备方向的项目，对区里的产业发展挺有帮助的，希望领导支持。
```

机器腔写法（不采用）：

```
首先，本次合作不仅是一次资本层面的联合，更是我司深度赋能区域产业的重要抓手。值得注意的是，该基金将为区域高质量发展注入强劲动力，具有十分重要的意义。综上所述，恳请领导予以大力支持，后续进展有待进一步研判。
```

公文写法：

```
　　我司拟联合C投资集团有限公司共同设立股权投资基金，基金总规模6,400万元，双方各出资3,200万元，投资方向为高端装备领域。本事项已经我司2026年第五次董事会审议通过。
　　特此报告。
```

改写要点：`想跟……一起搞`写作`拟联合……共同设立`；`大概6000多万`向用户核实后写确数并加千位分隔符；`一家出一半`写明各方金额；`已经过了`写明会议名称和届次；`跟您报告一下`由结语`特此报告。`承担；`挺有帮助`没有数据支撑，删去；报告不提请求，`希望领导支持`删去。
