# 纪要行文：平实的正式公文表述

起草纪要前与 [format-and-output.md](format-and-output.md) 一并读取。目标是让纪要读起来像有经验的投资经理或综合办公室同事整理的文稿：正式、平实、具体、克制，读者看不出机器生成的痕迹。本文件只管“怎么写”，内容边界、结构和版式仍以 format-and-output.md 为准；两者冲突时，以不丢失会议事实为先。

## 1. 基本要求

1. **一句一事，短句为主。** 主语明确（公司、该产品、本轮融资、会议），谓语用实义动词（实现、完成、签订、投产、拟、计划）。一句超过约 60 字时拆成两句。
2. **具体代替抽象。** 能写数字、名称、时间的地方，不写“较大”“显著”“诸多”“一系列”“相关”。会议只说了“增长较快”时照录“较快”，不替会议加程度词，也不替会议补数字。
3. **少用修饰。** 删去不承载信息的“深入”“充分”“全面”“有效”“积极”“重要”“持续”“进一步”；会议原有的“约”“预计”“初步”“目前”等限定词必须保留。
4. **段落长短随内容。** 不追求每段字数相近、句式对称；不在段尾追加总括句、升华句或展望句，事实写完即收。
5. **分项用公文写法。** 多个并列要点写成“一是……；二是……；三是……。”，不用“首先……其次……最后……”的演讲腔，也不写成冒号小标签加短语的列表。
6. **连接词克制。** “此外”“同时”“另外”“与此同时”不连续用作段首；前后句本来就接得上时不加连接词。
7. **标点平实。** 不用破折号插入解释，不用感叹号，不用引号制造概念或强调；会议明确使用的产品名、模式名可加引号一次，之后直接书写。
8. **不比喻、不排比、不喊口号。** 删除“护航”“引擎”“蓝海”“新高地”等比喻，删除三连并列的形容词堆砌，只保留会议实际提到的属性。

## 2. 机器腔表述（quality_check 拦截）

下列表述由 `quality_check.py` 的 `AI_TONE_PATTERNS` 检出，命中即报错。确为会议原话且必须保留时，才可用 `--allow-line <行号>` 放行并向用户说明。

| 类型 | 典型表述 | 改法 |
| --- | --- | --- |
| 总括套话 | 综上所述、总而言之、总的来说、总体来看、整体而言、简而言之、换言之 | 删去，直接写结论 |
| 推论套话 | 不难看出、由此可见、可以看出、显而易见、毋庸置疑 | 删去；结论确为会议所述时直接陈述 |
| 提示语 | 需要指出的是、需要说明的是、值得一提的是、具体而言、具体来看 | 删去，直接写内容 |
| 空泛拔高 | 具有重要意义、发挥关键作用、奠定坚实基础、提供有力支撑、注入新动能、未来可期、彰显、呈现良好态势 | 删去，或换成会议所述的具体事实和数字 |
| 修饰套话 | 深入交流、充分沟通、广泛探讨、全方位、多维度、深层次 | “就……进行了交流”；直接列出具体方面 |
| 口号式四字格 | 持续深耕、蓄势待发、行稳致远、厚积薄发、砥砺前行、保驾护航、大有可为、如火如荼、迈上新台阶 | 改为具体事实 |
| 机械分点 | 首先……其次…… | 一是……二是…… |
| 标点 | 破折号“——”、感叹号 | 改为逗号、分句或另起一句 |
| 问答开头 | “答：关于这个问题，……”“答：这个问题……”“问：请问……”“问：想了解一下……” | “答：”后直接回应；“问：”后直接写问题 |

此前已有的硬性规则继续有效：“值得注意的是”、否定对照句式、后续判断尾句、核验提示句、泛化受访主体及总结中的转述外壳，见 format-and-output.md 第 3 节。

## 3. 不由脚本拦截、起草时自行避免

- **网络和咨询黑话。** 赋能、抓手、打法、底层逻辑、颗粒度、心智、飞轮、组合拳等，按书面语改写：赋能→支持、提升；抓手→措施、切入点；打法→做法、策略。闭环控制、通信链路、护城河等确为行业术语或会议原话的，照录。机构不接受的词可写入 `glossary/banned-phrases.txt`，由 quality_check 拦截。
- **名词化堆砌。** “对产品进行了优化升级”“实现了收入的较快增长”改为“产品已升级至第三代”“收入增长约40%”。
- **无数据的程度副词。** 显著、大幅、极大、快速、稳步，会议给了数字就写数字，没给就照录会议原词。
- **千篇一律的句首。** 不要每段都以“在××方面，公司……”开头；直接以主语或时间开句。
- **结尾的评价和用途说明。** 删去“为后续投资决策提供参考”“整体发展值得关注”等记录人自己的话。
- **过度谨慎。** 不在每句前后堆“目前来看”“在一定程度上”“相对而言”；会议原话有的保留，没有的不加。

## 4. 改写示例

以下示例中的数字仅作说明，实际写作只用会议中出现的事实。

**导语**

- 机器腔：本次访谈围绕公司发展历程、核心技术、市场拓展及未来规划等方面展开了深入交流，取得了良好效果。
- 改写：我方与公司管理层就经营情况、产品技术、客户订单和本轮融资安排进行了交流。

**总结段落**

- 机器腔：总体来看，公司在技术研发方面持续深耕，已构建较为完善的产品矩阵，展现出较强的市场竞争力，为后续规模化发展奠定了坚实基础。
- 改写：公司现有三条产品线，主力产品为工业级无人机，2025年收入约1.2亿元，占总收入约70%。飞控和动力系统为自研，两款新机型计划于2026年下半年量产。

**转述腔和拔高**

- 机器腔：张总介绍，公司订单呈现快速增长态势，这充分体现了市场对公司产品的高度认可。
- 改写：公司2025年新签订单约3.5亿元，较2024年增长约60%，主要来自电力巡检和应急两类客户。

**机械分点**

- 机器腔：首先，公司拥有经验丰富的团队；其次，公司掌握核心技术；最后，公司具备完善的供应链体系。
- 改写：团队核心成员主要来自航空院所，平均从业约15年；飞控算法和电池管理系统为自研；电机、结构件由两家长期合作的供应商配套。

**破折号和引号**

- 机器腔：公司打造了“硬件+软件+服务”一体化模式——即通过硬件销售带动后续软件订阅收入。
- 改写：公司以硬件销售带动软件订阅，设备售出后按年收取软件服务费。

**问答：答非所问的“空心答复”**

- 机器腔：
  - 问：请问公司目前的产能情况如何？
  - 答：关于这个问题，公司目前产能情况良好，产能利用率处于较高水平，能够有效满足客户需求，同时公司也在积极推进新产线建设，为未来发展提供有力支撑。
- 改写：
  - 问：公司目前产能及利用率如何？
  - 答：现有两条产线，年产能合计约5万台，2025年产能利用率约85%。新产线已开工，预计2026年三季度投产，投产后年产能增加约3万台。

**口语转书面：保留条件和确定程度**

- 原话：这个毛利的话，嗯，我们今年大概能做到三十五左右吧，明年的话看量，量上去了应该能到四十。
- 过度润色：公司毛利率稳步提升，预计未来将进一步改善。
- 改写：答：2026年毛利率预计约35%；2027年如出货量增加，毛利率预计可提升至约40%。

## 5. 交付前通读自查

起草完成后，按以下顺序把全文通读一遍，逐处修改：

1. 每段第一句是否直接进入事实，而不是铺垫、过渡或概括。
2. 删去一个形容词或副词后意思不变的，删去。
3. 段尾有没有总括、升华、评价或用途说明，有就删。
4. 相邻两段是否用了同样的句首、连接词或句式，有就改其中一处。
5. 每个“答：”的第一句是否直接回应了“问：”。
6. 随机抽三段，与转录原话对照：纪要的信息量不少于原话，确定程度与原话一致，没有多出会议没说过的评价。
