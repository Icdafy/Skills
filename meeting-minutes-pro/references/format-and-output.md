# 会议纪要格式与输出规范

## 1. 固定版式

本规范依据《文件字体格式》样例、配套字体和《新员工入职培训资料（综合办公室）》中的公文格式要求整理。会议纪要采用 A4 纵向页面；上边距 3.7 厘米、下边距 3.5 厘米、左边距 2.8 厘米、右边距 2.6 厘米。正文两端对齐。

| 部位 | 字体与字号 | 对齐和间距 |
| --- | --- | --- |
| 大标题 | 二号方正小标宋简体（22 磅） | 居中，固定值 30 磅，不设首行缩进 |
| 副标题或部门行（仅在需要时） | 三号楷体_GB2312（16 磅） | 居中；其后空一行 |
| 一级标题 `一、` | 三号黑体（16 磅），不加粗 | 两端对齐，首行空两字，固定值 28 磅 |
| 二级标题 `（一）` | 三号楷体_GB2312（16 磅），加粗 | 两端对齐，首行空两字，固定值 28 磅 |
| 三级标题 `1.` | 三号仿宋_GB2312（16 磅），加粗 | 两端对齐，首行空两字，固定值 28 磅 |
| 四级标题 `（1）` | 三号仿宋_GB2312（16 磅），不加粗 | 两端对齐，首行空两字，固定值 28 磅 |
| 正文、会议基本信息、问答内容 | 三号仿宋_GB2312（16 磅） | 两端对齐，首行空两字，固定值 28 磅 |
| 页码 | 四号宋体（14 磅） | 奇数页右侧、偶数页左侧，格式 `-1-` |

字体文件内的可用字体族名称分别为：`FZXiaoBiaoSong-B05S`、`KaiTi_GB2312`、`FangSong_GB2312`。DOCX 生成工具必须写入这些实际字体族名称，同时设置东亚字体属性。

除居中的大标题，以及确有必要时居中的副标题或部门行外，所有内容均用两个全角空格 `　　` 起首。DOCX 中以 32.4 磅的首行缩进实现，不用普通半角空格凑缩进。

## 2. 层级与标点

层级依次使用 `一、`、`（一）`、`1.`、`（1）`，不得跳级或倒序使用。一级标题作为小标题时句尾不加标点；二级标题的句尾标点可依内容决定；三级标题和四级标题必须保留其编号后的标点。层级数量应服从内容需要，不为追求格式强行拆分。

会议纪要属于法定公文文种。形成一般内部会议纪要时不设置公文版头、发文字号、主送机关、印章和附件说明，除非用户提供的场景明确要求。会议信息、议题和正文均以材料事实为准。

## 3. 书面化口径

- 采用第三方记录口径，使用“会议听取”“会议围绕”“与会人员提出”“经讨论”“会议明确”等表述；结论性动词只用于材料有明确依据的内容。
- 同一事项遵循“事项背景或现状—讨论意见—明确结论或后续安排”的顺序。信息不足时，只保留已经出现的环节。
- 数字、时间、单位和责任主体照录或谨慎规范化；出现歧义时标注“待核”，不根据常识补齐。
- 区分“已决定”“拟推进”“建议研究”“需进一步核实”等状态，避免将意见写成决定。
- 删除口头语、客套语和重复句。保留不同意见、条件限制、风险提示和未决事项的实质内容。
- 禁止使用主观褒贬、宣传性修辞、空泛的价值判断和不具来源的效果预测。

## 4. 主题式纪要模板

```text
[会议名称]

　　会议时间：[仅在材料明确时填写]
　　会议地点：[仅在材料明确时填写]
　　参会范围：[仅在材料明确时填写]

　　一、[议题或事项名称]
　　（一）[事项背景、现状或讨论重点]
　　[对转录内容的完整归纳。]
　　（二）[会议意见或明确安排]
　　[对讨论意见、结论、责任分工和时限的完整归纳。]

　　二、[下一事项]
　　[按材料继续整理。]
```

未明确的基本信息不显示。标题行只写会议名称，保持居中；正文示例中的两个全角空格仅表示文本交付时的首行缩进。

## 5. 问答纪要模板

```text
[会议名称]

　　会议时间：[仅在材料明确时填写]
　　会议地点：[仅在材料明确时填写]

　　一、问答纪要
　　（一）[主题]
　　问：[完整归纳问题，不改变问题指向。]
　　答：[完整归纳答复；保留明确的事实、口径、条件、时间节点和后续安排。]

　　（二）[下一主题]
　　问：[问题]
　　答：[答复]
```

每一个“问”后必须有对应“答”。无法确认答复来源时，写明“答复待核”并保留可辨认的原始表述；没有问题的陈述性事项仍采用主题式结构。
