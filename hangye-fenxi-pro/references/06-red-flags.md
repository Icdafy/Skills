# 行业分析红旗库

本红旗库只服务于“二、所属行业分析”的固定结构，用来识别看起来专业但经不起投委会追问的叙事陷阱。红旗提示某个判断需要更硬证据、口径修正或降级表述，与结论对错无关。文中“公司简称”指拟投资公司的简称。

使用方法：写完 `市场规模与增长趋势`、`核心增长驱动力`、`产业链概况`、`产业链洞察与启示` 后逐项扫描。命中的红旗要转化为核查动作或正文修订，不要写“无”。

## 一、结构红旗

| 红旗现象 | 为什么危险 | 核查/改写动作 |
|---|---|---|
| 开篇出现“行业定义与研究边界”标题 | 与本技能固定输出结构冲突，破坏用户要求的范文式章节 | 删除该标题，只把边界判断自然融入市场规模口径和产业链卡位 |
| 输出竞争格局、风险分析、投资判断小结等额外同级章节 | 把行业分析扩成完整行研，偏离立项报告该部分的篇幅与结构 | 将必要判断压缩进增长驱动或产业链启示 |
| 小节没有加粗核心结论，直接铺数据或政策 | 投委会读不出判断，只看到资料堆砌 | 在每个细分部分首段补加粗判断句 |
| 核心结论前带“核心结论：”“核心观点：”标签 | 标签式写法生硬，判断句本身加粗即可 | 删除标签，保留加粗判断句 |
| 标题顶格或居中 | 与公文版式要求冲突 | 所有层级标题首行缩进 2 个中文字符，与段落平齐 |
| 对关键零部件/终端/基础设施类公司仍机械套用“市场规模先行” | 广义行业规模解释不了公司需求，容易把大市场当作可及市场 | 改用“关键配套/基础设施先行型”，先证明该环节为什么是刚需 |
| 判断型标题写成宣传口号 | 标题替代论证，削弱正式报告质感 | 标题只写可证明的功能地位，如“XX 是 XX 场景的关键配套” |

## 二、语言与称谓红旗

| 红旗现象 | 为什么危险 | 核查/改写动作 |
|---|---|---|
| 出现“不是……而是”“并非……而是”“不仅……而且”等成对转折/递进连词 | 句式繁琐，遮住核心判断，机器味重 | 改为直接正面陈述；需要对比时拆成两句，先写局限再写变化 |
| 出现“标的公司”“标的”“本标的”“目标公司” | 立项报告应直接指称公司，抽象称谓拉开距离感 | 全部替换为公司简称（如“因诺科技”“伊隆纬特”） |
| 出现“根据资料包”“根据 BP”“据会议纪要”“据访谈纪要” | 暴露内部资料依赖，且对方材料站在其优势角度叙事 | 删除来源表述；行业事实改用权威公开来源重新落证 |
| 出现“我们认为”超过 1 处 | 弱化公文客观性 | 改为“从……看”“整体来看”“可以判断” |

## 三、市场规模与增长趋势红旗

| 红旗现象 | 为什么危险 | 核查/改写动作 |
|---|---|---|
| 只引用广义大行业规模，缺公司相关细分市场 | 容易把宏观大盘当作公司可及市场，夸大天花板 | 按总市场、细分市场、公司相关市场分层 |
| 用异常低点或试点初期年份计算 CAGR | 把恢复性反弹包装成结构性高增长 | 选正常年份重算，或并列两个 CAGR 说明差异 |
| CAGR 与首末值不一致 | 投委会会直接复算，数据错误削弱全文可信度 | 用 `reconcile_check.py` 或手工复算 |
| 远期预测倍数跳跃大，但没有中间年份和关键假设 | 数字像募资故事，缺独立研究支撑 | 补渗透率、单价、客户数、装机量等假设，或降级为区间 |
| 正文出现“根据公司整理”“该数为公司自述”“仅作为方向参考” | 公司自述撑不起行业空间论证，也破坏正式报告质感 | 改用权威来源；无法验证则放待核实事项 |
| 写“市场空间巨大、前景广阔”但没有规模、增速和驱动机制 | 空泛乐观 | 用具体数字、CAGR、细分占比和驱动因素替代 |
| 广义市场、细分市场和公司可及市场混用 | 容易夸大公司市场天花板 | 分层写 TAM/细分市场/可及市场，说明换算关系 |

## 四、政策驱动红旗

| 红旗现象 | 为什么危险 | 核查/改写动作 |
|---|---|---|
| 政策原文只是“鼓励、支持、引导”，正文写成“强制、刚性、明确要求” | 夸大政策约束力，误导行业阶段判断 | 对照政策原文，力度弱时降级为方向性支持 |
| 罗列十几条政策但不归纳演进规律 | 政策清单不等于分析 | 先写战略定位、治理逻辑、政策工具的变化，再用表格支撑 |
| 只写政策利好，不写合规、准入、标准和监管成本 | 单边论证 | 同时说明政策如何提高门槛或改变竞争 |
| 地方试点政策被写成全国性趋势 | 试点不等于普遍放开 | 写明区域、试点阶段和复制条件 |
| 只写最新政策，缺与过去的对照 | 读者看不出政策拐点和需求增量 | 补“过去局限 -> 新增工具/约束 -> 行业影响”解释链 |

## 五、市场驱动红旗

| 红旗现象 | 为什么危险 | 核查/改写动作 |
|---|---|---|
| 把政策鼓励直接等同于真实付费需求 | 政策热不代表客户愿意长期买单 | 区分政策驱动和客户预算驱动 |
| 需求证据全部来自公司管理层访谈 | 样本有天然乐观偏差 | 找下游客户、行业协会、招投标、年报等独立证据 |
| 只写“效率提升、降本增效”，缺具体痛点和客户场景 | 需求无法验证 | 对应到客户、流程、成本、安全、覆盖范围或数据价值 |
| 把试点项目写成规模化商业化 | 试点验证和常态采购是不同阶段 | 标明“试点/示范/规模交付/常态运营” |
| 只写客户痛点，缺付费逻辑 | 痛点不等于市场 | 补预算来源、采购机制、复购/运维需求或降本测算 |

## 六、产业链概况红旗

| 红旗现象 | 为什么危险 | 核查/改写动作 |
|---|---|---|
| 上中下游只列企业名，不解释部件或服务功能 | 读者不知道钱和壁垒在哪里 | 每个类别补“功能+重要性+壁垒/成熟度” |
| 公司产业链位置照抄公司说法 | 公司常倾向写“全产业链布局”，与真实壁垒是两回事 | 根据收入来源、产品交付、客户价值和关键能力独立判断 |
| 产业链全景只围绕公司自身业务展开 | 遗漏与公司无关的环节，全景失真，卡位判断失去参照 | 独立还原上中下游全部主要环节和细分赛道，再落公司位置 |
| 环节只写笼统一段，未拆细分赛道 | 读者看不出该环节由哪些赛道构成、格局差异在哪 | 每个环节拆成 3-5 个细分赛道，逐一写构成、功能、格局、代表企业 |
| 孤立宣布“公司处于中游”，未落到具体赛道 | 缺少同赛道参照，卡位判断悬空 | 把公司简称写进所属细分赛道，与同赛道企业并列 |
| 上游核心部件成本或国产化缺口没有写 | 无法判断中游放量和毛利空间 | 补成本占比、国产化率、供应格局或认证难度 |
| 下游场景都写成“快速增长” | 不同场景商业化阶段差异很大 | 区分成熟场景、快速拓展场景和培育场景 |
| 产业链价值量和市场规模混加 | 终端市场、部件市场、服务市场不可直接相加 | 明确产业链层级，不同层级分开表述 |
| 技术参数堆砌但不解释场景含义 | 像技术说明书，与投资立项报告错位 | 把参数翻译成成本、性能、可靠性、客户采用或放量节奏 |
| 新技术路线被写成全面替代旧路线 | 可能忽略存量生态、成本和可靠性优势 | 写成并行、结构替代或增量渗透，并说明条件 |

## 七、产业链洞察与启示红旗

| 红旗现象 | 为什么危险 | 核查/改写动作 |
|---|---|---|
| 启示只是复述“上游重要、中游集成、下游应用” | 没有投资含义 | 改成价值迁移、瓶颈环节、降本节奏、客户结构等规律 |
| 启示没有落回公司 | 行业分析与项目投资脱节 | 每条启示增加“对公司简称而言”或自然落点 |
| 把对公司有利的趋势写成确定性结论 | 结论被投资意愿污染 | 给出条件式表达和待验证变量 |
| 没有写反向约束 | 只讲机会不讲产业链制约 | 补写上游成本、下游预算、标准认证、客户集中等约束 |

## 八、图表红旗

| 红旗现象 | 为什么危险 | 核查/改写动作 |
|---|---|---|
| 图表只有“如下图所示”，没有解释其证明什么 | 图表成为装饰，读者无法获得判断 | 在图前或图后补一句论证承接 |
| 图表数据和正文数字不一致 | 投委会会直接质疑数据可靠性 | 统一首末值、CAGR、预测年份和来源 |
| 政策表列很多文件但正文没有归纳 | 表格替代分析 | 正文先归纳战略定位、治理逻辑、工具落地，表格只承载明细 |
| 产业链图谱很完整但正文只列企业名 | 图替代不了价值和壁垒分析 | 正文补各环节功能、成本/技术/认证壁垒和公司卡位 |

## 九、组合红旗

多条红旗同时出现时，需要在正文中降级判断或补充核查动作：

- **大市场口径 + 无细分市场 + 公司卡位模糊**：行业盘子可能与公司收入无关。必须重建 TAM/细分/SAM 层级。
- **政策热 + 试点项目 + 无客户预算证据**：需求可能仍停留在示范阶段。市场驱动部分必须补真实付费逻辑。
- **需求高增 + 上游降本未兑现 + 中游竞争者增多**：行业规模增长不等于公司毛利改善。产业链启示中需点出成本和竞争压力。
- **全产业链表述 + 收入集中单一环节 + 核心能力未证明**：公司“全产业链布局”可能只是宣传口径。产业链卡位要以收入和交付能力为准。
