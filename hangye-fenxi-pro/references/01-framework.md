# 行业分析标准目录模板（13 模块）

本文件是行业分析章节的结构总纲。先读"总体逻辑与裁剪规则"，再按模块查阅写法。

## 总体逻辑：为什么按这个顺序写

行业分析的叙事线是一条**从"这是什么生意"到"这个生意值不值得投"的漏斗**：

```
定义边界（分析对象是什么）
  → 发展背景（为什么现在值得看）
    → 产业链（钱在哪个环节、标的卡在哪）
      → 市场规模（盘子多大、长多快）
        → 需求 / 供给（增长是真是假、供需是否错配）
          → 竞争格局（标的能不能分到钱）
            → 政策 / 技术（外部变量如何改变以上判断）
              → 商业模式（这个环节的钱好不好赚）
                → 趋势（未来3-5年以上判断会怎么变）
                  → 风险（以上判断错在哪最致命）
                    → 投资判断小结（收束为一句审慎结论）
```

每一层都以上一层为前提：不先定义边界，市场规模口径就是乱的；不先拆产业链，竞争格局就不知道跟谁比；不先讲清需求驱动，增长预测就是无源之水。**写作时若发现某段内容与上下层逻辑接不上，多半是放错了模块。**

## 标题编号体系（固定）

```
（一）一级标题        ← 章内大块，如（一）行业发展现状
1. 二级标题           ← 分析模块，如 1.市场规模与增长趋势
（1）三级标题         ← 模块内分论点，如（1）政策驱动
1) 四级标题           ← 分论点内再分层（能不用就不用）
一是/二是/三是        ← 段内列举，不单独成标题
```

若本章节在整份立项报告中编号为"二、所属行业分析"，则沿用该大标题；单独交付时大标题写"XX 行业分析"。

三级标题以下慎用：出现四级标题的条件是——该层内容有 3 条以上、每条超过 150 字、且相互并列。否则用"一是/二是"段内列举，避免标题过碎。相邻标题不得逻辑重复（如"（1）政策支持"与"1)政策利好"同现即为重复）。

## 模块裁剪规则

13 个模块是**全配置**，不是每篇都要写满。裁剪原则：

- **不可裁剪**（任何行业必写）：①行业定义与边界、④市场规模、⑦竞争格局、⑫风险分析、⑬投资判断小结；
- **强烈建议保留**：②发展背景、③产业链、⑧政策环境；
- **按行业特性取舍**：⑤需求 / ⑥供给（供需矛盾突出的制造业必写，可合并为"供需分析"）、⑨技术演进（硬科技必写，消费服务业可并入趋势）、⑩商业模式（To B 服务、平台型必写，标准品制造可并入产业链）、⑪发展趋势（可并入投资判断小结）；
- 精简版（初筛报告）最少配置：①+②+④+⑦+⑫+⑬，约 4,000–6,000 字；
- 模块可合并但**分析功能不得丢失**：合并后每个功能仍需有对应段落。

模块到标题的映射示例（参考成熟立项报告惯例）：

```
（一）行业发展现状          ← 模块①②④⑤（定义、背景、规模、需求驱动）
（二）产业链分析            ← 模块③⑥（产业链、供给格局）
（三）竞争格局分析          ← 模块⑦
（四）政策环境与技术趋势     ← 模块⑧⑨⑪
（五）商业模式分析          ← 模块⑩（按需）
（六）行业风险分析          ← 模块⑫
（七）行业分析小结          ← 模块⑬
```

## 模块① 行业定义与研究边界

**写什么**：行业概念定义（一句话说清这个行业卖什么给谁）；广义行业与狭义行业的区分及本文取哪一层；覆盖的产业环节、产品范围、服务范围、客户范围、应用场景；标的公司在此边界中的位置一句话点明。

**为什么写**：投委会最常见的质疑是"你说的市场规模到底是哪个市场的规模"。边界不清，全篇数据口径都会被挑战。此模块通常 300–600 字，可作为（一）的首段而不单独设标题，但功能必须存在。

**常用指标**：无硬性数据指标，重在概念与口径界定。可引用国家统计局/发改委的产业统计分类（如《低空经济及其核心产业统计分类（试行）》将产业划分为 4 大类 23 中类 65 小类——有官方分类必引，它是边界合法性的最强背书）。

**常见表格**：一般不需要。行业分类层级复杂时可用"广义行业—细分行业—标的所处赛道"三层示意。

**注意事项**：宁窄勿宽。"公司属于人工智能行业"是失焦写法；"公司属于工业级无人机行业中的油气管道巡检服务细分赛道，广义上归属低空经济产业"才是合格写法——先钉住狭义，再挂靠广义。

## 模块② 行业发展背景

**写什么**：宏观经济背景（仅取与本行业直接相关者，不写通用宏观综述）；政策背景（政策态度的演进方向，详表留给模块⑧）；技术背景（哪项技术成熟/降本触发了行业拐点）；需求变化背景（下游客户的什么变化催生了需求）；产业升级/国产替代等驱动因素；**收束到一句话：行业为何在当前时点具备研究价值**。

**为什么写**：回答"为什么是现在"。投资讲时机，行业分析必须论证当前是值得进入的阶段，而非泛泛证明行业"好"。

**常用指标**：政策发布密度与层级变化、渗透率所处区间（导入期<10%、成长期10–50%）、关键成本曲线（如"相控阵天线成本三年下降约50%"这类拐点信号）、国产化率现状。

**常见表格**：一般不需要，背景用叙述；若驱动因素多，可用"驱动因素—作用机制—证据"三列小表。

**注意事项**：背景写作最容易堆砌。纪律是：每个背景因素必须能回答"它如何具体改变了本行业的需求量、成本或准入"，答不上来就删。政策背景在此只写"演进判断"（如"政策从纲领性引导转向落地细则，约束力实质性增强"），政策明细表放模块⑧，避免重复。

## 模块③ 产业链结构分析

**写什么**：开篇"核心结论"段——一句话概括产业链结构（"上游X—中游Y—下游Z"）+ 当前产业链的核心瓶颈/价值集中环节 + 标的所处位置。然后分（1）上游（2）中游（3）下游逐环节展开：各环节核心参与者、关键资源、技术壁垒、成本结构、利润分布、议价能力；最后写"产业链演进的启示"（2–3 条），从价值迁移规律推导投资含义，落回标的所在环节的价值量、壁垒与竞争压力判断。

**为什么写**：回答"钱在哪个环节、标的卡位好不好"。同一行业里，卡在价值量 5% 的环节和 50% 的环节是两个完全不同的投资标的。

**常用指标**：各环节价值量/成本占比（如"T/R 组件占相控阵天线总成本的 50%–60%，T/R 芯片又占 T/R 组件成本的 60%–80%"——层层拆解到价值最集中的最小单元）、各环节国产化率、各环节毛利率带、集中度、上市公司数量（环节成熟度的代理指标）。

**常见表格**：产业链结构表（见 04-tables-charts.md 表 2）。上中下游各一张"类别|简介|头部代表企业|竞争格局"表是成熟写法。

**注意事项**：
- 每个环节的"竞争格局"栏必须给**定性结论**（如"高壁垒、低波动的成熟市场""高增长、高分化的黄金赛道"），不能只列企业名；
- 价值占比数据尽量引招股说明书（招股书成本拆解是一级市场最可信的免费数据源）；
- "启示"是本模块的灵魂：从"产业链重心向哪迁移""哪一环节是资源枢纽"推导"什么样的公司会赢"，再对照标的——这是行业分析与投资判断之间的桥。

## 模块④ 市场规模与增长空间

**写什么**：历史市场规模（近 3–5 年）→ 当前规模 → 未来 3–5 年预测；总盘子与标的所在细分赛道分开测算；增长的结构性特征（哪个细分贡献增长）；**测算的公式、假设、口径、数据来源必须写明**（规则详见 03-data-rules.md）。

**为什么写**：市场空间决定标的天花板，是估值的分母。投委会一定会复算这个数，测算过程不透明等于给否决递刀。

**常用指标**：市场规模（亿元）、CAGR（写明起止年份）、细分市场占比、渗透率、国产化率、量价拆分（销量×单价、装机量×单位配套价值量、用户数×渗透率×客单价）。

**常见表格**：市场规模测算表（见 04-tables-charts.md 表 3）+ 历史规模数据表（配柱状图建议）。

**注意事项**：
- 总市场（如"民用无人机 1,278 亿元"）与细分市场（如"工业级 776 亿元"）与标的可及市场（如"油气管道巡检服务约 XX 亿元"）三层递进，最终落到标的可及市场——这层往往资料里没有，需要自己搭公式测算，这正是体现专业性的地方；
- 远期预测跨度大的（如"2030 年 1,000–2,000 亿元"），必须交代预测方假设或改用区间+敏感性表述；
- 历史数据与预测数据在表格中用注释明确区分。

## 模块⑤ 行业需求分析

**写什么**：下游客户类型及其采购逻辑（G 端/央企/大 B/小 B/C 端的预算来源与决策链差异）；需求性质拆分——刚性需求、周期性需求、替代性需求（替代人工/替代旧技术）、新增需求（新场景创造）；需求增长驱动因素及**持续性判断**；标的所解决的客户痛点归纳（"一是…二是…三是…"痛点排列是成熟写法）。

**为什么写**：回答"增长是真是假"。政策催出来的需求和客户掏真金白银的需求，可持续性完全不同。

**常用指标**：下游客户资本开支/运维预算增速、客单价、复购率/续约率、渗透率提升空间、替代对象的成本对比（如"无人机巡检 vs 人工巡检的单公里成本"）。

**常见表格**：一般叙述即可；客户类型多时用"客户类型|需求场景|采购逻辑|需求性质"表。

**注意事项**：区分"存量替代"与"增量创造"两类需求分开论证（参考写法："针对存量需求提供更高效率/安全/低成本的替代方案；针对增量需求创造传统手段无法实现的新功能"）。判断持续性时明确说出依据：预算制度化（进入客户年度预算科目）、政策强制（合规要求）、经济性跨越拐点（ROI<1 年）都是持续性的硬证据。

## 模块⑥ 行业供给分析

**写什么**：行业产能/产量/供给结构；主要供给方类型（央企院所/上市公司/创业公司的分层）；供给门槛——技术门槛、资质门槛、资金门槛、交付能力门槛；供需匹配判断：是否存在供需错配、产能过剩或**优质供给不足**（很多行业总供给过剩但满足高端需求的供给稀缺，这正是投资机会所在）。

**为什么写**：需求好不等于生意好，供给格局决定价格与毛利走向。

**常用指标**：产能利用率、在建产能、新进入者数量与融资事件数、资质证照数量（如适航认证、军工资质、入网许可）、交付周期。

**常见表格**：可并入产业链表或竞争格局表，不必单独成表。

**注意事项**：制造业必写，服务业可弱化为"供给方能力分层"。警惕只写需求不写供给的单边论证——需求高增+供给无门槛=价格战，这是投委会必问的问题，与其被问不如先答。

## 模块⑦ 竞争格局分析

**写什么**：行业集中度及演变方向；竞争分层——头部企业、腰部企业、新进入者、潜在替代者（跨界巨头）；主要竞争者逐一对比：产品、技术路线、客户结构、渠道、价格、收入规模、盈利能力、融资进展；竞争性质判断（分散竞争/寡头竞争/区域竞争/技术竞争/价格竞争/生态竞争）；**标的公司在行业中的相对位置**及其竞争优势的可持续性。

**为什么写**：回答"标的能不能分到钱、分到的钱保不保得住"。

**常用指标**：CR3/CR5/CR10（写明分子分母口径）、头部企业市占率、竞品融资轮次与估值、竞品收入/毛利率（上市竞品引年报，非上市竞品引公开融资报道并注明可靠性等级）。

**常见表格**：竞争对手对比表（见 04-tables-charts.md 表 4）——行业分析中最重要的一张表。

**注意事项**：
- 分细分市场讨论格局（参考写法：军用"国家队垄断、格局固化"，消费级"全球寡头、大疆市占率超 70%"，工业级"细分场景分散竞争、无绝对龙头"——同一产业不同细分格局截然不同，混在一起谈集中度没有意义）；
- 对每个细分格局给定性判词："高壁垒、低波动""高增长、高分化""高潜力、高不确定性"；
- 描述标的相对位置时克制：用"细分领域头部服务商之一""在 XX 场景形成差异化优势"，避免"行业领导者""绝对龙头"（除非有市占率数据支撑）。

## 模块⑧ 政策与监管环境

**写什么**：先归纳政策**演进规律**（不是罗列）：政策层级变化（如"从部委文件上升到法律""连续写入政府工作报告"）、治理逻辑变化（如"从管控转向促进"）、政策工具变化（如"从纲领倡导转向标准体系+统计分类+试点授权的精准落地"）；然后落政策梳理表；准入门槛与资质要求单独说明；**每项政策必须落到对行业空间/竞争格局/商业模式/标的公司的具体影响**。

**为什么写**：中国一级市场的多数赛道，政策是第一变量。但投委会反感政策罗列——他们要的是"政策约束力是在增强还是减弱、对标的是利好还是门槛"。

**常用指标**：政策数量与层级趋势、试点城市/示范区名单（标的所在地是否在列）、标准制定进度（如"到 2030 年制定标准 300 项以上"）、财政补贴/政府采购规模。

**常见表格**：行业政策梳理表（见 04-tables-charts.md 表 1），"主要内容及对行业的影响"栏必须写到标的公司层面。

**注意事项**：政策分析的高级写法是**识别拐点**：指出哪一份文件使政策从"引导"变为"刚性约束"（如"某文件明文要求 XX 配套，从制度层面确立了刚需地位，行业政策预期实质性抬升"）。同时如实写出政策的局限（"此前政策以框架性扶持为主，缺少落地细则与量化指标，约束偏弱"）——敢写政策不足的分析才可信。监管趋严的行业，本模块要如实评估合规成本与淘汰风险。

## 模块⑨ 技术演进与产品趋势

**写什么**：核心技术路线及其竞争（如"抛物面 vs 相控阵""高轨 vs 低轨"）；技术迭代方向与降本曲线；产品升级趋势（一般可归纳为更 X、更 Y、更 Z 的排比式趋势句）；技术壁垒的具体构成（专利、工艺、算法、材料、系统集成能力、研发周期）；**技术变化对现有企业是机会还是替代风险**。

**为什么写**：硬科技投资中，押错技术路线是最大的单点风险。

**常用指标**：技术路线成本对比与交叉点预测、核心部件国产化率、专利数量（慎用，说明质量口径）、研发费用率、技术代际参数对比（时延、功耗、重量、精度等）。

**常见表格**：技术路线对比表（路线|原理|优势|劣势|成本|适用场景|代表企业）。

**注意事项**：技术路线之争不轻易判死刑，成熟写法是"双轨并行"判断："未来 3–5 年呈现 A 保基本盘、B 抢增量盘的双轨格局，B 的渗透速度取决于上游 XX 的成本下降斜率"——把路线之争转化为可跟踪的先行指标。标的押注的路线要如实说明其反面情形。

## 模块⑩ 商业模式与盈利模式

**写什么**：行业常见商业模式枚举（卖设备/卖服务/设备+服务一体化/订阅/运营分成）及演进方向（如"从卖设备向卖服务转型"）；收入来源与确认方式；成本结构；毛利率带及其决定因素；费用结构、回款周期、现金流特点（G 端/央企客户的回款周期要如实写）；护城河要素核查：规模效应、网络效应、客户粘性、复购率、渠道壁垒、数据壁垒——**逐项判断有无，不能笼统说"壁垒深厚"**；商业模式健康度结论：是否健康、可持续、可复制。

**为什么写**：行业空间大不等于商业模式好。回款 18 个月的大市场可能不如回款 30 天的小市场。

**常用指标**：毛利率/净利率带、单位经济模型（单客户/单项目/单台设备的收入-成本-毛利）、回款周期（DSO）、复购率/续约率、人效（人均创收）。

**常见表格**：商业模式对比表（见 04-tables-charts.md 表 5）。

**注意事项**：本模块写"行业层面"的商业模式规律，标的自身财务细节留给立项报告的公司分析章节，此处只需说明标的采用哪种模式、该模式在行业中处于什么生态位。

## 模块⑪ 行业发展趋势

**写什么**：未来 3–5 年主要趋势 3–5 条，**每条区分确定性与不确定性**；每条趋势 = 趋势判断 + 支撑证据（数据/政策/技术曲线）+ 对行业参与者和标的的影响；给出可跟踪的先行指标（如"低轨星座组网进度""标准发布数量"）。

**为什么写**：投资赚的是未来的钱，但趋势判断最容易写空。

**常用指标**：因趋势而异；每条趋势至少绑定一个可量化的先行指标。

**常见表格**：行业发展趋势表（趋势|确定性等级|支撑证据|先行指标|对标的影响）。

**注意事项**：禁止"前景广阔、空间巨大、大有可为"式空泛表达。确定性分级表述："确定性较高的趋势是……""方向明确但节奏存在不确定性的是……""尚待验证的是……"。

## 模块⑫ 行业风险分析

**写什么**：从以下清单中选取对标的影响最大的 4–7 项展开（不是全写）：政策风险、技术替代风险、市场需求波动风险、竞争加剧风险、价格下降风险、客户集中风险、供应链风险、周期性风险、商业模式验证不足风险。每条风险三段式：**风险事实（什么可能发生）→ 传导机制（如何影响行业和标的）→ 程度判断（影响多大、有无缓释因素）**。

**为什么写**：风险章节是立项报告公信力之锚。投委会用它检验报告是否诚实——风险写得敷衍，前面的乐观全部打折。

**常用指标**：客户集中度（CR1/CR5 收入占比）、价格年降率（尤其大客户年度议价机制）、竞品融资额（弹药对比）、政策依赖度（收入中来自补贴/政府采购的比例）。

**常见表格**：风险因素表（见 04-tables-charts.md 表 7），按影响程度排序。

**注意事项**：客观、克制、中立——既不弱化（为过会），也不夸大（为免责）。有缓释因素的如实写缓释因素，没有的不硬编。"商业模式验证不足"这类根本性风险如果存在，必须写，哪怕它动摇投资逻辑。

## 模块⑬ 行业投资判断小结

**写什么**：500–800 字收束全篇：行业所处发展阶段（导入/成长/成熟/分化）；市场空间与增速的一句话结论（带数）；竞争格局与进入壁垒的一句话结论；政策环境的一句话结论；主要风险的一句话提示；最后给出**审慎的行业层面结论**——"行业具备较好的投资研究价值，建议结合公司层面尽调进一步论证"或"行业空间与格局尚不足以支撑独立投资逻辑，需重点关注 XX"。

**为什么写**：投委们先读小结再决定是否细读全文。小结必须独立成立——只读这一节也能获得完整判断。

**注意事项**：
- 每句结论都是前文的浓缩，不得出现前文没有论证过的新判断、新数据；
- 禁用"强烈推荐""确定性极高""必然增长""绝佳赛道"；
- 行业结论与公司结论分离：本节只判断行业，"是否投这家公司"留给立项报告整体结论；
- 用条件式表达保留判断弹性："若低轨星座组网进度符合规划，则终端市场有望于 XX 年进入放量期；反之放量节奏可能推迟 1–2 年。"
