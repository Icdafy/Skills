# 质量自检清单与交付标准

交付前逐项自检。任何一项不通过，修订后再交付。自检时把自己切换为**投委会里最挑剔的那位委员**——他会复算你的数、检索你引的政策、追问每一个"广阔"和"领先"。

## 一、结构与逻辑（4 项）

**1. 行业边界是否清晰**
- [ ] 开篇明确了狭义/广义行业与本文口径
- [ ] 全文市场规模、竞争格局数据口径与该边界一致（最常见错误：边界定义在细分赛道，规模却引了大行业的数）
- [ ] 标的公司位置在边界内一句话可定位

**2. 章节结构是否完整**
- [ ] 必写模块齐全：定义边界、市场规模、竞争格局、风险分析、投资判断小结
- [ ] 被裁剪/合并的模块，其分析功能在其他章节有承接
- [ ] 标题编号体系统一（（一）→1.→（1）→1)），无跳级、无重号

**3. 逻辑顺序是否合理**
- [ ] 遵循"定义→背景→产业链→规模→供需→格局→政策/技术→模式→趋势→风险→小结"漏斗，或有合理变体
- [ ] 相邻标题无逻辑重复；每个判断出现在正确的模块
- [ ] 抽出全篇各段首句连读，能构成完整摘要（段落论点句检验法）

**4. 是否服务于后续投资判断**
- [ ] 每个大块末尾的"洞察/启示"落回标的公司位置
- [ ] 全篇能回答五问：行业多大 / 长多快 / 钱在哪个环节 / 格局对标的是否有利 / 最大风险是什么
- [ ] 投资判断小结可独立成立（只读小结即获完整判断），且无前文未论证的新判断

## 二、数据质量（3 项）

**5. 数据是否有来源**
- [ ] 每个规模、增速、份额、占比数字可回答"谁发布、什么口径、哪一年"
- [ ] 无匿名引用（"据公开数据""第三方机构预测"）——全部补明或降级为区间估算
- [ ] 章节末"数据来源说明"完整，表格来源注齐全

**6. 口径是否一致**
- [ ] 同一指标全文只用一个口径与数值（重点查：市场规模在不同章节复现时数字是否一致）
- [ ] 公司名、产品名、政策名全文统一（全文检索核对——参考范文曾在同一篇中出现标的公司三种写法）
- [ ] 历史数据与预测数据在正文与表格中均可区分（E 标注/预测方注明）

**7. 计算是否可复核**
- [ ] 每个自算数字有公式+假设+因子来源；CAGR 复算无误、起止年份写明
- [ ] 比率指标分子分母明确
- [ ] 表内数字与正文数字完全一致

## 三、表达与立场（3 项）

**8. 是否存在主观偏颇**
- [ ] 无为支持投资结论而选择性用数（不利数据也如实呈现）
- [ ] 风险章节未被弱化：4–7 条、三段式（事实→传导→程度）、按影响排序
- [ ] 标的描述克制（无裸用"行业领导者/绝对龙头"；判断强度与证据强度匹配）

**9. 是否存在空泛判断**
- [ ] 全文检索"前景广阔、潜力巨大、大有可为、蓝海、爆发式、必然、毫无疑问、确定性极高、强烈推荐"——出现即修
- [ ] 每条趋势有证据与先行指标；不确定事项均有审慎表达（预计/有望/仍需关注）

**10. 是否存在资料堆砌**
- [ ] 无功能不明的段落（每段可归入定义/背景/数据/机制/趋势/竞争/风险/小结之一）
- [ ] 政策部分先规律后表格，非罗列；指标与表格均服务于明确论证点，无凑数

## 四、风格与形式（2 项）

**11. 是否符合立项报告风格**
- [ ] 正式书面语，无口语、营销语、感叹号
- [ ] 核心章节用判断性标题，"核心观点/核心结论"引领到位
- [ ] 无"根据某某材料显示"式生硬引用，过渡采用"在……方面/从……端来看"
- [ ] 若输出 .docx：字体字号、表格样式、编号体系符合公文规范或用户模板

**12. 是否明确揭示风险与缺口**
- [ ] 行业风险提示完整且与正文一致
- [ ] "待进一步核实事项"清单完整列出：未能核实的数据、缺失的资料、依赖假设的测算
- [ ] 区间估算处均写明假设

## 交付物核对

最终交付的行业分析章节包含以下 8 件套：

1. 完整标题体系（编号规范）
2. 正式正文（含各大块"洞察/启示"）
3. 必要数据表格（按 04-tables-charts.md 规范）
4. 关键测算公式（正文或测算表内）
5. 数据来源说明（统一列示）
6. 行业风险提示
7. 行业投资判断小结
8. 待补充资料清单（待进一步核实事项）

自检发现的问题当场改，改完复检对应项。全部通过后交付，并在交付说明中用 2–3 句话向用户概括：本文行业边界取法、市场规模测算的核心假设、以及最需要用户补充核实的 1–3 项资料。
