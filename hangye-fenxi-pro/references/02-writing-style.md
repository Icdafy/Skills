# 写作风格规范

本文件规定行业分析的标题命名法、段落组织、句式与措辞纪律。这些规范抽象自成熟立项报告范文的写作方法，并修正了范文中的已知缺陷。

## 一、标题命名法

### 两类标题，两种用法

**结构性标题（名词短语）**：用于框架性章节，让读者快速定位内容。
- 例："市场规模与增长趋势""产业链概况""核心增长驱动力""政策驱动""市场驱动"
- 适用：一级标题、常规二级标题。

**判断性标题（完整判断句 / 主谓宾结构）**：标题本身就是本节结论，读者只看目录就能获得完整的分析链条。这是立项报告行业分析区别于普通行研的关键写法。
- 例："卫星通信终端是低空经济全域覆盖的核心基础设施"（定位判断）
- 例："低轨卫星：低时延与小型化优势拓展低空应用增量场景"（"主体：优势+动作+对象"冒号式）
- 例："低轨星座规模化组网释放终端市场成长空间"（因果链压缩进标题）
- 适用：承载核心论点的二、三级标题。

**对仗式概括标题**：并列论点用等长短语排列，制造记忆点。
- 例：政策演进三特征——"战略定位跃升 / 治理逻辑转变 / 政策工具精准"
- 例：产业特征——"高成熟度、高集中度、高上市率"的三高特征
- 适用：（1）（2）（3）级并列论点。构造方法：先写完各论点内容，再回头提炼 4–8 字等长短语。

### 使用配比

一篇行业分析中，判断性标题应覆盖核心论证章节（发展现状、产业链洞察、竞争格局判断），结构性标题覆盖其余。全篇全用名词短语则平淡无观点，全用判断句则显武断——核心章节判断句、框架章节名词短语，是正确配比。

## 二、段落组织

### "核心观点"引领法

每个承载论证的小节（二级标题下），首行以加粗引导语开门见山：

> **核心观点：** 在低空经济从"试点飞行"迈向"常态运营"的关键阶段，卫星通信正成为低空飞行器实现全域通信的必选方案之一。

或

> **核心结论：** XX 所处产业链为"上游 A—中游 B—下游 C"。当前产业核心瓶颈集中在……，中游竞争力取决于……

写法：一句话（最多两句）压缩本节全部论证。写完正文后回头核对：核心观点里的每个判断，正文是否都给了证据。

### 段落首句 = 论点句

每段第一句是该段唯一的论点，可加粗；其余句子全部是证据（数据、政策、案例、机制解释）。示例结构：

> **轨道特性奠定高轨卫星的广域覆盖基础。**（论点）高轨卫星轨道高度约 35,786 公里，单星覆盖范围可达地球表面三分之一以上，仅需 3 至 4 颗卫星即可实现除两极外的全球连续覆盖。（参数证据）其相对地面静止的轨道特性，使地面终端无需配置复杂跟踪伺服系统即可持续在线，（机制）在应急通信、海事航运等场景中具备不可替代的稳定性。（场景落点）

检验方法：把全篇每段首句抽出来连读，应当构成一篇逻辑完整的摘要。做不到就说明有段落没有论点、在堆信息。

### 段落功能类型

每段必须明确承担且仅承担以下功能之一：定义、背景交代、数据说明、原因/机制分析、趋势判断、竞争分析、风险提示、投资意义总结。一段混装多个功能的，拆段。

### "一是/二是/三是"段内列举

并列证据或痛点用段内序数词排列，每条内部"论点短句 + 展开"：

> 一是破解传统人工巡检效率低下的痛点，替代人工逐点排查……；二是解决巡检安全风险高的痛点，可替代人工进入高空、高温等高危场景……

3 条以内用"一是/二是"，超过 3 条且每条超 150 字才升级为 1) 2) 3) 标题。

### "洞察/启示"收尾法

每个大块（行业发展现状、产业链分析、竞争格局）末尾设"相关洞察 / 演进的启示"小节，2–3 条，每条结构：

```
第X，[行业规律判断句]。
  → 展开：规律的证据与机制（价值向哪迁移、什么决定成败）
  → 推导：什么样的企业会在这个规律下胜出
  → 落点：标的公司相对于这个规律的位置（有利/不利/待验证）
```

示例骨架："第一，产业链重心从'制造环节'向'应用服务环节'延伸。……未来的竞争关键在于能否提供深度融合业务逻辑的'专用装备+专业软件+常态化运营'一体化服务。因此，一批深谙特定行业、能提供深度垂直解决方案的服务商会更容易成为产业发展的关键力量。〔而标的公司正是/尚不是这类企业，理由是……〕"

**洞察小节是行业分析与投资判断之间的桥，是全篇最见功力的部分，不可省略。**

## 三、句式库

### 推荐的过渡表达（替代生硬引用）

正文禁止反复出现"根据某某材料显示""从某某资料看""某某文件提出"。改用维度引导式：

- "在政策支持方面，……" / "从政策导向来看，……"
- "在市场需求方面，……" / "从需求端来看，……"
- "在产业链结构方面，……" / "按照产业分工，可细分为……"
- "在竞争格局方面，……" / "当前国内市场呈现……的分层竞争格局"
- "在技术演进方面，……" / "从技术路线看，……"
- "在市场空间测算方面，……" / "据此测算，……"
- 数据引出："数据表明，……" "实测数据显示，……" "据 XX 招股书数据，……"（招股书、年报等高可信来源可以且应当在正文点名，这是加分项；泛泛的"根据公开数据"是减分项）

### 审慎表达（不确定事项必用）

"预计""有望""可能""或将""仍需关注""存在一定不确定性""尚待验证""仍需在尽调中核实""若……则……；反之……"

### 程度控制词

- 强判断（有硬数据支撑时）："已成为""确立了""显著""实质性"
- 中判断："正成为""逐步形成""趋于""明显"
- 弱判断："初步显现""存在……的可能""尚处于早期"

数据强度与判断强度匹配：只有一家研究机构的预测数据，配不起"已确立"这种强判断。

### 定性判词模板（竞争格局/市场成熟度）

给每个细分市场贴定性标签，是高效的格局概括法：
"高壁垒、低波动的成熟市场" / "高增长、高分化的黄金赛道" / "高潜力、高不确定性的培育期市场" / "高渗透率、低增速的存量市场" / "客户集中、服务商分层的稳定格局" / "上市公司红利收割期" / "跑马圈地阶段"

### 禁止表达

| 类型 | 禁止 | 替代 |
|---|---|---|
| 绝对化 | 必然、一定、毫无疑问、确定性极强、稳赚 | 预计、有望、大概率（需说明依据） |
| 空泛 | 前景广阔、潜力巨大、赛道火热、大有可为、蓝海市场（无数据裸用时） | 具体数字 + 增速 + 驱动因素 |
| 营销化 | 行业领导者、绝对龙头（无市占率数据）、革命性、颠覆性、爆发式增长 | 细分领域头部企业之一、增速显著高于行业均值（带数） |
| 倾向性 | 强烈推荐、绝佳标的、不容错过 | 具备较好的投资研究价值，建议进一步论证 |
| 生硬引用 | 根据材料显示、据了解、众所周知 | 见上文推荐过渡表达 |
| 口语 | 说白了、其实、非常非常、特别好 | 删除或改书面语 |

"我们认为"可少量使用（每篇不超过 2–3 处），且其后判断必须紧跟论据。

## 四、数据引用与来源标注

- 正文数字自然嵌入句子，来源在**章节末"数据来源说明"统一列出**（编号对应），或采用脚注；不打断正文流畅度；
- 高可信来源（招股书、年报、政府文件、统计局）**应当**在正文点名以增强说服力："据国博电子招股书数据，……""工信部等五部门联合印发《……》（工信厅联通信〔2026〕4 号）明文要求……"——政策引用带文号是专业性标志；
- 第三方预测必须点名机构与发布时间，禁止"据第三方机构预测""行业研究机构测算"这类匿名引用（这是范文中存在的缺陷，必须修正）；
- 表格下方注明"数据来源：……"，多来源时逐条对应。

## 五、一致性纪律（范文缺陷修正清单）

以下是参考范文中实际出现过的问题，写作与自检时逐项规避：

1. **公司名前后不一致**（同一文中出现三种写法）：动笔前锁定标的公司标准全称与简称，全文统一，最后全文检索核对；
2. **同一事实两种口径重复出现**（如轨道高度先写"3.6 万公里"后写"35,786 公里"）：同一参数全文只用一个口径，首次出现时定稿；
3. **匿名数据源**（"根据公开数据""据第三方机构预测"）：一律补明机构名与时间，补不出的降级为区间估算并列入待核实清单；
4. **远期预测跨度过大且无依据**（如"有望突破千亿甚至 1500–2000 亿元"）：改为"机构 A 预测 X 亿元，机构 B 预测 Y 亿元，差异主要源于口径……"或给出区间+关键假设；
5. **图表以截图嵌入、无数据表**：所有图建议均附可编辑数据表，图注标来源；
6. **政策表只写政策不写影响**：每行"影响"栏必须落到行业和标的公司层面；
7. **缺少风险章节与投资判断小结**：本 Skill 框架已强制补全，不得省略。

## 六、语言基调

正式、专业、克制、书面化。多用四字格与并列结构增强公文节奏感（"频谱资源管控、行业准入规则、终端产品规范、商业化应用等维度"），但不堆砌辞藻。句子信息密度高——每句话要么给事实、要么给判断、要么给机制，没有装饰句。全文以第三人称客观陈述，不出现"您""大家"，不用感叹号。
