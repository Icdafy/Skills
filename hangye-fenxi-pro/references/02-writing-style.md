# 写作风格规范

本文件规定“二、所属行业分析”的语言、标题、段落和加粗规则。核心目标是复现成熟立项报告范文的写法：**判断在前，证据在后；先归纳规律，再落行业和标的卡位。**

## 零、公文版式与字体规范

两篇范文的 Word 版式具有一致的公文底色。生成 `.docx` 时按以下基准执行；仅输出 Markdown 时，也要保持同样的标题层级和加粗逻辑。

### 页面与段落

- 页面：A4 纵向；
- 页边距：上、下约 1 英寸；左、右约 1.25 英寸；
- 行距：固定 28 磅；
- 字号：正文和各级标题均以 16pt 为基准；
- 缩进：段落首行缩进约 2 个中文字符；标题也可保持同样缩进，避免居中宣传化；
- 段前段后：不额外堆叠大间距，依靠标题层级和加粗形成阅读层次。

### 字体层级

| 层级/对象 | 中文字体 | 西文字体 | 字号 | 加粗 |
|---|---|---|---|---|
| `二、所属行业分析` | 黑体 | Times New Roman | 16pt | 可不加粗 |
| `（一）（二）`二级标题 | 楷体_GB2312 | Times New Roman | 16pt | 加粗 |
| `1.`三级标题 | 仿宋_GB2312 | Times New Roman | 16pt | 加粗 |
| `（1）`四级标题 | 仿宋_GB2312 | Times New Roman | 16pt | 加粗 |
| 正文 | 仿宋_GB2312 | Times New Roman | 16pt | 默认不加粗 |
| 核心结论/段首论点句 | 仿宋_GB2312 | Times New Roman | 16pt | 加粗 |
| 表格表头 | 仿宋_GB2312或宋体 | Times New Roman | 16pt或随正文 | 加粗 |
| 表格正文 | 仿宋_GB2312或宋体 | Times New Roman | 16pt或随正文 | 默认不加粗 |

不要使用彩色标题、营销式大标题、装饰性边框或过度视觉化排版。该章节应像正式立项报告正文，而不是路演材料或公众号文章。

## 一、标题规则

### 固定结构标题

以下标题必须保持名词短语，不改成判断句：

- `二、所属行业分析`
- `（一）行业发展现状`
- `1.市场规模与增长趋势`
- `2.核心增长驱动力`
- `（二）产业链分析`
- `1.产业链概况`
- `2.产业链洞察与启示`

三级标题下的分项可以使用结构性标题：

- `（1）政策驱动`
- `（2）市场驱动`
- `（3）技术驱动/成本驱动/供给驱动`
- `（1）产业链上游`
- `（2）产业链中游`
- `（3）产业链下游`

标题要短，不能写成口号。真正的判断放在标题后的加粗核心结论里。生成 `.docx` 时不要使用 Word 内置大号 Heading 样式改变字号；应保持范文式 16pt 公文标题体系。

### 两种范文标题路径

若标的所在行业市场口径清晰，采用 `1.市场规模与增长趋势` + `2.核心增长驱动力`。若标的是关键终端、核心零部件、系统模块或基础设施配套，可把第一节写成判断型三级标题，例如 `1.XX 是 XX 场景规模化发展的核心基础设施`，再写 `2.市场规模与增长趋势`。

判断型三级标题只能用于路径 B，必须克制、具体、可证明。不要写“XX 迎来历史机遇”“XX 打开万亿空间”等宣传式标题。

### 判断性小句

段首和启示句要使用判断性表达，让读者先看到结论：

- “工业级无人机已成为民用无人机增长的核心引擎。”
- “政策驱动的核心不在补贴，而在空域、标准和监管框架从试点走向常态化。”
- “上游核心零部件决定产品性能和成本曲线，中游企业的壁垒则体现为系统集成与场景适配能力。”

判断句必须可被后文证据支撑。写不出证据的判断，降级或删除。

## 二、核心结论前置

每个细分部分都要以加粗核心结论开头。核心结论不是摘要，而是本节的投资判断。

### 标准格式

```markdown
**核心结论：……。**
```

适用于：

- `1.市场规模与增长趋势`
- `2.核心增长驱动力`
- `（1）政策驱动`
- `（2）市场驱动`
- 其他按需驱动
- `1.产业链概况`
- `（1）产业链上游`
- `（2）产业链中游`
- `（3）产业链下游`

产业链洞察与启示使用：

```markdown
**第一，……。**
正文展开……

**第二，……。**
正文展开……
```

### 检验方法

把全文所有加粗句单独抽出来连读，应当形成完整摘要：

1. 行业处于什么阶段；
2. 市场规模和增速如何；
3. 增长由什么驱动；
4. 产业链如何分工；
5. 标的处于哪一环；
6. 产业链演进对标的意味着什么。

如果加粗句连读后仍看不出逻辑，说明核心结论没有写到位。

## 三、段落组织

### 段首论点句

每段第一句承担唯一论点，其余句子提供证据、机制、案例或数据。推荐结构：

```markdown
**政策层级提升使行业从地方试点进入国家统筹推进阶段。** 近年来，低空经济连续写入国家级政策文件，并在标准体系、统计分类、基础设施建设等方面形成配套安排。上述变化意味着行业发展不再只依赖地方示范，而开始具备跨区域复制和规模化运营的制度基础。
```

不要一段内同时写政策、市场、技术、风险多个功能。功能混杂时拆段。

### “一是/二是/三是”

政策驱动、市场驱动和痛点分析优先使用“一是/二是/三是”。每一点遵循：

```markdown
一是[短判断]，[展开机制、证据和影响]；
二是[短判断]，[展开机制、证据和影响]；
三是[短判断]，[展开机制、证据和影响]。
```

短判断可以加粗，但不要把整段加粗。超过三点时，优先合并同类项，而不是继续堆到“五是/六是”。

### 先抑后扬

涉及政策、技术路线、市场成熟度时，成熟写法通常先写局限，再写拐点：

- 先写早期政策偏框架性、约束力不足，再写新政策如何落到标准、空域、准入；
- 先写传统方案成本低、存量大，再写新方案如何凭借低时延、轻量化、智能化打开增量；
- 先写试点阶段商业闭环不足，再写客户预算和常态化运营如何改善。

这种写法比单向唱多更可信。

### 解释链

范文段落的关键不是“列事实”，而是解释事实为什么能支撑判断。常用三条解释链：

| 场景 | 标准链条 |
|---|---|
| 政策 | 过去政策局限 -> 新政策/新标准新增约束或工具 -> 改变准入、空域、预算、认证或基础设施 -> 拉动标的所在环节 |
| 市场 | 原有作业痛点 -> 新方案解决效率、安全、成本、覆盖或数据价值问题 -> 客户进入试点/常态采购 -> 需求可持续 |
| 技术 | 旧技术优势与局限 -> 新技术解决的关键问题 -> 成本/性能/可靠性取舍 -> 对放量节奏和产业链价值的影响 |

每段至少完成一条解释链。只写“政策持续加码”“需求快速释放”“技术不断进步”但不解释作用机制，视为未完成。

## 四、市场规模写法

市场规模段不要只给一个大数。必须形成“总量—结构—趋势—含义”的链条：

1. 总量：行业整体规模和 CAGR；
2. 结构：标的所在细分市场占比和增速；
3. 趋势：未来增长来自渗透率、客户数、装机量、价格、服务化还是政策放开；
4. 含义：该趋势是否提高标的所在环节的市场空间。

推荐句式：

- “数据表明，2020-2025 年我国 XX 市场规模由 X 亿元增长至 Y 亿元，复合增长率为 Z%。”
- “从结构看，A 细分市场增速显著高于行业整体，主要原因在于……”
- “这意味着行业增长并非均匀扩张，而是向……环节集中。”
- “若进一步聚焦标的所在环节，广义市场并不直接等同于其可及空间，真正影响放量的是……”

禁止句式：

- “市场空间巨大，未来前景广阔。”
- “根据公开数据，行业规模快速增长。”
- “根据公司整理，该市场规模约为……”

## 五、核心增长驱动力写法

### 政策驱动

政策驱动要写政策演进和作用机制。推荐三段式：

1. 政策层级：国家战略、法律法规、部委文件、地方试点；
2. 治理逻辑：从管控到促进、从试点到常态、从鼓励到标准化；
3. 具体影响：空域、准入、标准、采购、基础设施、客户预算。

推荐句式：

- “从政策导向看，行业支持政策正由方向性鼓励转向标准、准入和基础设施的系统性落地。”
- “该变化的核心影响不在短期补贴，而在于为规模化应用提供制度边界和合规路径。”

### 市场驱动

市场驱动要写真实需求和付费逻辑。推荐拆成：

1. 存量替代：替代人工、低效流程、旧技术或传统设备；
2. 增量创造：创造新功能、新场景或新服务形态；
3. 客户预算：是否有稳定预算、复购、常态化运营需求。

推荐句式：

- “从需求端看，行业增长的底层逻辑是下游客户对效率、安全和成本的系统性再平衡。”
- “在存量替代场景中，XX 方案通过……降低了……；在增量场景中，XX 进一步打开了……”
- “上述变化表明，需求并非停留在概念验证，而是开始进入……场景的常态化采购/规模化交付。”

### 其他驱动

技术、成本、供给、国产替代等驱动只在确有证据时写。不要为了凑结构写空泛的“技术进步推动行业发展”。

## 六、产业链写法

产业链段落必须解释“是什么、干什么、为什么重要”。不要写成企业名单。

### 上游

写核心资源、材料、芯片、传感器、算法模块、基础软件、检测认证等。每个类别说明功能：

- “动力电池决定续航、载荷和安全冗余。”
- “惯性导航单元负责姿态感知和定位补偿，是复杂环境下稳定运行的基础。”
- “射频前端负责信号收发和放大，直接影响链路稳定性和终端功耗。”

技术路线对比要写清“各自适配场景”，不要简单写新路线替代旧路线。若旧路线仍具备成本、稳定性或存量生态优势，应写成“双轨并行、结构替代、增量渗透”。

### 中游

写整机制造、系统集成、平台产品、解决方案、工程交付。重点解释中游如何把上游能力变成可交付结果：

- “系统集成能力体现在软硬件适配、可靠性验证、环境适应性和工程交付。”
- “场景定制化能力决定产品能否从样机走向客户常态化使用。”

### 下游

写终端客户、应用场景、运营服务和数据价值。重点解释需求兑现：

- “下游客户的预算制度、采购周期和场景成熟度决定行业放量节奏。”
- “运营服务将一次性设备销售延伸为持续运维、数据处理和业务闭环。”

## 七、洞察与启示写法

每条启示遵循“规律—机制—企业类型—标的落点”：

```markdown
**第一，产业链价值重心正从单一制造环节向场景化解决方案和运营服务延伸。**
随着上游核心零部件逐步成熟，单纯硬件制造的差异化空间收窄，客户更关注产品能否嵌入业务流程并形成持续运营闭环。因此，具备行业 Know-how、客户资源和运维能力的企业更容易在产业链中获得更高议价权。若标的公司已在 XX 场景形成稳定交付经验，则其卡位更接近本轮价值迁移方向；反之仍需验证其服务化能力。
```

洞察不能只是“上游很重要、中游竞争激烈、下游需求增长”。必须给出产业链演进方向和投资含义。

## 八、来源与表达纪律

### 推荐表达

- “数据表明，……”
- “从政策导向看，……”
- “从需求端看，……”
- “按照产业分工，……”
- “这意味着，……”
- “对标的公司而言，……”
- “整体来看，……”
- “进一步看，……”
- “上述变化表明，……”

### 可用但需克制

- “预计”“有望”“可能”“仍需关注”“尚待验证”
- “正成为”“逐步形成”“趋于”“明显”
- “已成为”“确立了”“显著”“实质性”（仅在证据强时使用）
- “我们认为”（原则上不用；如必须使用，每篇不超过 1 处，且后文必须紧跟证据）

### 禁止表达

| 类型 | 禁止 | 替代 |
|---|---|---|
| 公司资料免责声明 | 根据公司整理、该数为公司自述、仅作为方向参考 | 用权威来源；无法验证则放待核实 |
| 空泛乐观 | 前景广阔、潜力巨大、大有可为、蓝海市场 | 具体规模、增速、驱动因素 |
| 绝对化 | 必然、一定、毫无疑问、确定性极强 | 预计、有望、在……条件下 |
| 营销化 | 行业领导者、绝对龙头、革命性、颠覆性 | 细分领域头部企业之一、具备差异化优势 |
| 生硬引用 | 根据材料显示、据了解、众所周知 | 从……方面看、数据表明、政策导向显示 |
| 第一人称 | 我们认为、我们判断、笔者认为 | 从……看、整体来看、可以判断 |
| 口语化 | 说白了、其实、很明显、特别好 | 删除或改为书面表达 |

## 九、加粗规则

加粗只用于论点，不用于证据。

必须加粗：

- 每个细分部分的核心结论；
- 段首论点句（可选，但推荐）；
- “一是/二是/三是”的短判断；
- 产业链洞察与启示的总结句。

不要加粗：

- 数据来源、表格正文、企业名单；
- 长段证据；
- 无实质判断的形容词。

最终检验：加粗内容连读 = 论点摘要；未加粗内容 = 证据、机制和解释。
