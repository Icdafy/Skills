# 范文学习要点

本文件沉淀两篇“所属行业分析”范文（因诺科技、伊隆纬特）的可复用写作逻辑。使用本技能撰写或优化正文前，若用户要求贴近范文、提升行业分析质量，先读本文件，再回到 `01-framework.md`、`02-writing-style.md` 和 `04-tables-charts.md` 执行。文中“公司简称”指拟投资公司的简称。

学习范文时注意两点例外：范文原文偶见“核心观点：”“核心结论：”标签，成稿不沿用，核心结论直接加粗；范文个别句子使用“并非……而是”等成对连词，成稿一律改为正面直陈。

## 一、范文的底层写作逻辑

两篇范文都是立项报告中的投委会论证章节，与完整行业研究报告是两种文体。写作目标是回答四个可追问的问题，而“证明行业好”只是表象：

| 投委会问题 | 正文对应写法 |
|---|---|
| 行业是否已经进入可投资阶段 | 用市场规模、政策拐点、应用阶段证明行业从试点/培育走向规模化 |
| 增长为什么真实 | 用政策机制、客户痛点、技术/成本变化解释需求如何产生 |
| 价值和壁垒在哪个环节 | 用产业链上中下游拆解功能、成本、认证、客户和运营能力 |
| 公司卡位是否顺势 | 在产业链洞察中把行业规律落回公司所处环节 |

范文的共同结构是“先判断、再解释、再收束”。每个小节先给结论句，随后用政策、数据、技术参数、客户场景或产业链事实解释为什么可以得出该结论，最后用一句话落到行业阶段、细分机会或公司卡位。

## 二、范文对公司资料的使用方式

两篇范文的行业分析正文没有出现“根据资料包”“据会议纪要”“据 BP”等表述。范文从公司资料中只提取了三件事：公司叫什么（因诺科技、伊隆纬特）、做什么业务（工业无人机巡检、卫星通信终端）、卖给谁（能源央企、无人装备厂商）。其余全部内容——市场规模、政策演进、产业链结构、竞争格局、技术路线——都以公开行业事实和产业逻辑独立组织。

这样处理的原因：对方资料站在其自身优势角度组织叙事，直接沿用会把公司逻辑写成行业结论。撰写时以全球顶级一级股权投资机构的立场独立研究，公司资料只回答“它是谁、在哪一环”，行业怎么样由自己判断。

## 三、两种合格的行业现状路径

### 路径 A：市场规模先行型（因诺科技范文）

适用于公司处在较成熟、市场数据较充分的行业，如工业无人机、机器人、检测服务、能源运维等。

推荐顺序：

```markdown
（一）行业发展现状

1.市场规模与增长趋势

2.核心增长驱动力
```

写法要点：

- 先用市场规模图表或数据段证明行业增长，再解释增长来自哪个细分市场；
- “核心增长驱动力”要先排序：政策解决准入和规范，市场解决付费和规模化，技术/成本决定放量节奏；
- 政策驱动拒绝罗列文件，要提炼“战略定位提升、治理逻辑变化、工具细化落地”；
- 市场驱动要拆成“存量替代”和“增量创造”，并写清客户痛点、付费动机和商业化阶段。

### 路径 B：关键配套/基础设施先行型（伊隆纬特范文）

适用于公司主营更窄的技术环节、关键终端、核心零部件或基础设施配套，广义市场规模不能直接解释公司需求，如卫星通信终端、传感器、功率器件、工业软件模块、检测认证等。

推荐顺序：

```markdown
（一）行业发展现状

1.XX 是 XX 场景规模化发展的核心基础设施/关键配套

2.市场规模与增长趋势
```

写法要点：

- 第一节先回答“为什么这个细分环节是刚需”，不要急于堆总市场数据；
- 按“政策要求/制度拐点”与“需求短板/技术替代”展开，证明该环节是必选项；
- 技术路线要写“旧方案的优势和局限 -> 新方案解决什么问题 -> 双轨或替代关系如何演进”；
- 第二节再写市场规模，重点说明广义市场、相关终端市场和公司可及市场之间的关系。

## 四、政策解释链

范文中的政策段落是“政策层级 -> 过去局限 -> 新拐点 -> 需求影响”的解释链，政策表的文字版不合格。

合格写法：

```text
从政策导向看，行业支持政策正由方向性鼓励转向标准、准入和基础设施的系统性落地。早期政策更多提供产业培育框架，对具体场景的约束和拉动有限；近期政策在空域、准入、标准、统计口径、基础设施或采购机制上给出更明确安排，直接改变行业规模化运营的制度条件。
```

写政策时必须回答：

- 该政策是国家战略、法律法规、部委文件还是地方试点；
- 它与过去相比新增了什么约束、工具或标准；
- 它影响的是准入、空域、采购、预算、认证、基础设施还是统计口径；
- 它对公司所在细分环节形成直接拉动、间接支撑，还是仅构成长期方向。

## 五、市场需求解释链

范文中的需求段落都把“客户为什么买”写出来，只写“需求旺盛”不合格。

标准解释链：

```text
客户原有方式存在效率、安全、成本、覆盖范围或数据价值问题 -> 新方案解决其中一个或多个痛点 -> 技术和商业闭环经过验证 -> 从试点走向常态采购/规模交付。
```

常见拆法：

- 存量替代：替代人工、旧设备、低效流程或离线作业；
- 增量创造：创造过去做不到的新功能、新场景或新服务；
- 预算闭环：客户是否有稳定预算、是否进入招投标/集采/常态运营；
- 场景阶段：已规模化、快速拓展、试点验证、远期培育要分开写。

## 六、产业链写法：从公司业务倒推全景

两篇范文的产业链分析都遵循同一条路径，本技能固化为五步法：

1. **识别公司**：因诺科技做工业无人机巡检，伊隆纬特做卫星通信终端；
2. **判断行业与环节**：因诺科技属低空无人机行业，处中游整机与下游解决方案；伊隆纬特属卫通终端行业，处中游系统集成；
3. **还原产业链全景并拆分细分赛道**：独立梳理该行业上、中、下游，每个环节拆成 3-5 个细分赛道并写明各是什么。两篇范文的拆法印证了三条惯例——上游按部件/材料/要素类别或功能模块拆，中游按产品形态/市场类型或能力要素拆，下游按应用场景/客户类型/载体拆：

   | 环节 | 因诺科技范文（无人机） | 伊隆纬特范文（卫通终端） |
   |---|---|---|
   | 上游 | 原材料、感知与导航系统、飞行控制系统、动力系统、其他零部件（5 类，按部件类别） | 射频前端器件、天线系统、基带与控制、结构与电源、测试认证与制造配套（5 大板块，按功能模块） |
   | 中游 | 军用、消费级、工业级、新兴载人/物流（4 个赛道，按产品形态/市场类型） | 系统集成能力、运动控制与算法、场景适配与定制化（按能力要素），再写军工院所与民企的分层格局 |
   | 下游 | 工业应用、农业、消费、新兴场景、运营服务（5 类，按应用场景） | 无人机、无人艇/船载、无人特种车辆/机器人、eVTOL（4 类，按载体） |

   两篇范文中多数赛道与公司自身业务无直接关系（如军用、消费级无人机），但全景必须完整，卡位判断才有参照；
4. **逐赛道写透**：每个细分赛道写名称、核心构成、功能、格局定性（垄断/寡头/分散/培育）、代表企业和价值/壁垒信号。因诺范文给每个赛道配了简介、头部企业和格局点评（“国家队垄断”“双寡头”“高增长、高分化的黄金赛道”）；伊隆纬特范文在价值集中的板块再向下拆一层——天线系统拆到 T/R 组件、再拆到 T/R 芯片，用“T/R 组件占相控阵天线成本 50%-60%、T/R 芯片占组件成本 60%-80%”的成本占比说明钱集中在哪里；
5. **落位**：把公司简称写进它所属的细分赛道，与同赛道企业并列。因诺科技出现在中游“工业级无人机”赛道行内，与纵横股份、科比特并列，并在下游“油气管道巡检”场景中标注为核心服务商——定位由全景衬托出来，两篇范文都没有孤立地宣布“公司处于中游”。

技术段落的合格标准：

| 要素 | 要回答的问题 |
|---|---|
| 技术/部件是什么 | 它在产品或系统里承担什么功能 |
| 为什么重要 | 它决定成本、性能、可靠性、轻量化、时延、精度、认证或交付中的哪一项 |
| 当前阶段 | 已成熟、降本中、国产替代中、试验验证中，还是仍受制约 |
| 产业含义 | 它如何影响中游放量、毛利空间、客户采用或竞争壁垒 |

写上游时重点找成本占比、国产化率、认证周期、技术瓶颈；写中游时重点写系统集成、工程化、场景适配和交付；写下游时重点写客户预算、应用成熟度、运营服务和数据闭环。

## 七、图表的证据岗位

范文图表每张都承担一个明确论证岗位，装饰性图表不放：

| 图表类型 | 论证岗位 | 正文应该如何承接 |
|---|---|---|
| 市场规模柱状图 | 证明行业总量增长和细分跑赢 | 图前给增长结论，图后解释增长来自哪个细分/阶段 |
| 行业阶段时间轴 | 解释行业从早期探索到规模化的拐点 | 用它承接政策和市场阶段变化 |
| 政策表 | 支撑政策从战略定位到工具落地 | 正文先归纳三类政策演进，表格放明细 |
| 产业链全景图 | 定位上中下游和公司所处环节 | 正文必须解释各环节功能和价值，不让图替代分析 |
| 技术路线对比图 | 说明新旧方案各自适配场景 | 正文写优势、局限和演进关系 |

若无法生成图片，至少输出可编辑表格和“建议图表”说明；正文仍必须先完成判断和解释。

## 八、产业链洞察的收束方法

范文最后的“相关洞察/产业链演进启示”把产业链事实转成投资含义，仅复述前文不合格。

每条洞察按以下结构写：

```text
第一，产业链规律判断。前文事实如何支撑该判断；该规律意味着哪类企业更容易获得价值、壁垒或放量机会；对公司简称而言，其现有卡位顺应该规律、受制于该规律，还是仍待验证。
```

常见高质量洞察：

- 价值重心从硬件制造向“产品+场景+运营”迁移；
- 上游核心零部件降本决定中游放量速度；
- 标准化与定制化的矛盾决定企业能否复制交付；
- 下游客户集中带来订单确定性，也带来议价和回款压力；
- 下游客户分散时，中游平台/渠道整合能力成为壁垒；
- 新技术路线短期与旧路线并行，不能直接写成全面替代。

## 九、来源依据选择

优先级遵循 `03-data-rules.md`，但范文特别强调以下来源岗位：

- 政策结论：政府工作报告、法律法规、部委文件、地方实施方案、标准体系文件；
- 市场规模：行业研究机构、券商研报、行业协会、统计分类、上市公司年报或招股书交叉验证；
- 技术/成本：招股书成本拆解、上市公司公告、行业标准、核心供应商资料、权威研究报告；
- 竞争格局：上市公司公开资料、招股书、年报、行业协会、公开招投标和认证信息；
- 公司卡位：公司资料只用于确认产品、客户、收入来源和交付能力，行业结论另行落证。

## 十、范文式自检

成稿后问自己：

- 删除表格和图片后，正文是否仍有完整判断；
- 只读加粗句，是否能看懂行业阶段、增长原因、产业链价值和公司卡位；
- 每个数据是否知道来源、年份和口径；
- 每个政策是否写出了“改变了什么”，而非只写“支持”；
- 每个痛点是否对应客户、场景和付费逻辑；
- 每条产业链洞察是否能追溯到前文事实，并落回公司；
- 全文是否无“核心结论：”标签、无“标的公司”、无“不是……而是”类连词、无内部资料来源表述；
- 所有标题是否与正文平齐缩进两字。
