# 立项报告行业分析

`hangye-fenxi-pro` 用于撰写一级市场股权投资立项报告中的“二、所属行业分析”章节。技能名称保留英文，方便稳定调用；界面展示名通过 `agents/openai.yaml` 设置为中文。

## 适用场景

- 撰写拟投资企业所属行业分析；
- 梳理行业发展现状；
- 分析市场规模与增长趋势；
- 拆解政策驱动、市场驱动及其他核心增长动力；
- 分析产业链上游、中游、下游结构；
- 提炼产业链洞察与公司卡位启示。

## 默认输出结构

```markdown
二、所属行业分析

（一）行业发展现状

1.市场规模与增长趋势

2.核心增长驱动力

（二）产业链分析

1.产业链概况

2.产业链洞察与启示
```

默认不输出“行业定义与研究边界”，也不扩展为完整行业研究报告。

对于主营关键终端、核心零部件、系统模块或基础设施配套的公司，可采用范文中的“关键配套/基础设施先行型”结构：先写 `1.XX 是 XX 场景规模化发展的核心基础设施/关键配套`，再写 `2.市场规模与增长趋势`。

## 写作要求

- 每个细分部分开头直接写加粗核心结论判断句，不加“核心结论：”“核心观点：”标签，再展开数据、政策、机制和案例；
- 全文禁用“不是……而是”“并非……而是”“不仅……而且”等成对转折/递进连词，判断句正面直陈；
- 提及拟投资公司一律使用公司简称（如“因诺科技”“伊隆纬特”），禁止“标的公司”“标的”等词；
- 资料包、BP、会议纪要只用于识别公司叫什么、做什么、卖给谁，正文不得出现“根据资料包”“据会议纪要”等来源表述，行业事实以权威公开来源独立成文；
- 政策驱动必须写政策层级、治理逻辑、工具落地和对行业的具体作用；
- 市场驱动必须写真实客户痛点、付费逻辑、存量替代和增量创造；
- 产业链写作回答投委会五问：价值在哪个环节沉淀、议价权在谁手里、各环节壁垒正在加固还是瓦解、产业链往哪个方向演进、公司卡位能否捕获价值；
- 产业链遵循五步法：从公司业务倒推行业与环节，独立还原上中下游全景并按行业真实分工拆出细分赛道（数量不预设，由分工和价值分布决定；上游按部件类别、中游按产品形态或能力要素、下游按应用场景/载体），逐赛道写构成、功能、格局与代表企业，公司落位到所属赛道并与同赛道企业并列，最后提炼演进规律；
- 产业链洞察与启示必须落回公司产业链位置；
- 图表必须承担明确证据岗位，例如规模证明、阶段解释、政策佐证、技术路线对比或产业链定位；
- 关键技术路线必须解释旧方案局限、新方案作用、适配场景和放量节奏；
- 文风采用正式书面公文口吻，原则上不用“我们认为”“笔者认为”。

## DOCX 版式基准

两篇范文的版式规律已固化进技能：

- 页面：A4 纵向；
- 页边距：上下约 1 英寸，左右约 1.25 英寸；
- 行距：固定 28 磅；
- 字号：正文和标题基准 16pt；
- 缩进：正文与全部层级标题（含“二、”“（一）”“1.”“（1）”）首行缩进 2 个中文字符，标题与段落平齐，不顶格、不居中；
- 字体：一级章标题黑体，二级标题楷体_GB2312，正文及三级以下标题仿宋_GB2312；
- 加粗：标题、核心结论、段首论点句和启示总结句加粗；证据句和表格正文默认不加粗。

## 调用示例

```text
Use $hangye-fenxi-pro 为某公司撰写立项报告中的“二、所属行业分析”，公司属于工业无人机巡检赛道，主要处于产业链中下游。
```
