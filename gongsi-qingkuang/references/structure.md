# 公司情况骨架：每一层标题写什么、为什么、配什么

本文件是起草前必读的"施工图"。它把"四、公司情况"拆到每一个标题层级，说明该层写什么内容、背后的投资判断逻辑、配什么表。逐层照施工图走，再按 `writing-craft.md` 把句子写好、按 `data-and-tables.md` 把数算对。

---

## 第 0 节　动笔前：建"公司事实台账"

公司情况的可信度来自每个名称、日期、金额、比例都能溯源。起草前先把资料包、会议纪要（必要时联网补充）里的公司证据抽进下面的台账，再开始写。台账只为自己用，不进正文，但正文每句话都要能在台账里找到出处。

| 台账模块 | 要登记的字段 | 来源标注 |
|---|---|---|
| 主体信息 | 企业名称、统一社会信用代码、法定代表人、注册资本、实缴资本、成立日期、企业类型、登记状态、注册地址、办公地址、国标行业、营业期限、参保人数、经营范围 | 营业执照 / 工商公示 / 企查查天眼查 |
| 历史沿革 | 设立背景、更名、迁址、股改、业务转型、核心产品发布、重要资质取得等节点（时间＋事项） | 章程 / 沿革说明 / BP / 访谈 |
| 股东与股权 | 当前每一股东：名称、类型（创始人/持股平台/员工平台/产业/财务/国资）、认缴额、实缴额、实缴日期、持股比例、背后机构；穿透到自然人的比例；代持、对赌、回购、一致行动等特殊安排 | 股权表 / 章程 / 投资协议 / 工商 |
| 历次股权变动 | 每次转让/增资：日期、出让方、受让方、转让比例、价格（含0元）、投后估值、变动后完整股权表 | 沿革说明 / 工商变更记录 |
| 融资历史 | 轮次、时间、投资方、投资额、对应注册资本、投后估值、特殊条款线索 | 投资协议 / BP / 访谈 |
| 核心团队 | 每人：姓名、职务、出生年份、学历学位、毕业院校专业、职业履历（时间＋单位＋职务）、代表性成果、在公司分工、持股与激励 | 团队介绍 / BP / 简历 |
| 人员结构 | 员工总数（及时点）、参保人数、专业结构（多期）、学历结构、年龄结构、组织架构模式 | 花名册 / 访谈 / 年报 |
| 知识产权 | 分类计数（发明/实用新型/软著/商标）、授权状态、权属主体、来源（自研/受让/院校转入）、明细清单 | 证书 / 专利库检索 |
| 资质荣誉 | 资质证书（名称、发证机关、有效期）、荣誉（级别、年份、含金量说明） | 证书 / 公示 |
| 客户供应商 | 分年度前五/十大：名称、金额、占比、产品内容；关联方线索 | 财务明细 / 合同 / 访谈 |
| 子公司及对外投资 | 每家：名称、状态、注册资本、成立日期、持股比例、主要业务/设立用途 | 工商 / 访谈 |
| 财务数据 | 分年度：资产总计、负债合计、所有者权益、资产负债率、营业收入、营业成本、毛利率、三费、研发费用、净利润、未分配利润、三张表现金流指标；口径（审计报告年度/未审报表） | 审计报告 / 财务报表 |
| 合规信用 | 诉讼仲裁、行政处罚、被执行/失信、股权冻结、经营异常、税务/环保/安全生产、劳动纠纷、知识产权纠纷；已核查渠道清单 | 公示系统 / 裁判文书网 / 执行网 |
| 上市计划 | 挂牌/上市时间表、目标板块、对应标准、当前差距 | BP / 访谈 |

缺口先从资料包和权威来源补全，仍无依据的进入随稿核查清单，不在正文留占位句。完整来源、文件版本及不同口径留在事实台账。

**先辨别更新、口径差异与实质矛盾。** 不同日期的名册、已经明确替代的融资方案，采用已确认适用的口径，原记录留底稿；不能仅按版本号大小取舍。对于同一时点的未解矛盾，台账保留各来源，正文写影响判断的差异及结果，核查动作归入清单。审计、未审、预测口径分清，不能把较乐观的自述替代审计事实；小额尾差、名称单字差异等校对过程不展开成报告段落。

台账建完先跑第 0.2 节（榨干会议纪要）和第 0.5 节（三角验证），再动笔。

## 第 0.2 节　会议纪要挖掘清单：书面资料给骨头，纪要给血肉

两篇范文里最见功力的信息几乎全部来自访谈：因诺科技子公司表的用途列（"为了拿人才项目""配合股东工作"）、专利权属来源（"据访谈，核心技术源头来自公司创始人带队的高校技术团队……目前核心专利均已转至因诺公司"）、公司对财务问题的解释（"根据访谈，公司表示自设立以来，主要投入研发及场景验证……"）、上市时间表。会议纪要是本章的第二矿脉，逐条榨取，按下表对号入座：

| 纪要里通常独家供给的信息 | 落到哪一节 | 口径写法 |
|---|---|---|
| 子公司/参股公司的真实设立用途、注销计划 | 关联公司表"主要业务"列 | 照实入表（"为了拿人才项目"），来源在台账记"访谈" |
| 代持的形成原因、代持人身份、还原安排 | 股东结构及穿透表 | 披露代持事实与影响；核查协议及还原安排的动作进入清单 |
| 技术/专利的真实来源（高校课题组、前雇主、受让） | 知识产权节权属来源句 | "据访谈，核心技术源头来自……" |
| 公司对亏损、毛利率波动、高负债的解释 | 财务"存在问题（及对策）"节 | "根据访谈，公司表示……"＋"将在尽调阶段进一步分析" |
| 上市/挂牌时间表与板块选择 | 上市规划节 | "根据公司提供的最新计划，……" |
| 在手订单、预测依据 | 财务预测节口径句 | "公司根据在手订单情况……" |
| 员工真实人数、参保口径解释、近期人事变动 | 人员及组织架构节 | 数字照录，解释挂"据访谈" |
| 融资进展、本轮条款（估值、金额、领投方） | 融资历史节 | 数字入表，条款线索进待核查清单 |
| 客户关系背景、大客户续约情况 | 客户供应商节分析句 | 事实入文，判断挂限定词 |
| 团队分工、关键岗位空缺与补岗计划 | 核心团队节 | 分工入履历段，空缺进待核查清单 |

两条纪律：

1. **每条公司说法先分类再落笔**：有书面佐证的事实直接陈述；只有访谈依据的说法、解释及预测，统一在对应段落或表格前注明归属，必要核查事项留清单，不逐句以“有待验证”收尾。
2. **纪要与书面资料冲突按第 0 节包内冲突规则处理**：两口径并列，禁止用纪要覆盖审计报告，也禁止用 BP 覆盖纪要里更不体面的说法（纪要里"已经在注销流程"比 BP 里的"战略布局"更接近真相，两个口径都要在场）。

## 第 0.5 节　台账建完先跑：三角验证矩阵

本章的骨架是一张互锁的验证网。资深投资人"横着读"——跨模块对照，两条各自看似正常的信息，对到一起才暴露问题；文档必须经得起横读。数字级勾稽（合计＝100%、总数＝分项之和等）见 `data-and-tables.md` 第三节，本矩阵管**事实级互锁**。每一对核验只有三种结局：

- **一致**——通过，不必写入正文；
- **矛盾**——先排除时点、单位和版本更新原因，未解的实质差异如实写明及其影响，禁止圆数或隐去重要事实；
- **无法核验**——写入"待补充资料及后续核查事项"清单。

| # | 核验对 | 对什么 | 命中时的处理 |
|---|---|---|---|
| 1 | 工商信息表 ↔ 股东结构表 | 注册资本、实缴资本两处一致 | 并列口径＋需核实 |
| 2 | 参保人数（工商口径）↔ 员工总数（人员节） | 差异幅度 | 差异大→用工合规核查（范文一：参保49 vs 员工68，两处照录） |
| 3 | 核心团队履历 ↔ 客户/供应商名录 | 成员前雇主、兼职单位是否出现在交易对手中 | 关联关系及交易公允性核查（范文一：副总前雇主亚太卫星＝当年第一大供应商） |
| 4 | 核心团队履历 ↔ 同业名单 | 前雇主是否同行 | 竞业限制与技术来源合法性核查 |
| 5 | 核心团队名单 ↔ 股东表/穿透表/员工平台 | 核心成员是否持股绑定；代持关系两端是否均为关键人物 | 教授＋亲属代持→职务发明＋代持还原双核查（范文一：鄢凤波代持首席科学家鄢泽洪股份） |
| 6 | 成员入职时间 ↔ 人员结构表多期变化 | 叙事与数字互证 | 讲不通→正文点出（范文一：相控阵负责人2024年中加入 ↔ 研发人数20→27） |
| 7 | 知识产权状态/权属 ↔ 创始人前雇主、公司主体 | 受让专利的来源；权属是否在公司体内 | 受让来源与对价核查；体外权属→待核查清单 |
| 8 | 融资历史表 ↔ 股东结构表 | 投资方名称、认缴额、持股比例逐一咬合 | 反算不符→表注标注口径问题 |
| 9 | 增资/转让叙述 ↔ 变动后股权表 | 投资额、估值、认缴额、股权比例是否同口径 | 验算不符则先排查老股、税额及同步调整，未解差异如实记录 |
| 10 | 财务预测 ↔ 在手订单/客户表 | 已签、意向、已确认收入及剩余履约额是否区分 | 完成分类及可比测算，说明预测依赖的签约、交付和产能条件 |
| 11 | 客户表合计 ↔ 财务表营业收入 | 前N大占比反算 | 重算为准，不符标注 |
| 12 | 子公司业务 ↔ 收入/资产/知识产权归属 | 有无业务、资产在公司体外 | 主体完整性→影响退出路径的评估写入分析段/待核查清单 |
| 13 | 经营范围许可项目、资质证书主体 ↔ 公司主体 | 许可业务是否有证、证在谁名下、是否过期 | 无证经营／主体错位→待核查清单 |
| 14 | 会议纪要说法 ↔ 对应书面文件 | 纪要里可书面验证的说法有无文件佐证 | 无佐证→照录挂口径＋生成核查任务 |

矩阵跑完的产出直接决定正文质量：矛盾项就是"存在问题"的素材，无法核验项就是待核查清单的条目——**这张矩阵是"章节正文＋核查清单"双件套的发动机**。

## 第一节　（一）基本信息

这一节回答"这家公司是谁、靠谁经营、凭什么经营"。结构由静到动：**法律主体（工商）→ 人（团队与员工）→ 资产（知识产权与资质）→ 经营关系（子公司、客户供应商）**。先让投委会确认主体干净、清晰，再看支撑经营的人和资源。

### 1.工商信息（H3）

**写什么**：工商信息表＋一段主体定位正文（可省；两篇范文均只给表）。

**为什么**：这是全章的"身份证页"。投委会用它确认：主体是否存续、注册与实缴差多少、经营范围与实际业务是否一致、成立年限与融资阶段是否匹配。

**怎么写**：
- 直接上工商信息表（T1）。资料充分用四列全表（范文一：18项，含参保人数、纳税人资质），资料一般用两列简表（范文二：7项）。
- 经营范围全文照录，不删节——"许可项目"清单本身就是资质核查线索。
- 简称在此定义：表后正文首次出现全称处括注"（以下简称'××'）"，此后全章用"公司"或简称，禁用"标的公司"等称谓（规则见 `writing-craft.md` 第〇节第2条）。
- 若加定位段，一段话讲清：成立于何年、注册资本与实缴、法定代表人、主营方向与经营范围是否一致、当前发展阶段。句式："在公司基本情况方面，公司成立于××年，注册资本××万元（实缴××万元），主要围绕××领域开展经营活动，业务方向与工商登记经营范围整体一致；结合成立时间、业务进展及融资阶段，公司目前处于××阶段。"
- **注意勾稽**：注册资本、实缴资本要与（二）股东结构表的认缴/实缴合计一致；参保人数要与"人员及组织架构"的员工数对照，差异大时在人员节点出。

### 2.历史沿革（H3，条件节）

**写什么**：业务层面的重大节点——设立背景、更名、股改、迁址、业务转型、核心产品推出、重要资质取得。**股权类变动（转让、增资、引入投资人）一律放（二）股权变动情况，此处不重复。**

**为什么**：投委会关心公司如何走到今天：发展路径与主营业务演进是否连续，有无频繁转型、主业漂移。两篇范文的业务节点均已体现在股权变动叙事中，故都未单设本节——资料同样情况时照此处理，整体并入（二）。

**怎么写**：时间轴表（T2：时间/事项/关注点）或按段叙述；收束句给连续性判断："整体来看，公司发展路径与主营业务演进具有一定连续性。"

### 3.核心团队（H3）

**写什么**：（1）（2）（3）…逐人小标题（姓名＋公司职务），每人一段履历，顺序：创始人/董事长/总经理 → 总工/CTO → 业务/运营副总 → 财务负责人 → 首席科学家/核心研发负责人。

**为什么**：一级市场很大程度上投团队。投委会要在几段话里看清：核心成员的行业年限、技术与商业化能力从哪来（履历佐证）、分工是否覆盖战略/研发/市场/财务、与公司业务方向是否匹配。

**怎么写**（两篇范文的履历段公式，逐要素落）：
- **出生年份/学历学位 → 毕业院校与专业 → 职业履历（时间＋单位＋职务，逐段）→ 代表性成果/项目/荣誉 → 现任职务与在公司的分工**。
- 早期公司式（范文一）："1986年生，本科。拥有逾10年卫星通信天线研发经验，曾就职于××公司，担任××主任设计师，熟悉××整机设计和生产管理，负责公司研发和生产管理。"
- 学术背景式（范文二，逐年编年）："2007年博士毕业于西北工业大学导航、制导与控制专业，2008年任××，2010年至今任××，2015年至今任公司董事长兼总经理。……在国外学术期刊、会议发表论文20篇、EI收录6篇，申请并获得5项国家发明专利和国防专利……2021年获陕西省产业领军人才。"
- 履历必须写实：单位名称、职务、年限照资料录入；论文/专利/人才称号用可验证的计数照录；没有的不编。
- 逐人写完后可加一段整体分析（资料充分时）："在核心团队方面，创始团队主要成员具备××行业、××技术背景，分工覆盖战略决策、产品研发、市场拓展及运营管理等关键环节，履历与公司当前业务方向具有一定匹配度。后续仍需关注核心成员稳定性、股权激励安排及关键岗位补足情况。"
- **核查点随写随记**：核心成员是否持股/在员工平台（与（二）交叉验证）、有无竞业限制风险（前雇主为同行）、关键岗位（如 CFO）是否空缺。

### 4.人员及组织架构（H3）

**写什么**：员工总数与时点 → 专业结构表（多期对比）→ 学历结构表 → 年龄结构表 → 组织架构描述（或架构图占位）。

**为什么**：人员结构反映业务属性与阶段——技术驱动看研发占比，销售驱动看销售规模，制造型看生产与质量配置；多期对比看扩张方向。参保数与员工数的差异是用工合规的直接线索。

**怎么写**：
- 首句给总数、时点与参保数："截至××年第×季度，公司员工人数为××人，其中××人缴纳社保公积金。"差异明显时加一句"员工总数与参保人数存在一定差异，用工形式及社保缴纳情况需在尽调阶段进一步核实。"
- 专业结构表（T3）尽量给 2–3 个报告期（人数＋占比并列），趋势可读；学历（T4）、年龄（T5）单期即可。
- 占比自己核算（公式见 `data-and-tables.md`），各表合计＝100%、合计人数＝总数。
- 组织架构一段话讲模式即可（范文二："采用'核心业务事业部＋职能支撑部门＋研发及生产中心'运营模式……"），有架构图则注明"公司组织架构图如下："并占位。
- 成长期公司（数百人）可省结构表、只写总数与研发占比加组织模式段（范文二写法）；早期公司三表齐上（范文一写法）。

### 5.知识产权（H3）

**写什么**：总量与分项计数 → 权属来源说明 → 明细表（数量可控时）。

**为什么**：科技类公司技术壁垒最直接的书面证据。投委会关心三件事：数量与结构（发明专利含金量最高）、权属是否在公司体内、与主营业务是否对应。

**怎么写**：
- 首句分项计数，称谓准确：发明专利、实用新型、软件著作权、商标分开数，总数与分项之和必须勾稽（"公司拥有发明专利107项（已授权49项）、实用新型57项、软件著作权64项"）。授权与申请中分开。范文一"专利17项"实为知识产权合计（实用新型8＋软著6＋发明3）——写作时称谓要比范文更准确。
- 权属来源一句话（范文二："据访谈，核心技术源头来自公司创始人带队的高校技术团队及内部长期打磨沉淀，目前核心专利均已转至因诺公司"）——高校背景团队必查职务发明与权属转移。
- 专利在 30 项以内上明细表（T6：序号/专利号/名称/类型/状态）；状态列如实录"已下证""专利权的转移成功"——**受让专利是核查线索**（转让方是谁、对价、与核心产品关系），发现即在正文提示。
- 表后仅在有必要时解释核心技术与专利的对应关系、受让来源及已知权属问题。例行核查权属和法律状态的动作留在清单，不固定追加“后续需核查”结尾。

### 6.荣誉及资质（H3，条件节）

**写什么**：分组列示——国家级荣誉 / 省级荣誉 / 市级与行业荣誉 / 核心资质认证（bullet 列表，每项带年份与含金量注释）。

**为什么**：荣誉是第三方背书（专精特新"小巨人"、单项冠军、高新技术企业有实际政策与信用含义）；资质是经营的门票（军工四证、许可证、体系认证缺一项可能就做不了某类业务）。强监管行业本节必写，且资质优先于荣誉。

**怎么写**：逐条列示，含金量高的加一句注释（"陕西省低空经济领域唯一入选企业""全国仅两家"——须有依据，可联网核实）。资质注意有效期与主体：证书主体若非公司本体，正文提示。早期公司无荣誉资质则整节不设，禁写"暂无荣誉"。

### 7.关联公司（子公司及对外投资）（H3，条件节）

**写什么**：子公司/参股公司汇总表（T7：序号/名称/状态/注册资本/成立日期/持股比例/主要业务或设立用途）＋主体清晰度分析段。

**为什么**：判断收入、资产、人员、知识产权、合同是否集中在公司控制范围内；多主体结构下要警惕业务混同、同业竞争、利益输送，以及影响未来退出的主体完整性问题。

**怎么写**：
- 用途列**照实写**（范文二直录"已经在注销流程，为了拿人才项目""配合股东工作"）——真实用途本身就是尽调信息，禁止修饰成"战略布局"。这一列的信息通常只在会议纪要里（见第 0.2 节）。
- 正文说明各主体承担的研发、生产、销售等功能及与本轮投资主体的关系；收入、资产或知识产权分散在不同主体且影响判断时，写清已知影响。与项目无关的实控人任职长表不自动收入正文。
- 低持股比例（<50%）主体、异地空壳主体、注销中主体逐一点名关注。无子公司则整节不设。

### 8.前五（十）大客户及供应商（H3）

**写什么**：（1）前五（十）大客户——分年度表（T8：年度/序号/客户名称/销售金额/占当期营业收入比例/销售产品名称及数量，含合计行）；（2）前五（十）大供应商——同构表（T9）。

**为什么**：客户结构验证收入的真实性与质量（客户是谁、是否头部、是否持续复购），集中度暴露单一依赖风险；供应商结构暴露供应链依赖与外协程度。这也是与财务、业务交叉验证的枢纽。

**怎么写**：
- 引导句给口径："公司截至××年××月的前×大客户为："。金额单位全表统一（万元），占比给合计行。
- **两篇范文本节均为纯表格＋引导句，无分析段。** 默认在表后加一段三句以内的集中度分析（对范文的增值动作）；用户要求严格按范文时省略。
- 表后有分析价值时，解释集中度、客户性质及同一主体双向购销等关系，不逐行重述名单。已知业务暂停、回款滞后等写明金额和影响；关联关系及交易实质的未解问题进入核查清单。
- 本章只谈集中度与依赖度；收入结构、商业模式分析归主营业务章节。

## 第二节　（二）股权变动情况

这一节是全章的核心。回答四个问题：**股权是否清晰、控制权是否稳定、核心团队利益是否绑定、历史变动是否干净**。结构：先给"现在"（股东结构＋穿透），再给"过程"（逐次变动），最后给"资本视角"（融资与估值汇总）。

### 1.股东结构（H3）

**写什么**：当前股东全表 → 股东身份识别段 → 穿透至自然人表。

**怎么写**：
- 引导句："当前公司有×名股东，股东及股权占比如下："
- 股东表（T10）：股东名称/持股比例/认缴出资额/实缴出资额/实缴出资日期/股东背景（或关联机构）。**股东背景列是投资人最增值的一列**（范文二逐行标注"创始人""员工持股平台""国中资本，财政部""山东魏桥，民营资本""呼卫军父亲"），格式为"机构简称，资金性质"，原料来自联网三大必检之一（`data-and-tables.md` 第四节），务必填实。
- 身份识别段逐类点名：谁是创始人；哪个是创始团队持股平台、谁任 GP/LP；哪个是员工持股平台；其余哪些是财务投资人、产业投资人、国资。（范文一："张勇为公司创始人；××合伙企业为创始团队持股平台，其中张勇为GP，××为LP；……其他股东均为公司的财务投资人。"）
- 穿透表（T11）区分名义比例与实际受益比例，代持直接在表内披露。正文说明对控制权的已知影响；形成原因、协议效力与还原安排的核验动作记入清单。
- 股权分析围绕第一大股东、实际控制人、创始团队及外部投资人的比例和关系展开，不逐项复述表格。实际控制人认定以证据为基础；有明确结论时直接写，只有公司说法时保留归属。未发现具体特殊条款线索时，不机械追加协议核查清单。

### 2.历史股权变动（H3）

**写什么**：设立时初始股权表 → 按时间逐次变动（1）（2）（3）…，每次一段事实描述＋变动后完整股权表。

**为什么**：这是尽调级的写法（范文一全程如此）：逐次重演股权演变，任何异常——0元/低价转让、短期反复转让、突击入股、平价代持还原——都会自动浮出水面；每次变动后的股权表相互勾稽，防止"讲不通的股权故事"。

**怎么写**：
- 开头总括："公司于××年××月××日注册设立，经历×次股权变动，包括×次股权转让、×次增资。公司初始股权如下："＋初始股权表。
- 每次变动的小标题："（1）××年×月，公司第一次股权转让"；正文一句式记录事实："××年×月×日，××将其持有的××%股权共计××万元以××万元转让至××"——**价格照实写，0元就写0元**；增资写"××以××万元投后估值出资××万元，认缴公司新增注册资本××万元持股××%"（四要素齐且可验算：投资额÷投后估值＝释放比例）。
- 每次变动后附股权表（T12：序号/股东/认缴出资/股权比例/实缴出资/合计行），逐表勾稽（比例合计100%、认缴合计＝当期注册资本）。
- 异常变动按日期、主体、价格及比例如实写明，并分析其对股权或控制权的已知影响。定价、资金、完税及代持安排的具体核查步骤进入随稿清单；正文需要交代时用本方后续计划表达。
- 变动次数极多的成长期公司，压缩为"股东结构＋融资汇总表"（范文二写法：不逐次重演）。

### 3.历史融资及估值情况（H3）

**写什么**：融资历史汇总表（T13：时间/投资方/股权占比/对应注册资本/投资额/投后估值/轮次）＋估值演进分析段。

**为什么**：融资历史是资本市场对公司的定价轨迹。投委会关心：估值增长有无业绩支撑、融资节奏与业务进展是否匹配、本轮估值与上轮的关系（有无倒挂）、历轮协议有无对赌/回购/优先清算/反稀释条款。

**怎么写**：
- 引导句："公司历次融资及估值情况如下："（范文二："因诺科技历次融资及估值情况如下："——简称开头也是合法写法）＋汇总表，按时间正序，同轮多个投资方分行列示、共用投后估值。
- 估值分析只在资料可证时联系融资时点、定价与业务进展，不凭估值涨幅作投资推荐。已知特殊条款如影响本轮权益须披露；例行协议核查动作进入清单。

### 4.本轮融资及资金使用计划（H3，按需）

一段或两段交代拟融资额、投前或投后估值、资金用途与金额。区分已完成融资与计划、本轮与后续融资。一般省略材料版本变迁、逐轮磋商及完整稀释公式；若条款变化实质影响控制权，或用户要求测算，再展开相应分析。不能在用户要求重写后只删去整段，留下空标题。
- 估值数字只能来自资料（协议/BP/访谈），检索可佐证但不可替代；测算的投后估值列公式。

## 第三节　（三）财务数据

本节只做"快照＋问题提示＋公司预测"，深度财务分析归财务分析章节。

### 1.核心财务数据（H3）

**写什么**：口径交代句＋核心财务表（T14，三段式：资产负债核心指标/利润表核心指标/现金流量表核心指标，3–4 个报告期）＋趋势分析段。

**怎么写**：
- 口径句必写："根据公司提供的××年度、××年度审计报告及××年×–×月财务报表，核心财务数据如下："——审计与未审口径分清。
- 表内固定指标：资产总计、负债合计、所有者权益合计、资产负债率；营业收入、营业成本、毛利率、销售/管理/研发费用、净利润、未分配利润（期末）；经营/投资/筹资活动现金流量净额、现金及现金等价物净增加额、期末余额。单位统一万元，千分位分隔。
- 分析段公式（两篇范文同构，**首句以简称开头**）：**简称＋收入逐年数字＋复合增长率 → 盈亏轨迹与归因 → 毛利率轨迹与归因 → 审慎提示**。范文："伊隆纬特2023年、2024年和2025年营业收入分别为741.81万元、2,443.26万元和2,805.94万元，三年复合增长率约94.5%，业务规模呈快速扩张态势。净利润方面……毛利率从2023年的4.43%大幅提升至……但2026年一季度毛利率回落至23.90%，需关注其后续持续性。"正面数字与反向数字同段并列，转折只用"但"。

### 2.存在问题（及对策）（H3）

**写什么**：按实际问题分项，先呈现数据及其关系，再写证据支持的结论。公司解释与本方判断分开。需要说明后续工作时，可集中交代“将在尽调阶段进一步分析”，不要求每项都以核查任务结束。

**为什么**：这一节是本章"客观公允"的试金石——立项阶段就把持续亏损、毛利率波动、高负债率、现金流为负等问题摆上桌面，同时区分"公司的解释"与"本方的判断"。

**怎么写**：标题直陈“持续亏损”“大客户业务暂停”“合同与收入金额存在差异”等现象；数据解释清楚，结论限定在证据范围内。对同一项目完成合同额、售价、收入和回款对照；对贸易业务完成售价、采购及运输成本比较。无法解释的差异如实保留，不虚构原因。

### 3.财务预测（H3）

**写什么**：公司预测口径句及分业务、分年度预测表；已签订单、意向项目分开呈现数量、金额、交付期，另区分已确认收入与剩余可确认收入。

**为什么**：预测是公司自报口径。先计算与实绩的差距，再说明其依赖的签约、交付及产能等条件。已签合同总额、意向金额与已确认收入不能直接加总；税额或履约重合未核清时不算虚假的覆盖率。不要只写“应分别考察”“应验证可行性”，把可完成的分析做完。

## 第四节　（四）上市规划（条件节）

**写什么**：1.时间表（挂牌/升层/申报/审核的节点规划，口径句"根据公司提供的最新计划……"）；2.上市标准——目标板块的官方标准表（如新三板创新层四选一、北交所四选一）＋逐条差距分析。

**为什么**：有明确上市规划的公司，退出路径是立项的重要考量。写法的关键是**差距分析**，禁写展望：公司现在满足哪条、缺哪条、靠什么补上（范文二："当前股本总额为668.53万股，不满足要求，故公司计划在新三板基础层挂牌期间，可通过资本公积转增股本满足股本总额条件"）。

**怎么写**：标准表照录官方标准（联网核对最新版本并注明年份）；差距分析逐条对照公司实际数据；收束句："公司当前业务及定位符合××要求，但财务数据尚不满足××标准，其改善路径的可行性需持续跟踪。"资料无上市规划则整节不设。

## 第五节　随稿交付物：待补充资料及后续核查事项清单

**这是与正文平级的正式交付物，在对话回复中输出，不写入报告正文/.docx**（正文遵循范文四节制，不额外挂尾巴节；用户明确要求时才把清单另存为独立文件）。格式：

`序号 | 事项 | 涉及章节 | 需要的资料/核查动作`

来源三股：三角验证矩阵的"矛盾/无法核验"项、红旗扫描命中项、三源（资料包、纪要、联网检索）都拿不到的数据缺口。三条规则：

1. 清单定位到相应章节，覆盖影响判断的未解差异及实质缺口；不把每项事实都转为任务，也不在正文要求逐项重复核查句；
2. 每条说明本团队拟核查的资料、对象及问题，避免“建议投资方”“应该关注”的外部指导口吻；
3. 完整事实保存在工作台账；无关细节、重复资料和用户已删除的段落不因覆盖要求自动回填报告。用户删除内容涉及重大未解问题时，在交付说明简明提示，尊重正文取舍。

## 增配节（默认不启用；用户要求或红旗组合命中时开启，编号顺延）

### 增配节A　合规、信用及重大风险事项

**启用时机**：用户机构模板要求；或公开检索发现实质性涉诉/处罚/失信事项，需要成节呈现。

**写什么**：已核查范围说明＋风险核查表（T15：风险类型/当前情况/影响判断/后续核查事项，覆盖诉讼仲裁、行政处罚、被执行/失信、股权冻结、经营异常、税务/环保/安全生产、劳动纠纷、知识产权纠纷）＋待核查事项收束段。

**怎么写**：
- 未发现问题时的标准句："在合规及信用情况方面，现有资料及公开检索未显示公司存在对持续经营构成重大不利影响的行政处罚、重大诉讼仲裁或失信被执行事项。"**禁止写"无风险"或空栏"无"。**
- 发现事项的逐条写：事实（案号/文号、时间、金额、状态）＋影响初判＋核查指向。
- 正文报告已完成的核查结果和证据边界，未执行的渠道检查留清单。只有必要时补一句“后续我们将……”，不固定罗列一套查询渠道。
- 不启用本节时，前文发现的关注点（代持、0元转让、参保差异、专利受让、关联交易线索）全部汇入随稿交付的待核查清单，一条都不能丢。

### 增配节B　公司情况综合判断

**启用时机**：用户机构模板要求；或红旗组合拳命中、需要把跨节线索合并陈述给投委会。

**写什么**：一段（至多两段）"事实基础＋投资判断＋待核查事项"的收束，回答八问：主体是否清晰、股权是否稳定、实控人是否明确、团队是否匹配业务、组织能力是否支撑当前阶段、核心资质资源能否支撑主营、有无重大合规瑕疵、哪些信息待补充。

**怎么写**：
- 综合判断概括与立项有关的核心事实及其影响，有实质矛盾时说明边界。不要套“主体较为清晰、具有一定匹配度、后续仍需关注”的通用总结；结论应因项目事实而不同。
- 待核查事项必须与前文一一呼应（前文没提过的禁止在此突然出现；前文标了"待核查"的禁止在此遗漏）。
- **禁写成宣传总结**：零"优质""强烈建议"字样；立项结论归报告的立项结论章节，本节只对"公司情况"作判断。
- **落笔前核对 `red-flags.md` 的跨项关系。** 多项事实确实共同影响技术归属、控制权或交易实质时，说明其联系及已有影响；不能仅因出现某个组合就定性违规。尚不能判断的部分留证据边界，核查动作进入清单。

## 末节　结构自适应裁剪规则

按资料完整度与公司阶段裁剪骨架，条件节不启用时编号顺延：

| 情形 | 处理 |
|---|---|
| 早期公司（天使—A轮，几十人） | 参照范文一：无荣誉资质、无子公司、无上市规划则三节全裁；人员三表齐上；历史股权变动逐次重演 |
| 成长期公司（B轮后，数百人） | 参照范文二：人员结构简写（总数＋研发占比＋组织模式）；股权变动压缩为股东结构＋融资汇总表；关联公司、荣誉资质、上市规划按资料启用 |
| 资料只有 BP、无工商与股权明细 | 工商信息联网补全；股权只写 BP 口径并整节标注"以下股权信息来自公司提供材料，尚未与工商登记核对"；历史变动节改为待核查清单条目 |
| 无财务资料 | 无依据的财务内容不写入正文，缺口在对话清单中交代；禁止用零散BP数字拼凑三张表 |
| 强监管行业（军工、医疗、金融、测绘等） | "荣誉及资质"提级为必写节且资质在前；缺关键牌照直接写入待核查清单（增配节A启用时入风险表） |
| 用户机构模板另有骨架 | 以用户模板为准，把本骨架的信息模块映射进去；模板未覆盖的关注点（代持、合规）以"存在问题"或待核查清单形式保留，禁止丢失 |

主体、控制权、团队及财务是本章重点。资料不足的模块不编造、不放占位段，在随稿清单交代缺口；用户已有模板及明确删改取舍优先。
