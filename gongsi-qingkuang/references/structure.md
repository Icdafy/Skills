# 公司情况骨架：每一层标题写什么、为什么、配什么

本文件是起草前必读的"施工图"。它把"四、公司情况"拆到每一个标题层级，说明该层写什么内容、背后的投资判断逻辑、配什么表。逐层照施工图走，再按 `writing-craft.md` 把句子写好、按 `data-and-tables.md` 把数算对。

---

## 第 0 节　动笔前：建"公司事实台账"

公司情况的可信度来自每个名称、日期、金额、比例都能溯源。起草前先把资料包（必要时联网补充）里的公司证据抽进下面的台账，再开始写。台账只为自己用，不进正文，但正文每句话都要能在台账里找到出处。

| 台账模块 | 要登记的字段 | 来源标注 |
|---|---|---|
| 主体信息 | 企业名称、统一社会信用代码、法定代表人、注册资本、实缴资本、成立日期、企业类型、登记状态、注册地址、办公地址、国标行业、营业期限、参保人数、经营范围 | 营业执照 / 工商公示 / 企查查天眼查 |
| 历史沿革 | 设立背景、更名、迁址、股改、业务转型、核心产品发布、重要资质取得等节点（时间+事项） | 章程 / 沿革说明 / BP / 访谈 |
| 股东与股权 | 当前每一股东：名称、类型（创始人/持股平台/员工平台/产业/财务/国资）、认缴额、实缴额、实缴日期、持股比例、背后机构；穿透到自然人的比例；代持、对赌、回购、一致行动等特殊安排 | 股权表 / 章程 / 投资协议 / 工商 |
| 历次股权变动 | 每次转让/增资：日期、出让方、受让方、标的比例、价格（含0元）、投后估值、变动后完整股权表 | 沿革说明 / 工商变更记录 |
| 融资历史 | 轮次、时间、投资方、投资额、对应注册资本、投后估值、特殊条款线索 | 投资协议 / BP / 访谈 |
| 核心团队 | 每人：姓名、职务、出生年份、学历学位、毕业院校专业、职业履历（时间+单位+职务）、代表性成果、在公司分工、持股与激励 | 团队介绍 / BP / 简历 |
| 人员结构 | 员工总数（及时点）、参保人数、专业结构（多期）、学历结构、年龄结构、组织架构模式 | 花名册 / 访谈 / 年报 |
| 知识产权 | 分类计数（发明/实用新型/软著/商标）、授权状态、权属主体、来源（自研/受让/院校转入）、明细清单 | 证书 / 专利库检索 |
| 资质荣誉 | 资质证书（名称、发证机关、有效期）、荣誉（级别、年份、含金量说明） | 证书 / 公示 |
| 客户供应商 | 分年度前五/十大：名称、金额、占比、产品内容；关联方线索 | 财务明细 / 合同 / 访谈 |
| 子公司及对外投资 | 每家：名称、状态、注册资本、成立日期、持股比例、主要业务/设立用途 | 工商 / 访谈 |
| 财务数据 | 分年度：资产总计、负债合计、所有者权益、资产负债率、营业收入、营业成本、毛利率、三费、研发费用、净利润、未分配利润、三张表现金流指标；口径（审计报告年度/未审报表） | 审计报告 / 财务报表 |
| 合规信用 | 诉讼仲裁、行政处罚、被执行/失信、股权冻结、经营异常、税务/环保/安全生产、劳动纠纷、知识产权纠纷；已核查渠道清单 | 公示系统 / 裁判文书网 / 执行网 |
| 上市计划 | 挂牌/上市时间表、目标板块、对应标准、当前差距 | BP / 访谈 |

缺口处理三档：**资料包 > 联网权威来源 > "相关资料尚未提供／该事项仍需进一步核查"**。三档之外不得编造。资料包与公开信息冲突的，台账里两个口径都记，正文并列呈现并标注"需进一步核实"。

台账建完不要急着动笔——先跑完第 0.5 节的三角验证矩阵。

## 第 0.5 节　台账建完先跑：三角验证矩阵

本章的骨架是一张互锁的验证网，不是一张清单。资深投资人是"横着读"的——跨模块对照，两条各自看似正常的信息，对到一起才暴露问题；文档必须经得起横读。数字级勾稽（合计=100%、总数=分项之和等）见 `data-and-tables.md` 第三节，本矩阵管**事实级互锁**。每一对核验只有三种结局：

- **一致**——通过，不必写入正文；
- **矛盾**——两处各自如实记录，正文并列口径＋"需进一步核实"，不得替资料圆谎、不得修饰掉任何一边；
- **无法核验**——写入"待补充资料及后续核查事项"清单。

| # | 核验对 | 对什么 | 命中时的处理 |
|---|---|---|---|
| 1 | 工商信息表 ↔ 股东结构表 | 注册资本、实缴资本两处一致 | 并列口径＋需核实 |
| 2 | 参保人数（工商口径）↔ 员工总数（人员节） | 差异幅度 | 差异大→用工合规核查（范例一：参保49 vs 员工68，两处照录） |
| 3 | 核心团队履历 ↔ 客户/供应商名录 | 成员前雇主、兼职单位是否出现在交易对手中 | 关联关系及交易公允性核查（范例一：副总前雇主亚太卫星＝当年第一大供应商） |
| 4 | 核心团队履历 ↔ 同业名单 | 前雇主是否同行 | 竞业限制与技术来源合法性核查 |
| 5 | 核心团队名单 ↔ 股东表/穿透表/员工平台 | 核心成员是否持股绑定；代持关系两端是否均为关键人物 | 教授＋亲属代持→职务发明＋代持还原双核查（范例一：鄢凤波代持首席科学家鄢泽洪股份） |
| 6 | 成员入职时间 ↔ 人员结构表多期变化 | 叙事与数字互证 | 讲不通→正文点出（范例一：相控阵负责人2024年中加入 ↔ 研发人数20→27） |
| 7 | 知识产权状态/权属 ↔ 创始人前雇主、拟投资主体 | 受让专利的来源；权属是否在标的体内 | 受让来源与对价核查；体外权属→风险表 |
| 8 | 融资历史表 ↔ 股东结构表 | 投资方名称、认缴额、持股比例逐一咬合 | 反算不符→表注标注口径问题 |
| 9 | 增资/转让叙述 ↔ 变动后股权表 | 四要素可验算（投资额÷投后估值=释放比例；Σ=100%） | 验算不过→"数据口径不一致，需进一步核实" |
| 10 | 财务预测 ↔ 在手订单/客户表 | 预测是否有对应订单与客户结构支撑 | 跳跃过大→"预测实现的可行性需在尽调阶段验证" |
| 11 | 客户表合计 ↔ 财务表营业收入 | 前N大占比反算 | 重算为准，不符标注 |
| 12 | 子公司业务 ↔ 收入/资产/知识产权归属 | 是否有业务、资产在拟投资主体体外 | 主体完整性→影响退出路径的评估写入（七）/风险表 |
| 13 | 经营范围许可项目、资质证书主体 ↔ 拟投资主体 | 许可业务是否有证、证在谁名下、是否过期 | 无证经营／主体错位→风险表 |

矩阵跑完的产出直接决定正文质量：矛盾项就是"存在问题"和风险表的素材，无法核验项就是待核查清单的条目——**这张矩阵是"证据陈列＋尽调任务清单"双件套的发动机**。

## 第一节　（一）基本信息

这一节回答"这家公司是谁、靠谁经营、凭什么经营"。结构是由静到动：**法律主体（工商）→ 人（团队与员工）→ 资产（知识产权与资质）→ 经营关系（子公司、客户供应商）**。先让投委会确认主体干净、清晰，再看支撑经营的人和资源。

### 1.工商信息（H3）

**写什么**：工商信息表 + 一段主体定位正文（可省，视资料而定；两份范例均只给表）。

**为什么**：这是全章的"身份证页"。投委会用它确认：主体是否存续、注册与实缴差多少、经营范围与实际业务是否一致、成立年限与融资阶段是否匹配。

**怎么写**：
- 直接上工商信息表（T1）。资料充分用四列全表（范例一：企业名称/法定代表人/注册资本/实缴资本/登记状态/统一社会信用代码/成立日期/企业类型/核准日期/国标行业/所属地区/登记机关/人员规模/参保人数/营业期限/纳税人资质/注册地址/经营范围），资料一般用两列简表（范例二：企业名称/统一社会信用代码/法定代表人/注册资本/注册地址/营业期限/经营范围，7–10 项）。
- 经营范围全文照录，不删节——"许可项目"清单本身就是资质核查线索。
- 若加定位段，一段话讲清：成立于何年、注册资本与实缴、法定代表人、主营方向与经营范围是否一致、当前发展阶段。句式："在公司基本情况方面，公司成立于××年，注册资本××万元（实缴××万元），主要围绕××领域开展经营活动，业务方向与工商登记经营范围整体一致；结合成立时间、业务进展及融资阶段，公司目前处于××阶段。"
- **注意勾稽**：注册资本、实缴资本要与（二）股东结构表的认缴/实缴合计一致；参保人数要与"人员及组织架构"的员工数对照，差异大时在人员节点出（见下）。

### 2.历史沿革（H3，条件节）

**写什么**：业务层面的重大节点——设立背景、更名、股改、迁址、业务转型、核心产品推出、重要资质取得。**股权类变动（转让、增资、引入投资人）一律放（二）股权变动情况，此处不重复。**

**为什么**：投委会关心公司如何走到今天：发展路径与主营业务演进是否连续，是否存在频繁转型、主业漂移。若资料中业务节点很少或已体现在股权变动叙事中（范例一、二均如此处理），本节整体并入（二），不单设。

**怎么写**：时间轴表（T2：时间/事项/关注点）或按段叙述；收束句给连续性判断："整体来看，公司发展路径与主营业务演进具有一定连续性。"

### 3.核心团队（H3）

**写什么**：（1）（2）（3）…逐人小标题（姓名＋公司职务），每人一段履历，顺序：创始人/董事长/总经理 → 总工/CTO → 业务/运营副总 → 财务负责人 → 首席科学家/核心研发负责人。

**为什么**：一级市场很大程度上投团队。投委会要在几段话里看清：核心成员的行业年限、技术与商业化能力从哪来（履历佐证）、分工是否覆盖战略/研发/市场/财务、与公司业务方向是否匹配。

**怎么写**（两份范例的履历段公式，逐要素落）：
- **出生年份/学历学位 → 毕业院校与专业 → 职业履历（时间+单位+职务，逐段）→ 代表性成果/项目/荣誉 → 现任职务与在公司的分工**。
- 例："1986年生，本科。拥有逾10年卫星通信天线研发经验，曾就职于××公司，担任××主任设计师，熟悉××整机设计和生产管理，负责公司研发和生产管理。"
- 履历必须写实：单位名称、职务、年限照资料录入；有论文/专利/人才称号的照录（"申请并获得5项国家发明专利""2021年获陕西省产业领军人才"）；没有的不编。
- 逐人写完后可加一段整体分析（资料充分时）："在核心团队方面，创始团队主要成员具备××行业、××技术背景，分工覆盖战略决策、产品研发、市场拓展及运营管理等关键环节，履历与公司当前业务方向具有一定匹配度。后续仍需关注核心成员稳定性、股权激励安排及关键岗位补足情况。"
- **核查点随写随记**：核心成员是否持股/在员工平台（与（二）交叉验证）、是否有竞业限制风险（前雇主为同行）、关键岗位（如 CFO）是否空缺。

### 4.人员及组织架构（H3）

**写什么**：员工总数与时点 → 专业结构表（多期对比）→ 学历结构表 → 年龄结构表 → 组织架构描述（或架构图占位）。

**为什么**：人员结构反映业务属性与阶段——技术驱动看研发占比，销售驱动看销售规模，制造型看生产与质量配置；多期对比看扩张方向。参保数与员工数的差异是用工合规的直接线索。

**怎么写**：
- 首句给总数、时点与参保数："截至××年第×季度，公司员工人数为××人，其中××人缴纳社保公积金。"差异明显时加一句"员工总数与参保人数存在一定差异，用工形式及社保缴纳情况需在尽调阶段进一步核实。"
- 专业结构表（T3）尽量给 2–3 个报告期（人数+占比并列），趋势可读（研发占比升/降）；学历（T4）、年龄（T5）单期即可。
- 占比自己核算（公式见 `data-and-tables.md`），各表合计=100%、合计人数=总数。
- 组织架构一段话讲模式即可（范例二："采用'核心业务事业部+职能支撑部门+研发及生产中心'运营模式……"），有架构图则注明"公司组织架构图如下："并占位。
- 后期公司（数百人）可省结构表、只写总数与研发占比加组织模式段（范例二写法）；早期公司三表齐上（范例一写法）。

### 5.知识产权（H3）

**写什么**：总量与分项计数 → 权属来源说明 → 明细表（数量可控时）。

**为什么**：科技类标的的技术壁垒最直接的书面证据。投委会关心三件事：数量与结构（发明专利含金量最高）、权属是否在拟投资主体、与主营业务是否对应。

**怎么写**：
- 首句分项计数，称谓准确：发明专利、实用新型、软件著作权、商标分开数，总数与分项之和必须勾稽（"公司拥有发明专利107项（已授权49项）、实用新型57项、软件著作权64项"）。授权与申请中分开。
- 权属来源一句话（范例二："据访谈，核心技术源头来自公司创始人带队的高校技术团队及内部长期打磨沉淀，目前核心专利均已转至因诺公司"）——高校背景团队必查职务发明与权属转移。
- 专利在 30 项以内上明细表（T6：序号/专利号/名称/类型/状态）；状态列如实录"已下证""专利权的转移成功"——**受让专利是核查线索**（转让方是谁、对价、与核心产品关系），发现即在正文提示。
- 收束句："上述知识产权主要围绕公司××业务方向展开；后续需进一步核查权属主体、有效状态及其与核心产品之间的对应关系。"

### 6.荣誉及资质（H3，条件节）

**写什么**：分组列示——国家级荣誉 / 省级荣誉 / 市级与行业荣誉 / 核心资质认证（bullet 列表，每项带年份与含金量注释）。

**为什么**：荣誉是第三方背书（专精特新"小巨人"、单项冠军、高新技术企业有实际政策与信用含义）；资质是经营的门票（军工四证、许可证、体系认证缺一项可能就做不了某类业务）。强监管行业本节必写，且资质优先于荣誉。

**怎么写**：逐条列示，含金量高的加一句注释（"陕西省低空经济领域唯一入选企业""全国仅两家"——须有依据）。资质注意有效期与主体：证书主体若非拟投资主体，正文提示。早期公司无荣誉资质则整节不设，不写"暂无荣誉"。

### 7.关联公司（子公司及对外投资）（H3，条件节）

**写什么**：子公司/参股公司汇总表（T7：序号/名称/状态/注册资本/成立日期/持股比例/主要业务或设立用途）+ 主体清晰度分析段。

**为什么**：判断收入、资产、人员、知识产权、合同是否集中在拟投资主体控制范围内；多主体结构下要警惕业务混同、同业竞争、利益输送，以及影响未来退出的主体完整性问题。

**怎么写**：
- 用途列**照实写**（范例二直录"已经在注销流程，为了拿人才项目""配合股东工作"）——真实用途本身就是尽调信息，不要修饰成"战略布局"。
- 表后分析段："在子公司及对外投资方面，公司目前拥有××家控股子公司及××家参股公司，主要承担××等职能，业务主体架构较为清晰／存在多主体分散情形。若收入、核心资产或知识产权分散于不同主体，需进一步评估其对本轮投资主体完整性及未来退出路径的影响。"
- 低持股比例（<50%）主体、异地空壳主体、注销中主体逐一点名关注。无子公司则整节不设。

### 8.前五大客户及供应商（H3）

**写什么**：（1）前五（十）大客户——分年度表（T8：年度/序号/客户名称/销售金额/占当期营业收入比例/销售产品及数量，含合计行）；（2）前五（十）大供应商——同构表（T9）。表后各配一段集中度分析。

**为什么**：客户结构验证收入的真实性与质量（客户是谁、是否头部、是否持续复购），集中度暴露单一依赖风险；供应商结构暴露供应链依赖与外协程度。这也是与财务、业务交叉验证的枢纽。

**怎么写**：
- 引导句给口径："公司截至××年××月的前×大客户为："。金额单位全表统一（万元），占比给合计行。
- 分析段抓四点：前五大合计占比及趋势、单一客户占比是否过高、客户性质（央国企/上市公司/海外）、客户与供应商中是否出现同一主体或关联方线索（范例一中"亚太卫星宽带通信"既关联高管履历又是供应商——此类线索必须点出，写"需进一步核查关联关系及交易公允性"）。
- 本章只谈集中度与依赖度；收入结构、商业模式分析归主营业务章节，不展开。

## 第二节　（二）股权变动情况

这一节是全章的核心。回答四个问题：**股权是否清晰、控制权是否稳定、核心团队利益是否绑定、历史变动是否干净**。结构：先给"现在"（股东结构+穿透），再给"过程"（逐次变动），最后给"资本视角"（融资与估值汇总）。

### 1.股东结构（H3）

**写什么**：当前股东全表 → 股东身份识别段 → 穿透至自然人表。

**怎么写**：
- 引导句："当前公司有×名股东，股东及股权占比如下："
- 股东表（T10）：股东名称/持股比例/认缴出资额/实缴出资额/实缴出资日期/股东背景（或关联机构）。**股东背景列是投资人最增值的一列**（范例二逐行标注"创始人""员工持股平台""国中资本，财政部""呼卫军父亲"），务必利用资料与检索填实。
- 身份识别段逐类点名：谁是创始人；哪个是创始团队持股平台、谁任 GP/LP；哪个是员工持股平台；其余哪些是财务投资人、产业投资人、国资。（范例一："张勇为公司创始人；××合伙企业为创始团队持股平台，其中张勇为GP，××为LP；……其他股东均为公司的财务投资人。"）
- 穿透表（T11）：自然人股东/（名义比例）/穿透后股权占比。**代持直接在表内披露**（"鄢凤波（代持鄢泽洪股份）""呼景峰 0%（代持呼卫军股份）"），并在正文给核查指向："股权代持的形成原因、代持协议效力及还原安排需在尽调阶段核实。"
- 分析段回答核心指标（算法见 `data-and-tables.md`）：第一大股东比例、实控人合计控制比例、创始团队合计比例、员工平台比例、外部投资人合计比例；给判断："整体来看，公司控制权结构相对清晰／股权较为分散，核心团队与公司长期发展具有一定利益绑定。后续仍需结合公司章程、股东协议及历次投资协议，进一步核查是否存在特殊股东权利、股权代持、回购安排或其他可能影响本轮投资退出的条款。"

### 2.历史股权变动（H3）

**写什么**：设立时初始股权表 → 按时间逐次变动（1）（2）（3）…，每次一段事实描述 + 变动后完整股权表。

**为什么**：这是尽调级的写法（范例一全程如此）：逐次重演股权演变，任何异常——0元/低价转让、短期反复转让、突击入股、平价代持还原——都会自动浮出水面；每次变动后的股权表相互勾稽，防止"讲不通的股权故事"。

**怎么写**：
- 开头总括："公司于××年××月××日注册设立，经历×次股权变动，包括×次股权转让、×次增资。公司初始股权如下："+ 初始股权表。
- 每次变动的小标题："（1）××年×月，公司第一次股权转让"；正文一句式记录事实："××年×月×日，××将其持有的××%股权共计××万元以××万元转让至××"——**价格照实写，0元就写0元**；增资写"××以××万元投后估值出资××万元，认缴新增注册资本××万元，持股××%"。
- 每次变动后附股权表（T12：序号/股东/认缴出资/股权比例/实缴出资/合计行），逐表勾稽（比例合计100%、认缴合计=当期注册资本）。
- 异常变动不回避、不渲染，收束段统一给核查指向："公司自设立以来历次股权变动中存在多次0元／低价转让情形，相关定价依据、资金来源、完税情况及是否涉及代持安排，需结合工商变更文件及转让协议进一步核查。"
- 变动次数极多的后期公司，可压缩为"关键变动叙述+融资汇总表"（范例二写法：股东结构表直接接融资汇总表，不逐次重演）。

### 3.历史融资及估值情况（H3）

**写什么**：融资历史汇总表（T13：时间/投资方/股权占比/对应注册资本/投资额/投后估值/轮次）+ 估值演进分析段。

**为什么**：融资历史是资本市场对公司的定价轨迹。投委会关心：估值增长是否有业绩支撑、融资节奏与业务进展是否匹配、本轮估值与上轮的关系（是否倒挂）、历轮协议是否埋有对赌/回购/优先清算/反稀释条款。

**怎么写**：
- 引导句："公司历次融资及估值情况如下："+ 汇总表，按时间正序，同轮多个投资方分行列示。
- 分析段：估值从××（首轮）到××（最近轮）的倍数与时间跨度、对应的业务里程碑（若资料可证）；本轮融资的拟用途；收束到条款核查："后续需结合历轮投资协议，进一步核查是否存在对赌、回购、优先清算权、反稀释权或其他可能影响本轮投资权益的特殊条款。"
- 估值数字只能来自资料（协议/BP/访谈），检索可佐证但不可替代；测算的投后估值列公式。

## 第三节　（三）财务数据

本节只做"快照 + 问题提示 + 公司预测"，深度财务分析归财务分析章节。

### 1.核心财务数据（H3）

**写什么**：口径交代句 + 核心财务表（T14，三段式：资产负债核心指标/利润表核心指标/现金流量表核心指标，3–4 个报告期）+ 趋势分析段。

**怎么写**：
- 口径句必写："根据公司提供的××年度、××年度审计报告及××年×–×月财务报表，核心财务数据如下："——审计与未审口径分清。
- 表内固定指标：资产总计、负债合计、所有者权益合计、资产负债率；营业收入、营业成本、毛利率、销售/管理/研发费用、净利润、未分配利润（期末）；经营/投资/筹资活动现金流量净额、现金及现金等价物净增加额、期末余额。单位统一万元，千分位分隔。
- 分析段公式（两份范例同构）：**收入逐年数字 + 复合增长率 → 盈亏轨迹与归因 → 毛利率轨迹与归因 → 审慎提示**。例："××2023–2025年营业收入分别为××、××和××万元，三年复合增长率约××%，业务规模呈快速扩张态势。净利润方面……毛利率从××%提升至××%，反映××，但××季度回落至××%，需关注其后续持续性。"

### 2.存在问题（及对策）（H3）

**写什么**：（1）（2）…逐项问题，每项 = 事实数字 + 可能归因 + 待验证判断；有公司回应时如实转述并注明"据访谈／公司表示"，最后一句"关于上述财务发现的问题，将在尽调阶段进一步分析。"

**为什么**：这一节是本章"客观公允"的试金石——立项阶段就把持续亏损、毛利率波动、高负债率、现金流为负等问题摆上桌面，同时区分"公司的解释"与"我们的判断"。

**怎么写**：问题小标题直陈（"（1）持续亏损""（2）毛利率波动较大"）；归因用审慎语（"可能受益于早期定制化项目溢价或一次性订单结构""产品标准化程度、成本控制能力及议价能力有待验证"）；公司对策单独一段并保留"公司表示"的口径标记，不与本方判断混写。

### 3.财务预测（H3）

**写什么**：口径句"公司根据在手订单情况，对未来3年的财务预测如下：" + 预测表（分产品线收入/成本/毛利率，或年度收入/净利润简表）。

**为什么**：预测是公司自报口径，立项阶段照录并明确归属即可，不为其背书；预测与当期收入的跳跃幅度本身是信息，明显激进时加一句"预测实现的可行性需结合在手订单、产能及交付能力在尽调阶段验证。"

## 第四节　（四）合规、信用及重大风险事项

**写什么**：已核查范围说明 + 风险核查表（T15：风险类型/当前情况/影响判断/后续核查事项，覆盖诉讼仲裁、行政处罚、被执行/失信、股权冻结、经营异常、税务/环保/安全生产、劳动纠纷、知识产权纠纷）+ 待核查事项收束段。

**为什么**：不能简单写"无风险"——立项阶段的诚实写法是"核查了什么渠道、发现了什么、没发现不等于没有"。

**怎么写**：
- 没有发现问题时的标准句："在合规及信用情况方面，现有资料及公开检索未显示公司存在对持续经营构成重大不利影响的行政处罚、重大诉讼仲裁或失信被执行事项。"**禁止写"无风险"或空栏"无"。**
- 发现事项的逐条写：事实（案号/文号、时间、金额、状态）+ 影响初判 + 核查指向。
- 收束段固定给核查渠道清单："考虑到该部分对投资安全性影响较大，后续仍需结合企业信用信息公示系统、裁判文书网、执行信息公开网、知识产权数据库及税务、环保、安全生产等专项核查结果进行进一步确认。"
- 本章前文发现的关注点（代持、0元转让、参保差异、专利受让、关联交易线索）在此汇总入表，形成全章的"风险与待核查清单"。

---

## 第五节　（五）上市规划（条件节）

**写什么**：1.时间表（挂牌/升层/申报/审核的节点规划）；2.上市标准——目标板块的标准表（如新三板创新层四选一、北交所四选一）+ 逐条差距分析。

**为什么**：有明确上市规划的标的，退出路径是立项的重要考量。写法的关键是**差距分析**而非展望：公司现在满足哪条、不满足哪条、靠什么补上（范例二："当前股本总额668.53万股不满足要求，公司计划在基础层挂牌期间通过资本公积转增股本满足股本总额条件"）。

**怎么写**：标准表照录官方标准（可联网核对最新版本并注明年份）；差距分析逐条对照公司实际数据；收束句："公司当前业务及定位符合××要求，但财务数据尚不满足××标准，其改善路径的可行性需持续跟踪。"资料无上市规划则整节不设。

## 第六节　（六）公司情况综合判断

**写什么**：一段（至多两段）"事实基础 + 投资判断 + 待核查事项"的收束，回答八问：主体是否清晰、股权是否稳定、实控人是否明确、团队是否匹配业务、组织能力是否支撑当前阶段、核心资质资源能否支撑主营、有无重大合规瑕疵、哪些信息待补充。

**怎么写**：
- 标准句式："整体来看，公司主体设立及经营情况较为清晰，股权结构、核心团队及业务资源与其当前发展阶段具有一定匹配度。公司已围绕××业务形成基本的组织架构、人员配置及资源基础，为后续业务拓展提供了一定支撑。与此同时，后续尽调仍需重点关注历次股权变更的合规性、核心知识产权权属、特殊股东权利安排、核心团队稳定性及重大合规事项核查结果，以进一步判断公司主体质量及本轮投资的基础条件。"
- 待核查事项必须与前文一一呼应（前文没提过的不得在此突然出现；前文标了"待核查"的不得在此遗漏）。
- **绝不写成宣传总结**：不出现"优质标的""强烈建议"等字样；立项结论归报告的立项结论章节，本节只对"公司情况"作判断。

## 末节　结构自适应裁剪规则

按资料完整度与公司阶段裁剪骨架，条件节不启用时编号顺延：

| 情形 | 处理 |
|---|---|
| 早期公司（天使—A轮，几十人） | 参照范例一：无荣誉资质、无子公司、无上市规划则三节全裁；人员三表齐上；历史股权变动逐次重演 |
| 成长期公司（B轮后，数百人） | 参照范例二：人员结构简写（总数+研发占比+组织模式）；股权变动压缩为股东结构+融资汇总表；关联公司、荣誉资质、上市规划按资料启用 |
| 资料只有 BP、无工商与股权明细 | 工商信息联网补全；股权只写 BP 口径并整节标注"以下股权信息来自公司提供材料，尚未与工商登记核对"；历史变动节改为待核查清单 |
| 无财务资料 | （三）保留节标题，写"公司财务报表及审计报告尚未提供，核心财务数据待补充后完善"，不得用 BP 里的零散数字拼凑三张表 |
| 强监管行业（军工、医疗、金融、测绘等） | "荣誉及资质"提级为必写节且资质在前；缺关键牌照直接写入风险表 |
| 用户机构模板另有骨架 | 以用户模板为准，把本骨架的信息模块映射进去；模板未覆盖的关注点（代持、合规）以"存在问题"或"待核查事项"形式保留，不得丢失 |

裁剪的底线：**（一）工商信息、核心团队，（二）股东结构，（四）合规与待核查清单，（六）综合判断**五个模块任何情况下不可裁（资料不足则写明缺口），因为它们对应投委会不可让渡的四个问题：主体、控制权、团队、风险。
