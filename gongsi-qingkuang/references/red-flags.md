# 红旗模式库：四十年死法清单（按文档位置索引）

"四十年经验"落到工程上，就是一个按文档位置索引的失败模式库——投资人见过的每一种死法，都对应公司情况章节里的一个具体位置。**用法**：写完每一节，对照该节的红旗清单逐条扫描；命中的红旗按"**现象白描 ＋ 核查出口**"写入正文或风险表（白描不评论、不定罪，出口必须是具体的尽调动作）；未命中的**不写"无"**，不在正文里逐条否认。

三条纪律：

1. 红旗 ≠ 否决。绝大多数红旗是"需要一个解释"，不是"这个项目不能投"——立项阶段的任务是把它变成尽调任务，不是下结论。
2. 红旗的力量来自白描。"以0万元转让"五个字比任何评论都有力；渲染反而削弱可信度。
3. 每面红旗必须有出口。查什么文件、走什么渠道、问什么问题——写不出出口的红旗说明你还没想清楚它为什么危险。

## 一、工商信息处

| 红旗现象 | 为什么危险（见过的死法） | 核查动作 |
|---|---|---|
| 经营范围"许可项目"清单里的业务没有对应资质证书 | 无证经营：收入合法性存疑，严重的直接影响收入确认与估值基础 | 逐项对照资质证书；缺项的确认是否实际开展该业务 |
| 注册资本大、实缴比例低 | 认缴制下的"面子资本"；股东出资义务悬空，公司净资产虚胖 | 核对实缴凭证与验资报告；确认出资期限与本轮交割的先后关系 |
| 注册地址与实际经营地分离（尤其注册在税收洼地/园区） | 税收优惠依赖与迁址风险；返税政策退坡直接打利润 | 确认优惠政策依据、期限及占净利润比重 |
| 频繁更名、迁址、变更经营范围 | 主业漂移或规避性变更（诉讼、处罚、债务） | 调取全部工商变更记录，逐次问原因 |
| 成立时间与团队叙事、产品成熟度矛盾（公司4年、产品"十年打磨"） | 技术资产可能沉淀在前主体/前雇主，权属不在标的体内 | 追问技术来源主体；与知识产权受让记录交叉验证 |
| 登记状态非"在业/存续"、营业期限临近 | 主体本身有瑕疵 | 公示系统核验；问明原因 |

## 二、核心团队处

| 红旗现象 | 为什么危险 | 核查动作 |
|---|---|---|
| 核心成员前雇主是同行（范例一：多名高管来自天翌天线） | 竞业限制诉讼＋商业秘密纠纷，可在放量期精准引爆；整建制出走的团队风险加倍 | 核查竞业协议、离职时间与入职时间间隔、前雇主是否有主张记录 |
| 成员前雇主/兼职单位出现在客户或供应商名录（范例一：亚太卫星） | 关联交易非公允定价——收入或成本被"人情"扭曲，投后消失 | 关联关系披露＋交易定价公允性核查 |
| 高校教授/科研院所人员在职创业（范例二：呼卫军副教授在任） | 职务发明权属纠纷＋校方成果转化合规；上市审核的经典问题 | 校方成果转化批复、专利权属链条、教授坐班与利益冲突安排 |
| 核心技术人员不持股、不在员工平台 | 利益不绑定，B轮后被挖走带走整条产品线 | 核对股东表与激励安排；追问原因 |
| 关键岗位空缺（无 CFO/质量负责人）或由创始人兼任 | 财务规范化滞后，融资交割与上市申报时集中爆雷 | 确认补岗计划；本轮交割条件是否含关键岗位到位 |
| 履历时间断档、单位无法检索 | 简历注水 | 背景调查列入尽调清单 |
| 创始人年龄/背景与行业强绑定但无接班与授权安排 | 单点故障 | 关注决策集中度与组织成熟度（对照组织架构节） |

## 三、人员及组织架构处

| 红旗现象 | 为什么危险 | 核查动作 |
|---|---|---|
| 参保人数明显低于员工总数（范例一：49 vs 68） | 社保补缴负债＋劳动仲裁风险；上市申报硬伤 | 用工形式（劳务/外包/兼职）拆解；测算补缴敞口 |
| 员工总数下降但对外叙事"高速扩张"（范例一：72→68） | 现金流压力的先行指标，比财务表更早暴露 | 问明减员原因与去向；与经营现金流对照 |
| 研发占比与"技术驱动"定位不符 | 故事与组织不一致——要么故事假，要么执行弱 | 研发人员定义口径（是否含测试/实施）核查 |
| 人员结构里"其他"类占比过高 | 分类遮掩：可能藏着大量非核心或关联安排人员 | 要花名册明细 |
| 组织架构与业务规模明显错配（几十人设十几个部门，或数百人无职能线） | 早期过度架构=内耗；后期无架构=失控 | 对照发展阶段判断，写"阶段适配"评价 |

## 四、知识产权处

| 红旗现象 | 为什么危险 | 核查动作 |
|---|---|---|
| 专利状态为"转移取得"（范例一：多项"专利权的转移成功"） | 技术不是自研的：转让方是谁？对价多少？是否来自创始人前雇主或关联方？ | 转让链条、对价、转让方与团队的关系逐项核查 |
| 权属在创始人个人、高校或体外主体名下 | 投的主体没有技术——估值的核心资产在体外 | 确认转入安排为本轮交割前置条件 |
| 发明专利占比低、以实用新型和软著充数 | 壁垒叙事与IP结构不匹配 | 分项计数如实呈现（称谓准确），正文不写"技术壁垒深厚" |
| 大量"申请中"未授权 | 授权不确定；用申请数当授权数是常见注水 | 授权/申请分开计数 |
| 核心专利临近年费断缴或保护期尾声 | 花钱买过期壁垒 | 法律状态与年费缴纳记录核查 |

## 五、客户与供应商处

| 红旗现象 | 为什么危险 | 核查动作 |
|---|---|---|
| 单一客户占比≥30%（范例一：中国卫通 39%） | 大客户流失=收入腰斩；对央国企大客户还有账期与议价双重弱势 | 合同期限、续约历史、在手订单核查 |
| 客户与供应商名单重叠或同属一个集团 | 对倒做收入的经典结构 | 双向交易的商业实质与定价核查 |
| 客户为贸易商/集成商而非终端（范例一：多家"科技有限公司"中间商） | 收入的终端真实性存疑，渠道压货造假高发区 | 追问终端去向；期后回款核查 |
| 海外客户占比突增（范例一：2026Q1 境外客户跃升第一） | 出口合规（军民两用物项管制）＋回款风险 | 出口管制合规与结汇记录核查 |
| 前五大合计占比逐年剧烈波动 | 客户结构不稳定，收入可预测性差 | 逐年名单对照，识别"一次性客户" |
| 供应商单一来源且不可替代 | 卡脖子：断供或涨价直接打毛利 | 备选供应商与备货策略访谈 |

## 六、子公司及对外投资处

| 红旗现象 | 为什么危险 | 核查动作 |
|---|---|---|
| 为申报补贴/资质/人才项目设立的空壳（范例二白描："为了拿人才项目""为了项目申报"） | 补贴依赖＋清理成本；申报材料与实际不符的合规尾巴 | 逐家问真实用途（照实入表）；确认注销计划 |
| 低持股（<50%）主体承载实际业务（范例二：36%、40%、20%的业务主体） | 收入并不并表/并表存疑，且控制力不足 | 该主体收入资产占比、公司章程控制条款核查 |
| 与拟投资主体业务相同或相近的体外主体（尤其创始人控制的） | 同业竞争＋利益输送通道 | 穿透创始人及其近亲属的全部对外投资 |
| 注销中、吊销、经营异常的主体 | 历史遗留债务与担保可能回溯 | 注销进度、债务清理、对外担保核查 |
| 核心资产（房产、设备、IP）在兄弟公司 | 主体不完整，退出时资产装不进来 | 资产归属清单；重组安排为交割条件 |

## 七、股东结构处

| 红旗现象 | 为什么危险 | 核查动作 |
|---|---|---|
| 代持（范例一：鄢凤波代持鄢泽洪；范例二：呼景峰代持呼卫军） | 代持还原是上市硬门槛；代持人翻脸、离婚、死亡都会让股权悬空 | 代持协议效力、形成原因、还原时间表与税务成本 |
| 创始人持股比例过低（<20%）或股权过度分散 | 控制权不稳＋创始人动力衰减；后轮融资后可能失去实控地位 | 一致行动协议、AB股/委托表决安排核查 |
| 员工持股平台 GP 非创始人 | 平台表决权旁落，"员工激励"变成他人筹码 | 合伙协议 GP 权限核查 |
| 国资股东占比高但决策流程未安排 | 增资、转让、对赌都要走国资审批，交易节奏被锁死 | 国资监管层级与本轮交易审批路径确认 |
| 本轮前 6–12 个月内低价突击入股 | 利益输送或估值操纵；上市申报重点核查区 | 入股价格、资金来源、与公司/实控人关系 |
| 股东中有供应商、客户或其关联方 | 交易与股权的双重利益纠缠 | 与客户/供应商名录交叉比对（三角验证矩阵#3） |
| 明股实债线索（固定回报、远期回购由实控人担保） | 名义股权实为负债，资产负债表失真 | 历轮协议的回购与担保条款逐份核查 |

## 八、历史股权变动处

| 红旗现象 | 为什么危险 | 核查动作 |
|---|---|---|
| 0元/明显低价转让（范例一：多次0元转让） | 定价依据缺失＋个税追缴风险；常与代持形成/还原伴生 | 转让协议、定价依据、完税凭证、是否代持还原 |
| 设立股东与现任实控人不是同一批人（范例一：曹杲、高海超设立后一年内全部退出） | "公司到底是谁的"——设立背景可能藏着前雇主、竞业或借壳安排 | 设立背景访谈；初始股东与现团队关系核查 |
| 短期内同一股权反复转让 | 过桥、对倒或纠纷平仓 | 逐次问商业原因 |
| 增资价格倒挂（后轮单价低于前轮） | 估值下行信号＋前轮投资人反稀释条款可能已触发 | 每注册资本单价逐轮排列（公式8）；反稀释条款核查 |
| 出资以非货币资产（专利、设备）且作价高 | 出资不实：评估虚高的技术出资是抽逃出资的变体 | 评估报告与权属转移凭证核查 |
| 股权曾被质押、冻结、司法拍卖 | 控制权曾经/正在不稳 | 工商质押登记与解除记录 |

## 九、融资历史及估值处

| 红旗现象 | 为什么危险 | 核查动作 |
|---|---|---|
| 估值增速远超收入增速（范例一：18个月估值1000万→8000万，2023年收入741万） | 下轮融资难产→触发回购→挤兑式死亡螺旋 | 每轮估值对应的业务里程碑核查；本轮估值依据单独评估 |
| 估值倒挂或平轮 | 市场已投出不信任票；老股东反稀释与新股东压价的三方博弈 | 上轮条款与本轮条款的冲突点梳理 |
| 融资节奏过密（年年融资） | 烧钱模式未验证，融资依赖症 | 单位经济模型与经营现金流对照 |
| 投资方全是财务投资人、无产业方 | 缺产业背书与订单协同；也可能是产业方尽调后放弃 | 访谈是否接触过产业投资人及其反馈 |
| 融资中混入老股转让 | 创始人提前套现，动力与信号双重问题 | 老股转让的比例、价格、用途 |
| 历轮存在对赌/回购/优先清算/反稀释且触发条件临近 | 本轮进入即继承条款堆叠的"权利债务" | 历轮协议特殊条款全量清单（立项阶段至少列出"有/无/未知"） |

## 十、财务数据处

| 红旗现象 | 为什么危险 | 核查动作 |
|---|---|---|
| 持续亏损且经营现金流持续为负、靠筹资续命（范例一：三年经营现金流均为负） | 融资断档即死；本轮资金是续命钱还是发展钱要分清 | 现金跑道测算（月烧钱×现金余额）；本轮用途拆解 |
| 毛利率剧烈波动（范例一：4%→42%→24%） | 高毛利可能来自一次性定制项目，不可持续 | 分产品毛利拆解；订单结构核查 |
| 资产负债率快速攀升（范例一：18%→96%） | 资不抵债边缘，股东权益已被亏损吃穿 | 负债结构（经营性/金融性/股东借款）拆解 |
| 未分配利润深度为负且逼近实收资本 | 减资、清算优先权的实际价值受损 | 与估值谈判联动考虑 |
| 收入确认异常（Q4/期末突击确认、与参保人员规模不匹配的人均产出） | 收入注水 | 期后回款、人均产出横向对比 |
| 财务预测与当期跳跃过大（范例一：2025收入2806万→2026预测9690万） | 预测即融资故事；跳跃越大，在手订单的成色越关键 | "预测实现的可行性需结合在手订单、产能及交付能力在尽调阶段验证" |

## 十一、合规信用处（核查渠道即清单）

该节的红旗不靠资料自查，靠**渠道跑全**：企业信用信息公示系统（处罚/异常）、裁判文书网＋审判流程网（诉讼）、执行信息公开网（被执行/失信/限高）、工商质押冻结登记、信用中国（联合惩戒）、税务/环保/应急管理部门公示、知识产权局（权属与纠纷）。跑过的渠道写进"当前情况"列（"公开检索未显示"），没跑的渠道就是待核查清单条目。**任何渠道都不能用"公司说没有"替代。**

## 十二、红旗的组合拳（单旗可解释，组合即模式）

单面红旗通常有合理解释，**多面红旗指向同一方向时构成模式**，正文的"存在问题"或综合判断应点出组合而非单点：

- **0元转让 ＋ 亲属代持 ＋ 教授在职** → 高校成果转化未走正门的全套特征（范例一三旗齐全）——核查重心：校方合规文件是否存在。
- **估值飙升 ＋ 收入低基数 ＋ 回购条款 ＋ 现金流为负** → 回购挤兑的完整燃料——核查重心：回购义务人是公司还是实控人、触发时间表。
- **客户集中 ＋ 客户即前雇主关系网 ＋ 应收高企** → 收入的"人情成色"——核查重心：离开这层关系收入还剩多少。
- **多子公司 ＋ 低持股业务主体 ＋ 补贴依赖** → 主体不完整＋利润不可持续的双重折价——核查重心：装进来要花多少钱、多少时间。
- **参保差异 ＋ 人员下降 ＋ 毛利率跳升** → 用裁员和社保欠缴"做"出来的利润——核查重心：还原真实成本后的毛利。

组合拳的写法仍遵守语法：每一旗白描事实，组合判断放在"存在问题"或综合判断节，用"上述事项相互关联，需在尽调阶段统筹核查"收口，不用阴谋论语气。

**组合命中后必须在（六）综合判断节明确点名，不得拆散稀释。** 单条红旗各自出现在对应小节时按常规"现象白描＋核查出口"处理即可；但写到（六）综合判断前，回头检查本章是否命中本节任一组合模式（或结构相似的新组合）。命中时，综合判断不能把几条红旗拆开分别揉进"股权较为清晰／团队具有一定匹配度"这类常规措辞里——那样每条单独看都有"合理解释"，组合的危险信号会被措辞的中性口吻抵消掉。正确写法是把组合作为一个整体单独陈述（具体句式与位置见 `structure.md` 第六节），让投委会看到的是"这几件事连在一起意味着什么"，而不是四条互不相关的注脚。这是本库唯一要求"跨小节主动关联"的场景，其余红旗各自落在命中的小节即可，不必强行关联。
