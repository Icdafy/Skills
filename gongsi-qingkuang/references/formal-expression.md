# 书面公文表述

本文件规定立项报告三章（所属行业分析、主营业务分析、公司情况）的行文语体：用什么句式、什么词、什么口吻。写法提炼自本机构实际上会的多份立项报告终稿，逐句比对了初稿到终稿的改动；文中例句的公司、人名、数字均为虚构，只示范句式。三个技能共用本文件，内容完全一致。

判断语体是否合格的标准：把成稿任意一段单独拿给投委会委员，对方看不出是模型写的，也看不出是口头汇报的记录；每句话删去后都会少一条事实、一个判断或一层关系。

论证怎样搭、上下文怎样接，见 [硬逻辑论证](hard-logic.md)。两份文件同时执行：本文件管“怎么说”，另一份管“说得对不对、站不站得住”。

## 一、立项报告的语体特征

实际终稿在语体上有九个稳定特征，起草时逐条对照。

1. **陈述主体是事实和对象，写作者不出场。** 主语用“公司”“该产品”“上游环节”“本轮融资”，不用“我们”“笔者”。本机构自己的动作用“我司”“我方”“项目组”，只在投资方案、立项结论和尽调安排处出现。
2. **判断句短，依据句实。** 判断用一句话说完，紧跟主体、时间、数字俱全的依据。全文几乎没有不带数字或具名事实的自然段。
3. **用“××方面，”分领域起句。** 概况、业务开展、财务等并列内容，以“行业及市场方面，”“财务方面，”“生产及经营方面，”起句，一段一领域，不用“首先、其次、此外”。
4. **节首有导语。** 一节开头先给本节结论，再交代下文从哪几方面展开；随后的小标题与导语一一对应。
5. **先定义后使用。** 专门口径第一次出现即用“所称××，指……”界定；简称在全称处括注一次，全文不换。
6. **归属写清。** 公司单方说法、预测、测算一律带归属（“据公司介绍”“公司预计”“据公司测算”）；审计数、工商登记、已签合同直接陈述并交代口径（“按审计报告口径”）。
7. **优势与限制写在一处。** 写完进展，紧接着用“但”“仍”“尚”交代现阶段的限制，再用“取决于”“以……为准”交代条件，一句写完，不拖到文末，也不反复追加。
8. **表前有引导句，表后有结论句。** 表前一句交代看什么，表后一句说出从表里得出的判断；正文不逐行念表。
9. **用词克制。** 程度词后面跟数字；没有数字的程度词删去。全文没有感叹、反问、比喻和口号。

## 二、功能句式库

按句子在文中承担的功能取用。句式是骨架，内容全部来自当前项目资料。

### 1. 定性定位句（一章、一节、一个板块的第一句）

- `××是……与……融合形成的新兴方向，正处于由技术验证向商业应用过渡的阶段。`
- `公司以……为核心产品，向……延伸，为……提供……解决方案。`
- `××环节承担将……转化为……的任务，竞争重点集中于……、……和……。`
- `××系公司核心产品。现阶段A、B型号已定型并对外销售，C型号处于研发阶段。`
- `公司核心成员覆盖经营管理、技术研发、产品开发、市场及融资等岗位。`

定位句写三样：对象是什么、处在什么阶段或位置、往哪个方向走。不写“随着……的发展”“在……的大背景下”之类铺垫。

### 2. 分领域起句

- `行业及市场方面，……` `公司业务方面，……` `财务方面，……` `在交易层面，……`
- `产品研发及验证方面，……` `场景验证方面，……` `生产及经营方面，……`
- `业务布局方面，……` `市场拓展方面，……` `配套服务方面，……`

同一组并列段落用同一种起句方式，领域名称取自本节内容，不生造。

### 3. 导语与预告句

- `以下从市场需求、技术路线、商业化进程和政策支持四方面梳理行业现状。`
- `公司主要产品按A、B和C三部分列示。A为核心交付内容，B为应用延伸方向，C主要服务于试验及现场保障。`
- `公司核心技术围绕……展开，主要体现在A、B、C及D四个方面。`
- `主要业务情况如下。` `主要参数如下。` `具体如下：` `各主体及场地安排如下：`

预告了几方面，下文就写几方面，顺序相同。

### 4. 定义与口径句

- `所称长距离作业，指单程50公里以上需返航或单次连续作业2小时以上的任务。`
- `本节所称在手订单，指已签署合同且尚未完成交付的项目；意向订单指已形成书面意向但尚未签约的项目。`
- `以相同载重为对比前提，各路线储能系统统一折算至同一重量，能源价格取2030年规模化口径。`
- `按审计报告现金流量表口径，……` `按订单条数统计，同一客户不同产品分别计列。`

### 5. 数据陈述句

- `公司2023年、2024年和2025年营业收入分别为1,200.50万元、2,350.80万元和3,120.36万元，三年复合增长率约61.22%。`
- `2025年前五大客户收入合计2,105.40万元，占全年收入的67.47%。`
- `截至2026年6月30日，公司共有员工86人，其中研发人员41人，占比47.67%。`
- `国家能源局数据显示，截至2025年底……` `××证券研究报告列示，2023年市场规模约……亿元，预计2030年达到约……亿元。`
- `该产品单价约6万元，海外同规格产品售价约2.5万美元。`

数字句的固定成分：时点或期间、主体、指标名、数值和单位，必要时加口径和来源。连续列示多期数据用“分别为……、……和……”，不逐期重复主语。

### 6. 归属句

| 事实性质 | 写法 |
|---|---|
| 审计、工商、证书、已签合同 | 直接陈述，必要时写口径：`根据公司提供的2023—2025年度审计报告，……` |
| 公司对事实的解释 | `公司解释，……` `据公司介绍，……` `公司称……` |
| 公司的计划和预测 | `公司计划……` `公司预计……` `公司最新预计2026年营业收入为……` |
| 公司的测算 | `据公司结合在推场景所作初步测算，……` |
| 公开数据 | `××数据显示，……` `××发布的研究报告列示，……` `公开报道显示，……` |
| 本方判断 | `总体判断，……` `整体来看，……`（依据须已写在前文） |
| 本方安排 | `我方拟以……为投资主体，投资不超过……万元。` `立项后重点围绕……开展尽调。` |

同一段内同一来源交代一次即可；不为减少归属而把公司说法写成既成事实。

### 7. 比较句

- `公司产品整机重量5.8公斤，海外同规格产品为5.1公斤；售价6万元，约为后者的三分之一。`
- `相较于传统方案采用……，公司采用……，驱动部件重量降低50%—70%。`
- `同等作业量下，方案A全生命周期成本为95元/作业小时，方案B为210元/作业小时。`
- `A公司公开产品主要面向固定式场景，B公司已有同规格移动式产品，两者与公司产品的用途和设计要求有所不同。`

比较句必须有具名对象、相同前提和双方数值；只有一方数值的不叫比较。

### 8. 因果与推进句

- `……，××由此构成前置条件。` `由此形成按场景分工的格局：……`
- `作业区向偏远地区延伸后，补能节点减少，保障成本随之扩大至整条线路。`
- `线路里程增加与站点向偏远地区延伸，同步提高巡检距离与现场保障要求。`
- `对配套企业而言，稳定的材料和部件供应有助于提高试制效率，并降低后续交付波动。`
- `上述要求通过整机采购或作业服务采购，传导至制造及动力配套环节。`

因果句的原因必须已经写在纸面上。优先用动词本身表达因果（“决定”“影响”“带动”“传导至”“取决于”），少用“因为……所以……”。

### 9. 限制与条件句

- `但现有合同仍以测试及小批量交付为主，批量销售尚未形成，后续转化取决于示范项目采购与认证进度。`
- `上述标准目前以团体标准层级为主，具体以主管部门规定和审批结果为准。`
- `相关区域建设资金及采购计划不构成已取得的订单。`
- `现有认证针对A型产品，不代表其他型号已取得同等认证。`
- `实际采购仍以招投标结果及合同约定为准。` `部门人数不等同于直接从事研发的技术人员数量。`
- `该预测以示范项目验证、采购转化及产能建设进度为前提。`

限制句只写具体事实及其影响，一处一句。

### 10. 时间节点句

- `2024年7月，公司与……共同研制的样机完成运行测试。`
- `截至2026年6月，公司共有9名股东，其中自然人5名、机构4名。`
- `本轮融资完成后，公司拟建设约2,000平方米中试基地。`
- `2026—2027年拟推进……示范项目，2028—2030年逐步扩大……规模。`

“目前”“近期”“近年来”换成具体年月；确实只能概括时用“现阶段”“截至本报告出具日”。

### 11. 表前引导句与表后承接句

- 表前：`各路线主要指标对比如下。` `公司设立后的主要研发及应用节点如下：` `2025年前五大客户如下，单位为万元：`
- 表后：`上表差异决定了各路线当前的适用边界。` `五名客户中三名为科研院所，收入集中于测试服务。` `意向订单金额较集中于单一大型项目，其余12项合计380.00万元，主要为中小批量测试及样机配套。`

表后句写表里读得出的结构性结论（集中度、差距、趋势、异常项），不复述各行数字。

### 12. 计划与安排句

四个词分别对应四种状态，不混用：

| 用词 | 状态 | 例 |
|---|---|---|
| 已 | 已完成 | `已取得` `已签署` `已实现对外销售` `已完成适配` |
| 正在／处于 | 进行中 | `正在开展性能验证` `处于研发阶段` `处于送审稿完善阶段` |
| 拟／计划 | 公司的安排 | `拟建设中试基地` `计划于2026年内开展示范` |
| 预计／有望 | 对结果的预期 | `公司预计2027年交付` `有望进一步巩固工程应用优势`（少用） |

### 13. 节末收束句

- `总体判断，在需求释放、技术路线收敛和政策支持的共同作用下，2026—2030年该类装备将由试用验证走向专业应用。`
- `现阶段业务推进仍以小批量交付和具体场景验证为基础，中长期规模扩张须以订单转化、生产能力及供应保障同步落实为前提。`

收束句只归纳本节已写内容，一节至多一句；没有新判断时不写。行业、主营、公司情况三章均不写“建议立项”“值得投资”，投资结论属于立项结论一章。

## 三、书面用词

### 1. 常用书面虚词

| 词 | 用法 | 例 |
|---|---|---|
| 系 | 判断、说明原因 | `该设备系公司主营产品的配套设备` `主要系研发投入较高所致` |
| 为 | 判断、数值 | `李某为公司实际控制人` `资产负债率为42.16%` |
| 均 | 全部 | `四名自然人均为联合创始人` |
| 亦 | 也 | `学校亦参与相关国家重点研发项目` |
| 尚／仍 | 还没有／还在 | `尚未形成规模化收入` `仍主要来自贸易业务` |
| 已／拟／将 | 完成／打算／将来 | `已定型` `拟申请` `将影响商业化节奏` |
| 其／该 | 指代紧邻上文的唯一对象 | `其牵头起草的团体标准` `该产品面向小型平台` |
| 于／至／自 | 时间、处所 | `成立于2021年3月` `2024年至2025年` `自2010年起` |
| 以／按／据 | 方式、口径、来源 | `以储能变流器为核心产品` `按业务类别划分` `据公司介绍` |
| 并／及／暨 | 并列 | `完成适配并推进场景验证` `客户及供应商` |
| 故／由此／因此 | 结果 | `故设立公司` `由此形成……格局` |
| 约／近／超过／不超过 | 约数与界限 | `约800平方米` `不超过3,000万元` |
| 分别／合计／其中 | 分项与汇总 | `分别持股11.25%` `合计持股76.50%` `其中全职32人` |

文言虚词只取公文通行的这一批，不写“之乎者也”，不写“鉴于此”“兹”“特此”（那是请示、通知的用语，不是报告正文的用语）。

### 2. 动词用准

- 表进展：取得、完成、实现、形成、通过、获得、签署、交付、定型、投产、适配、验证。
- 表安排：拟、计划、推进、开展、建设、申请、对接、筹建。
- 表关系：依托、承担、负责、提供、配套、采购、归口、牵头、参与。
- 表影响：决定、影响、制约、带动、传导至、有助于、有利于、取决于。
- 表数量变化：增长、增加、下降、回落、提升至、由……降至……、同比增长、较上年增加。

一个动作一个动词，不叠用“进行……的开展”“实现了……的提升”。`对产品进行了升级` 改 `升级产品`；`实现了收入的增长` 改 `收入增长`。

### 3. 名词用实

用可核对的名词替代概括性名词：`头部客户` 改成客户名称；`核心技术` 后面写出技术名称；`多项专利` 写 `专利17项，其中发明专利6项`；`较长时间` 写 `约18个月`；`相关部门` 写出部门名称。

## 五、机器腔与改法

以下写法一出现即被识别为模型成文，正文一律不用；`scripts/style_check.py` 对其中可机械识别的部分报错或告警。

| 类别 | 表现 | 改法 |
|---|---|---|
| 对话痕迹 | “好的，以下是……”“希望以上内容对您有帮助”“如需进一步……” | 删去；正文从标题或第一句事实开始，以最后一条事实结束 |
| 提示性引子 | “值得注意的是”“需要指出的是”“不难看出”“众所周知”“可以说” | 删去引子，保留后面的事实 |
| 对举绕行 | “不是……而是……”“不仅……更……”“与其说……不如说……” | 直接写肯定的那一半；确需对照时拆成两个事实句 |
| 三连排比 | “高效、精准、智能”“更快、更稳、更省” | 保留有数据的一两项，写出数据 |
| 空泛拔高 | “前景广阔”“潜力巨大”“未来可期”“意义重大”“具有里程碑意义” | 换成规模、增速、订单、节点等事实 |
| 比喻与口号 | “护航”“引擎”“基石”“赋能”“打通最后一公里”“驶入快车道” | 写实际作用：谁、做了什么、带来什么数值变化 |
| 铺垫式开头 | “随着……的不断发展”“在……的大背景下”“近年来，……” | 第一句直接写判断或事实；背景确有必要时写具体年份和文件 |
| 机械连接 | 段首“首先／其次／再次／最后”“此外”“另外”“与此同时”“除此之外” | 并列项用“一是……二是……三是……”或“××方面，”；递进靠内容承接 |
| 段尾总结 | 每段末尾“综上所述”“总而言之”“由此可见”“这充分说明” | 删去；一节至多一句收束，且有新判断 |
| 尾巴式保留 | “仍需进一步观察”“有待后续验证”“需持续关注” | 写出已知限制及其影响；补证事项放正文外清单 |
| 堆叠不确定词 | “可能或许在一定程度上有望” | 只留一个，并写明条件 |
| 冒号小标题句 | “核心优势：……”“风险提示：……”“结论：……” | 改成完整的判断句；标题只用模板规定的层级 |
| 破折号解释 | “……——即……”“……——这意味着……” | 改成两个句子或括注 |
| 自问自答 | “那么，公司的优势在哪里？” | 直接陈述 |
| 泛指主体 | “业内人士认为”“有观点指出”“据了解” | 写出机构、文件或人名；写不出则删去 |
| 互联网与咨询黑话 | “抓手”“闭环”“打法”“风口”“蓝海”“颗粒度”“对齐”“心智” | 换成业务事实 |
| 中英夹杂 | “ToB端”“solution”“roadmap”“pipeline”（非专有名词） | 用中文；专有名词、型号、单位保留原文 |
| 过度对称 | 每节都是三点、每点都是“定义—优势—意义”同一长度 | 按事实多少安排篇幅，主次分明 |
| Markdown 痕迹 | 正文出现 `#`、`*`、`-` 列表符、表情符号 | 交付文本只保留模板标题层级、加粗论点句和表格 |

## 六、称谓与人称

1. 拟投资企业全称首次出现时括注简称，其后只用“公司”或简称；不用“标的公司”“目标公司”“该企业”“贵司”。
2. 本机构自称“我司”“我方”；项目团队自称“项目组”。三章正文原则上不出现本机构，只有涉及本方尽调安排处才出现。
3. 人名首次出现写全名和职务，其后用全名，不用“李总”“王博士”“创始人老李”。
4. 机构首次出现用全称或通行简称并交代其与公司的关系（客户、供应商、合作方、股东、竞争对手、归口单位）。
5. 行文不出现“你”“您”“大家”“小编”“笔者”“本人”。

## 七、数字的书面写法

1. 整数部分满四位的数量每三位加半角逗号：`2,350万元` `12,000台` `1,530.6122万元`；年份、文号、标准号、型号、电话、证件号、专利号、证券代码不加。
2. 数值范围两端都带量级和百分号：`7万—10万元` `15%—30%`；单位不含“万、亿”时只在末尾写：`30—40套`。
3. 约数只用一个标记：`约800平方米`，不写“约800平方米左右”“大概800多平方米”。
4. 金额以万元为单位保留两位小数，大额可用亿元；比率保留两位小数；同一张表小数位一致。
5. 同一指标全文数值、单位、时点一致；摘要、正文、表格三处核对。
6. 增长写清基期和报告期：`2025年营业收入3,120.36万元，同比增长32.74%`；基数小的增长率后面补一句基数。
7. 占比写清分母：`占全年收入的67.47%` `占意向订单金额的46.20%`。
8. 数字与单位之间不空格；百分号、单位符号用半角。

## 九、实际报告中出现、不沿用的写法

实际终稿并非处处可学，以下写法在审阅中被反复指出：

- `展现出巨大的发展潜力` `技术壁垒高、稀缺性突出` `具有稀缺性、唯一性与不可替代性`：无对标、无数据的拔高，改为对标结果或删去。
- `我们认为……`：改为“整体来看”或直接下判断。
- `市占率达80%，居全国第一`：未写口径和来源的排名，补“据公司介绍，在……口径下”，并列出最接近的竞争者。
- `大幅提升` `显著改善`：补数字。
- 概况段与后文数字不一致、同一订单金额前后两种写法：以最新口径统一。
- 一句话超过120字、套三层以上定语：拆句，每句一个主谓结构。
- 金额未加千位分隔符、数值范围只在末尾写量级：按第七部分改。

## 十、成文前自查

1. 每段首句是否为判断或核心事实，能否单独成立。
2. 是否存在不带数字、不带具名事实的段落；有则补依据或删去。
3. 公司说法、预测、测算是否全部带归属；审计与工商数据是否写明口径。
4. “已、正在、拟、预计”四类状态是否用对。
5. 全文搜索第四、第五部分所列口语和机器腔，逐处改写。
6. 程度词（大幅、显著、明显、较高、较强）后面是否有数字。
7. 称谓是否全文一致，是否出现“标的公司”“我们认为”“笔者”。
8. 每张表前是否有引导句，表后是否有一句结论。
9. 数字是否按第七部分书写；同一指标各处是否一致。
10. 通读一遍：是否有读起来像口头汇报、宣传稿或教科书的句子。
