# 公司情况写作工艺

> 标题以用户选择的 `assets/templates/early.json` 或 `mid-late.json` 为唯一来源。本文件的旧例仅说明标题内部的内容写法，不能用于选阶段、改题、裁剪、合并或新增章节。先执行 [阶段模板规则](stage-template-workflow.md)。

写作者是本机构负责项目的投资团队成员，读者是内部立项评审人员。直接把已经完成的梳理和分析交代清楚。完整证据保存在台账，正文让读者理解公司及其对立项判断的影响。

## 第〇节　语言红线

1. 称谓以“公司”和章内定义的简称为主，不用“标的公司”“目标公司”。描述本方工作时可以用“我们”或“项目组”，不能把被研究公司和本机构混为一方。
2. 不写“不是……而是”“并非……而是”“不仅……而且”等对举句式。直接陈述事实，需要转折时自然使用“但”“仍”“而”。
3. 删除“值得注意的是”“综上所述”等无信息的引子，以及“赋能”“行业领先”“前景广阔”等缺少证据的宣传词。正文不用感叹、反问、编辑留言或“核心结论：”式标签。
4. 以核心事实或判断起段。不要把“在……方面—整体来看—后续仍需”固定成段落模板，不要求每节都有总结句。
5. 不以外部顾问口吻向团队派任务：“应核查”“应该关注”“建议投资方”“需对……进一步核实”均须检查改写。先完成能够完成的分析；必要后续核查进入正文外清单；正文直接写明当前结论及证据边界。不能只替换“应”为“将”而保留整段任务罗列。
6. 报告正文、表头、表注不出现资料文件名、附件编号、回复轮次或 V9、V10.0 等材料版本号。文号、法规施行年份、真实产品型号及标准版本属于事实，不在此限。确实影响判断的方案变更用业务日期和条款变化说明。

## 第一节　直接汇报已经完成的分析

自然段围绕一个问题展开：先讲重要事实，再说明彼此关系及影响。不同段落可有不同长度，不强制为每句话分类，不机械加入“具有一定匹配度”等空泛限定。

| 容易写成的指导意见 | 报告应完成的工作 |
|---|---|
| 应分别考察在手订单与意向订单 | 分设已签订单和意向项目，写清金额、签约状态与预计交付时间 |
| 应核实贸易业务利润水平 | 算清售价、采购价和运输成本，说明价差及尚未包含的费用；依据现有数据给出有边界的判断 |
| 后续应关注大客户回款 | 写明客户收入占比、已知尾款及业务是否暂停，说明对收入延续和资金周转的影响 |
| 相关合同和成果归属应一并核查 | 正文交代现有合作关系及已知权属安排；未解决的协议或审批问题进入核查清单 |

事实充分时判断可以直接结束段落。只有后续核查确实影响当前判断、且交代计划有助于读者理解时，正文才保留一句本方工作安排。法律义务、合同约定中原有“应”字可以保留，不作机械替换，也不虚构已核实、已落实或必将发生的行动。

## 第二节　表格与正文各做什么

表格适合多项记录的同口径比较，如股东、历次融资、人员结构、专利及客户供应商明细。正文解释创办经过、任职关系、股权集中度、业务分工、经营变化和数据差异。

- 表前交代对象、时点、单位等必要信息，表头直接用“人数”“占比”“融资轮次”“投资方”，不写“回复更新名册人数”“材料所列轮次”。
- 表后不逐行重复姓名、金额和比例。选择对当前判断有意义的关系，例如创始团队合计持股、单一客户占比、收入与回款的差异。
- 几项资金用途可用一段自然文字交代；跨年度、跨方案且需要比较时才用表。
- 数据对账、重排顺序、改过哪些字、为何保留几位小数等过程留在底稿。表注只保留理解数据所需的口径，如含税与不含税、净额分母、授权与申请状态。
- 不因追求简洁删除已知重大差异，也不把全部细枝末节升级为风险。用户明确删去的段落不自动恢复；发现其涉及实质问题时，在交付说明中简明提示并保留原始依据。

## 第三节　来源归属与材料版本

来源可追溯通过事实台账实现，不能靠每句话重复“公司在尽调回复中表示”。台账记录文件名、版本、页码、统计时点、证据类型及计算式。

可验证的工商、股东、人员、履历等事实直接写“公司共有……”“某人任……”。如目前只有公司介绍而缺少佐证，在相应段首或整组表格前注明一次；同一来源连续陈述不反复挂牌，但跨段、换来源或切换到本方判断时保持归属清楚。

以下口径必须保留：

1. 财务数据的期间及证据性质：审计报表、未审报表、公司提供的收入明细汇总分清。没有审计报告不能写成审计口径。
2. 公司解释、仅口头提供的信息、尚待完成的计划：用“公司解释”“据访谈”“公司拟”等明确归属。删掉机械来源句不等于提高证据等级。
3. 预测和意向：始终是“公司预计”“意向项目”，不能变成确定收入、已签合同或完成的成果。

| 材料整理式表达 | 自然表达 |
|---|---|
| 公司股东表列示共有若干股东 | 截至相应时点，公司共有若干股东 |
| 公司在尽调回复中将某人认定为实控人 | 证据充分时直接说明实际控制人；只有公司说法时写“公司介绍，……”并保留证据边界 |
| 回复某版本列示若干项在手订单 | 公司在手订单共若干项，已签合同金额合计……，公司预计于……交付 |
| 按两份花名册分别统计如下 | 先区分统计时点，采用已确认适用的人数，旧名单及人员变动过程留底稿 |

不同版本先判断是否已经明确更新替代、是否属于不同时间或统计口径。已确认更新，采用有效口径；矛盾未解且影响判断，说明业务事实和差异，不把版本流水写进正文。不能只因版本号较大就选定数据，也不能为保持一致擅自改数。

## 第四节　几类重点段落

### 本轮融资

简明交代拟融资金额、估值及投前/投后口径、主要用途。数额勾稽正确，区分本轮和后续融资。一般不展开多轮磋商、版本变迁、完整稀释公式和每项用途的操作清单；用户要求或条款确实影响控制权时再展开。方案仍在磋商时写“拟”，不能把计划写成已完成融资。

### 财务与经营问题

标题写实际问题，如“贸易价差较薄”“大客户业务暂停”，不用“需核实”“应衔接”给任务命名。正文给数据、解释必要关系、形成结论。报价差额不等于毛利或净利润，合同额不等于确认收入，半年占全年比例不等于同比增速。已知差异暂不能解释时，可直接判断“当前结算口径尚不一致”，不以虚构税率或假设替资料圆数。

### 预测与订单

先呈现公司预测，再将已签合同与意向项目分别列示，明确数量、金额、状态及预计交付期间。已有收入另列；区分合同总额、剩余履约金额、收款及已确认收入。口径未统一或有履约重叠时，不把三者直接相加，不用未经核对的合同额测算收入覆盖率。用当期实绩与全年预测算出后续需实现的收入，再说明其依赖的签约、交付、产能等条件，不能只写“应分别考察”。

### 团队、专利及关联主体

团队说明任职、全职/兼职、关键履历及分工；专利区分授权、申请及受让；关联主体讲与本项目有关的关系和功能。无关任职清单、无实质影响的名称差异、重复核查结尾不堆入正文。公司自述的归属安排不能替代已完成的转让或审批事实。

实控人或创始人在其他企业的任职、持股，写明时点状态（曾任/现任/至今仍持有）和该企业与公司的关系；一个“前”字无法让读者判断是“以前是、现在不是”还是“一直是”。荣誉、资质、标准和项目写明授予或组织单位及层级（国家/部委/省/市/协会、国标/行标/团标），读者据此判断分量。

### 股东、对赌与估值

控股股东或实际控制人在设立背景首句交代姓名、直接及穿透持股、背景；融资表逐轮列估值、对赌及回购（义务主体、触发条件）和其他特殊条款；对赌与回购义务主体必须写明是公司、实控人还是二者共同。用户要求论证估值时，按 `structure.md`“估值合理性论证”写可比估值、增幅及里程碑依据。

### 数字、括号与用词

数值范围两端都带量级和百分号：`300万—350万元`、`15%—30%`，不写 `300—350万元`；单位不含“万/亿”时可只在末尾写，如 `30—40套`。中文语境用全角括号。规范用词：来自（非“来自于”）、黏度（非“粘度”）；履历罗列用“先后任”。`scripts/style_check.py` 会扫描前三项。

## 第五节　成稿质检清单

1. 作者始终是本方项目团队，研究对象与“我们”区分明确？
2. 能完成的分类、计算和判断已经完成，正文没有把分析任务留给读者？
3. 逐项反馈均已落实，删除、替换、整段重写及表格删除意图已区分；编辑留言未留在成稿？
4. 每段围绕一个事实关系或判断，首句写结论，读者不会问“这段想表达什么”；未机械复述表格，未套“四拍”结尾？
5. 正文、表头、表注没有材料版本号、回复轮次及制作过程？
6. 每个重要事实可溯源；数据期间、单位、证据等级、计划状态清楚？
7. 公司解释与本方判断分开，同组来源不过度重复，也没有把未经证实的说法升级为事实？
8. 融资金额、估值与用途简明一致，本轮与后续融资分清？融资表逐轮列估值、对赌及回购（含义务主体）和其他特殊条款？
8A. 控股股东/实控人的直接及穿透持股、背景已在设立背景处交代？实控人关联的同名、近名企业关系及任职时点已写清？
9. 财务问题有客观数据及有依据的结论，未堆砌核查任务？
10. 已签订单、意向项目、确认收入分开，重复履约、税额及期间差异未被错误加总？意向订单已按业务板块拆项数、金额及占比，深度合作或绑定大客户已写清？
11. 股权、人员、融资、客户、财务及预测的必要勾稽通过；不靠改数消除差异？
12. 实质性风险与未解矛盾没有遗漏，细节及核查动作按重要性留在底稿或随稿清单？
13. 语言红线、标题层级及章节边界通过；Word修订结构、表格和分页已检查？
14. 早前期：设立背景以实控人及实际持股开篇并附工商表与节点表；资质表后写清资质覆盖范围；本轮融资一段写完；财务问题在核心财务数据分析段内写清；意向订单按年份与板块两种口径拆分？
15. 与行业、主营两章交叉的数字（合同项数与金额、认证与试飞时间、产品状态、人员数量、估值）完全一致？

机械扫描使用 `scripts/style_check.py`。扫描只定位疑点；自然行文、判断质量、来源作用域及证据边界仍需逐段阅读。
