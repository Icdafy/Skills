# 公文常用字体

本目录随技能自带以下公文排版字体，供生成 `.docx` 立项报告时使用：

| 文件 | 字体 | 用途 |
|---|---|---|
| `simfang.ttf` | 仿宋 / 仿宋_GB2312 | 三级及以下标题、正文、核心结论（16pt） |
| `方正小标宋简体.ttf` | 方正小标宋简体 | 公文大标题 |
| `楷体_GB2312.ttf` | 楷体_GB2312 | “（一）（二）”层级标题（16pt 加粗） |

## 自动检测与安装

生成公文前运行：

```bash
python ../../scripts/ensure_fonts.py          # 检测并按需安装
python ../../scripts/ensure_fonts.py --check  # 仅检测缺失，不安装
```

脚本会检查本机是否已安装上述字体；若缺失，则从本目录复制到当前用户的字体
目录（Windows: `%LOCALAPPDATA%\Microsoft\Windows\Fonts`，无需管理员权限）。
