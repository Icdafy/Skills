# 产业链深挖手册（价值占比 / 竞争格局标签 / 表格式与散文式 / 专属指标与表）

本文件是「（二）产业链分析」的**深挖工艺手册**，在 [01-framework.md](01-framework.md) 第五节（投委会五问 + 五步法 + 细分赛道拆分）的框架之上，补齐把产业链写到投委会级深度所需的定量方法、呈现范式、标签体系与措辞纪律。01-framework 解决"产业链这一节的骨架与五问"，本文件解决"如何把价值占比写透、如何给环节定性、用表格还是散文、数字怎么算怎么核"。

## 何时启用深挖

产业链卡位是这笔投资主逻辑时，务必按本文件深挖：拟投资公司处于价值量集中的核心零部件 / 关键器件 / 系统集成环节，硬科技、先进制造、半导体、卫星通信、机器人、新能源等成本结构与国产化逻辑厚重的赛道，或投委会关注点就是"公司卡的这一环值不值钱、能不能捕获价值"。常规服务业、市场统计成熟且产业链较短的赛道，01-framework 第五节的深度即可，本文件按需取用（标签库、去来源句改写、表格纪律通用）。正文一律用公司简称，禁止"标的公司""标的"等词（与 [02-writing-style.md](02-writing-style.md) 一致）。

深挖不改变章节结构（仍是 `1.产业链概况`（含（1）（2）（3）上中下游）+ `2.产业链洞察与启示`），只加厚每一环的定量与定性密度。

## 一、每个环节段落的内在节奏：定性 → 证据 → 卡位

产业链每个环节段落走同一条暗线：**环节定性（判断）→ 价值/格局证据 → 对公司卡位的意义**。先一句给环节定调（壁垒/价值占比/成熟度/集中度/标签），再用价值占比、国产化率、代表企业等证据支撑，最后挂回公司简称在该环节的卡位。三步缺一即退化：

- 只有定性没有证据 = 口号（"上游壁垒很高"）；
- 只有证据没有定性 = 图谱罗列（堆一串企业名却不说这一环值不值钱、谁主导）；
- 有定性有证据但不挂公司 = 产业链研报（正确但与这笔投资无关）。

领起词制造结构感：环节细分并列用"一是…二是…"或黑体引导词（散文式）；启示段用"第一，…第二，…第三，…"。密集的产业链信息需要骨架，便于投委会扫读。

## 二、表格式 vs 散文式：两种呈现范式

两种成熟范式，按产业链特征二选一，并在上中下游三环节内保持基本一致（允许某一环节因细分特别多而单独用表）。两种范式的**开篇概况段、环节定性段、竞争格局标签、演进启示段写法完全一致**，差异只在细分的承载方式。

| 判断维度 | 倾向表格式（因诺·无人机范式） | 倾向散文式（伊隆·卫通终端范式） |
|---|---|---|
| 环节内细分数量 | 多（≥3 个并列类别可同维度横比） | 少（2~4 个，但各自厚重） |
| 数据形态 | 以"代表企业 + 竞争格局"定性为主 | 以价值占比 / 成本结构 / 嵌套占比 / 技术路线为主 |
| 比较价值 | 跨类别格局横向对比 | 单环节价值量纵深与成本传导 |
| 读者收益 | 一眼扫清各细分谁主导、什么标签 | 看清价值量最集中环节与降本逻辑 |

- **表格式**：每个环节配一张环节表（见第六节 T1），表头固定；简介列写细分是什么、作用，竞争格局列落国产化率+代表企业（上市带股票代码）+成熟度与标签。价值在于跨类别格局横比。
- **散文式**：每个细分用黑体引导句（"射频前端器件：……""天线系统：……"）起头，把价值占比、技术壁垒、国产化瓶颈层层写进段落。价值量密集时另配价值占比表（T2）。

## 三、价值占比怎么写（产业链分析的看家本领）

价值占比是产业链分析区别于行业分析的核心。写法要点：

- **嵌套要层层咬合**，并指明价值量最集中的环节。示例："T/R 组件成本占相控阵天线总成本的 50%–60%，而 T/R 芯片又占 T/R 组件成本的 60%–80%，是产业链中价值量最集中的环节；天线分系统占载荷成本的 75%（据国博电子招股书）。"
- **占比必带"占什么的百分比"口径**：占整机成本、占系统成本、还是占某组件成本，不能含糊；不同分母的占比不可直接比较或相加。
- **占比要带出处括注**：用简短括注"（据 XX 招股书）""（据公开数据）"，不写成句首来源句"根据 XX 招股书显示"。
- **用价值占比推出投资含义**：高价值占比 + 高壁垒 + 低国产化率 = 国产替代的黄金环节；公司若卡在此则卡位好，若受制于此则成本/供应风险。示例用"相控阵终端整机成本远高于抛物面"推出"替代节奏取决于上游 T/R 芯片降本斜率"。
- 区间值（50%–60%）保留来源口径；自算占比保留 2 位小数。

## 四、竞争格局标签库（环节定性的速记结论）

每个环节或细分定性时落一个标签，便于投委会扫读。标签"双特征对仗"，并配一句解释"为什么是这个标签"（集中度/市占率/壁垒来源）：

| 标签 | 适用环节特征 |
|---|---|
| 高成熟度、高集中度、高上市率（三高） | 技术收敛、寡头主导、龙头已上市的成熟上游 |
| 高壁垒、低波动 | 国家队/央企垄断、资质壁垒高、订单稳定（如军用） |
| 成熟度极高、创新空间有限 | 全球寡头、市占率长期稳定（如消费级无人机·大疆 70%+） |
| 高增长、高分化 | 细分场景分散、无绝对龙头、靠 Know-how 差异化（工业级·黄金赛道） |
| 高潜力、高不确定性 | 技术与政策双驱动、尚未规模化盈利、蓝海（新兴载人/物流） |
| 高增长、高附加值 | 从卖设备到卖服务、数据/运维壁垒（下游运营服务） |
| 上游资源垄断、下游需求分散 | 用于全链结构判断，导出中游枢纽机会 |

允许按赛道自造对仗标签，但须有据。标签不是贴上就完，必须紧跟解释，并在公司所在环节点明卡位。

## 五、中立措辞：去来源句与优势配约束

产业链分析是投委会内部决策文件，两条铁律：**优势与不确定性同台**、**正文不出现机械来源句**（此为对范文的改进，范文本身有此瑕疵）。

### 5.1 去来源句 + 去"从…看"

来源放进表注、括号或事实台账，正文用分析型承接。**凡"从……看/从……来看"一律改写为"在……方面/在……侧"**：

| 不推荐 | 推荐 |
|---|---|
| 根据招股书显示，T/R 组件占天线成本 50% | 在价值分布方面，T/R 组件占天线成本约 50%–60%（据 XX 招股书） |
| 从价值占比看，上游价值量最大 | 在价值分布方面，上游价值量占比最大 |
| 从竞争格局看，中游高度分散 | 在竞争格局方面，中游呈现细分分散、无绝对龙头的特征 |
| 资料显示，下游客户以央企为主 | 在需求侧，下游采购主体以央国企为主，采购决策高度集中 |

正文主语始终是分析对象（环节、价值、格局），不是文件。这与 01-framework 对"行业事实禁用公司来源句"的要求一致，此处再补"产业链证据的来源改括注、'从…看'改'在…方面'"。

### 5.2 定量优先，慎用空泛词

能用数字就不用形容词。把"完整/协同/广阔/领先/核心"替换成价值占比、国产化率、集中度（CRn）、市占率、毛利率、单价。

| 慎用 | 替换为 |
|---|---|
| 产业链完整、协同性强 | 上游国产化率约 XX%、中游集中度 CR3 约 XX%、下游客户集中于央国企 |
| 上游壁垒巨大 | 上游价值占比约 XX%、技术收敛、龙头已上市，新进入者面临认证周期与资本开支壁垒 |
| 价值向下游爆发 | 价值重心正向下游应用服务迁移（运营服务毛利率高于整机制造） |

### 5.3 优势必须配约束

讲完某环节景气、国产替代、公司卡位后，诚实写阶段性约束，这是可信度来源：

- "上游核心芯片国产替代进程接近尾声，但高频段（Ka/Q/V）、小型化方向仍有提升空间。"
- "公司处于高增长高分化的中游黄金赛道，但该环节无绝对龙头、技术迭代快，差异化优势的稳固性仍需持续验证。"
- "下游运营服务为价值迁入方向，但目前尚未形成规模化盈利，数据与运维壁垒仍在积累。"

### 5.4 禁用与慎用词

- 禁用：绝对垄断、唯一、无可替代、必然、稳赚、卡死全链、确定上市。
- 慎用且必须带证据：垄断（写市占率/份额）、卡脖子（写国产化率）、护城河、壁垒——一律要价值占比/国产化率/集中度/订单支撑。
- 推荐基调词：价值量最集中 / 处于过渡期 / 结构性卡位机会 / 比较优势 / 已形成一定壁垒 / 仍待验证 / 高潜力高不确定性。

## 六、专属指标与标准表

### 6.1 产业链专属指标（先算、再核、后入文）

| 指标 | 含义/用途 | 公式 / 口径 |
|---|---|---|
| 价值/成本占比 | 某环节或部件占整机/系统的价值或成本比例，判断价值量集中在哪一环 | `该环节(部件)成本 / 整机(系统)成本`；必须注明"占什么"的分母；保留 2 位小数或来源区间（如 50%–60%） |
| 嵌套价值占比 | 部件占组件、组件占系统、系统占整机的层层占比 | 逐层相乘要自洽：`部件占整机 = 部件占组件 × 组件占系统 × 系统占整机`，前后口径不能打架 |
| 国产化率 | 某环节自主供应比例，国产替代逻辑核心 | `国产供应量(额) / 该环节总需求量(额)`；注明环节与年份 |
| 国产替代空间 | 仍依赖进口、可被国产替代的份额 | `1 − 国产化率` |
| 环节集中度 CRn | 头部 n 家市占率之和，判断寡头/分散 | `CRn = Σ(前 n 家市占率)`；CR1>50% 近寡头，CR4<40% 偏分散 |
| HHI（可选） | 集中度另一口径 | `HHI = Σ(各家市占率%)²`；>2500 高集中，<1500 分散 |
| 毛利率分布 | 各环节毛利率对比，判断利润池在哪一环 | 各环节代表公司毛利率；佐证"价值/利润向哪环聚集" |
| 上市率/资本化 | 某环节头部已上市比例 | "头部 n 家中 m 家已上市"；高上市率=成熟、降本充分、新进入者难突破 |

计算纪律：嵌套占比务必自洽（写完"T/R 芯片占 T/R 组件 60%–80%、T/R 组件占天线 50%–60%"后，心算 T/R 芯片占天线约 30%–48%，确保后文不矛盾）；来源口径不清（占整机还是占系统？）要核到口径再用；占比区间保留来源口径，自算单值保留 2 位小数。

### 6.2 股票代码纪律

代表企业列真名，上市的带股票代码（交易所 6 位 + .SH/.SZ/.BJ/.HK，如 中海达（300177.SZ）、宁德时代（300750.SZ））。**股票代码必须核对真实，不得臆造**；查不到只写企业名或按缺口规则处理（见下）。

### 6.3 缺口规则（与三技能统一）

资料包、会议纪要、权威公开检索（**招股书/年报是价值占比、成本结构、国产化率的第一出处**）三源都拿不到的价值占比、国产化率、集中度、企业名、代码，**正文与表格一律不写、不留占位语**（表格实在删不掉的单元格填"—"）；全部缺口逐条汇入交付时在对话回复中输出的"资料缺口与待核查清单"，不写入报告文档。绝不凭空创造占比、国产化率、企业名或代码。

### 6.4 标准表（套用字段，勿自创表头）

口径单位写在表题或列名；表前必有引导句，表后必有分析句。表格样式（仿宋五号、表头加粗浅蓝底、autofit、单元格居中）由 [../scripts/build_docx.py](../scripts/build_docx.py) 自动套用，"单位/来源"用 `tnote` 块。

**T1 产业链环节表（表格式呈现的主表，按环节各出一张）**

- 上游表：`类别 | 简介 | 头部代表企业及竞争格局`
  - 简介列：该细分是什么、作用、关键材料/技术；
  - 末列：国产化率 + 代表企业（上市带股票代码）+ 成熟度与格局判断 + 标签。
- 中游表：`类别 | 简介 | 头部代表企业 | 竞争格局`
  - 公司所属细分（如工业级）行：把公司简称列入代表企业并点明卡位；
  - 竞争格局列：以标签收束（高壁垒低波动 / 成熟度极高创新有限 / 高增长高分化 / 高潜力高不确定性）+ 解释。
- 下游表：`类别 | 简介 | 核心场景与代表企业 | 竞争格局`
  - 分层：工业应用（核心价值阵地）/ 农业 / 消费 / 新兴场景 / 运营服务；
  - 公司相关行点出公司简称（如"管网巡检的因诺科技等头部服务商"）。

**T2 价值占比 / 成本结构表（散文式或价值量密集时配）**

`环节 / 部件 | 占什么的成本占比 | 数值（含区间） | 国产化率 | 来源`

- "占什么"列必须明确分母（占整机/占系统/占组件）；
- 末列写来源（招股书/研报名），正文不写句首来源句；
- 可附一行"价值量最集中环节"结论。

## 七、深挖质检清单（在 05-quality-checklist 之外补充）

**价值与定量**
- [ ] 每个价值占比/国产化率/集中度/市占率带"占什么"口径与来源括注；嵌套占比口径前后自洽（乘积不打架）。
- [ ] 各细分占比之和与环节口径自洽，未把不同分母占比混加；单位/口径全章统一。
- [ ] 股票代码逐一核对真实，未臆造；查不到的只留企业名或进缺口清单。

**定性与标签**
- [ ] 每个环节先"定性"（壁垒/价值占比/成熟度/集中度/标签）再列细分；标签都配了"为什么是这个标签"的解释。
- [ ] 公司简称在其所属环节被点名卡位，未孤立宣布"公司处于中游"。

**措辞与中立**
- [ ] 正文无"根据…显示""资料显示"等机械来源句；全文搜"从"字，"从……看/从……来看"已改为"在……方面/在……侧"。
- [ ] 每处利好/卡位优势后有约束或待验证事项（同段内）；无禁用词；定量优先。

**呈现与收口**
- [ ] 表格式/散文式三环节基本一致；表前有引导句、表后有分析句。
- [ ] 启示段给 2~3 条演进判断（价值/瓶颈、价值迁移、结构特征），末句把公司钉到产业链坐标（环节+能力+阶段），未加"综合来看/建议立项"式结论段。
