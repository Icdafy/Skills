# 硬逻辑论证

本文件规定立项报告三章的论证方法：结论怎样前置，论点怎样立，论据怎样选，推理怎样走，上下文怎样接，结论怎样经得住追问。方法提炼自本机构实际上会的立项报告终稿及其历次审阅修改；例子中的公司、数字均为虚构。三个技能共用本文件，内容完全一致。句式和用词见 [书面公文表述](formal-expression.md)；跨章主线和论据分级的原始规定见 [投资逻辑复核](investment-logic-review.md)，本文件是其展开和加严。

## 一、合格标准

成稿同时满足以下四条才算逻辑过关，任何一条不满足即返工。

1. **首句成文。** 不看标题，只把各段第一句连起来读，能够复述本章的结论和理由。
2. **段段有来由。** 任意抽出一段，能说清它回答的是上一段留下的哪个问题，又给下一段留下什么。
3. **四问不倒。** 对每一个判断追问四次——凭什么这么说、和谁比、这对公司意味着什么、有没有反例——答案都能在该判断所在的段落或紧邻段落里找到。
4. **前后不打架。** 同一事实在全文各处的数值、口径、时点和判断强度一致，后文的结论不超出前文的证据。

## 二、先搭骨架再成文

动笔之前，在草稿里写出本章的论证骨架。写不出来说明材料还没想清楚，先补材料或列缺口，不要用文字把空洞填满。骨架不进入报告正文。

1. **一句话总论点。** 本章要读者接受的判断，一句话写完。行业章如：`该细分环节需求真实、技术路线已收敛，公司位于价值集中的中游配套环节。` 主营章如：`公司已有可交付产品和可对标的技术优势，收入处于由验证向小批量过渡阶段。` 公司情况章如：`公司控制权清晰、团队与业务匹配，现有规模较小，预测有订单支撑但集中度高。`
2. **三至五个分论点。** 每个分论点是一个可以被事实证明或推翻的判断，对应模板中的一个二级或三级标题。分论点之间只用一个标准划分（按对象、按时间或按因果），互不重叠，合起来能推出总论点。
3. **每个分论点下的硬论据。** 每个分论点至少一条强论据（分级见第五部分），写明主体、时间、数字和来源。找不到强论据的分论点，收窄到证据撑得住的范围，或者删去。
4. **每个分论点的限制。** 该判断在什么条件下不成立、目前还缺什么验证，各用一句话写出，成文时与优势放在同一段。
5. **章间交接。** 本章从上一章接过什么结论，交给下一章什么结论，各写一句。

固定标题、层级和顺序由阶段模板决定，骨架只决定每个标题下面论证什么，不改标题。

## 三、结论前置的四个层级

结论前置须在章、节、段、表四层同时落实，只在段首加一句话不够。

| 层级 | 位置 | 写什么 | 检验 |
|---|---|---|---|
| 章 | 一级标题下的第一个自然段，或第一个二级标题的导语 | 本章总论点，加上下文展开的方面 | 只读这一段，能知道本章结论 |
| 节 | 每个二级、三级标题下的第一句 | 本节分论点；节内有多个小标题时再用一句预告方面和顺序 | 小标题数量、顺序与预告一致 |
| 段 | 每个自然段第一句 | 本段论点，是一个完整的判断句 | 删去其余句子，首句仍然成立 |
| 表 | 表前一句、表后一句 | 表前交代看什么；表后给出从表中得出的判断 | 遮住表格，只读前后两句仍知道结论 |

判断句的要求：

- 有主语、有判断、有范围或时点，三者齐全。`技术优势方面。` `关于客户结构。` 只报题目，不是判断句；`公司客户集中于科研院所，2025年前五大客户收入占比78.20%。` 才是。
- 能被证伪。`公司具有较强竞争力` 无法证伪；`公司产品重量较海外同规格产品轻20%，售价约为其三分之一` 可以核对。
- 强度与证据相称（阶梯见第五部分），不靠副词加码。
- 论点式标题本身就是该节结论，正文只负责证明它，不另立一个不同的结论。

节首导语的写法：先结论，后预告。

```
　　××行业正处于由试点验证向规模应用过渡的阶段，下游需求持续释放，技术路线趋于收敛，政策支持方向明确。以下从市场需求、技术路线、商业化进程和政策支持四方面梳理行业现状。
```

随后必须恰好四个小标题，顺序相同；每个小标题下的首句回应导语中对应的那半句。

## 四、论证单元：论点—依据—推理—含义—边界

一个论证段按五步写，一段只证明一个论点。

1. **论点**：段首判断句。
2. **依据**：主体、时间、数字、来源齐全的事实，两三条足够，最强的放最前。
3. **推理**：说明依据为什么能推出论点，即因果机制。这一步最容易被省略，省略后读者看到的只是“数字＋结论”，中间是断的。
4. **含义**：对公司或对本次判断意味着什么，把事实接回主题。
5. **边界**：判断成立的条件、尚未验证的部分，一句话。

示例（虚构）：

```
　　批量化采购正在改变配套需求的形态。三家运营单位公布的建设规划合计约2.4万台，单台制造成本较2021年下降约40%。成本下降使采购方有条件由单台试用转为成批部署，采购合同随之由一次性研制交付转为多批次、长周期供货。对配套企业而言，能够在保证可靠性的同时给出批产价格和交付节拍的供应商，才具备进入采购名录的条件。上述规划为运营单位公开口径，实际采购节奏取决于年度预算和交付能力。
```

五步的取舍：

- 纯事实段（工商信息、履历、专利清单、合同清单）写“总括句—分项—必要说明”，不强行加推理和含义。
- 凡写了判断，依据和边界必须有；凡列了一组数据，必须有一句说明它说明什么。
- 推理只写机制，不写方法论。`应结合订单情况综合判断` 是方法论；`在手订单覆盖2026年预测收入的62%，其余部分依赖尚未签约的意向项目` 是推理。
- 含义句不重复论点。论点说“是什么”，含义说“所以怎样”。

事实段示例（虚构）：

```
　　公司共有员工46人，其中全职41人、兼职5人。按部门划分，研发部21人、市场部9人、生产部11人、职能部门5人。研发部人数包含知识产权和综合管理岗位，直接从事研发的技术人员为17人。
```

## 五、论点强度与论据强度匹配

论点有多强，论据就得有多硬。先定论据，再定措辞，顺序不能反。

| 证据状态 | 可以写的判断 | 不能写的判断 |
|---|---|---|
| 已签合同、交付验收记录、审计收入 | 已实现销售、已形成收入、已进入××供应体系 | — |
| 小批量交付、付费测试、样机验证 | 已完成验证、处于小批量交付阶段 | 已规模化、已量产、已商业化落地 |
| 第三方检测认证、具名竞品公开参数、同前提对比测算 | 该指标优于／相当于××产品，具备成本优势 | 全面领先、行业第一 |
| 意向订单、框架协议、中标公示（未签约） | 已形成意向、已中标，金额以合同为准 | 在手订单、确定性收入 |
| 公司口述、公司测算、远期规划 | 据公司介绍……、公司预计…… | 不带归属的任何确定性判断 |
| 仅有专利数量、创始人履历、行业增速 | 具备研发基础、所处行业处于增长阶段 | 壁垒高、技术领先、公司将受益 |

论据分三级，核心判断至少一条强论据：

- **强**：政府统计与规划原文、标准编号、审计数据、工商登记、已签合同与交付记录、第三方认证与检测、具名竞品公开参数、统一前提的对比测算。
- **中**：券商研报、学术期刊测算、行业协会数据、写明工况的公司测试数据。写明发布方和口径。
- **弱**：公司口述、意向订单、远期规划、公司测算的市场空间。放在强论据之后，带归属，不作核心判断的唯一依据。

硬论据的五个要素：**具名**（谁）、**时点**（什么时候）、**数值**（多少，带单位）、**口径**（怎么统计的）、**来源**（谁发布的）。缺一项就不算硬。`行业规模超千亿` 缺四项；`××证券研究报告列示，2024年我国××设备市场规模约320.5亿元` 五项齐全。

缺少强论据时的三种处理，按顺序选用：收窄论点（“领先”改为“在××指标上优于××产品”）；降低强度（“已具备”改为“据公司介绍”）；删去论点，缺口记入正文外的清单。不用堆砌弱论据或加重语气代替。

## 六、推理链不跳步

读者不是行业专家，推理的每一环都要写在纸面上。三章各有一条标准链条，成文后逐环核对有没有缺。

**行业章：需求链**

`任务或客户的具体要求（量化边界）→ 现有方案在同等条件下为什么不够（量化）→ 新方案靠什么机制解决 → 同前提对比的结果 → 已有的付费或验证证据 → 仍受什么制约 → 价值落在产业链哪个环节 → 公司处在哪个环节`

**主营章：兑现链**

`公司卖什么、谁在付费 → 产品解决客户什么问题（参数换算成客户价值）→ 靠哪项技术做到 → 技术难在哪里、公司做到什么程度、和谁比 → 别人追赶缺什么 → 已交付什么、在手什么、意向什么 → 放量取决于什么`

**公司情况章：能力链**

`谁控制公司、为什么创办 → 团队分工与业务是否匹配 → 专利、资质、场地等落地条件是否到位 → 客户与供应商反映的收入质量 → 历次融资与本轮估值的依据 → 财务现状 → 预测由哪些订单支撑、集中度如何`

常见的跳步和补法：

| 跳步 | 表现 | 补上的环节 |
|---|---|---|
| 大盘直接推公司 | `行业规模将达千亿，公司将充分受益` | 需求落在哪个细分环节，该环节规模多少，公司是否在其中，凭什么拿到份额 |
| 政策直接推需求 | `政策大力支持，行业迎来机遇` | 政策的层级和工具是什么，改变了准入、资金还是采购中的哪一项，传导到谁的订单 |
| 参数直接推优势 | `能量密度达到420Wh/kg，技术领先` | 该参数对客户意味着什么（多运行多久、少花多少），同前提下别人是多少 |
| 优势直接推壁垒 | `技术先进，壁垒较高` | 别人追赶需要什么（时间、资金、数据、认证、人才），现有进入者做到哪一步 |
| 意向直接推收入 | `意向订单1,280万元，业绩有保障` | 多少已签约、多少待签，签约和交付的条件，单一大项占比 |
| 履历直接推能力 | `创始人为××大学教授，研发实力强` | 履历对应公司哪项技术，是否全职，成果权属是否在公司 |
| 增速直接推趋势 | `收入同比增长9倍，成长性突出` | 基数多少，增量来自什么业务，是否可持续 |

## 七、常见逻辑谬误

成文后逐类排查，命中即改。

| 谬误 | 表现 | 改法 |
|---|---|---|
| 循环论证 | `公司技术领先，因为公司掌握领先技术` | 用外部可比结果证明 |
| 偷换口径 | 前文写工业级市场规模，后文按全行业规模算公司空间 | 全文锁定一个口径，换口径时明示 |
| 混同阶段 | 把试验、样机、送样、小批量、量产混称“已实现” | 按第五部分的阶梯分别表述 |
| 混同性质 | 把意向、中标、合同、交付、验收、确认收入、回款混称“订单” | 分列并写金额 |
| 相关当因果 | `公司成立后行业快速增长` | 写出因果机制，或只陈述两个事实 |
| 以偏概全 | 一家客户的评价写成“客户普遍认可” | 写明是哪一家、哪一次 |
| 诉诸权威 | `依托××大学，技术实力雄厚` | 写合作内容、成果归属、人员投入 |
| 否定无关项 | `公司不是简单的贸易商，而是……` | 直接写公司是什么 |
| 分母不清 | `市占率80%` 未说明哪个细分口径 | 写明口径和来源，口径窄就如实写窄 |
| 合计失真 | 不同分母的占比相加、含税与不含税相加、认缴与实缴相比 | 分别列示并加注 |
| 预测当事实 | `2027年收入1,000万元` 不带归属 | `公司预计2027年营业收入1,000万元`，并写支撑依据 |
| 只证不驳 | 只写有利事实，不利事实不提或放到别的章 | 同段写出对应限制 |
| 自相矛盾 | 前写“已形成付费交付”，后写收入主要来自其他业务 | 在相应位置交代两者关系：主业收入占比多少，其他业务是否为过渡性来源 |
| 结论越界 | 小结出现正文没有的新事实，或强度高于正文 | 小结只取正文已有内容 |

## 八、比较的逻辑

比较是立项报告里最有说服力、也最容易被挑毛病的部分。

1. **先立前提，再比较。** 用一句话写明比较的条件：相同载重、相同工况、相同统计口径、同一年份价格。条件不同的数字不放进同一张表；确需并列时加注。
2. **比较对象具名。** 写出企业和产品型号；公开资料查不到同规格产品时，写检索范围和最接近的可比对象，不写“国内暂无竞品”。
3. **双方都有数。** 公司一列有数、对方一列空白的不叫比较。对方数据来源写明（官网、年报、认证公告）。
4. **比完说结果。** 表后一句写出差距的方向和幅度，以及差距对客户或成本意味着什么。
5. **优劣都列。** 对公司不利的指标同样列入。只列优势项的对比表，委员第一眼就会追问被省略的指标。
6. **不替对手下结论。** 区分“对方做不到”“对方能做但成本高”“对方尚未公开验证”，没有证据不写第一种。

## 九、数字的逻辑

1. **勾稽**：分项之和等于合计，占比之和为100%，股权比例合计100%，资产等于负债加所有者权益。因口径或四舍五入不等的加注说明。
2. **基数**：写增速必带基数或绝对值。`同比增长865.40%，但收入基数仍较小` 比单写增速可信。
3. **分母**：写占比必带分母。同一段内分母变化时重新交代。
4. **同源**：同一指标全文只用一个来源的数；来源不同、数值不同的，选定一个并在工作底稿记录原因，实质差异在正文交代。
5. **预测的假设链**：预测数字后面写清它由哪些订单、产能、价格假设支撑，各假设目前落实到什么程度。预测与历史数据分开列示。
6. **测算可复核**：对比测算写清原型、工况和单价取值；算式留底稿，正文写前提和结果。
7. **量级自检**：单价乘数量是否约等于金额，订单乘交付节奏是否约等于收入预测，人均产值、产能与预测是否匹配。对不上的如实写出差异，不调数字迁就结论。

## 十、上下文衔接

段与段靠内容承接，不靠连接词硬接。后一段的开头要接住前一段的结论。

| 衔接方式 | 写法 | 例句 |
|---|---|---|
| 承接结论 | 段首用上段的结论或关键词起句，再推进一步 | `现有方案尚不能覆盖上述边界。` `验证进展已同步转化为合同。` |
| 由因及果 | 因果两端都写明 | `由此形成按场景分工的格局：……` |
| 转入限制 | 肯定之后用“但”“仍”交代不足 | `产品已实现对外销售；但现有合同仍以测试和小批量交付为主。` |
| 由面到点 | 一层写完，末句落到下一层的对象 | `公司的核心业务位于中游的××环节，并与整机企业开展产品集成。` |
| 承接图表 | 表前引导，表后结论 | `上表差异决定了各路线当前的适用边界。` |
| 时间推进 | 用明确的时间起句 | `2026—2027年，……` `本轮融资完成后，……` |
| 分领域并列 | 同一组段落统一用“××方面，”起句 | `产品研发方面，……` `场景验证方面，……` |

衔接规则：

1. **指代唯一。** “上述”“该”“其”“前述”所指对象在紧邻上文出现且只有一个；隔了一段以上的，重新写出名称。
2. **因果完整。** 写“因此”“由此”“故”之前，原因已经写在纸面上。
3. **先定义后使用。** 专门概念、简称、统计口径第一次出现即界定。
4. **预告兑现。** 导语预告的方面，下文逐一写到，不多不少，顺序相同。
5. **承诺兑现。** 写了“见下节”“如下表”，下节和下表必须有对应内容；写了“两个口径合并的结果见下节测算”，下节就要给出这个结果。
6. **主次有序。** 板块、产品、技术、客户按重要性由主到次排列，最重要的放最前，篇幅与重要性相称。
7. **章间交接。** 行业章末尾落到公司所处环节；主营章开头接住这个环节，说明公司在该环节做什么；公司情况章的团队、专利、资质、订单回应主营章的技术和产品。三章对同一事实的表述一致。

## 十一、正反并陈而不稀释结论

1. **一处优势配一处限制。** 写完进展和优势，在同一段或紧邻的下一段写与之对应的限制，不集中堆到文末，不省略。
2. **限制写事实，不写情绪。** `现有合同以测试及小批量交付为主，批量销售尚未形成` 是事实；`仍存在较大不确定性` 是情绪。
3. **限制写一次。** 同一限制全章只在最相关的位置写一次，不在每段末尾重复。
4. **限制不取消判断。** 先给判断，再给限制，最后给条件：`已……；但……；后续取决于……`。不写成“虽然……但是……然而……不过……”的来回摇摆。
5. **不机械悲观。** 证据充分的判断直接下，不为显得审慎而添加没有事实对应的保留语。

## 十二、小结与结论

- 节末小结至多一句，只归纳本节已论证的内容，并且包含一个各段单独没有说出的综合判断；只是复述就删去。
- 小结不引入新事实、新数字。
- 三章均不写“建议立项”“值得投资”一类投资表态；需要为立项结论提供素材时，按“依据—不足—判断范围”写到事实为止。
