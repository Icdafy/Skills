# 质量自检清单与交付标准

交付前逐项自检。任何一项不通过，修订后再交付。自检时把自己切换为投委会里最挑剔的委员：他会复算你的 CAGR，追问政策是否真有约束力，也会问公司到底卡在产业链哪一环。文中“公司简称”指拟投资公司的简称。

## 一、结构合规

**1. 是否从固定标题开始**

- [ ] 成稿第一个标题是 `二、所属行业分析`
- [ ] 前面没有“XX行业分析”“行业定义与研究边界”等大标题
- [ ] 没有输出“行业定义与研究边界”小节

**2. 是否只保留范文路径内的标题**

- [ ] `（一）行业发展现状`
- [ ] 路径 A 使用 `1.市场规模与增长趋势` + `2.核心增长驱动力`
- [ ] 路径 B 使用 `1.XX 是 XX 场景规模化发展的核心基础设施/关键配套` + `2.市场规模与增长趋势`
- [ ] `（二）产业链分析`
- [ ] `1.产业链概况`
- [ ] `2.产业链洞察与启示`、`2.相关洞察` 或 `2.产业链演进的启示` 三者择一，且功能是规律提炼与公司卡位
- [ ] 未擅自新增同级的竞争格局、风险分析、投资判断小结等章节
- [ ] 已根据公司特点选择“市场规模先行型”或“关键配套/基础设施先行型”路径
- [ ] 若采用关键配套/基础设施先行型，第一节标题说明了该环节与下游场景的刚需关系，且未写成宣传口号

**3. 标题编号是否统一**

- [ ] 编号层级为 `二、` → `（一）` → `1.` → `（1）` → 段内“一是/二是/三是”
- [ ] 无跳级、重号、标题逻辑重复

**3A. `.docx` 公文版式是否符合范文**

- [ ] 页面为 A4 纵向
- [ ] 页边距上 3.7cm、下 3.5cm、左 2.8cm、右 2.6cm（三技能统一）
- [ ] 正文及各级标题基准字号为 16pt
- [ ] 段落固定 28 磅行距
- [ ] 正文段落首行缩进 2 个中文字符
- [ ] **所有标题（“二、”“（一）”“1.”“（1）”各级）首行缩进 2 个中文字符，与段落平齐，无顶格或居中标题**
- [ ] `二、所属行业分析` 使用黑体 16pt，不加粗
- [ ] `（一）（二）` 层级使用楷体_GB2312 16pt 加粗
- [ ] `1.` 三级标题使用仿宋_GB2312 16pt 加粗；`（1）`四级标题与正文使用仿宋_GB2312 16pt 不加粗；核心结论段整段加粗
- [ ] 表格全表统一仿宋_GB2312、五号字（10.5pt）
- [ ] 表格仅首行（表头）加粗并加浅蓝底（#D9E2F3），其余单元格不加粗
- [ ] 表格所有单元格内容水平居中、垂直居中；表头行跨页重复
- [ ] 表格宽度按窗口/页面自动调整（autofit），列宽自适应，未写死固定磅值
- [ ] 页脚页码为“-1-”格式、宋体四号、奇偶页外侧
- [ ] 正文与表格无“资料未披露”“待核查”类缺口占位语（缺口只在对话交付的清单中提示）
- [ ] 已运行 `python scripts/style_check.py` 且全部通过

## 二、核心结论前置

**4. 每个细分部分是否以加粗判断句开头**

- [ ] 市场规模与增长趋势开头有加粗判断句
- [ ] 路径 A 的核心增长驱动力开头有加粗总论句
- [ ] 路径 B 的关键配套/基础设施地位开头有加粗判断句
- [ ] 政策驱动开头有加粗判断句
- [ ] 市场驱动开头有加粗判断句
- [ ] 其他驱动（如有）开头有加粗判断句
- [ ] 产业链概况开头有加粗判断句
- [ ] 上游、中游、下游分别以加粗判断句开头
- [ ] 产业链洞察与启示每条均以加粗总结句开头
- [ ] **全文没有“核心结论：”“核心观点：”等标签前缀，核心结论只加粗**

**5. 加粗内容连读是否构成摘要**

- [ ] 加粗内容能说明行业阶段、规模增速、增长驱动、产业链结构和公司卡位
- [ ] 加粗句有后文证据支撑，无空泛口号
- [ ] 证据句、企业名录、表格正文没有滥用加粗

## 三、语言与称谓合规

**5A. 禁用连词与称谓**

- [ ] 全文无“不是……而是”“并非……而是”“不仅……而是”“不止……而是”“不仅……而且”“不但……还”“不在……而在”等成对转折/递进连词
- [ ] 全文无“标的公司”“标的”“本标的”“该标的”“目标公司”等词，拟投资公司一律用公司简称
- [ ] 全文无“根据资料包”“根据 BP”“据会议纪要”“据访谈纪要”“根据公司提供的资料”等内部资料来源表述

## 四、行业发展现状

**6. 市场规模与增长趋势是否扎实**

- [ ] 写了行业总规模、近年增长和 CAGR
- [ ] 写了公司相关细分市场，覆盖广义大市场之外的核心口径
- [ ] CAGR 已按首末值复算
- [ ] 历史数据和预测数据区分清楚
- [ ] 数据来源、时间、口径明确
- [ ] 无“根据公司整理”“该数为公司自述”“仅作为方向参考”

**7. 增长趋势是否有结构判断**

- [ ] 说明增长来自总量扩张、细分渗透、量价变化、下游客户增加或服务化延伸中的哪几类
- [ ] 判断行业处于导入期、成长期、成熟期或分化期，并给出理由
- [ ] 未使用“前景广阔、潜力巨大、大有可为”等空泛词替代分析

**8. 核心增长驱动力是否完整**

- [ ] 必写政策驱动
- [ ] 必写市场驱动
- [ ] 如写技术/成本/供给/国产替代驱动，确有证据，无凑数项
- [ ] 总论里对驱动因素有排序或主次判断

**9. 政策驱动是否写出机制**

- [ ] 超越政策罗列，写了政策层级、治理逻辑或工具变化
- [ ] 每条政策影响都落到准入、标准、空域、采购、预算、基础设施或监管成本等具体机制
- [ ] 政策力度未夸大；倡导性政策未写成强制约束
- [ ] 写出了“早期政策局限/过去阶段 -> 新政策或新标准拐点 -> 对行业需求或准入的影响”

**10. 市场驱动是否写出真实需求**

- [ ] 区分存量替代和增量创造
- [ ] 写明下游客户是谁、痛点是什么、为什么愿意付费
- [ ] 写明需求是试点验证、常态化采购还是远期培育
- [ ] 公司相关场景得到重点展开
- [ ] 写出了“原有作业痛点 -> 新方案解决的问题 -> 客户付费/采购闭环”

**10A. 技术路线或关键配套是否写出产业含义**

- [ ] 技术参数服务于场景判断，无孤立科普
- [ ] 写清旧方案/现有方案的优势和局限
- [ ] 写清新方案解决什么问题，以及成本、性能、可靠性、轻量化、时延或精度的取舍
- [ ] 没有把短期并行路线写成简单全面替代

## 五、产业链分析

**11. 产业链概况是否总起到位**

- [ ] 首段概括“上游 A—中游 B—下游 C”
- [ ] 明确公司简称处于上游/中游/下游/一体化，以及主要侧重环节
- [ ] 写出核心瓶颈或价值集中环节
- [ ] 产业链全景为独立还原，覆盖与公司自身无关的赛道，未照抄公司自己的产业链叙事
- [ ] 公司简称落位到具体细分赛道，与同赛道企业并列呈现，无孤立宣布“公司处于中游”式写法
- [ ] 产业链概况整体能回答前三问：价值在哪个环节沉淀、议价权在谁手里、各环节壁垒正在加固还是瓦解

**12. 上游是否拆分赛道并写出功能**

- [ ] 上游以加粗判断句开头
- [ ] 上游按行业真实分工拆出细分赛道/板块（按部件/材料/要素类别或功能模块，数量不预设），写明各是什么并逐一介绍
- [ ] 每类构成都解释了功能和重要性
- [ ] 写明技术/成本/成熟度/国产化/供应壁垒中的关键点
- [ ] 价值集中的板块有向下再拆一层或成本占比数据支撑

**13. 中游是否拆分赛道并写出功能**

- [ ] 中游以加粗判断句开头
- [ ] 中游按行业真实分工拆出细分赛道（按产品形态/市场类型或能力要素，数量不预设），写明各是什么并逐一介绍
- [ ] 每个赛道有格局定性（垄断/寡头/分散/培育）和代表企业
- [ ] 解释中游如何把上游要素转化为可交付产品或服务
- [ ] 公司若处于中游，写进所属赛道并说明其壁垒来自全栈自研、集成能力、场景适配、客户资源还是交付能力

**14. 下游是否拆分赛道并写出功能**

- [ ] 下游以加粗判断句开头
- [ ] 下游按行业真实分工拆出细分领域（按应用场景/客户类型/载体，数量不预设），写明各是什么并逐一介绍
- [ ] 写明终端客户、应用场景、运营服务和数据价值
- [ ] 区分成熟应用、快速拓展和试点培育场景
- [ ] 说明下游需求如何影响中游放量和公司成长

**15. 产业链洞察与启示是否有投资含义**

- [ ] 每条启示先写加粗总结，再详写
- [ ] 启示回答了第四、五问：产业链演进方向（未来哪类玩家位置变好或变坏）与公司价值捕获（顺势/逆势、关键依赖）
- [ ] 启示提炼价值迁移、瓶颈环节、降本逻辑、客户格局或服务化趋势，超越产业链复述
- [ ] 每条启示都落回公司简称的卡位、机会或待验证事项
- [ ] 启示数量以 2-4 条为宜，宁少而深，不凑数
- [ ] 每条启示都能追溯到前文事实，无凭空拔高
- [ ] 每条启示都回答“哪类企业更容易赢，公司顺势、受制约还是待验证”

**15A. 产业链深挖（仅当按 08-chanlian-deep-dive.md 深挖时补查）**

- [ ] 呈现范式已明确（表格式/散文式），三环节基本一致；表前有引导句、表后有分析句
- [ ] 价值占比带“占什么”口径与来源括注；嵌套占比口径前后自洽（乘积不打架）
- [ ] 每个环节落了竞争格局标签（三高/高壁垒低波动/高增长高分化等）并配“为什么是这个标签”的解释
- [ ] 国产化率、集中度 CRn（如写）带环节与年份；代表企业股票代码逐一核对真实，未臆造
- [ ] 全文搜“从”字，“从……看/从……来看”已改为“在……方面/在……侧”；来源改括注不作句首主语
- [ ] 每处卡位优势后有约束或待验证事项（同段内）
- [ ] 三源都查不到的价值占比/国产化率/企业名/代码未写入正文与表格，已进对话交付的缺口清单

## 六、数据与来源

**16. 数据是否可追溯**

- [ ] 每个规模、增速、占比、成本、国产化率等数字能回答“谁发布、哪一年、什么口径”
- [ ] 第三方预测点明机构和发布时间
- [ ] 表格来源与正文来源一致

**17. 公司资料使用是否克制**

- [ ] 公司资料只用于判断公司产品、客户和产业链位置
- [ ] 公司自述行业数据未直接作为关键行业结论
- [ ] 无公司资料免责声明式措辞或内部资料来源表述污染正文

**18. 机械校验是否完成**

- [ ] 涉及市场规模、CAGR、占比、表格时，已运行 `python scripts/reconcile_check.py 行业分析.md`
- [ ] FAIL 项已回原始资料核实，未反向改数字消灭报错
- [ ] REVIEW 项已人工复核

**18A. 图表是否承担证据岗位**

- [ ] 每张图表都能说明其论证功能：规模证明、阶段解释、政策佐证、技术对比或产业链定位
- [ ] 图表前后有承接句说明“这张图证明了什么”
- [ ] 图表数据、正文数字、表格数字和来源一致
- [ ] 产业链图谱没有替代正文分析，正文仍解释各环节功能、壁垒和价值分布

## 七、语言与风格

**19. 是否符合立项报告语气**

- [ ] 正式、客观、克制，无口语和营销语
- [ ] 采用书面公文口吻，原则上不用“我们认为”“笔者认为”
- [ ] 段首论点句清晰
- [ ] 政策、数据、产业链都先归纳规律再展开明细
- [ ] 政策、市场、技术段落至少完成一条解释链
- [ ] 未出现“必然、一定、毫无疑问、确定性极强、强烈推荐”等绝对化表达

**20. 是否真正服务投委会判断**

- [ ] 全文能回答行业盘子、增长真实性、产业链价值分布、公司卡位四个问题
- [ ] 未把行业分析写成行业科普
- [ ] 未把公司优势写成未经验证的行业结论
- [ ] 对仍需核实的数据或假设保持审慎

## 交付物标准

最终交付的行业分析章节至少包含：

1. 固定标题体系（全部标题首行缩进 2 个中文字符）；
2. 各小节开头的加粗核心结论判断句（无标签前缀）；
3. 市场规模、增长趋势及关键数据来源；
4. 政策驱动和市场驱动的详细机制；
5. 上游、中游、下游产业链构成及功能说明；
6. 公司简称的产业链位置判断；
7. 产业链洞察与启示；
8. 必要表格和数据来源说明。
