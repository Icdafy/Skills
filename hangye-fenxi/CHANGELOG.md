# 变更记录

## 1.1.0（2026-11-12）

- 书面公文表述：新增 `references/formal-expression.md`（三技能统一），据本机构实际上会的多份立项报告终稿及其初稿到终稿的改动提炼，包括九项语体特征、十三类功能句式（定位、分领域起句、导语、定义与口径、数据、归属、比较、因果、限制、时间节点、表前表后、计划安排、节末收束）、书面虚词和动词用法、口语与书面语对照、机器腔及改法、称谓、数字写法、三章常用表述、不沿用的写法和成文自查；例句中的公司和数字均为虚构。
- 硬逻辑论证：新增 `references/hard-logic.md`（三技能统一），规定四条合格标准、动笔前的论证骨架、结论前置的章节段表四层、“论点—依据—推理—含义—边界”论证单元、论点强度与证据状态的对应、三章各自的推理链（本章为需求链）及常见跳步、十四类逻辑谬误、比较和数字的逻辑、上下文衔接与章间交接、正反并陈、质询预演和十三项逻辑自查。
- `SKILL.md` 新增“书面公文表述与硬逻辑（硬性规则）”一节，表述十二条、逻辑十条全部写入正文，宿主不读取参考文件时仍按规则成文；工作流程增加“动笔前搭论证骨架”和“成文后逐项自查、质询预演”；`references/02-writing-style.md`、`references/05-quality-checklist.md`、`references/investment-logic-review.md` 增加对两份规范的引用和自查项。
- `scripts/style_check.py` 新增硬规则六类（对话痕迹、提示性引子与总结腔、口语及网络表达、空泛拔高与宣传黑话、主观人称、表情符号）和告警九类（铺垫式开头、机械连接词起段、第一人称判断、口语化程度词、程度词后无数字、单句超过130字、导语列举项数与“N方面”不符、导语预告方面数与下文小标题数不符、表前缺引导句）；书名号和引号内的原文不扫描。
- 页码由 `-1-` 改为 `- 1 -`（短横线与页码数字之间各一个半角空格），整体仍为四号宋体、奇右偶左；生成器、烟测、规则文档和回归测试同步。
- 千位分隔符：规则原已写入文档并由 `style_check.py` 扫描，但生成器不处理。现由 `scripts/build_docx.py` 生成 Word 时对正文、标题、表格、表注、图名、附件名称中的数量自动补齐；年份、日期、文号、标准号、型号、电话、证件号、统一社会信用代码、专利号、证券代码等标识保持原样，表头或行首为“代码、编号、专利号、型号”等的列或行不处理；可用 `"thousands": false`（全文或单个块）或 `--no-thousands` 关闭。
- 跨客户端：新增 DeepSeek Harness（`--agent dsh`）和千问办公（`--agent qwenwork`）的安装目录、入口和调用说明，并汇总 ChatGPT、Claude、Qoder、TRAE、WorkBuddy、DeepSeek Harness、千问办公、豆包八个客户端的安装方式。`scripts/skill_portability.py`、`references/agent-compatibility.md` 自本版起由立项报告三技能共用一份，与 `yiti-skill`、`soe-post-investment-report` 的旧共享版本分开维护。
- 固定标题模板、阶段询问流程、字体文件、字体映射、行距、表格和附件落款规则不变。
