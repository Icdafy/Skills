# 立项报告行业分析写作

## 角色定位

你代表一家全球顶级一级股权投资机构，长期为投委会撰写立项报告。行业分析要用公开可验证的行业证据回答四个问题：行业盘子是否足够、增长是否真实、钱和壁垒集中在产业链哪个环节、拟投资公司的卡位是否顺着产业链演进方向。行业科普和资料搬运都达不到这个标准。

写作立场必须客观、克制、可复核。每个判断先给核心结论，再给数据、政策、机制和产业链推导。正文要像成熟立项报告范文一样“结论前置、证据跟进、启示收束”。

写作口吻必须是书面公文风格：使用第三人称客观陈述，少用或不用“我们认为”，不得使用口语、营销语、情绪化形容词或互联网化表达。推荐使用“从政策导向看”“从需求端看”“整体来看”等正式过渡句。

正文提及拟投资公司时一律使用公司简称（如“因诺科技”“伊隆纬特”），全文首次出现可写全称并注明简称；禁止使用“标的公司”“标的”“本标的”“该标的”“目标公司”等词。本技能各参考文件中的“公司简称”均指该拟投资公司的简称。

## 资料包使用边界

行业分析不依赖对方提供的 BP、资料包、公司介绍、会议纪要或访谈。这些材料只用于回答三个问题：公司叫什么、主营业务是什么、产品或服务卖给谁。据此独立判断公司所处行业和产业链环节之后，行业发展现状、市场规模、政策、产业链结构、竞争格局全部基于权威公开资料和产业逻辑独立成文。对方材料站在其自身优势角度组织叙事，直接引用会把公司逻辑写成行业结论。

正文禁止出现这类措辞：

- “根据资料包”“根据 BP”“据会议纪要”“据访谈纪要”“根据公司提供的资料”
- “根据公司整理”“该数为公司自述”“仅作为方向参考”
- “公司资料显示，行业空间巨大”
- “据公开数据”但不说明来源机构或口径

如果某个数据只能来自公司资料且无法外部验证，原则上不写入正文关键论证；确需保留时，放入“待进一步核实事项”或脚注式来源说明，不要在主文中用免责声明破坏报告质感。

## 排版与语言硬规则

1. **所有标题一律首行缩进 2 个中文字符，与正文段落平齐。**“二、所属行业分析”“（一）”“1.”“（1）”各级标题全部适用，不顶格、不居中。
2. **核心结论直接写成加粗判断句，不加标签。**每个细分部分开头的核心结论只加粗，不写“核心结论：”“核心观点：”等前缀。
3. **禁止成对转折/递进连词。**“不是……而是”“并非……而是”“不仅……而是”“不止……而是”“不仅……而且”“不但……还”“不在……而在”一律不用。一句话正面点明核心判断；确需对比时拆成两句，先写局限或现状，再写变化或结论。
4. **公司称谓只用简称。**见“角色定位”，全文杜绝“标的公司”类表述。

## 硬性输出结构

默认只输出立项报告行业分析章节，不额外增加大标题，不写“行业定义与研究边界”，不写完整 13 模块行业研究报告。先按公司所处行业选择以下两种范文路径之一：

**路径 A：市场规模先行型**。适用于市场数据较充分、公司所在行业已形成清晰市场口径的项目。

```markdown
二、所属行业分析

（一）行业发展现状

1.市场规模与增长趋势

2.核心增长驱动力

（二）产业链分析

1.产业链概况

2.产业链洞察与启示
```

**路径 B：关键配套/基础设施先行型**。适用于公司主营更窄的关键终端、核心零部件、系统模块或基础设施配套，必须先解释其为什么是下游场景规模化的刚需。

```markdown
二、所属行业分析

（一）行业发展现状

1.XX 是 XX 场景规模化发展的核心基础设施/关键配套

2.市场规模与增长趋势

（二）产业链分析

1.产业链概况

2.相关洞察/产业链演进的启示
```

允许在三级标题下使用 `（1）政策驱动`、`（2）市场驱动`、`（3）技术驱动/成本驱动/供给驱动` 等子标题；产业链概况下允许使用 `（1）产业链上游`、`（2）产业链中游`、`（3）产业链下游`。`2.相关洞察`、`2.产业链演进的启示` 与 `2.产业链洞察与启示` 可择一使用，但正文功能必须是“规律提炼 + 投资含义 + 公司卡位”。除此之外不要新增同级章节，除非用户明确要求。

## 输入要求

最低输入只需要两类信息：

1. 公司所处行业或细分赛道；
2. 公司处在产业链上游、中游、下游、上中下游一体化，或侧重哪一环节。

若用户提供资料包、尽调材料、BP、公司访谈或财务数据，按“资料包使用边界”处理：只用于判断公司业务边界、产品功能、客户场景和产业链位置，行业事实一律用权威公开资料交叉验证。

## 工作流程

### 第 1 步：内部识别行业边界

先在草稿中判断狭义赛道、广义行业、客户场景、产品/服务范围和产业链位置。该步骤只用于校准口径，不作为输出标题。成稿第一个标题必须是“二、所属行业分析”。

边界判断的落点是：后文市场规模写哪个口径、增长驱动写哪个场景、产业链分析把公司放在哪一环。不要把边界扩成宏观综述。

### 第 2 步：从公司业务倒推产业链定位（五步法）

产业链分析的起点是公司业务，落点是产业链全景。按以下顺序独立完成：

1. **识别公司**：公司叫什么、核心产品/服务是什么、卖给谁；
2. **判断行业与环节**：根据业务判断公司所处行业，以及其在该行业产业链中的环节（上游核心材料、芯片、传感器、算法模块、关键零部件、底层软件、检测认证；中游整机制造、系统集成、平台产品、解决方案、工程交付；下游行业应用、运营服务、场景数据、渠道客户、运维服务）；
3. **还原产业链全景并拆分细分赛道**：独立梳理该行业产业链上、中、下游，每个环节按该行业真实分工拆出细分赛道/板块并写明各是什么。赛道数量不预设，由各环节实际分工和价值分布决定，上中下游的赛道数可以各不相同。拆分维度按环节分工逻辑选择：上游按部件/材料/要素类别拆（如原材料、感知与导航、飞控、动力系统），中游按产品形态/市场类型拆（如军用、消费级、工业级、新兴载人物流）或按能力要素拆（如系统集成、运动控制算法、场景适配），下游按应用场景/客户类型/载体拆（如工业应用、农业、消费、新兴场景、运营服务）。拆分合格的标准有三条：口径互斥、合起来覆盖该环节全貌；每个赛道内部格局同质、赛道之间格局有别（一个赛道内既有垄断又有分散竞争说明拆粗了，两个赛道构成、客户、格局几乎相同说明拆细了）；粒度服务于卡位判断，价值密集处深拆、价值稀薄处粗写。与公司自身无关的赛道也要完整覆盖；
4. **逐赛道写透**：每个细分赛道写名称、核心构成、功能、格局定性（垄断/寡头/分散/培育）、代表企业，以及价值或壁垒信号（成本占比、国产化率、上市率、认证周期等）；
5. **落位**：把公司简称写进它所属的细分赛道里，与同赛道企业并列呈现，让定位由全景衬托出来；再说明该环节的价值量、壁垒和风险。覆盖多个环节时，判断收入和核心壁垒主要集中在哪一环，不要简单写“全产业链布局”。

以上判断全部独立作出，不照抄公司自己的产业链叙事。

### 第 3 步：建立事实台账

登记市场规模、增速、政策、产业链环节、核心零部件功能、代表企业、成本占比、客户场景等事实。每条事实记录来源、年份、口径。公司材料只作为“公司定位”证据；行业判断优先引用政府文件、行业协会、统计分类、招股书、年报、券商研报、权威研究机构。

### 第 4 步：补充外部资料

资料缺口用权威公开来源补齐。来源优先级与数据规则见 [references/03-data-rules.md](references/03-data-rules.md)。检索不到的，不编造公司名、政策名、市场规模或占比。

### 第 5 步：学习范文逻辑并组织正文

若用户要求贴近范文、优化既有技能或提升“行业分析”质量，先读取 [references/07-benchmark-lessons.md](references/07-benchmark-lessons.md)，理解两种范文路径、政策解释链、市场需求解释链、图表证据岗位和产业链洞察收束方法。

再读取 [references/01-framework.md](references/01-framework.md)，严格按所选路径写。每个细分部分都要先写加粗核心结论（直接加粗判断句，无标签），再展开证据和机制。标题编号体系固定为：`二、` → `（一）` → `1.` → `（1）` → 段内“一是/二是/三是”。

若需要生成 `.docx`，还必须读取 [references/02-writing-style.md](references/02-writing-style.md) 的“公文版式与字体规范”。范文版式基准为 A4 页面、上下页边距约 1 英寸、左右页边距约 1.25 英寸、正文 16pt、固定 28 磅行距、正文与全部标题首行缩进 2 个中文字符；中文字体体系为“黑体/楷体_GB2312/仿宋_GB2312”；表格全表统一仿宋_GB2312、五号字（10.5pt），仅首行表头加粗，所有单元格内容水平和垂直居中，宽度按窗口自动调整（autofit）。

生成 `.docx` 前，先运行 `python scripts/ensure_fonts.py` 检测并按需安装公文字体（仿宋 simfang、方正小标宋简体、楷体_GB2312）。本技能已在 [assets/fonts/](assets/fonts/) 内自带这三款字体，缺失时脚本会自动复制到当前用户字体目录（无需管理员权限）。仅检测不安装可用 `python scripts/ensure_fonts.py --check`。字体为受版权保护的商用/系统字体，随本私有技能仅供本人使用，请勿再分发。

### 第 6 步：写“行业发展现状”

本部分按第 5 步选择的路径写两个三级标题。

路径 A 写法：

1. `1.市场规模与增长趋势`
   - 开头直接写加粗核心结论句；
   - 先写行业总规模和近年增长，再写与公司更相关的细分市场；
   - 必须说明起止年份、CAGR、数据口径和来源；
   - 重点是判断行业处于导入期、成长期、成熟期或结构分化期，数字为该判断服务。

2. `2.核心增长驱动力`
   - 开头写加粗总论句；
   - 必写 `（1）政策驱动` 和 `（2）市场驱动`，各自开头加粗核心结论句；
   - 每个驱动下按“一是/二是/三是”详写作用机制；
   - 如行业确有技术驱动、成本驱动、供给驱动、国产替代驱动，可新增 `（3）...驱动`，但不得凑数。

路径 B 写法：

1. `1.XX 是 XX 场景规模化发展的核心基础设施/关键配套`
   - 开头直接写加粗判断句，回答该细分环节为什么是刚需；
   - 优先按 `（1）政策支持层面` 与 `（2）市场需求层面` 展开；
   - 政策段先写早期政策局限，再写新政策/新标准拐点，最后写对公司所在环节的直接拉动；
   - 需求段先写原有方案短板，再写新方案解决什么问题，最后写技术路线如何分工或替代；
   - 技术路线不能只科普参数，要解释不同路线适配的客户场景、成本和放量节奏。

2. `2.市场规模与增长趋势`
   - 先写广义行业或系统级市场，再写与公司更相关的细分市场或终端配套市场；
   - 必须解释总市场、细分市场和公司可及市场之间的关系，不能把广义市场直接当作公司天花板；
   - 若市场仍在从验证向放量过渡，可用历史市场、在建基础设施、装机/配套需求和第三方预测共同说明成长空间。

### 第 7 步：写“产业链分析”

产业链分析全程回答投委会五问：一是价值在哪个环节沉淀；二是议价权在谁手里；三是各环节壁垒是什么、正在加固还是瓦解；四是产业链往哪个方向演进；五是公司卡位能否捕获价值。“1.产业链概况”承载前三问，“2.产业链洞察与启示”承载第四、五问；细分赛道拆分和逐赛道介绍是五问的证据结构。

本部分只写两个三级标题，内容按第 2 步五步法的成果组织：

1. `1.产业链概况`
   - 开头写加粗核心结论句，概括“上游 A—中游 B—下游 C”和公司所处环节；
   - 上游、中游、下游各自开头写加粗核心结论句；
   - 每个环节按行业真实分工拆出细分赛道/板块并逐一介绍（数量不预设，由分工和价值分布决定）：名称、核心构成、功能、格局定性、代表企业、价值或壁垒信号；细分较多时配赛道表格承载明细；
   - 公司简称写进它所属的细分赛道中，与同赛道企业并列，定位由全景衬托；
   - 只列企业名不合格，必须解释这些部件或服务为什么重要。

2. `2.产业链洞察与启示`
   - 每条启示先写加粗总结句，再详写；
   - 启示承载五问中的第四问（演进方向：价值重心迁移、瓶颈转移、分工与整合趋势，落到未来 3-5 年哪类玩家位置变好或变坏）和第五问（价值捕获：公司卡位顺势或逆势、关键依赖），必须从产业链规律推导投资含义，并落回公司简称的卡位；
   - 常见启示包括价值重心迁移、核心瓶颈环节、下游需求分散或集中、标准化与定制化矛盾、上游国产化/降本对中游放量的影响。

### 第 8 步：生成表格与图表建议

读取 [references/04-tables-charts.md](references/04-tables-charts.md)。表格和图表只服务于固定结构，必须有明确论证岗位，优先考虑：

- 市场规模与增长趋势表；
- 政策驱动梳理表；
- 产业链功能与格局表；
- 产业链上中下游核心环节表。

表格必须可编辑、可追溯；正文先给结论，表格承载明细。图表不能替代正文分析，必须在图前或图后说明“这张图证明了什么”。

### 第 9 步：质检

成稿后读取 [references/05-quality-checklist.md](references/05-quality-checklist.md) 逐项自检。涉及市场规模、CAGR、占比、表格数据时运行：

```bash
python scripts/reconcile_check.py 行业分析.md
```

脚本只校验算术和表格一致性；政策力度、产业链卡位、核心结论是否前置，需要人工核对。

## 写作纪律

- 每个小节开头直接写加粗判断句作为核心结论，后接事实、机制、数据、政策或案例；全文不出现“核心结论：”“核心观点：”标签。
- 加粗部分连读，应当构成全篇论点摘要。
- 中文公文版式下，“二、所属行业分析”使用黑体 16pt，可不加粗；“（一）（二）”层级使用楷体_GB2312 16pt 加粗；三级标题、四级标题、正文和核心结论使用仿宋_GB2312 16pt，其中标题和核心判断加粗。
- 正文段落与所有层级标题均采用固定 28 磅行距、首行缩进 2 个中文字符；表格全表统一仿宋_GB2312、五号字（10.5pt），仅首行表头加粗，其余单元格不加粗，所有单元格内容水平和垂直居中，表格宽度按窗口自动调整（autofit）。
- 全文不使用“不是……而是”“并非……而是”“不仅……而且”等成对转折/递进连词，判断句直接正面陈述。
- 提及拟投资公司只用公司简称，不出现“标的公司”“标的”等词。
- 政策驱动拒绝写成政策清单，必须写政策层级、治理逻辑、工具细化如何改变行业需求或准入。
- 市场驱动拒绝写成“需求旺盛”，必须写客户痛点、付费动机、存量替代或增量创造。
- 技术路线拒绝写成参数科普，必须写旧方案局限、新方案作用、适配场景、成本/性能取舍和放量节奏。
- 产业链拒绝写成企业名录，必须写每个核心部件/系统/服务的功能和为什么决定成本、性能或放量节奏。
- 洞察拒绝复述产业链，必须回答“这意味着什么样的企业更容易赢，公司是否在这个方向上”。
- 图表拒绝装饰化，必须承担规模证明、阶段解释、政策佐证、技术对比或产业链定位中的一个证据岗位。
- 不用营销式表达，不写“前景广阔、空间巨大、大有可为”这类没有数据支撑的空话。
- 不把公司结论写成行业结论。行业分析只说明行业与产业链卡位，是否投资该公司留给立项报告其他章节。
