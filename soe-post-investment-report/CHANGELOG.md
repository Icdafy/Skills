# 变更记录

## 1.6.0（2026-11-13）

- 表述：新增 `references/report-voice.md`（口吻与句法：十三种基本句型、段首定位词、固定动词和程度词及其使用条件、访谈和纪要素材的转写对照、去机器腔清单、三组改写示范）。方法据维护者提供的本地投后报告成稿只读研读得出（年度、半年度、季度汇总报告及各项目附件，同一报告自首稿至定稿的全部修改稿，投后访谈报告和月度投后纪要），材料不入库，例句中的主体和数字均为虚构。
- 逻辑：新增 `references/logic-chain.md`（一句四问、六种句间关系、各类项目逻辑链及闭环检查、判断五级与证据要求、算式写法、十五条一致性硬约束、审阅人十问、逐句示范）。
- `SKILL.md` 增加“口吻与逻辑硬规则”，宿主不读取参考文件时同样适用；必读参考由一份增至三份，交付成果增加口吻自查和逻辑自查结论。
- 校验器：`validate_expression_style` 增加自称、提示语和推论套话、序列与对比套式、拔高词、无数字评价、口语约数、行业简称、相对时间、方向词与负号、“每年”与“年化”叠用、破折号、Markdown 残留等警告；新增 `validate_logic_chain`，对正文段首过渡语、“预计”无来源、风险判断无依据、“下一步”缺主语、内部报告式项目未收束给出警告。
- 页码由 `-1-` 改为 `- 1 -`（短横线与数字之间各空一个半角空格），生成器、校验器、冒烟测试和文档同步。
- 千位分隔符：校验器原有的阻断规则复查无误并保留；新增 `scripts/group_thousands.py`，对规格的正文、表格、附件标题和台账断言一次补齐，年份、日期、文号、编号等标识性数字不动。
- 跨客户端：`scripts/skill_portability.py`、`references/agent-compatibility.md` 改为本技能单独维护，增加 DeepSeek Harness（`--agent dsh`）和千问办公（`--agent qwenwork`），必备文件清单加入新增参考和脚本；补充宿主无代码执行时只交付文本的处理办法。
- 合成示例 `report-spec.internal.example.json` 中一处“近期”改为确定表述。测试由55项增至60项。
