# 投后报告的口吻与句法

本文件回答“这句话该怎么说”。它提炼自维护者提供的一批实际投后报告成稿：年度、半年度、季度的汇总报告及其各项目附件，同一份报告自首稿至定稿的全部修改稿，以及作为原始素材的投后访谈报告和月度投后管理纪要。研读方式是逐句比对“素材怎么说、首稿怎么写、定稿改成什么”，归纳出定稿稳定使用的句式、用词和删改规律。

逐类项目的要素顺序和段落模板见 [expression-playbook.md](expression-playbook.md)，句与句之间为什么这样接、判断凭什么成立见 [logic-chain.md](logic-chain.md)。三份文件冲突时，要素顺序以 `expression-playbook.md` 为准，其余以本文件和 `logic-chain.md` 为准。

本文件所有例句均已脱敏：主体写作“我司”“投管公司”“甲证券”“甲智能”“甲空天”“甲号基金”等，数字均为改写后的虚构数，不对应任何真实项目。

## 一、口吻从哪里来

定稿读起来像投后报告而不像聊天记录或机器摘要，靠的是四件事，缺一件口吻就会走样。

1. **站位固定。** 写的人是出资主体，读的人是上级单位或国资监管机构。全文只有一个“我”，即“我司”；被投企业、基金、合作方各有固定称谓，全文不换。不替被投企业说话，不替上级单位表态。
2. **依据在前。** 凡不是我司自己做的事，句子开头先交代凭什么这样说：“根据甲证券提供的YYYY年半年度财务报告（加盖公章，未经审计）”“根据YYYY年M月D日股东名册”“根据甲空天YYYY年M月D日滚动预测”“按照上级单位专题会议纪要要求”。
3. **用数字陈述，不用形容词陈述。** 定稿里几乎找不到“显著”“大幅”“亮眼”“稳健”这类词，程度由数字本身和同比、较年初、完成率体现。必须下判断时，使用第四部分的固定程度词。
4. **判断留有分寸。** 好事不夸大，坏事不回避，也不替未来打包票。定稿把“整体风险可控”改为“运营总体正常”，把“各项业务风险可测、可控、可承受”整句删去，换成“我司将持续关注其主要风险控制指标及相关风险应对措施落实情况”。

## 二、十三种基本句型

投后报告的正文几乎全部由下面十三种句子组成。起草时先判断这句话承担哪一种功能，再套对应句型；一句话只承担一种功能，功能不明的句子不写。

| 序号 | 功能 | 句型 | 例句 |
| --- | --- | --- | --- |
| 1 | 定义句 | 〔全称〕（以下简称“〔简称〕”）＋投资关系 | 甲证券股份有限公司（以下简称“甲证券”）初始股权投资金额为3亿元，我司现持有甲证券60,000,000股，持股比例1.2000%。 |
| 2 | 期间句 | YYYY年上半年，〔简称〕实现〔指标〕X、〔指标〕Y，同比分别…… | YYYY年上半年，甲证券实现营业收入10.20亿元、利润总额3.30亿元、净利润2.70亿元，同比分别下降15.20%、22.40%、20.10%。 |
| 3 | 时点句 | 截至YYYY年M月D日，〔简称〕〔存量指标〕X、Y、Z | 截至YYYY年6月30日，资产总额520.00亿元、负债总额380.00亿元、所有者权益140.00亿元。 |
| 4 | 读数句 | 用一句话读出上一句数字的含义，结论可由数字直接复算 | 资产规模保持增长，但负债增幅高于资产增幅，所有者权益有所回落。 |
| 5 | 归因句 | 因……，叠加……，〔简称〕……承压／受……等因素影响，……／主要系……所致 | 因项目验收集中于下半年，叠加售后成本增加及费用投入较高，甲空天经营业绩和现金流承压。 |
| 6 | 转折句 | 〔正向事实及数字〕，但受……影响，〔反向结果〕 | 报告期内，甲证券经纪业务、投资银行业务手续费净收入同比分别增长35.00%、28.00%，但受投资收益下降、公允价值变动收益减少等因素影响，营业收入和利润同比下滑。 |
| 7 | 研判句 | 根据〔依据〕研判，〔简称〕〔指标〕预计难以达到〔约定目标〕，〔后果〕的风险较高 | 根据YYYY年9月投后访谈及经营情况研判，甲智能全年营业收入预计难以达到《增资协议》约定的200万元目标，年末触发回购条款的风险较高。 |
| 8 | 传导句 | 若〔条件〕，〔简称〕可能〔后果〕，对〔对象一〕和〔对象二〕产生影响 | 若资产管理计划清算资产不足，甲证券可能承担相应现金支出，对经营现金流和当期损益产生影响。 |
| 9 | 测算句 | 按〔口径〕测算，〔结果〕；或“若实现……，下半年需……，约为上半年的N倍” | 若实现全年滚动预测，下半年需实现营业收入21,800.00万元，约为上半年的5.19倍。 |
| 10 | 措施句 | 为〔目的〕，〔我司或下属主体〕已〔动作〕并〔结果〕 | 为防范投资本金损失，投管公司已与甲智能实际控制人就退出事项进行初步沟通并达成回购意向。 |
| 11 | 履职句 | 〔简称〕召开〔会议〕N次，我司对应召开〔决策会议〕N次，对全部议案审议并形成表决意见 | 甲证券召开股东大会3次，我司对应召开投资决策委员会会议3次，对全部议案审议并形成表决意见。 |
| 12 | 无事项句 | 报告期内，〔主体〕未发生／未召开／未形成…… | 报告期内，两支基金未发生项目退出。 |
| 13 | 下一步句 | 下一步，我司将跟踪〔简称〕〔事项一〕、〔事项二〕……等情况，重点关注…… | 下一步，我司将跟踪甲空天重点项目交付验收、回款及毛利情况，重点关注应收账款和存货占用、全年业绩预测兑现及挂牌申报进度。 |

句型使用要点：

- 期间句和时点句用分号连成一句时，分号前后各自带齐时间状语；“YYYY年上半年，……；截至YYYY年6月30日，……”。
- 读数句只说数字里已有的东西。数字得不出的结论（如“经营质量明显改善”）不是读数句，要么补依据写成研判句，要么删去。
- 归因句的原因不超过三项，每一项都能在正文或附件中找到对应数字或事实。原因多于三项时，在附件用“主要受三方面影响：一是……；二是……；三是……”展开，正文只留最主要的两项。
- 无事项句不能省。没有退出、没有分配、没有召开会议，同样是需要上级知悉的状态，写“未发生”比不写更完整。
- 措施句的主语必须是实际做事的主体（我司或投管公司），不写“已沟通”“已对接”这类无主语短句。

## 三、段首定位词

定稿的每一段都以一个定位词起头，读者只看段首就知道这一段的时间范围和性质。全文只用下表这几种，不用“此外”“另外”“与此同时”“值得一提的是”等过渡语起段。

| 段首 | 表示 | 之后只能接 |
| --- | --- | --- |
| 截至YYYY年M月D日， | 期末时点 | 存量数：支数、规模、余额、资产负债、持股 |
| YYYY年上半年，／YYYY年度， | 报告期间 | 流量数：收入、利润、现金流及同比 |
| 报告期内， | 报告期间内发生的事项 | 分配、退出、会议、业务变化；不得接期后事项 |
| YYYY年以来， | 自年初至成文前 | 跨越期末的经营趋势描述 |
| 截至YYYY年M月， | 期后更新时点 | 诉讼仲裁、融资、挂牌、会议累计次数等期后进展 |
| 根据〔材料或日期〕， | 引用外部依据 | 持股、预测、研判 |
| 按照〔会议纪要或制度〕要求， | 决策依据 | 投资主体的确定、出资 |
| 为防范……，／为……， | 目的 | 已采取的措施 |
| 自投资以来， | 累计口径 | 累计分红、累计回收 |
| 下一步， | 后续安排 | 我司将……（对象＋动作） |

附件中另可使用“总体看，”“总体判断，”领起一句综合判断，使用“需说明的是，”领起口径差异说明；这三种只用于附件，每份附件各不超过两处，正文不用。

## 四、固定用词

### （一）动词

| 场合 | 用 | 不用 |
| --- | --- | --- |
| 业绩 | 实现营业收入、实现净利润 | 做到、达成了、斩获、录得 |
| 资金流入 | 取得现金分红、收回本金、取得投资收益 | 拿到、收到了、落袋 |
| 出资 | 完成首期实缴、足额支付出资款、累计实缴 | 打款、出了、投进去 |
| 基金动作 | 实施本金返还、完成中基协备案、完成项目立项 | 做了分配、搞定备案 |
| 会议 | 召开股东大会、审议并形成表决意见、履行决策程序 | 开会、过会、上会 |
| 负债准备 | 已计提预计负债 | 已经留了钱、做了准备 |
| 我司管理动作 | 跟踪、关注、研判、对接、推进、落实、督促 | 盯、盯紧、紧盯、把控、抓好 |
| 退出程序 | 推进退出方案审议、审计评估、逐级报批、国资备案及产权交易 | 走流程、办手续 |
| 股权关系 | 持有、受让、无偿划转、穿透测算、间接对应 | 占了、拿了、手里有 |

### （二）程度词及其使用条件

程度词是判断，必须与证据强度匹配，由轻到重只用下列几档，不自造。

| 程度词 | 使用条件 |
| --- | --- |
| 运营总体正常／总体稳定 | 报告期内无违约、无逾期、无监管处罚、程序正常，且列出了至少一项支撑事实（如“未发生项目退出，实施本金返还1次”） |
| 有所回落／有所压降／略有下降 | 同比或较年初变动为个位数百分比，句中已给出具体数字 |
| 进度不及预期／转化缓慢 | 有约定进度或预算可对照，实际明显落后 |
| 承压／持续承压 | 收入、利润、现金流中至少两项同比下降或为负，“持续”须有两期以上数据 |
| 存在较大压力 | 有量化缺口：预测数低于预算数，或完成率明显低于序时进度 |
| 风险较高 | 有明确的触发条件（协议条款、监管指标）和研判依据，实际与触发线差距明显 |
| 已触发／已发生 | 条件已成就，有文件或数据证明 |

不使用的程度词：显著、大幅、明显向好、强劲、亮眼、稳健（作评价时）、良好、可观、充足、充裕、无压力、向好态势、高质量。它们要么来自被投企业自我评价，要么没有可核验的标准。确需说明幅度时直接写数字。

### （三）状态词

写进展时用下列状态词，状态与事实一一对应，不混用。

| 状态 | 含义 |
| --- | --- |
| 已完成 | 事项办结，有日期或文件 |
| 正在推进／正在办理 | 已启动，未办结 |
| 尚未 | 应做而未做，或条件未具备 |
| 仍在 | 持续状态未变化（“仍在清算”“仍在执行”） |
| 暂无 | 截至成文时没有（“暂无证照使用记录”） |
| 计划于 | 被投企业或基金的计划，须带时间，并在下期核对是否兑现 |
| 拟 | 我司或下属主体尚未履行完决策程序的安排 |
| 预计 | 预测数，须带来源主体和预测日期 |

## 五、从素材到正文：口语和企业口径的转写

投后访谈、月度纪要、管理人季报里的话不能直接进报告。转写时做四件事：把口语词换成书面词，把约数换成有口径的数，把企业的自我评价改成带来源的事实或删去，把内部讨论的过程删去只留结果。

| 素材中的说法 | 问题 | 报告写法 |
| --- | --- | --- |
| 账上现在有10个亿，含8亿多清收款加2亿结余 | 口语；约数；加号入文 | 截至YYYY年M月D日，合伙企业银行账户余额10.20亿元，其中清收处置回款8.10亿元。（明细下沉附件） |
| 案子已经打通立案通道，首批一百多笔启动诉讼 | 口语；过程细节 | 正文不写；附件写“已有130笔债权进入诉讼程序”。 |
| 二审胜诉后待执行盘活，预计回款可观 | “可观”无标准；预测无依据 | 附件写“该案二审已胜诉，尚待执行”，删去回款预期。 |
| 利息兑付无压力，整体清收呈向好态势 | 企业口径的结论 | 删去；以回款金额、分配情况等事实代替。 |
| 公司反馈目前现金比较充足，财务状况良好 | 采信自我评价 | 期末货币资金60.00万元，较年初85.00万元下降29.41%。 |
| 营收大概在4.6亿左右，净利6,000万左右 | 简称；约数重复 | 据甲电子介绍，预计全年营业收入约4.60亿元、净利润约0.60亿元。（仅入附件） |
| 我们跟公司保持积极充分交流，一方面……另一方面…… | 自称；空话；套式 | 写具体动作：召开投资决策委员会会议N次、取得分红X万元、对接潜在受让方。 |
| 全面研判发展趋势，预择机退出 | 空泛；“预择机”不通 | 研究优化所持股权投资收益的可行路径，积极对接潜在受让方。 |
| 净值跌入1以下 | 口语 | 基金净值低于1（因本基金按成本法估值，扣除管理费后净值低于1）。 |
| 完成2025年度业绩对赌目标 | 行话 | 2025年度营业收入已达到《增资协议》约定金额。 |
| 营业利润达到81.83%的增益 | 生造搭配 | 营业利润同比增长81.83%。 |
| 公司作为中小券商，处于劣势，整改缓慢 | 评价被投企业，语气失当 | 受资产管理规模收缩及业绩报酬计提减少影响，资产管理业务收入同比下降。 |
| 较去年增长、今年内、目前、近期 | 相对时间 | 写具体年份或“截至YYYY年M月”。 |
| 三板、营收、净利、三费、投决会、软著 | 行业简称 | 新三板、营业收入、净利润、期间费用、投资决策委员会、软件著作权。 |
| 1-9月、2023-2024年 | 连接号 | 1—9月、2023—2024年。 |

转写后的句子仍要过一遍 [logic-chain.md](logic-chain.md) 的“一句四问”：主体、时点、数量、依据是否齐全。

## 六、去除机器腔

以下写法在定稿中一处也没有，出现即改。校验器对其中大部分给出警告。

| 类型 | 表现 | 改法 |
| --- | --- | --- |
| 开场和收尾 | “以下是……”“根据您提供的材料……”“综上所述”“总的来说”“总而言之”“希望以上内容……” | 删去。正文以开头段直接进入，以最后一个项目的“下一步”或台账结束。 |
| 提示语 | “值得注意的是”“需要指出的是”“需要强调的是”“不难看出”“可以看到” | 删去提示语，直接写事实。附件中的口径说明用“需说明的是，”。 |
| 推论套话 | “由此可见”“这表明”“这意味着”“从而”“进而” | 改为读数句，或补依据写成研判句。 |
| 序列套话 | “首先……其次……最后……”“一方面……另一方面……” | 正文按要素顺序直接写；附件确需分项时用“一是……；二是……；三是……”。 |
| 对比句式 | “不是……而是……”“不仅……更……”“既……又……”连用 | 直接陈述肯定的内容。 |
| 修辞 | 比喻、拟人、设问、反问、排比 | 全部删去。 |
| 拔高词 | 赋能、助力、抓手、闭环、打造、深耕、护航、引擎、新高度、新台阶、全方位、多维度 | 换成具体动作和对象；被投企业的业务介绍确需保留的，只进附件并注明“据〔简称〕介绍”。 |
| 无数字的形容 | 显著提升、大幅增长、稳步推进、持续向好、成效明显 | 写同比、较年初、完成率的具体数字。 |
| 自称 | 我们、本人、笔者、本报告认为 | 我司。 |
| 模糊限定叠加 | “可能或将在一定程度上对……产生一定影响” | 只保留一个限定：“可能对……产生影响”。 |
| 段末复述 | 段落最后一句把本段内容换个说法再讲一遍 | 删去。每段以事实、研判或“下一步”结束。 |
| 标点和版式 | 破折号引出解释、感叹号、问号、省略号、Markdown 的 `**`、`#`、`- ` 列表、表情符号 | 破折号改为逗号或“即”；正文不用列表，分项用“一是、二是”写在段内。 |

判断一句话是否有机器腔，可用一个简单办法：把这句话删去，上下文的事实、判断、安排有没有减少。没有减少的，就是该删的句子。

## 七、段落怎么写

1. **一段一事。** 正文每个项目写两至三段：第一段写投资关系和报告期数据，第二段写变化原因和研判，第三段写期后进展、履职情况和下一步。篇幅小的类别（如新设基金）合为一段。
2. **句子长度。** 一句话列举同类指标不超过四项，超过时拆句或下沉附件。一句话只有一个主语；分号之后换主语的，把新主语写出来。
3. **并列用顿号，层次用分号。** 同一句内的并列指标用“、”连接，最后两项之间不加“和”“及”；不同指标组之间用分号。
4. **“其中”只表示包含关系。** “其中”之后的数必须是前一个数的组成部分，且小于等于前数。
5. **“分别”与列举项一一对应。** “分别为A、B、C”前面必须有三个对象，顺序与对象一致。
6. **不在正文解释名词。** 需要解释的概念说明读者不需要它，移到附件或删去。
7. **不堆背景。** 被投企业是谁办的、获得过什么荣誉、行业前景如何，不进正文；首稿中“系某教授创办的智能设备科技公司”“为某基地优质科技孵化项目”在定稿中全部删去。

## 八、正文与附件的口吻差别

| 项目 | 正文 | 附件 |
| --- | --- | --- |
| 指代被投企业 | 一律用简称，不用“公司” | 开头定义后可用“公司”，但该附件内“公司”所指必须唯一 |
| 详略 | 只写结论和关键数字 | 写完整数据、表格、变动分析、口径说明 |
| 综合判断 | 不写“总体看” | 可用“总体看，”“总体判断，”各一至两处 |
| 业务描述 | 不写 | 可写事业部、产品、订单，写完数字后跟一句读数 |
| 行业排名、资质、荣誉 | 不写 | 可写，须注明“根据〔简称〕提供的经营分析材料” |
| 分项 | 不分项 | 可用“一是……；二是……；三是……” |
| 收束 | 下一步，我司将…… | “下一步”或“总体评价” |

附件开头统一交代依据和口径，例如：“按照股权投资项目投后管理工作安排，我司对参股企业甲证券YYYY年上半年经营发展、重大事项及风险情况进行了梳理。根据甲证券提供的YYYY年半年度财务报告（加盖公章，未经审计）及经营分析等材料，现将有关情况报告如下。”

## 九、改写示范

下面三组都是同一事实的两种写法。前一种是口语稿或机器稿，后一种是按本文件改写后的写法。

**示范一：参股公司**

> 改前：值得注意的是，甲证券今年上半年业绩出现了一定程度的下滑，营收约10.2亿，同比下降了15%左右。不过，公司经纪业务表现亮眼，整体来看经营依然稳健，风险可控。我们将持续关注。

> 改后：YYYY年上半年，甲证券实现营业收入10.20亿元、净利润2.70亿元，同比分别下降15.20%、20.10%。报告期内，甲证券经纪业务手续费净收入同比增长35.00%，但受投资收益下降、公允价值变动收益减少等因素影响，营业收入和利润同比下滑，主要风险控制指标总体稳定。下一步，我司将跟踪甲证券预算执行、投资收益及净资产变化等情况。

改动：删提示语；“今年上半年”写成具体期间；“营收约10.2亿”写成全称和确数；“亮眼”换成增幅；“稳健”“风险可控”换成有指标支撑的“主要风险控制指标总体稳定”；“我们将持续关注”换成有对象的下一步句。

**示范二：早期企业**

> 改前：甲智能目前经营情况不太理想，产品推广比较慢，现金流也比较紧张。首先，核心产品还没有形成规模销售；其次，新产品还在验证。这意味着今年的对赌目标大概率完不成，可能要触发回购。

> 改后：YYYY年以来，甲智能核心产品推广进度不及预期，新产品多处于样机验证或小批量交付阶段，收入转化缓慢，经营活动和现金流持续承压。根据YYYY年9月投后访谈及经营情况研判，甲智能全年营业收入预计难以达到《增资协议》约定的200万元目标，年末触发回购条款的风险较高。

改动：“目前”换成“YYYY年以来”；“不太理想”“比较慢”“比较紧张”换成固定程度词；删“首先、其次”；“这意味着”换成带依据的研判句；“对赌目标”写成协议名称和金额；“大概率完不成”“可能要”合并为“预计难以达到……风险较高”。

**示范三：专项投资载体**

> 改前：该SPV运作良好，资金已全部到位，交易对价也都付完了，后续我们会积极跟进清收情况，确保国有资产安全。

> 改后：截至YYYY年6月30日，甲资产投资合伙企业（有限合伙）实缴出资合计80.00亿元，其中我司作为优先级有限合伙人实缴出资3亿元，出资比例3.75%。合伙企业已付清不良资产包全部交易对价，并委托甲银行开展清收处置。下一步，我司将跟进甲银行SPV项目清收回款及本金、收益分配进展。

改动：“运作良好”删去，以出资和交易事实代替；“资金已全部到位”写出金额和比例；“我们”改“我司”；“积极跟进清收情况”写出跟进的三个对象；“确保国有资产安全”属无法由我司单方保证的承诺，删去。

## 十、成稿前口吻自查

- [ ] 全文没有“我们”“值得注意的是”“综上所述”“首先、其次”“不是……而是……”“由此可见”等写法，没有破折号、感叹号、问号和列表符号。
- [ ] 每一段以第三部分列出的定位词起头。
- [ ] 每一句都能归入第二部分的十三种句型之一。
- [ ] 程度词只用第四部分列出的几档，且各自的使用条件成立。
- [ ] 来自被投企业或管理人的评价性表述已删去，或已改为带来源的事实。
- [ ] 约数只用“约”，不用“左右”“大概”“附近”“上下”；同一数字不同时带“约”和“左右”。
- [ ] 行业简称已写全称；相对时间已写成具体年月。
- [ ] 删去任何一句都会减少事实、判断或安排；否则该句已删。
