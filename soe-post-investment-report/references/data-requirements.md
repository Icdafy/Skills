# 数据需求与勾稽清单

本清单按定稿投后报告实际使用的数据整理：先列全局信息，再按项目类型列出必需数据项、口径、常见来源和落位，最后给出勾稽公式、时间口径规则和定稿核对中暴露的数据陷阱。建立项目名册和事实台账（见 `source-intake-and-fact-ledger.md`）时逐项对照；缺项写入交付说明，不得臆补。

## 一、全局信息

| 数据项 | 要求 |
| --- | --- |
| 报告单位全称及自称 | 正文统一自称“我司” |
| 上级单位、下属投资主体 | 固定称谓表，如“上级单位××控股公司”“我司下属××投资管理有限公司（以下简称“投管公司”）” |
| 报告形式 | 取自上一期定稿：`文件式` 或 `内部报告式` |
| 报告年度与报告期间 | 由数据截止日期推定，6月30日、12月31日须用户确认口径 |
| 数据截止日期 | 财务数据的期末时点 |
| 期后事项更新时点 | 重大事项、诉讼仲裁、会议、融资等进展的更新月份，写入开头口径声明 |
| 成文日期 | 内部报告式在标题下显示为“YYYY年M月” |
| 上一期定稿 | 基础模板，提供固定框架、上期累计数和上期口径 |

## 二、按项目类型的数据清单

### （一）参股基金

| 数据项 | 口径 | 常见来源 | 落位 |
| --- | --- | --- | --- |
| 基金全称、简称、所处阶段 | 按合伙协议期限结构判断投资期或退出期 | 合伙协议、管理人报告 | 正文＋附件 |
| 设立日期、期限结构、到期日 | 合伙协议 | 合伙协议 | 附件 |
| 基金认缴规模、累计实缴规模 | 基金口径 | 管理人季度／年度报告 | 正文（实缴）＋附件 |
| 我司认缴、累计实缴、份额 | 我司口径 | 出资凭证、合伙人名册 | 正文＋台账 |
| 账面净资产 | 截至期末，基金口径 | 基金财务报表 | 附件 |
| 已分配及退出累计 | 自成立至期末 | 分配通知、管理人报告 | 附件 |
| 公允价值（含已分配及退出部分） | 账面净资产＋已分配累计 | 计算 | 正文＋附件 |
| 基金净值 | 公允价值÷累计实缴规模 | 计算 | 正文＋附件 |
| 估值方法 | 成本法、市场法、最近融资法等；净值低于1时说明原因 | 估值报告 | 附件 |
| 报告期内分配、本金返还、退出 | 分配给各合伙人的金额及我司所得 | 分配通知 | 正文（我司所得）＋附件 |
| 累计投资项目数、退出项目数 | 截至期末 | 管理人报告 | 附件 |
| 子项目：投资额、当前持股比例、投资时估值、后轮融资、近两年及本期营业收入和净利润、上市进展、回购或对赌安排 | 子项目口径 | 管理人报告、被投企业资料 | 附件表格 |

### （二）双GP基金（新设基金）

备案日期、合作管理人、成立日期、存续期、认缴规模、首期及累计实缴、我司认缴与实缴、重点投向、当前阶段；报告期投资决策委员会召开情况、立项与投资项目数、退出与分配；期末净资产、报告期收入构成。期后立项等进展单独标注截至月份。

### （三）参股公司——成熟企业

| 类别 | 数据项 |
| --- | --- |
| 投资 | 初始投资金额、取得方式（如无偿划转及时间）、现持股数、持股比例 |
| 业绩 | 营业收入、利润总额、净利润及同比；主要业务条线收入及同比；投资收益、公允价值变动收益；业务及管理费 |
| 财务状况 | 资产总额、负债总额、所有者权益及较年初变动；其他综合收益税后净额、综合收益总额 |
| 行业指标 | 如证券公司的净资本、风险覆盖率、资本杠杆率、流动性覆盖率、净稳定资金率 |
| 预算 | 年度预算数及上半年完成率（与序时进度比较） |
| 分红 | 利润分配方案、每10股派息、我司应得及实得金额、到账月份、历次分红及累计数 |
| 风险 | 诉讼仲裁的标的、阶段、计提、实际支付；行政处罚及整改；业务资格恢复情况 |
| 治理 | 报告期（或截至期后月份）股东大会次数、我司投资决策委员会会议次数及表决情况 |
| 其他 | 行业排名、荣誉、资质（仅附件） |

### （四）参股公司——早期或对赌企业

投资主体、投资金额、持股比例、交割时间；未经审计的资产、负债、所有者权益，营业收入、净利润、经营活动现金流量净额，货币资金、应收账款及较年初变动；在手合同（委托方、金额、进展、回款）；知识产权；《增资协议》业绩目标、专利目标、回购触发条件及价格规则原文；国资文件对回购价格的要求；投后访谈时间及研判结论；退出沟通进展、退出议题形成时间、退出程序步骤。

### （五）SPV项目——受让不良资产类

决策依据文件、投资主体、协议签署日、出资日、出资金额、收益约定；合伙企业注册资本与实缴、各级合伙人出资金额及比例、我司身份和比例；不良资产包交易价、各期价款支付节点；委托处置协议及公告；清收回款及对账情况；合伙人大会次数、议题及表决结果；账户余额、累计收入与支出构成；章证照使用、对外合同履行；工商变更进展。

### （六）SPV项目——股权投资类

专项投资载体结构及各方出资比例；股东名册日期、载体持股数及比例、穿透持股测算；利润表主要项目两期对比（营业收入、营业成本、毛利及毛利率、期间费用、净利润、经营活动现金流量净额）；资产负债主要项目及较年初变动（资产负债率、货币资金、应收账款、存货、借款）；业务线订单、收入、毛利；经营口径与会计口径差异；年度预算与滚动预测；期后融资（投前估值、增资金额、投后估值、新股东）；资本市场路径与时间表。

### （七）项目台账

每个项目：法定全称、首次出资时间、投资期限、我司实缴投资、账面净值（标注暂估）、累计退出资金、累计收益率（账面）；以及合计行。列定义见 `expression-playbook.md` 第四部分第（七）项。

## 三、勾稽公式

| 用途 | 公式 |
| --- | --- |
| 基金公允价值 | 账面净资产＋已分配及退出累计 |
| 基金净值 | 公允价值÷累计实缴规模 |
| 我司基金账面净值 | 基金账面净资产×我司份额 |
| 我司基金累计退出资金 | 基金累计分配×我司份额（或按分配通知逐笔加总） |
| 累计收益率（账面） | （账面净值＋累计退出资金－实缴投资）÷实缴投资 |
| 台账合计 | 各行对应列之和；比率列不求和 |
| 累计分红 | 上期累计＋本期到账 |
| 预算完成率 | 本期实际÷年度预算，并与序时进度（半年50%）比较 |
| 下半年需实现 | 全年预测－上半年实际；倍数＝下半年需实现÷上半年实际 |
| 穿透持股 | 载体持股比例×我司各主体在载体中的出资比例 |
| 出资比例 | 我司实缴÷合伙企业实缴合计 |
| 同比 | （本期－上年同期）÷上年同期绝对值；比率指标用“百分点” |
| 亏损变化 | 本期净利润－上年同期净利润，亏损扩大写“同比增亏” |
| 投后估值 | 投前估值＋本轮增资额 |
| 期末货币资金变动 | （期末－年初）÷年初 |

每个计算事实在台账中保留公式、输入事实和舍入规则；四舍五入差异在一个最小单位以内时注明“因四舍五入存在尾差”。

## 四、时间口径规则

- 财务数据一律为数据截止日期或报告期口径；期后进展单独标注“截至YYYY年M月”。
- “报告期内”只统领报告期内发生的事项。期后才发生或统计口径延伸到期后的事项，不得以“报告期内”领起。
- 时点写到日（“截至YYYY年6月30日”，不写“6月末”）；期后进展可写到月。
- 同一事件的日期在正文、台账、附件中必须一致；台账“首次出资时间”只用一种口径。

## 五、定稿核对中暴露的数据陷阱

| 陷阱 | 表现 | 处理 |
| --- | --- | --- |
| 分项更正未联动 | 某基金退出资金更正后，该行收益率和合计行仍是旧数 | 分项改动后重算所在行比率和合计行；校验器对合计行做加总核对 |
| 日期口径混用 | 台账“设立／投资时间”与附件“设立日期”不一致 | 列名限定单一口径并与附件一致 |
| 累计数未滚动 | 沿用上期累计分红，主体仍写上级单位 | 上期累计＋本期；主体改为我司 |
| 统计区间越界 | “报告期内召开股东大会5次”，实际统计到期后 | 改为“截至YYYY年9月”或只数报告期内 |
| 状态滞后 | 已到账仍写“预计可取得” | 按实际状态改写 |
| 口径混写 | 经营口径收入与合并报表收入混用 | 写明差异金额和原因，以合并报表为准 |
| 异常值无说明 | 营业收入为负、负债为负 | 在出现处注明原因（如收入冲回） |
| 格式缺陷 | 缺千位分隔符、同列小数位不一、畸形分节、净利润大于营业收入 | 按来源核对后统一两位小数和千分位 |
| 单位混用 | 同一附件中“元”与“万元”并存 | 表头或单位行写明，正文统一万元 |
| 个人信息 | 子项目表含法定代表人、联系人、电话、地址 | 删除，不进入报告 |
