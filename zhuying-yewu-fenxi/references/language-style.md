# 语言风格规范与句式库

## 一、总体风格

立项报告是投资机构内部评审文件，语言基调为正式、清楚、中性：呈现事实、说明因果、形成与证据相称的判断。

1. 专业——保留必要的投资与财务术语，首次出现时解释其含义及对决策的作用，无网络语、口语；
2. 客观——陈述句为主，无感叹、反问、排比造势；
3. 适度——判断强度与证据匹配，直接表述，不刻意弱化已经证实的结论；
4. 公允——优劣并陈，为项目方辩护和刻意唱衰都不允许；
5. 清楚——一段围绕一个判断，长句按因果关系拆开，关键数字和具名事实服务判断；
6. 结论前置——章、节、段三层先判断后证据（详见 writing-dna.md 第一节）。

## 二、硬性禁令（输出前逐条全文扫描）

### 禁令一：称谓

全文禁用**标的公司、标的企业、该标的、本标的、目标公司**。直接写公司简称（因诺科技、伊隆纬特）或"公司"。同一段内首次出现用简称，后续可用"公司"回指，两者交替使用避免单调。

### 禁令二：对举连词（AI腔标志，一律禁用）

- ~~不是……而是……~~
- ~~并非……而是……~~
- ~~不仅……而且……~~ / ~~不仅……更……~~ / ~~不仅……还……~~ / ~~不仅……也……~~
- ~~不止……而是……~~ / ~~不只是……更是……~~
- ~~不但……还……~~ / ~~不光……还……~~
- ~~不仅仅是……~~ / ~~更是……~~（用作递进强调时）
- ~~与其说……不如说……~~

**改写方法**：一语点明核心，正面直陈；确需对比时用"相较于……，公司……"或拆成两个独立句。

| AI腔原句 | 规范改写 |
| --- | --- |
| 这不仅降低了用户的重复购置成本，更使其产品能够无缝适配产业格局 | 该设计降低了用户的重复购置成本，产品可同时适配高轨与低轨并存的产业格局 |
| 这不是单一模块的优化，而是射频、基带、伺服等多项技术的耦合 | 该能力涉及射频、基带、伺服、热设计、结构多项技术的耦合，单一模块优化无法实现 |
| 公司不仅有硬件优势，还有软件算法积累 | 公司的优势覆盖硬件与软件两端：硬件方面……；软件方面…… |
| 竞争力并非来自价格，而是来自可靠性 | 竞争力来自可靠性：故障率千分之五以下，优于大疆同类产品 |

### 禁令三：机械过渡与总结腔

- ~~综上所述~~、~~总而言之~~、~~由此可见~~、~~不难看出~~、~~值得一提的是~~（风险直接写事实及影响，省去提示性引子）；
- ~~首先/其次/再次/最后~~ 的机械四段（枚举用"一是…二是…三是…"，这是公文体标准写法）；
- 三个短语的排比堆叠（"高效、精准、智能"式），保留一两个有数据支撑的即可。

### 禁令四：引注学生腔

~~根据某某材料显示~~ / ~~从某某材料可以看出~~ / ~~通过分析我们发现~~。改用分析语态或范文式归因：

- 在收入结构方面，……／在客户结构方面，……
- 根据2025年分业务口径经营数据，……
- 根据访谈，……／公司表示，……／据管理层访谈，……
- 经核实，……（仅限已核实数据）／根据XX的BOM清单及采购台账，……

### 禁令五：营销与夸张措辞（无第三方数据支撑一律不得出现）

- ~~行业领先~~、~~遥遥领先~~、~~处于领先地位~~（有依据时写"据管理层访谈，公司在……细分领域市占率约……%"）；
- ~~壁垒极高~~、~~不可替代~~、~~独一无二~~、~~颠覆性~~、~~革命性~~、~~护城河深厚~~；
- ~~前景广阔~~、~~极具潜力~~、~~爆发式增长~~、~~高速增长~~（增速有数据直接写数字）；
- ~~赛道火热~~、~~风口~~、~~蓝海~~、~~赋能~~、~~闭环~~（业务黑话；"蓝海"若为企业原话须归因并保持距离）；
- 引用产品资料入表时同样降格：~~真正实现~~、~~卓越~~、~~全新模式~~ → 中性功能描述；
- ~~国内暂无同规格竞品~~、~~唯一~~、~~首家~~、~~填补国内空白~~：排他论断一经反例即损害全文可信度。确有检索依据时写“经公开检索，国内暂未发现同规格产品”，并紧跟最接近的国内外可比企业及其产品差异（用途、规格、售价）。

### 禁令七：措辞与证据错位

- 证据已支撑技术差异时，不用“具备一定技术基础”“有一定优势”等模糊措辞收尾——写清对标结果（“公司 X 型产品空重 3.2kg，与海外同规格产品 3.0kg 处于同一水平，售价约为其 1/5”）；
- 证据不足时收窄判断范围，不用“处于领先地位”“第一梯队”拔高；
- 删去只给自己留余地的免责尾句（“该价格不包含……”“该毛利率为初步测算，不代表……”），把口径写进表头或同句限定语；真实的实质约束保留。

### 禁令八：公文数字、括号与用词

- 数值范围两端都带量级和百分号：`7万—10万元`、`300万—350万元`、`15%—30%`；单位不含“万/亿”时可只在末尾写，如 `30—40套`、`2—3天`；
- 中文语境用全角括号 `（电池+燃料电池）`；
- 规范用词：来自（非“来自于”）、黏度（非“粘度”）、“为公司核心产品”（非“公司为核心产品”）、DF 系列为某公司无人机“原机”（非“所属”）；
- 人员或主体的任职、持股状态写明时点：“曾任”“现任”“至今”，不用“前”字造成歧义。

### 禁令六：越权结论

~~建议立项~~、~~值得投资~~、~~建议尽快推进~~（立项结论属于报告其他章节与投委会）；~~该数据真实可靠~~（立项阶段无法背书数据真实性）。

## 三、确定性分级句式（结论强度阶梯，不允许跨级）

| 证据级别 | 典型来源 | 句式 |
| --- | --- | --- |
| A 已审计/已核实 | 审计报告、核对过的报表 | 直接陈述："报告期内公司实现主营业务收入……万元" |
| B 企业自述 | BP、访谈纪要、管理层报表 | 保留归因："根据访谈，……""公司提供数据显示……""公司预测……" |
| C 外部公开 | 招股书、年报、政府文件、研报 | 注明来源："据……披露/统计，……" |
| D 推算 | 由A/B/C数据计算 | 给出算式："按在手订单测算，订单覆盖率约……%（=……/……）" |
| E 缺失/矛盾 | — | 缺失：该数据不写入正文与表格，缺口进对话交付的"资料缺口与待核查清单"；矛盾（两口径都有数据）：正文并列实质不同的口径，写明差异与影响；核查任务另放清单 |

程度副词纪律：

- "较高/较低/一定/相对"——仅在有比较基准或适用范围时使用；
- "较大/明显"——须有数据反差支撑（占比超50%、波动超30%）；
- "绝对领先/龙头"——仅当有市占率数据且已归因（范文："市场占有率超过90%，处于绝对领先地位"）；
- "重大/严重"——仅用于足以影响立项判断的事项；
- "极/非常/十分/显著"——原则上不用。

## 四、高频功能句式库

**板块定位判断句（板块开头必用）**：

> XX板块为公司……（起家的核心优势赛道/核心成熟板块/战略新赛道），核心围绕……打造……，（技术壁垒/市占率/客户覆盖的最硬事实），目前正从……向……（战略走向）。

**开节定调**：

> 在……方面，公司……／根据2025年分业务口径经营数据，……

**归因**：

> ……，主要系……所致／增长主要来自……（具体客户、订单、产品放量）

**优势收束（每项竞争力的落点）**：

> 公司在……方面形成……积累，主要体现在……（事实/数据）。其形成原因是……，对客户的实际价值体现为……（以已有证据填写）。

**转折与风险内嵌**：

> 公司……业务受……条件约束；若……发生变化，将通过……影响……（说明实际机制和依据）。
> ……回款周期为……，资金占用增加……，影响……（写已有依据支持的经营影响）。

**或有事项**：

> 若试用顺利将增配至……／若项目进展顺利，后续订单量至少……（条件句，与确定性订单分开）

**预测收束**：

> 根据公司在手订单，预计20XX年实现总营收……亿-……亿元，其中……板块……。上表为公司管理层预测数据，其实现依赖……，本报告未对该预测进行验证。

## 五、改写示例

**例1（营销化→规范）**

- 原文（企业BP）："公司产品性能遥遥领先，已成为行业标杆，未来三年将迎来爆发式增长。"
- 改写："公司提供的测试数据显示，产品飞行半径20公里，大疆同类产品为5-6公里。公司预测未来三年收入由……增长至……万元，该预测的实现依赖……，本报告未对其进行验证。"

**例2（空泛→有据）**

- 原文："公司客户资源丰富，合作关系稳定。"
- 改写："公司客户以央企及军工院所为主，与中国卫通已形成长期配套关系，报告期内前五大客户收入占比为……%。客户集中于大型国有主体，订单质量较高，同时验收流程长、回款周期慢，对营运资金形成持续压力。"

**例3（结论后置→结论前置）**

- 原文："油气管网巡检市场规模较大，公司在该领域布局多年，积累了较多客户，市场地位较为领先。"
- 改写："因诺科技在国家管网集团的市场占有率超过90%，处于绝对领先地位。国家管网集团有巡检需求的18家二级单位中，公司已覆盖17家。"

**例4（对举连词→直陈）**

- 原文："公司的壁垒不仅在于硬件，更在于八年数据积累训练出的算法模型。"
- 改写："公司的核心壁垒是八年数据积累训练出的算法模型，可实现数据分级风险判定与即时预警处置，短期内竞对难以复刻；硬件端的定制开发能力提供了配套支撑。"

**例5（回避风险→审慎呈现）**

- 原文："公司毛利率维持在较高水平。"（实际最近一期从41.70%降至23.90%）
- 改写："报告期内公司综合毛利率分别为41.84%、41.70%和23.90%，最近一期明显下降，主要系……。上述期间长度和产品结构差异需按相同口径比较；不据单季数据外推全年水平。"
