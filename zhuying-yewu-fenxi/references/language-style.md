# 语言风格规范与句式库

## 一、总体风格

立项报告是投资机构内部评审文件，语言基调是**冷静的专业怀疑**：呈现事实、组织证据、审慎判断。整体要求：

1. 专业——用投资与财务的规范术语（报告期、口径、集中度、可持续性），不用网络语、口语；
2. 客观——描述事实用陈述句，不用感叹、反问、排比造势；
3. 审慎——判断留有余地，强度与证据匹配；
4. 公允——优势与劣势并呈，不为项目方辩护，也不刻意唱衰；
5. 中性——不代入情绪，不用"遗憾的是""令人惊喜的是"；
6. 逻辑严密——每个判断能回溯到前文的数据或事实；
7. 书面化——完整句子，公文化衔接词（"在……方面""与此同时""需要关注的是"）。

## 二、禁用表达清单

**禁用·引注句式**（学生腔，改用分析语态）：

- ~~根据某某材料显示~~ / ~~根据某某文件提出~~ / ~~从某某材料可以看出~~ / ~~通过分析我们发现~~

**禁用·夸张与营销措辞**（无数据支撑一律不得出现；即便企业自述中出现，也须降格改写）：

- ~~公司非常优秀~~、~~前景十分广阔~~、~~极具投资价值~~、~~未来必将高速增长~~
- ~~行业领先~~、~~遥遥领先~~、~~处于领先地位~~（除非有第三方数据，且写明依据）
- ~~壁垒极高~~、~~不可替代~~、~~独一无二~~、~~颠覆性~~、~~革命性~~
- ~~显著领先~~、~~极具潜力~~、~~高速增长~~（增速有数据时直接写数字）、~~前景广阔~~
- ~~赛道火热~~、~~风口~~、~~蓝海~~（引用企业原话须加归因并保持距离）

**禁用·越权结论**：

- ~~建议立项~~ / ~~值得投资~~ / ~~建议尽快推进~~（立项结论不属于本章）
- ~~该数据真实可靠~~（立项阶段无法背书数据真实性）

## 三、替代表达对照

| 想表达的意思 | 禁用写法 | 规范写法 |
| --- | --- | --- |
| 引出分析角度 | 根据材料显示…… | 在主营业务构成方面，……／在收入结构方面，……／在客户结构方面，……／在产品布局方面，……／在盈利能力方面，……／在业务持续性方面，…… |
| 引用资料信息 | 从BP可以看出…… | 现有资料反映，……／结合目前可获得信息，…… |
| 引用管理层说法 | 公司表示自己市占率第一 | 据管理层访谈，公司在……细分领域市占率约……%，该数据尚需第三方数据佐证 |
| 增长快 | 高速增长 | 报告期内收入由……万元增长至……万元，年复合增长率约……% |
| 有竞争优势 | 行业领先、壁垒极高 | 公司在……方面形成了一定积累，主要体现在……；该等积累有助于……，但其持续性仍需结合……进一步验证 |
| 有风险 | （回避不写） | 需要关注的是，……若未来……发生变化，可能对……产生一定影响 |
| 资料没有 | （编一个或跳过） | 资料未披露／尚需进一步核查／该事项仍需在后续尽调中进一步核查 |
| 业务有基础但未验证 | 前景广阔 | 该业务具备一定基础，但其持续性仍需结合……进一步验证 |

## 四、确定性分级句式（结论强度阶梯）

按证据强度选择句式，**不允许跨级使用**：

| 证据级别 | 典型来源 | 句式 |
| --- | --- | --- |
| A 已审计/已核实 | 审计报告、核对过的报表 | 直接陈述："报告期内公司实现主营业务收入……万元" |
| B 企业自述 | BP、访谈、管理层报表 | 保留归因："公司提供数据显示……""据管理层访谈，……""公司预测……" |
| C 外部公开 | 官网、研报、公开披露 | 注明来源："据……披露/统计，……" |
| D 推算 | 由 A/B 数据计算 | 给出算式："按在手订单测算，订单覆盖率约……%（=……/……）" |
| E 缺失/矛盾 | — | "资料未披露""不同来源之间存在差异，需进一步核查" |

程度副词的使用纪律：

- "较高/较低/一定/相对"——常规审慎表述，可自由使用；
- "较大/明显"——须有数据反差支撑（如占比超 50%、波动超 30%）；
- "重大/严重"——仅用于足以影响立项判断的事项；
- "极/非常/十分/显著"——原则上不用。

## 五、高频功能句式库

**开节定调**：

- 在……方面，公司……
- 报告期内，公司……情况如下：

**归因**：

- ……，主要系……所致
- 增长主要来自……（具体客户/订单/产品放量），而非……

**转折提示**（优势后接约束，本文体的标志性节奏）：

- 但同时，仍需关注……
- 需要指出的是，……
- 与此同时，……对公司营运资金形成持续压力

**风险提示**（模块 11 固定句式）：

- 需要关注的是，报告期内公司……占比较高，若未来……发生变化，可能对公司……产生一定影响。建议后续尽调中核查……

**持续性存疑**：

- ……是否具有持续性，仍需结合……进一步观察
- 该模式的可复制性尚待……验证
- ……需持续关注

**小结**（模块 12 固定句式）：

- 总体来看，公司主营业务围绕……展开，收入来源主要来自……，业务模式具备一定清晰度。报告期内，公司……表现出一定增长基础。但同时，仍需关注……等因素对业务持续性和盈利稳定性的影响。后续尽调中，建议重点核查……

## 六、改写示例

**例 1（营销化 → 规范）**

- 原文（企业 BP）："公司产品性能遥遥领先，已成为行业标杆，未来三年将迎来爆发式增长。"
- 改写："公司提供的测试数据显示，其产品在……指标上优于所对比的传统方案（……降低……%）。公司预测未来三年收入由……增长至……万元，该预测的实现依赖……，本报告未对其进行验证。"

**例 2（空泛 → 有据）**

- 原文："公司客户资源丰富，合作关系稳定。"
- 改写："公司客户以央企及军工院所为主，与……已形成长期配套关系（……年起持续供货），报告期内前五大客户收入占比为……%。客户资源集中于大型国有主体，订单质量较高，但亦伴随验收流程长、回款周期慢的特征。"

**例 3（回避风险 → 审慎呈现）**

- 原文："公司毛利率维持在较高水平。"（实际最近一期毛利率从 41.70% 降至 23.90%）
- 改写："报告期内公司综合毛利率分别为 41.84%、41.70% 和 23.90%，最近一期毛利率明显下降，主要系……。该变动是否具有持续性，仍需结合全年数据及产品结构变化进一步观察。"
