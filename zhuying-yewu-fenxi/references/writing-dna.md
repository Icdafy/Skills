# 范文写作基因解构

> 标题以用户选择的 `assets/templates/early.json` 或 `mid-late.json` 为唯一来源。本文件的旧例仅说明标题内部的内容写法，不能用于选阶段、改题、裁剪、合并或新增章节。先执行 [阶段模板规则](stage-template-workflow.md)。

本文件是内部范文（因诺科技、伊隆纬特主营业务分析，以及 2026-09 早前期终稿）的逐段解构结果。写作时每一条都是硬要求，自检时逐条对照。早前期的节结构与逐节写法以第十节为准，第一至九节的句式、订单写法和数据纪律两阶段通用。

## 一、结论前置三层法

范文在章、节、段三个层级全部采用"先判断、后证据"的顺序，这是全篇最核心的写作习惯。

**层级一｜板块/章节开头的定位判断句。** 每个业务板块的第一句话必须同时说清三件事：这块业务在公司内部什么地位、在市场上什么位次、战略上往哪走。范文原句：

> 军工板块为公司起家的核心优势赛道，核心围绕巡飞弹/靶机打造全链条配套解决方案，技术壁垒高、市场占有率领先，客户覆盖各大军兵种及核心军工工业部门，目前正从军工配套企业向军方直接供应商迈进。

> 能源板块为公司核心成熟板块……目前聚焦于以油气管网巡检业务为支柱，风电光伏巡检业务为补充的业务场景，尤其已在油气管网巡检领域形成绝对龙头地位，是公司营收增长的主要来源。

一句里有地位（起家赛道/成熟板块）、位次（市占领先/绝对龙头）、方向（配套商→直供商）。后文全部内容都是给这句话补证据。

**层级二｜内容化标题。** 小节标题能承载结论的就让它承载。范文原题：

> 2. 下游客户结构：央企主导、海外突破、集中度较高

评审扫一眼目录就能拿到判断。适用于模式、客户、供应链等归纳型小节；业务介绍、订单明细等事实型小节用中性标题即可，标题结论化以不牵强为度。

**层级三｜段首判断句。** 分析段的第一句是判断，数字跟在后面。范文原句：

> 因诺科技在国家管网集团的市场占有率超过90%，处于绝对领先地位，剩余10%主要为大疆或部分用大疆飞机做小单的代理公司。

先给位次（90%、绝对领先），随手把剩余市场的构成也交代了。反例是先铺陈背景最后才说结论——立项报告不用这种写法。

**概况节的定性+定量双开门。** 章首概况固定两段起手：第一段一句话定性（载体/产品+围绕什么板块或场景+向谁提供什么+怎么收钱），第二段立即给最近一期分业务收入拆分（总额+各板块金额+占比），然后上收入结构表。范文原文：

> 因诺科技以智能飞行机器人为核心硬件载体，围绕军工、能源、交通三大业务板块开展细分场景的软硬件及解决方案的一体化服务。
> 根据2025年分业务口径经营数据来看，2025年经营收入2.63亿元，其中特种飞行集群业务0.58亿元，占比22.17%，能源巡检业务为1.23亿元，占比46.96%，智慧城市管理业务0.81亿元，占比30.87%。

## 二、数据密实：每个判断跟一个可验证事实

范文的信息密度来自四个纪律：

**1. 订单写法（五要素）。** 客户 + 数量 + 金额/单价 + 当前阶段 + 或有上翻空间。范文原句：

> 公司中标火箭军某龙基地侦察监视无人机项目，当前处于研发阶段，2026年开始交付，首期订单14套，若试用顺利将增配至60余套，单套单价200余万元。若项目进展顺利，……未来订单量至少6000万元。

或有部分（"若试用顺利""若项目进展顺利"）必须用条件句，与确定性订单区分。产品表的"销售情况"列同理：写"南京六九零二0.45米Ka无人船（50套/750万，单价15万）"，让评审直接判断商业化真实程度；未量产的如实写"样机验证阶段，尚未形成规模收入"。

**2. 对比必须具名。** 性能与成本优势一律给出具名基准和量化差值：

> 实际测试工作的飞行半径20公里（远超大疆的5-6公里）……故障率降到千分之五以下，优于大疆。
> 目前伊隆纬特的抛面动中通价格在15-17万，此前行业均价在30万左右。
> 行业传统0.35m机载机械式动中通主流重量12～24kg，（公司产品）重量小于6kg。

"性能优异""极具性价比"这类无基准形容词不允许单独出现。

**3. 生产与团队要素可稽核。** 写到产能、团队时给出可以在尽调中复核的具体要素：厂房面积、人数、班制、台数、关键人物姓名与背景。范文原句：

> 生产场地为租赁厂房640㎡（含库房120㎡），现有生产人员12人（含电装4人、机装4人），采用单班制（周一至周五8小时），年组装能力当前约400–500台。
> 研发中心现有27人，核心6人，首席科学家鄢泽洪教授（西电电磁场与微波技术）、射频总工伍金霄（西电硕士、华为/天鼎背景）……

**4. 大客户渗透深度量化。** 客户关系写到"覆盖到什么程度"这一层：

> 围绕国家管网集团有巡检需求的18家二级单位中，已覆盖17家，其中一家海南公司尚未覆盖，主要考虑距离因素。

## 三、四拍技术优势法（技术驱动型业务专用）

伊隆纬特范文的核心技术优势节，每一条优势都按固定四拍展开：

1. **传统方案痛点**：先客观描述行业通行方案及其缺陷（"传统抛面动中通采用'电机+控制器+减速机构'架构，部件多、体积大、重量高"）；
2. **公司方案**：公司采用了什么不同做法（"采用机器人直驱关节一体化设计，搭载自研电机伺服矢量控制器"）；
3. **量化改善与行业高度**：给出改善幅度（"驱动部件重量降低50%-70%；综合成本降低70%-80%"），数据须来自资料并归因；同时写清该技术在业内的位置——“行业通行做法/具名企业 A 达到……，公司达到……”，多项技术用技术对标表（见 `chapter-template.md`）。只写公司做了什么、不写与谁比、比到什么程度，读者看不出技术高度，立项结论也只能写成“具备一定技术基础”；
4. **壁垒论证**：解释为什么后来者短期难以复制。范文给出三种论证路径，选贴合的用：
   - **先发闭环**："已完成特定器件选型、误差标定、试飞验证及客户报价体系建立，后来者需在同等时间周期内完成上述闭环，且面临客户对新型号可靠性不信任的验证门槛"；无人机、航空器、车载等需要整机适配和飞行（运行）验证的行业，先发优势往往是最重要的壁垒，应单独成段着重写：首飞/首单/首个配套型号的时间及与同类企业的时间差，已适配的平台数量，参与起草的标准，进入整机设计阶段后客户更换供应商需重新做接口匹配、地面试验和飞行验证的成本；
   - **多技术耦合**："需要在一套射频前端内解决收发隔离、频率规划、时序同步等工程冲突，是射频、基带、伺服、热设计、结构多项技术的耦合，难以通过外采模块简单拼装实现"；
   - **隐形工程经验**："存在大量隐形Know-how，无法通过外购参考设计或招聘单一领域工程师快速复制，需要长期项目试错积累"。

第四拍是这套写法与产品手册的本质区别：前三拍企业BP里都有，第四拍是投资分析师的增量判断。资料不足以支撑壁垒判断时，正文保留已证实的技术效果和实现条件，删除无依据的高壁垒结论；必要补证进入对话清单。

资质/客户关系/先发市占驱动的业务（如军工资质、央企长期供货），改用"一是…二是…三是…"的事实举证式（中标记录、市占率、合作年限），四拍法与举证式在同一份报告中可按板块分别使用。

## 四、客户背景小传（战略客户专用）

单一战略客户贡献主要收入时，用2-3句话给评审补客户背景：它为什么存在、掌握什么资源、采购体制如何——这决定了订单的持续性逻辑。范文原文：

> 国家管网集团的设立背景是……推动国家油气体制改革和油气管网运营机制改革，设立日期为2019年12月9日，其核心目的是打破原有三桶油对油气管网的垄断……因此我国油气管网资源主要掌握在该公司上。

背景资料优先从权威公开信源检索补充（见 research-protocol.md），写清楚后紧接公司在该客户体内的渗透进度，形成"客户有多大→公司吃到多少"的闭环。

## 五、市场空间四句式（嵌入业务介绍，不单独成章）

范文把细分市场空间测算嵌在业务介绍里，固定四句递进：

1. **总盘子**："当前我国油气管网的公里数约为15万-20万公里……国家管网集团在石油管网每年的维护费超50亿"；
2. **当前渗透率**："该细分赛道目前处于商业模式初步跑通的初始阶段，当前整体渗透率约为5%"；
3. **公司进度**："因诺科技累计飞行公里数为1万公里，商业模式已初步跑通"；
4. **阶段判断**："行业处于规模推广初期，未来增长空间可清晰测算"。

总盘子数字必须有来源（"根据多方访谈及测算"或权威公开数据）；宏观行业叙事（政策东风、万亿赛道）不写——那是行业分析章的事，本章只写与公司收入直接相关的细分空间。

## 六、优劣并陈与风险内嵌

范文没有独立的"风险与关注事项"章，风险全部内嵌在对应分析处，可参考三种写法，按实际事实及影响选用：

**1. 客户评价三段式**（下游客户表后必写）：

> 优势：下游客户以央企、军工院所及海外战略代理为主，订单质量高、坏账风险低。……
> 劣势：客户集中度偏高，前五大客户……预计占2026年营收比重较大；且下游客户多为大型国企/军工单位，议价能力强、交付验收流程长、回款周期较慢，对公司营运资金形成持续压力。
> 独家/排他：目前未见明确的独家供货或排他性协议，但伊隆纬特与中国卫通存在长期配套关系，其客户黏性较强。

**2. 实际约束及影响**，紧贴在暴露短板的事实后面：

> 公司当前销售团队为5人，规模偏小，计划扩编至10人。销售力量相对薄弱，客户开拓高度依赖样机验证到批量复制的路径。现有销售人员数量限制了同时跟进客户的规模，扩编计划与已到岗人数分别列示。

**3. 如实呈现不利数字，不做修饰。** 产能利用率19.23%、季度毛利率从41.70%降至23.90%、竞对转型、历史业务混入板块口径——照实列出，异常波动在正文解释证据支持的原因或经营影响，核查任务另放清单。

补充业务的降温写法也属此类：对公司自己都不重点投入的业务，如实转述其定位，防止评审高估——"公司表示，该业务未投入核心研发资源，仅聚焦头部光伏基地打造标杆……不投入更多研发及运营力量。"

## 七、会议纪要挖掘清单

范文中最有价值的信息几乎全部来自访谈（标志：反复出现"根据访谈""公司表示""根据多方访谈及测算"）。精读会议纪要时按此清单逐项打捞，登记入事实台账：

| 挖掘项 | 范文对应产出 |
| --- | --- |
| 订单明细（客户、数量、单价、阶段、或有空间） | 重要订单段、产品表销售情况列 |
| 市占率及口径（在哪个客户/细分内的占有率） | 竞对分析段（保留"据访谈"归因） |
| 竞对名单及与公司的真实关系（竞合、甲方兼竞对） | 竞对分析段（"电科智能院是因诺科技的甲方，双方在集群领域存在竞争，在平台领域为合作关系"） |
| 定价机制与毛利逻辑（单台成本、售价、服务费模式） | 毛利分析、预测支撑依据列 |
| 客户内部渗透进度（覆盖多少家二级单位/院所） | 客户分析段 |
| 销售模式与获客路径（招投标、口碑推介、样机验证转化） | 销售模式段 |
| 产能、场地、班制、团队人数与短板自述 | 生产模式段、实际约束及影响 |
| 未来规划的量化目标（直签比例50%→70%、扩编至10人） | 未来规划段 |
| 管理层对自身弱项的坦承（回款慢、团队小、某业务不投入） | 劣势与风险内嵌 |
| 市场空间的管理层测算（总里程、年维护费、渗透率） | 市场空间四句式（标注"据访谈及测算"） |

纪要里的每一句话都是B级证据（企业自述），引用时保留归因，与A级（审计核实）数据冲突时提示差异。

## 八、规划与预测的固定写法

**未来规划段**：`一是…二是…三是…`，每条 = 方向 + 落地机制 + 量化目标。范文原句：

> 一是深化军方核心合作与供应体系。重点发力科研院所平台供应业务，将其作为2026年度核心发力点……着力提升军方直接签约比例，目标从2025年的50%提升至2026年的70%。

只有方向没有机制和数字的规划（"积极拓展市场""持续加大研发"）视为无效内容，压缩或删除。

**章末预测收束**：全章固定收在"未来业务发展预测"上，锚定在手订单，给区间而非单点：

> 根据公司在手订单，对于2026年全年因诺科技三大主营业务板块的财务收入预测如下：预计实现总营收3.8亿-4.3亿元，其中军工板块1.3亿元、能源板块1.5-1.8亿元、交通板块1-1.2亿元。

预测表的"备注/支撑依据"列是这张表的灵魂：逐板块写清增量从哪来（在手订单金额、意向订单、客户预算、政策要求），让评审可以逐项质疑。历史收入并列呈现（"公司2023-2025年确认收入分别为742万元、2,443万元、2,805万元。按公司订单预测，2026-2028年收入预测为9,690万元……"），跳跃幅度自己暴露出来，附"计划2026年实现年度盈利"类关键节点。

## 九、范文瑕疵清单（不要学）

范文本身有以下瑕疵，输出时必须做得比范文更严：

1. **对举连词残留**：范文偶有"这不仅降低了…更使其…""这不是单一模块的优化，而是…"。本技能全面禁用（见 language-style.md），改为直接正面陈述或"相较于…"句式；
2. **原始未舍入数字**：表格出现"26294.01254"，应为"26,294.01"；金额两位小数、千分位分隔；
3. **表格搬运营销话术**：产品简介列出现"真正实现""卓越""高效化作业新模式"等厂商语言，引用产品资料入表时应降格为中性功能描述；
4. **标题不统一**：同一层级出现"竞争优势"与"产品优势"两种标题，同一报告内保持统一；
5. **个别断言缺归因**："出货量第一"未标注来源，此类断言必须加"据管理层访谈/据XX数据"；第三方佐证任务归入正文外清单；
6. **空壳表格**：对比示意图占位的空表格，输出时要么有内容要么删除；
7. **合计行与分项精度不一致**：合计行用原始精度、分项用舍入值，导致表内自相矛盾，输出前逐表校验。

## 十、早前期终稿范式（2026-09 起为早前期标准写法）

早前期模板改用一份经多轮审阅定稿的立项报告结构：`（一）主营业务介绍`→`（二）主要产品概况`→`（三）核心技术与优势`→`（四）业务开展情况`。原稿为内部文件，以下只保留写法，示例均为虚构。

### 1.（一）主营业务介绍：一段定性＋一张板块表

定性段四句：核心产品与延伸方向→公司负责什么、合作方提供什么、哪些外购（分工边界一次讲清）→已实现的销售与适配→业务所处阶段（如“由科研定制和项目验证向标准化产品交付过渡”），末句“主要业务情况如下。”

> 公司以A类机载装置及完整供给系统为核心，向整机集成及场景服务延伸。公司负责储存、换热、供给控制及与动力单元的连接适配，整机合作方提供飞控、机体及电机，动力单元外购。公司已实现两款型号销售并完成两类平台适配，业务正由科研定制和项目验证向标准化产品交付过渡。主要业务情况如下。

业务板块表固定四列：`业务板块｜业务内容及开展方式｜当前阶段｜落地证据`。“当前阶段”写成熟在售、重点研发、按订单生产、样机验证；“落地证据”写具名客户订单、已售台数、示范项目，非核心配套板块直接写“非核心主业”及合作方式。

### 2.（二）主要产品概况：由主到次，每个产品六个要素

节首一句写主次关系：“A 为核心交付内容，B 为应用延伸方向，C 主要服务于试验及现场保障。”每个产品按以下顺序写，缺哪项不硬凑：

1. **定位与状态**：“A 为公司核心产品。现阶段 X、Y 型号已成熟且对外销售，Z 为重点研发型号，其他规格根据设计及订单进度推进。主要参数如下。”
2. **参数表**：指标项为行、型号为列，最后一行写“当前状态及配置”；
3. **用户价值换算**：把参数翻译成客户能理解的量，如“储能相当于××kWh可用电量”“面向小型长航时平台”；
4. **价格与成本**：单件估价→成套报价→整体报价上限，写明计价范围；整机类产品在机型表列“应用场景｜售价｜成本”；
5. **竞品对比表**：公司产品与国内外同规格具名产品按净容积、总容积、关键性能、空重、售价对比，表前一句写竞品是谁、售价差异；
6. **结构原理与配置规则**：一段写产品由哪些部分组成、各起什么作用；一段写不同需求如何配置（如功率××以下用方案一，以上用方案二）。

配套或非核心产品写现状、为何暂不量产、如何通过合作满足需求、何时启动，三四句写完。

### 3.（三）核心技术与优势：只写支撑核心产品的技术，每项三段

节首一段：技术围绕什么展开、分几个方面；为何单一部件改善难以形成可用产品；公司具备哪些条件；公司优势的依据（已具备开发、试制、联合适配条件，减少从基础研究进入应用验证的摸索）。

技术项的选择与排序：只列直接支撑核心产品交付的技术，按产品价值链顺序排列（本体制造→保存性能→供给控制→整机适配与先发）；研究储备、配套装备的工艺、与交付无关的监测技术不单列。

每项技术三段，首句加粗为判断句：

1. **作用与难点**：“X 解决……问题，是核心产品形成交付能力的基础。”随后写行业普遍难在哪里、为何难（材料、工艺、热力、控制上的具体约束），末句写“单凭××，不能证明××”，把门槛说透；
2. **公司做法与量化结果**：具体工艺、方案、自研设备，以及可比的量化结果（厚度、层数、性能提升百分比、真空度及维持时间、日损耗、流量），同时写清结果的适用范围（如“属于公司特定试验方案间的改善”）；
3. **价值与追赶难点**：技术给客户带来什么（小体积、低重量、稳定保存、连续供给）；竞争者为什么难以直接复制——需确定哪些参数范围、经历哪些试制和检验，“仅采购××并不能保证××”。

第一项技术末段写具名对标：“据现有调研，海外 H 公司已有同规格产品，国内 F 公司公开产品主要面向地面储运，用途和设计要求不同；公司的差异化优势主要体现在……”。

末项写**整机适配与先发优势**（需要整机适配和运行验证的行业尤其重要）：较早切入的时间与首次验证事件→与仍处于单项研发或地面样机阶段的进入者相比，已具备什么→跨系统协同为何需要反复地面联调和实际运行验证→先期进入机型开发后，客户更换供应商需重新做接口匹配、地面试验和运行验证，形成配套延续性→后续平台验证将如何巩固优势。

### 4.（四）业务开展情况：近期、中期、远期三节，按“方面”分段

节首一段：当前已开展什么、现阶段重点是什么，近期、中期、远期各做什么（各一句）。

- **近期**（通常两年内）：“产品研发及验证方面，……；场景验证方面，……；生产及经营方面，……”。写已定型型号、在制型号、已取得认证、已完成的运行验证、标准起草、已启动的取证；示范项目的时间、地点、合作方和目标；客户测试达标后的采购意向（写明以测试结果及合同签署为准）；现有产能、良品率，本轮融资后的产线规划与目标良品率，公司对当年和次年收入的预计。
- **中期**：“业务布局方面”（各主体分工）、“市场拓展方面”（从示范项目向周边推广、意向订单项数与金额及其构成）、“大型项目配套方面”（目标参数、方案、意向金额、计划交付期、参与投标单位，写明以招投标结果和合同为准）。
- **远期**：产能规划（年产量、年产值）、长期业务方向、配套服务与标准制定；末句写扩张前提：“现阶段业务推进仍以小批量交付和具体场景验证为基础，中长期规模扩张需以订单转化、生产能力及供应保障同步落实为前提。”

### 5. 初稿到终稿的改写规律（主营章）

| 初稿写法 | 终稿写法 |
|---|---|
| 以收入拆分表开篇，写“核心技术布局与当期收入来源存在差异” | 以业务定性段＋板块表开篇，收入与客户放公司情况章 |
| 分“核心装备业务”“过渡性贸易业务”两个板块，各写模式、客户、竞争、技术、规划五段 | 按产品写（核心产品在前），技术单列一节，开展情况按时间分三段 |
| 每段写“需核实型号版本”“应分别判断”“不能据此得出全面优于对方的结论” | 直接给参数表和竞品对比表，差异在一句内说明 |
| 竞争关系表转述公司资料并注“不视作独立核实” | 竞品对比放入核心产品段和第一项技术段，只写可比参数和用途差异 |
| 技术列五项，含配套装备工艺和安全监测等非核心技术 | 技术四项，全部围绕核心产品，末项为整机适配与先发优势 |
| 技术段只写公司做了什么 | 每项三段：难点→做法与量化→价值与追赶难点，附具名对标 |
| 订单明细、意向明细和算式写在主营章 | 订单依据归公司情况章；主营章只在开展情况中写关键项目及金额 |
| 正文附“数据来源：业务回复Q5.1，V10.0订单口径” | 不写资料文件名、问题编号与版本 |
