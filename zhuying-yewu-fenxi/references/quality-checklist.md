# 质量自检清单

> 标题以用户选择的 `assets/templates/early.json` 或 `mid-late.json` 为唯一来源。本文件的旧例仅说明标题内部的内容写法，不能用于选阶段、改题、裁剪、合并或新增章节。先执行 [阶段模板规则](stage-template-workflow.md)。

成稿输出前逐项自检，任何一项不通过即回改后重查。自检过程不展示给用户，发现的数据冲突等重大问题在正文中以规范方式体现。

## 一、语言禁令扫描（全文逐词检索）

- [ ] 无"标的公司/标的企业/该标的/本标的/目标公司"——全部为公司简称或"公司"；
- [ ] 无对举连词：不是…而是 / 并非…而是 / 不仅…而且 / 不仅…更 / 不仅…还 / 不仅…也 / 不止… / 不只是… / 不但… / 不光… / 不仅仅是 / 更是（递进强调用法）/ 与其说…不如说；
- [ ] 无"综上所述/总而言之/由此可见/不难看出/值得一提的是"；
- [ ] 无"根据某某材料显示"式引注腔；
- [ ] 无营销措辞（行业领先/壁垒极高/前景广阔/颠覆性/赋能/闭环/蓝海等，逐项对照 language-style.md 禁令五）；
- [ ] 无"建议立项/值得投资"越权结论；
- [ ] 引用产品资料入表的文字已降格为中性功能描述（无"真正实现""卓越"）；
- [ ] 无“国内暂无竞品/唯一/首家”式排他论断；确有检索依据的写明检索范围并列出最接近的可比企业；
- [ ] 数值范围两端带量级（“7万—10万元”“15%—30%”），中文语境全角括号，无“来自于”“粘度”；`style_check.py` 已通过。

## 二、结论前置落实

- [ ] 每个业务板块开头有定位判断句（公司内地位+市场位次+战略走向三要素）；
- [ ] 概况节为"定性一句话+定量拆分段"双开门，第二段即给出总收入与分板块金额占比；
- [ ] 归纳型标题仅填写模板定义的变量，依据当前公司事实；其余标题保持原模板文字；
- [ ] 分析段段首为判断句，证据数据紧随其后；
- [ ] 全章收在"未来业务发展预测"，无空泛小结。

## 二A、早前期终稿范式（仅早前期）

- [ ] （一）一段定性写清核心产品、分工边界（自做/合作方/外购）、已实现交付与阶段，配四列业务板块表（含落地证据）；
- [ ] （二）节首写主次关系；核心产品写定位与状态、参数表、用户价值换算、价格与成本、竞品对比表、结构与配置规则；
- [ ] （三）只列支撑核心产品的技术，按产品价值链排序；每项三段且首句加粗，第一项含具名对标，末项为整机适配与先发优势；
- [ ] （四）近期、中期、远期按“××方面”分段，意向与采购写明以测试结果、招投标或合同为准，末句写扩张前提；
- [ ] 主营章不写订单明细表和算式，不写资料文件名、问题编号与版本；同一数字与行业章、公司情况章一致。

## 三、数据密实度

- [ ] 重要订单均为五要素（客户+数量+金额/单价+阶段+或有空间），或有部分用条件句；
- [ ] 性能/成本对比均有具名基准（vs 大疆5-6公里式），无孤立形容词；
- [ ] 战略大客户有背景小传和渗透深度数字；
- [ ] 细分市场空间按四句式（总盘子→渗透率→公司进度→阶段判断）且总盘子有来源；
- [ ] 未来规划每条有方向+机制+量化目标，无"积极拓展市场"式空话；
- [ ] 生产与团队要素可稽核（面积、人数、班制、产能、关键人背景）；
- [ ] 业务板块与产品按由主到次排序，核心产品在前；概况段嵌入了主要客户与合作对象名称；
- [ ] 产品表有应用场景列，价格写明计价范围（整机/系统/部件），改装集成类产品列出购入价、售价及单台毛利；
- [ ] 核心技术每项都有“具名企业 A 达到……，公司达到……”的对标，能看出技术高度；先发优势（如适用）有时间差、适配平台数、客户切换成本等证据；
- [ ] 专业术语首次出现已用一句话解释；价格随规格、产能变化的句子驱动因素清楚，无歧义；
- [ ] 意向订单按业务板块拆分项数、金额及占比，单一大项占比已点明；深度合作、绑定大客户或中标项目已单独写清；
- [ ] 有实物照片的核心产品已插图，无照片的已列入对话清单。

## 四、证据与归因

- [ ] 结论强度与证据级别匹配（A直陈/B归因/C注明来源/D写明测算口径（算式留底稿）/E缺口进对话清单），无跨级；
- [ ] 访谈信息均有"根据访谈/公司表示"归因；市占率数据保留来源及口径，领先性判断有可比的第三方证据；缺证不作定论；
- [ ] 联网检索的数字均有来源归因；竞对财务注明期间；
- [ ] 无凭空编造或"合理估计"的数字；正文与表格无"资料未披露"类缺口占位语，全部缺口已汇入对话交付的"资料缺口与待核查清单"；
- [ ] 已运行 `python scripts/style_check.py` 且全部通过（称谓/对举连词/结论标签/缺口占位语）；
- [ ] 可做的交叉印证已做，印证不上的已在正文提示；
- [ ] 不同来源实质冲突处写明差异及影响，未擅自取舍，核查任务留正文外清单。

## 五、逐表校验

- [ ] 每表有引导语、单位、数据期间；口径特殊处有表注；
- [ ] 分项之和=合计行；占比之和=100%（四舍五入差异已注明）；合计行与分项精度一致（无"26294.01254"式原始数字）；
- [ ] 同一数字在正文与表格、不同表格之间一致；
- [ ] 预测（E）与历史分离，预测表已注"公司管理层预测，本报告未验证"；
- [ ] 盈利预测表版本与资料颗粒度匹配，完整版勾稽已核验（营业利润/利润总额/净利润三级）；
- [ ] 无空壳表格。

## 六、结构与立场

- [ ] 阶段已经用户明确选择；已执行 stage_template.py check，标题、层级、顺序及变量均与所选模板一致；不适配槽位已按用户明确意见处理；
- [ ] 内容覆盖底线12问全部有落点（chapter-template.md 第三节），缺资料的已标注；
- [ ] 竞争优势呈现方式与优势类型匹配（技术驱动用四拍法且第四拍有壁垒论证；资质关系驱动用举证式）；
- [ ] 风险已内嵌：客户表后有优势/劣势/独家排他三段式；短板处说明具体事实与影响；前文暴露的异常（毛利率骤降、产能利用率低、集中度高）均有证据支持的解释或当前影响，核查任务留正文外清单；
- [ ] 优劣并陈（自测：把全文当成竞对写的，是否仍然成立？）；
- [ ] 补充业务/公司不重点投入的业务已如实降温，未制造增长错觉；
- [ ] 编号体系 三、→（一）→1.→（1）→1) 层级无跳档；同层级标题格式统一。

## 七、Word 输出核对（仅输出 .docx 时执行）

- [ ] 已先运行 `python scripts/ensure_fonts.py`（或 `scripts/ensure-fonts.ps1`），三个公文字体确认就绪；
- [ ] 由 `scripts/build_docx.py` 渲染（三技能统一脚本），未手写 docx-js/OOXML 排版；
- [ ] 字体层级正确：（一）级标题楷体_GB2312三号加粗、1.级仿宋_GB2312三号加粗、（1）级与正文仿宋_GB2312三号**不加粗**、一级标题黑体三号**不加粗**；
- [ ] 行距为固定值（正文28磅），页边距上3.7/下3.5/左2.8/右2.6cm，A4；页脚页码"-1-"格式宋体四号奇偶外侧；
- [ ] 每张表格：全部文字仿宋_GB2312五号、第一行表头加粗+浅蓝底（#D9E2F3）+跨页重复、宽度100%版心+按窗口自动调整（tblW pct=5000 + tblLayout autofit）、所有单元格水平+垂直居中；
- [ ] "单位：万元""注："用 tnote 块（仿宋五号），未混入正文三号段落；
- [ ] 生成后已用 docx 校验工具验证文件有效。

## 成稿最后复核

- [ ] 已逐项执行 [投资逻辑复核](investment-logic-review.md)，修订实际写入正文；术语和指标已解释为客户价值及投资含义。
- [ ] 二至四级标题、编号和顺序与所选模板一致；论证问题已在正文中修订，未借复核自行改题。
- [ ] 已运行语言扫描并逐段复读，正文无拖延判断套话及否定后肯定句式；实质风险与来源边界保留。
- [ ] Word表内文字均五号，括注中文楷体；表外括注三号楷体，四级标题三号仿宋加粗。
- [ ] 最后统一西文字体为 Times New Roman，中文字体及字号保留；奇偶页不同已启用，奇数页右侧、偶数页左侧，页码两侧短横线和数字均四号。
