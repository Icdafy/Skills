# 质量自检清单

成稿输出前逐项自检，任何一项不通过即回改后重查。自检过程不展示给用户，发现的数据冲突等重大问题在正文中以规范方式体现。

## 一、语言禁令扫描（全文逐词检索）

- [ ] 无"标的公司/标的企业/该标的/本标的/目标公司"——全部为公司简称或"公司"；
- [ ] 无对举连词：不是…而是 / 并非…而是 / 不仅…而且 / 不仅…更 / 不仅…还 / 不仅…也 / 不止… / 不只是… / 不但… / 不光… / 不仅仅是 / 更是（递进强调用法）/ 与其说…不如说；
- [ ] 无"综上所述/总而言之/由此可见/不难看出/值得一提的是"；
- [ ] 无"根据某某材料显示"式引注腔；
- [ ] 无营销措辞（行业领先/壁垒极高/前景广阔/颠覆性/赋能/闭环/蓝海等，逐项对照 language-style.md 禁令五）；
- [ ] 无"建议立项/值得投资"越权结论；
- [ ] 引用产品资料入表的文字已降格为中性功能描述（无"真正实现""卓越"）。

## 二、结论前置落实

- [ ] 每个业务板块开头有定位判断句（公司内地位+市场位次+战略走向三要素）；
- [ ] 概况节为"定性一句话+定量拆分段"双开门，第二段即给出总收入与分板块金额占比；
- [ ] 归纳型小节标题已内容化（如"下游客户结构：央企主导、集中度较高"），事实型小节保持中性标题；
- [ ] 分析段段首为判断句，证据数据紧随其后；
- [ ] 全章收在"未来业务发展预测"，无空泛小结。

## 三、数据密实度

- [ ] 重要订单均为五要素（客户+数量+金额/单价+阶段+或有空间），或有部分用条件句；
- [ ] 性能/成本对比均有具名基准（vs 大疆5-6公里式），无孤立形容词；
- [ ] 战略大客户有背景小传和渗透深度数字；
- [ ] 细分市场空间按四句式（总盘子→渗透率→公司进度→阶段判断）且总盘子有来源；
- [ ] 未来规划每条有方向+机制+量化目标，无"积极拓展市场"式空话；
- [ ] 生产与团队要素可稽核（面积、人数、班制、产能、关键人背景）。

## 四、证据与归因

- [ ] 结论强度与证据级别匹配（A直陈/B归因/C注明来源/D给算式/E写缺口），无跨级；
- [ ] 访谈信息均有"根据访谈/公司表示"归因；市占率、"第一"类断言均归因且注明"尚需第三方佐证"（除非有第三方数据）；
- [ ] 联网检索的数字均有来源归因；竞对财务注明期间；
- [ ] 无凭空编造或"合理估计"的数字；缺口写"资料未披露，建议后续尽调核查"；
- [ ] 可做的交叉印证已做，印证不上的已在正文提示；
- [ ] 不同来源冲突处已提示"需进一步核查"，未擅自取舍。

## 五、逐表校验

- [ ] 每表有引导语、单位、数据期间；口径特殊处有表注；
- [ ] 分项之和=合计行；占比之和=100%（四舍五入差异已注明）；合计行与分项精度一致（无"26294.01254"式原始数字）；
- [ ] 同一数字在正文与表格、不同表格之间一致；
- [ ] 预测（E）与历史分离，预测表已注"公司管理层预测，本报告未验证"；
- [ ] 盈利预测表版本与资料颗粒度匹配，完整版勾稽已核验（营业利润/利润总额/净利润三级）；
- [ ] 无空壳表格。

## 六、结构与立场

- [ ] 结构选型正确（多板块判定三条标准核对过；单产品线未强行拆板块；服务型未硬套产能框架）；
- [ ] 内容覆盖底线12问全部有落点（chapter-template.md 第三节），缺资料的已标注；
- [ ] 竞争优势呈现方式与优势类型匹配（技术驱动用四拍法且第四拍有壁垒论证；资质关系驱动用举证式）；
- [ ] 风险已内嵌：客户表后有优势/劣势/独家排他三段式；短板处有"需持续关注"从句；前文暴露的异常（毛利率骤降、产能利用率低、集中度高）均有归因或核查提示；
- [ ] 优劣并陈（自测：把全文当成竞对写的，是否仍然成立？）；
- [ ] 补充业务/公司不重点投入的业务已如实降温，未制造增长错觉；
- [ ] 编号体系 三、→（一）→1.→（1）→1) 层级无跳档；同层级标题格式统一。

## 七、Word 输出核对（仅输出 .docx 时执行）

- [ ] 已先运行 `scripts/ensure-fonts.ps1`，三个公文字体确认就绪；
- [ ] 字体层级正确：（一）级标题楷体_GB2312三号加粗、1.级仿宋_GB2312三号加粗、正文仿宋_GB2312三号、一级标题黑体三号**不加粗**；
- [ ] 行距为固定值（正文28磅），页边距上3.7/下3.5/左2.8/右2.6cm，A4；
- [ ] 每张表格：全部文字仿宋_GB2312五号、第一行表头加粗、宽度100%版心+按窗口自动调整（tblW pct=5000 + tblLayout autofit）、所有单元格水平+垂直居中；
- [ ] 中文字体已写入 eastAsia 属性（只设 ascii 会导致中文回退宋体）；
- [ ] 生成后已用 docx 校验工具验证文件有效。
