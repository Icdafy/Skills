# 质量自检清单

成稿输出前逐项自检。任何一项不通过，回改后重查。自检结果不必展示给用户，但发现并修正的重大问题（如数据冲突）应在正文中以规范方式体现。

## 一、内容完整性

- [ ] 12 个分析维度全部覆盖（概述、产品服务、商业模式、收入结构、成本盈利、采购供应链、生产交付、销售客户、竞争力、成长性、风险、小结），资料缺失的维度已写明"资料未披露/建议尽调核查"而非静默跳过；
- [ ] 结构编排与企业类型匹配（多板块企业用了方案C或说明了理由；服务型企业没有硬套产能框架）；
- [ ] 选用方案C的，已核对量化判定标准（分部客户群/商业模式/毛利率实质差异、最大分部占比≤60%、分部核算已在企业口径落地），三者不全部满足时已改用方案A/B或在正文说明拆分理由；
- [ ] 方案C下各板块"竞争优势"呈现方式与该板块优势来源类型匹配（技术驱动型用对照表+量化对比，资质/客户关系驱动型用文字归纳），未不加区分地全部套用同一种格式；
- [ ] 每节都有实质分析落点，没有纯粹的资料搬运段落。

## 二、数据与证据

- [ ] 所有关键结论都有资料或数据支撑，且证据级别与结论强度匹配（见 language-style.md 第四节）；
- [ ] 无凭空编造或"合理估计"的数字；
- [ ] 数据口径已统一或已注明差异；不同来源冲突处已提示"需进一步核查"；
- [ ] 关键计算已给出算式，可复核；
- [ ] 没有仅凭单一数据得出的重大判断；
- [ ] 可做的交叉印证已做，印证不上的已写入风险。

## 三、表格校验（逐表执行）

- [ ] 表格有引导语、单位标注、数据期间；
- [ ] 分项之和 = 合计行；占比之和 = 100%（四舍五入差异已注明）；
- [ ] 同一数字在正文与表格、不同表格之间一致；
- [ ] 预测数据（E）与历史数据明确区分，预测表已注明"公司管理层预测，本报告未验证"；
- [ ] 盈利预测表的版本（完整版/简化版）与资料颗粒度匹配，完整版未出现资料中不存在的费用科目编造数字，且营业利润/利润总额/净利润三级勾稽已核验；
- [ ] 口径特殊处已加表下注释。

## 四、语言与立场

- [ ] 无禁用表达（逐项对照 language-style.md 第二节清单）；
- [ ] 无"根据某某材料显示"式引注句；
- [ ] 无宣传化、营销化、夸张化、情绪化、口语化表达；
- [ ] 企业自述（市占率、"第一"、性能宣称）均保留归因且未升格为事实；
- [ ] 优势表述均落到具体事实/数据，且带持续性约束；
- [ ] 站位是投资机构内部立项评审视角，而非企业宣传视角（自测：把全文当成竞对写的，是否仍然成立？）。

## 五、风险与判断

- [ ] 风险事项具体、有数据、有影响路径、有核查建议，非免责套话；
- [ ] 前文暴露的异常（毛利率骤降、产能利用率低、集中度高、数据打架）都在风险节有呼应；
- [ ] 小结为"优势 + 约束 + 后续核查重点"结构，未出现"建议立项/值得投资"等越权结论；
- [ ] 小结未引入前文没有的新事实。

## 六、格式

- [ ] 编号体系为 三、→（一）→ 1. →（1）→ 1)，层级无跳档；
- [ ] 金额两位小数（万元）、比率两位小数（%）；
- [ ] 章节序号与用户报告结构一致（默认第三章）。

# 用户资料清单（应用户询问时提供）

用户问"我需要准备什么资料"时，给出以下清单：

**核心资料（直接决定分析深度）**

1. 近 2-3 年及最近一期财务报表或审计报告；
2. 分产品/分业务收入、成本、毛利明细；
3. 业务介绍或商业计划书（BP）；
4. 管理层/业务/技术访谈纪要。

**重要资料（决定结构分析质量）**

5. 前五大客户清单及销售金额；
6. 前五大供应商清单及采购金额；
7. 在手订单、新签合同台账或中标通知；
8. 产品资料、价格表；
9. 产能、产量、销量数据（制造型）或项目交付、续约数据（服务型）。

**补充资料（用于交叉验证）**

10. 招股书、公开披露文件（如有）；
11. 行业研报或市场数据；
12. 竞争对手信息；
13. 官网及公开宣传材料（仅作背景参考）。

缺项不阻断分析，但相应章节将标注"资料未披露"并列入后续尽调核查建议。
