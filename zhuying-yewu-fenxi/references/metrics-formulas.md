## 指标体系

只计算资料能支撑的指标，不为凑指标而假设数据。每组指标按"资料常见程度"排序，前面的优先算。

### 收入类（模块 1、4、10）

| 指标 | 用途 | 最低数据要求 |
| --- | --- | --- |
| 主营业务收入及增长率 | 规模与成长基本盘 | 两期收入 |
| 分产品/业务收入占比 | 收入集中度与结构 | 分项收入明细 |
| 前五大客户收入占比 | 客户集中度 | 客户销售明细 |
| 经常性收入占比 | 收入质量 | 收入模式拆分 |
| 新客户收入贡献 / 老客户复购率 | 增长来源拆解 | 分客户跨期明细 |
| 在手订单、新签订单、合同负债 | 未来收入可见度 | 订单台账/报表 |
| 订单覆盖率（在手订单/次年预测收入） | 预测可信度 | 订单+预测 |
| 订单转化率 | 销售漏斗效率 | 投标/签约记录 |

### 盈利类（模块 5）

| 指标 | 用途 | 最低数据要求 |
| --- | --- | --- |
| 毛利、毛利率（综合及分产品） | 盈利能力核心 | 收入+成本 |
| 单位售价、单位成本、单位毛利 | 价格与成本变动拆解 | 量价数据 |
| 成本构成占比（材料/人工/制造费用/外协） | 成本结构 | 成本明细 |
| 期间费用率（销售/管理/研发/财务） | 经营效率 | 利润表 |
| 成本费用率 | 总成本负担 | 利润表 |
| 净利率 | 综合盈利 | 利润表 |

### 客户与销售类（模块 8）

| 指标 | 用途 | 最低数据要求 |
| --- | --- | --- |
| 前五大客户收入占比 | 集中度 | 客户明细 |
| 客户留存率 / 续约率 / 复购率 | 粘性 | 跨期客户名单 |
| 新客户数量 / 新客户收入贡献 | 拓客能力 | 跨期客户名单 |
| 客单价、获客成本、销售费用率 | 销售效率 | 客户数+费用 |
| 应收账款周转率、回款周期（DSO） | 回款质量 | 应收账款+收入 |

### 供应链类（模块 6）

| 指标 | 用途 | 最低数据要求 |
| --- | --- | --- |
| 前五大供应商采购占比 / 单一供应商占比 | 供应集中度 | 采购明细 |
| 原材料成本占比 | 成本敏感性 | 成本构成 |
| 采购价格变动幅度 | 价格风险 | 跨期采购价 |
| 安全库存周期、供应商账期 | 供应链弹性 | 采购台账 |

### 生产与交付类（模块 7）

| 指标 | 用途 | 最低数据要求 |
| --- | --- | --- |
| 产能、产量、产能利用率、产销率 | 制造型交付能力 | 产能产量销量 |
| 良品率、交付周期、准时交付率 | 质量与交付 | 生产记录 |
| 项目实施周期、人均产出、服务续约率 | 服务型交付能力 | 项目/人员数据 |

## 公式清单

**收入类**

- 收入增长率 =（本期收入 − 上期收入）/ 上期收入 × 100%
- 年复合增长率（CAGR）=（期末值 / 期初值）^(1/年数) − 1
- 单项业务收入占比 = 单项业务收入 / 主营业务收入 × 100%
- 前五大客户收入占比 = 前五大客户销售收入 / 主营业务收入 × 100%
- 客户集中度 = 主要客户销售收入 / 主营业务收入 × 100%
- 订单覆盖率 = 在手订单金额 / 次年预测收入 × 100%

**盈利类**

- 毛利 = 主营业务收入 − 主营业务成本
- 毛利率 = 毛利 / 主营业务收入 × 100%
- 单位毛利 = 单位售价 − 单位成本
- 单位毛利率 = 单位毛利 / 单位售价 × 100%
- 期间费用率 = 期间费用 / 营业收入 × 100%
- 成本费用率 =（营业成本 + 期间费用）/ 营业收入 × 100%
- 净利率 = 净利润 / 营业收入 × 100%

**生产交付类**

- 产能利用率 = 实际产量 / 设计产能 × 100%
- 产销率 = 销量 / 产量 × 100%
- 良品率 = 合格产品数量 / 总生产数量 × 100%
- 人均产出 = 主营业务收入 / 业务人员数量

**回款类**

- 应收账款周转率 = 营业收入 / 平均应收账款余额
- 回款周期（DSO）= 365 / 应收账款周转率

## 计算与呈现规则

1. **列出计算逻辑**：关键计算在正文括号或表注中给出算式，如"2025 年收入同比增长 14.9%（=（2,805.94−2,443.26）/2,443.26）"。让评审可复核，也让数据错误无处藏身。
2. **保留位数**：金额（万元）保留两位小数，千分位分隔；比率保留两位小数（%）；倍数保留一位小数。
3. **期间标注**：每个数据首次出现必须带期间（"2025 年度""2026 年 1-3 月"）。最近一期不足一年的，不得直接与全年比较，需说明"最近一期为 X 个月数据"或做年化提示（年化仅作参考，须注明）。
4. **口径标注**：收入含税/不含税、合并/单体、报表口径/业务口径，首次出现时说明；两套口径并存时分别标注，不得混用于同一张表。
5. **合计校验**：输出前逐表验证——分项之和 = 合计行；占比之和 = 100%（±0.1% 四舍五入容差内注明"合计数与分项之和差异系四舍五入所致"）；同一数字在不同表/正文中出现时数值一致。
6. **预测与历史分离**：预测数据（E）与历史数据不放在同一列序列中不加区分；预测表必须注明"公司管理层预测数据，本报告未验证"。
7. **异常值必须处理**：同比波动超过 ±30% 的指标、毛利率变动超过 5 个百分点的产品，必须在正文中归因或提示核查，不得让异常数字裸奔。

## 交叉印证方法

写作前至少做以下可行的印证（资料允许几项做几项），印证结果（一致/存在差异）写入相应章节：

| 印证项 | 方法 | 差异时的处理 |
| --- | --- | --- |
| 收入 vs 订单 | 报告期新签/交付订单金额与确认收入的量级和节奏是否匹配 | 提示"订单与收入的匹配关系需进一步核查" |
| 收入 vs 量价 | 销量 × 平均单价 ≈ 分产品收入？ | 检查是否漏了其他收入或单价口径不同 |
| 分客户合计 vs 总收入 | 客户明细金额合计 ≈ 主营业务收入？ | 说明覆盖率（"前述客户合计占收入的 X%"） |
| 毛利率 vs 单价成本 | 分产品毛利率与单位售价/成本推算是否一致 | 提示口径差异 |
| 产能 vs 收入预测 | 预测收入所需产量是否超出产能规划 | 写入成长性约束或风险 |
| 团队 vs 收入预测 | 服务型企业：预测收入所需人力是否远超现有及招聘计划 | 写入成长性约束或风险 |
| 企业自述市占率 vs 外部数据 | 有外部行业数据时对照 | "该数据尚需第三方数据佐证" |

## 数据充分性判断

结论强度必须与证据强度匹配。判断标准：

| 想下的结论 | 至少需要 | 不满足时的写法 |
| --- | --- | --- |
| "收入保持增长" | 连续两期以上可比口径收入数据 | "最近一期收入为……，因缺少可比数据，增长趋势尚无法判断" |
| "盈利能力稳定" | 两期以上综合毛利率 + 至少一层分产品拆解 | "综合毛利率为……%，其结构与稳定性需分产品数据进一步验证" |
| "存在客户集中风险" | 前五大客户占比数据（或客户清单可推算） | "客户结构资料未披露，集中度情况建议尽调核实" |
| "成长性有支撑" | 在手订单/新签合同金额 + 交付能力对照 | "公司预期增长主要基于……，现有资料尚不足以验证其实现基础" |
| "具备成本优势" | 与竞对或行业的可比价格/成本数据 | "公司产品定价低于/接近……，成本端优势尚需可比数据验证" |
| "市占率领先" | 第三方行业数据，或可复核的测算过程 | "据管理层访谈，公司市占率约……%，该数据尚需第三方佐证" |

一票否决项：**任何情况下不得为了让某节"看起来完整"而编造、外推或"合理估计"一个资料中不存在的数字。** 宁可写"资料未披露"。
