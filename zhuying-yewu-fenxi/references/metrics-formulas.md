# 指标体系、公式与数据处理规则

只计算资料能支撑的指标，任何情况下不为凑指标假设数据。

## 一、指标体系（按用途分组）

### 收入与成长

| 指标 | 用途 | 最低数据要求 |
| --- | --- | --- |
| 主营业务收入及增长率、CAGR | 规模与成长基本盘 | 两期收入 |
| 分板块/分产品收入占比 | 收入结构与集中度 | 分项收入明细 |
| 前五大客户收入占比 | 客户集中度 | 客户销售明细 |
| 在手订单、新签订单、合同负债 | 未来收入可见度 | 订单台账/报表 |
| 订单覆盖率（在手订单/次年预测收入） | 预测可信度 | 订单+预测 |
| 经常性收入占比（服务费/维保/订阅） | 收入质量 | 收入模式拆分 |

### 盈利

| 指标 | 用途 | 最低数据要求 |
| --- | --- | --- |
| 毛利率（综合及分板块/分产品） | 盈利能力核心 | 收入+成本 |
| 单位售价、单位成本、单位毛利 | 量价拆解 | 量价数据 |
| 成本构成占比（材料/人工/外协/制造费用） | 成本结构 | 成本明细 |
| 期间费用率、净利率 | 经营效率 | 利润表 |

### 客户与市场

| 指标 | 用途 | 最低数据要求 |
| --- | --- | --- |
| 大客户内部渗透率（已覆盖单位数/客户全部相关单位数） | 客户关系深度（范文：18家二级单位覆盖17家） | 访谈/客户清单 |
| 细分市场渗透率（公司或行业累计量/市场总量） | 赛道阶段定位 | 市场总盘子+公司数据 |
| 特定客户/细分内市占率 | 竞争位次 | 访谈+第三方数据佐证 |
| 客户留存/续约/复购 | 粘性 | 跨期客户名单 |
| 应收账款周转率、DSO | 回款质量 | 应收账款+收入 |

### 供应与交付

| 指标 | 用途 | 最低数据要求 |
| --- | --- | --- |
| 前五大供应商采购占比 | 供应集中度 | 采购明细 |
| 产能、产量、产能利用率、产销率 | 制造型交付能力 | 产能产量销量 |
| 项目实施周期、人均产出、续约率 | 服务型交付能力 | 项目/人员数据 |

## 二、公式清单

- 收入增长率 =（本期收入 − 上期收入）/ 上期收入 × 100%
- CAGR =（期末值 / 期初值）^(1/年数) − 1
- 单项占比 = 单项收入 / 主营业务收入 × 100%
- 订单覆盖率 = 在手订单金额 / 次年预测收入 × 100%
- 毛利率 =（收入 − 成本）/ 收入 × 100%
- 期间费用率 = 期间费用 / 营业收入 × 100%
- 净利率 = 净利润 / 营业收入 × 100%
- 产能利用率 = 实际产量 / 设计产能 × 100%；产销率 = 销量 / 产量 × 100%
- 应收账款周转率 = 营业收入 / 平均应收账款余额；DSO = 365 / 周转率
- 大客户内部渗透率 = 已覆盖单位数 / 客户有需求的单位总数 × 100%

## 三、计算与呈现规则

1. **关键计算给算式**：正文括号或表注中给出（"同比增长14.9%（=(2,805.94−2,443.26)/2,443.26）"），让评审可复核；
2. **保留位数**：金额（万元）两位小数、千分位分隔；比率两位小数；倍数一位小数；
3. **期间标注**：每个数据首次出现带期间；最近一期不足一年的注明"最近一期为X个月数据"，与全年比较须提示口径；
4. **口径标注**：含税/不含税、合并/单体、报表口径/业务口径首次出现时说明，两套口径不混入同一张表；板块划分调整的加表注（范文："注：公司业务分类……系前期签署订单口径所致，不影响整体结构"）；
5. **合计校验**：分项之和=合计行；占比之和=100%（±0.1%容差内注明四舍五入）；同一数字跨表跨正文一致；
6. **预测与历史分离**：预测（E）单独列示并注明"公司管理层预测，本报告未验证"；
7. **异常值必须处理**：同比波动超±30%、毛利率变动超5个百分点的项目，正文归因或提示核查，不允许异常数字裸奔。

## 四、交叉印证方法

写作前把可行的印证全部做完，结果（一致/存在差异）写入相应章节：

| 印证项 | 方法 | 差异时的处理 |
| --- | --- | --- |
| 收入 vs 订单 | 新签/交付订单金额与确认收入的量级节奏是否匹配 | "订单与收入的匹配关系需进一步核查" |
| 收入 vs 量价 | 销量×平均单价 ≈ 分产品收入？ | 检查漏项或单价口径 |
| 分客户合计 vs 总收入 | 客户明细合计 ≈ 主营收入？ | 说明覆盖率 |
| 产能 vs 收入预测 | 预测所需产量是否超出产能规划 | 写入成长性约束 |
| 团队 vs 收入预测 | 服务型：预测所需人力 vs 现有及扩编计划 | 写入成长性约束 |
| 自述市占率 vs 外部数据 | 联网检索第三方数据对照 | "尚需第三方数据佐证" |
| 毛利率 vs 单价成本 | 访谈中的单台成本/售价推算毛利率，与报表毛利率比对 | 提示口径差异 |

## 五、数据充分性判断（什么数据够撑什么结论）

| 想下的结论 | 至少需要 | 不满足时的写法 |
| --- | --- | --- |
| "收入保持增长" | 两期以上可比口径收入 | "因缺少可比数据，增长趋势尚无法判断" |
| "盈利能力稳定" | 两期以上毛利率+一层分产品拆解 | "其结构与稳定性需分产品数据进一步验证" |
| "客户集中度较高" | 前五大客户占比或可推算的客户清单 | 该判断不写入正文，缺口进对话交付的待核查清单 |
| "成长性有支撑" | 在手订单金额+交付能力对照 | "现有资料尚不足以验证其实现基础" |
| "市占率领先/绝对领先" | 第三方数据，或访谈数据+归因 | "据管理层访谈，市占率约……%，尚需第三方佐证" |
| "具备成本/性能优势" | 具名基准的可比数据 | "尚需可比数据验证" |

一票否决：任何情况下不得为让某节"看起来完整"而编造、外推或"合理估计"资料中不存在的数字；宁可正文不写该数字，把缺口列入对话交付的"资料缺口与待核查清单"。
