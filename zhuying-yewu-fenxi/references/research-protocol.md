# 联网检索协议

用户资料包覆盖不到的信息，按本协议主动检索补充。外部资料只用于补充背景、验证事实、完善分析，任何情况下都以项目自身资料为分析主体。

## 一、四类必查信息

### 1. 竞争对手财务与估值

竞对表的"财务状况"和"估值"列是评审做相对判断的锚点，优先检索：

- **上市/新三板挂牌竞对**：查最近年报与半年报（营业收入、净利润、毛利率、总资产负债、经营现金流），来源为巨潮资讯、上交所/深交所/北交所披露、公司定期报告；写入时注明期间（"2024年营业总收入1.75亿元……2025年上半年销售毛利率38.68%"）；
- **一级市场竞对**：查最近一轮融资的公开报道（轮次、金额、投后估值、领投方），来源为36氪、投资界等融资报道及工商变更信息；估值为市场传闻的注明"据公开报道"；
- **竞对业务动向**：转型、退出某市场等重大变化（范文："2024年已转型做无人机，其机载卫通产品仅服务自身无人机使用"）——这类信息直接改变竞争格局判断。

### 2. 市场空间锚点

细分市场总盘子数字（里程数、保有量、装机量、年维护费预算）按以下优先级取数：

1. 政府部门文件与统计（部委规划、统计公报、政府工作报告）；
2. 行业协会与官方背景智库；
3. 上市公司招股书与年报中的行业章节（券商与发行人核验过，可溯源）；
4. 头部研究机构公开报告；
5. 管理层访谈测算（标注"根据多方访谈及测算"，与外部数据交叉印证）。

只取与公司收入直接相关的细分空间数字，宏观赛道叙事不写。

### 3. 战略客户背景

单一大客户贡献主要收入时，检索其设立背景、体制地位、采购机制、年度预算量级，写成2-3句"客户背景小传"（见 writing-dna.md 第四节）。军方客户注意脱敏，写军兵种类别即可，具体番号以资料原文为限。

### 4. 企业自述核验

- 市占率、"第一"、"唯一"：检索第三方行业数据对照；找不到就保留归因并写"尚需第三方数据佐证"；
- 性能宣称：检索竞品公开参数做具名对比；
- 重大订单/中标：检索中标公告、政府采购网验证（可验证的升级为C级证据）。

## 二、信源优先级

1. **优先采信**：监管披露文件、招股书、年报、政府网站、行业协会、交易所公告、政府采购网、权威研究机构；
2. **谨慎采信**：企业官网、公众号、媒体报道（需二源交叉）；
3. **不采信**：自媒体软文、营销通稿、无法溯源的数据聚合站。

## 三、使用规则

1. 外部信息必须与项目主体、行业、产品直接相关；
2. 所有外部数字保留来源归因（正文"据……披露"或表注）；
3. 外部资料与用户资料冲突时，呈现差异并建议进一步核查，两边都不擅自采信；
4. 无法核实的信息只能以"据公开报道"等降级句式出现，禁止写成确定性结论；
5. 检索不到时如实写"公开渠道未获取到……数据"，列入后续核查建议。

## 四、检索词构造示例

- 竞对财务："星展测控 年报 营业收入"、"星展测控 2024 年度报告"；
- 竞对估值："迅翼卫通 融资 估值"、"XX公司 A轮 投后"；
- 市场空间："全国油气管网 总里程 国家管网"、"公路桥梁 数量 交通运输部 统计公报"；
- 客户背景："国家管网集团 设立 油气体制改革"；
- 订单验证："XX公司 中标 政府采购网"。
