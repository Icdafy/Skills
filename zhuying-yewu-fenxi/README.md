# 立项报告书｜主营业务分析生成 Skill

> 技能标识：`zhuying-yewu-fenxi` ｜ 版本：v1.0（2026-07-03）

## 一、功能定位

撰写一级市场股权投资立项报告书中的**「主营业务分析」章节**（默认为报告第三章）。

上传某一项目的资料包（业务介绍、BP、访谈纪要、财务数据、审计报告、产品/销售/客户资料、招股书、尽调材料等任意组合）后，本技能以一位拥有 40 年一级市场股权投资经验的资深投资业务经理视角，站在**投资机构内部立项评审立场**（而非企业宣传立场），输出结构完整、逻辑严谨、数据有据、语言审慎中立、可直接并入立项报告书的章节正文，含标准表格、指标计算与风险提示。

与本仓库其他技能的关系：

- `hangye-fenxi-pro` 负责立项报告的「所属行业分析」章节，本技能负责「主营业务分析」章节，两者配合覆盖立项报告的核心分析部分；
- 行业层面的市场规模、竞争格局、政策分析用 `hangye-fenxi-pro`；企业自身的产品、商业模式、收入成本、客户供应链、成长性分析用本技能。

## 二、核心特性

1. **12 个分析维度强制覆盖**：主营业务概述 → 产品与服务 → 商业模式 → 收入结构 → 成本与盈利 → 采购供应链 → 生产/交付 → 销售与客户 → 核心竞争力（含竞对） → 成长性（含预测检验） → 风险与关注事项 → 小结。缺资料的维度标注"资料未披露、建议尽调核查"，不静默跳过；
2. **三套结构方案自动选型**：标准十二节式（资料充分）／八节整合式（资料中等，实际立项报告最常见形态）／多板块式（多业务线企业，分板块五段式展开）；
3. **事实台账与证据分级**：所有关键数据登记来源与口径，按"已审计 / 企业自述 / 外部公开"三档分级，结论强度与证据强度严格匹配——企业自述的市占率、性能指标一律保留归因，不升格为事实；
4. **交叉印证**：订单↔收入、量价↔收入、客户明细↔总收入、产能↔预测收入等自动勾稽，印证不上的差异如实写入风险事项；
5. **审慎语言规范**：内置禁用表达清单（"行业领先""遥遥领先""前景广阔""壁垒极高""根据某某材料显示"等）与替代句式库，对公司预测明确标注"管理层预测，本报告未验证"，不写"建议立项"等越权结论；
6. **数据纪律**：绝不编造数据；关键计算附算式可复核；表格逐表校验合计与占比；口径冲突（如 BP 收入与审计收入不一致）主动提示并建议核查。

## 四、使用方法

**安装**：将 `zhuying-yewu-fenxi` 文件夹放入 Claude 技能目录（或将文件夹打包为 .skill 上传安装）。

**调用**：上传项目资料包后，直接说：

- "帮我写XX公司的主营业务分析"
- "根据这个资料包出立项报告的主营业务分析章节"
- "分析一下这家公司的业务、产品和商业模式（用于立项）"

**建议提供的资料**（缺项不阻断，对应章节会标注待核查）：

| 优先级 | 资料 |
| --- | --- |
| 核心 | 近 2-3 年财务报表/审计报告、分产品收入成本明细、BP/业务介绍、访谈纪要 |
| 重要 | 前五大客户及供应商清单、在手订单/合同台账、产品价格资料、产能产量销量（制造型）或交付续约数据（服务型） |
| 补充 | 招股书、行业研报、竞对信息、官网资料 |

**输出**：默认 Markdown 章节正文（编号体系：三、→（一）→ 1. →（1）），可要求生成符合公文排版的 Word 文档。

## 五、设计依据

本技能的章节结构、表格模板与语言风格，归纳自真实立项报告的主营业务分析章节写作范式（硬件制造型与多板块方案型两类样本），并固化了以下实操要素：

- 订单三要素写法（客户 + 数量 + 金额/单价）；
- 分产品收入成本毛利跨期对比表、产能产量销量表、前五大客户/供应商表、竞争对手对比表、盈利预测表等 10 余张标准表格模板；
- 客户评价"优势/劣势/独家排他"三段式；
- 风险事项"事实 → 影响路径 → 核查建议"固定写法；
- 小结"优势 + 约束 + 后续核查重点"四句式结构。

## 六、注意事项

- 本技能仅生成「主营业务分析」单章，不撰写立项报告全篇；
- 财务预测、估值测算不在本章范围（本章仅对公司预测做支撑性检验）；
- 输出内容基于用户资料与可验证公开信息，正文中标注"需进一步核查"的事项应在后续尽调中落实。
