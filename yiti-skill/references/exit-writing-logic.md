# 投资项目退出议题写作逻辑（B 类）

适用：我司已投项目拟通过实际控制人回购、公司回购或股权转让退出，报投委会审议启动退出、确定定价原则并授权开展审计评估。

来源：2026年9月一份项目退出议题终稿的逐段研读。原稿为内部资料，仓库只保存结构、句式与逻辑；主体、人名、文号、金额均以 XX 替代，完整脱敏范文见 `gold-examples.md` 例六，可直接套用的 JSON 见 `assets/examples/exit-yiti-spec.json`。

## 〇、动笔前的四个判断

1. **退出触发点。** 业绩对赌即将触发、经营持续下滑、战略调整还是投资期届满。触发点决定"退出原因"两条怎么立：终稿为"经营面不及预期＋对赌条款预期触发"。
2. **退出路径与定价依据。** 谁回购（实际控制人/公司）或向谁转让；定价依据先找协议条款（回购条款、回购价格下限），再找国资监管要求（投资备案通知中的回购定价要求），两者冲突时按"孰高"。
3. **程序链。** 国有资产交易监管依据（《企业国有资产交易监督管理办法》）＋内部逐级审批（投委会→产投投决会→控股党委会→控股董事会）＋国资报告备案＋产权交易所挂牌公告＋交割、完税、工商变更＋归档与投资评价。程序链同时写进正文"退出工作流程"和附件流程表，两处一一对应。
4. **本次请求什么。** 终稿只请两件事：同意启动退出并确定定价原则；授权聘请审计、评估机构并明确费用上限。正式回购协议和最终价格留待审计评估后另行上会。

　　（二）经营情况分析

　　（二）退出工作流程
　　五、请示事项
　　（空一行）
　　附件：XX有限公司项目退出方案
　　（空两行）
　　　　　　　　　　　　　　　　署名单位
　　　　　　　　　　　　　　　　成文日期
（另页）附件：XX有限公司项目退出方案

全文逻辑链：为什么投（背景与决策合规）→ 约定了什么（对赌回购条款）→ 现在怎样（数据）→ 为什么这样（分析）→ 所以要退（两条原因）→ 怎么退（定价＋流程）→ 请投委会同意什么（一是、二是）。每一部分的结论都是下一部分的起点，用衔接词显式接上（见第三节）。

## 二、逐节写法

### 标题与导语

- 标题公式：`审议关于＋标的公司工商全称＋投资项目退出＋的议题`，在公司全称后折行。
- 导语第一段写"为什么投、怎么投成的"，三步：
  1. 背景：平台或政策（"XX年X月，XX基地正式开业……为响应国家《促进创业投资高质量发展的若干政策措施》，落实'投早、投小、投长期、投硬科技'的政策导向，推动……产业化落地"）；
  2. 决策：时间＋决策机构及届次＋投资主体＋出资方式＋金额＋投后股比（"同意由XX（简称'投管公司'或'我司'）作为投资主体，对XX（简称'XX'）以自有资金投资XX万元、投后股权占比XX%"）；
  3. 备案与交割（"区国资局出具《关于……的通知》，项目完成投资事项备案及《增资协议》签订和股权交割"）。
- 导语第二段写"为什么现在退、退到哪一步"，五步一段：投后动作（"投后管理小组定期对项目进行跟踪访谈和赋能"）→ 变化（"XX年以来……业务发展远不及预期"，点明主要因素）→ 研判结论（"截至XX年X月，项目组研判XX已明确无法达成《增资协议》约定的业绩目标，业绩对赌条款存在到期触发的极高可能"）→ 目的（"为进一步防范风险、提前锁定投资本金不受损失"）→ 已做动作与提请（"近日，我司与公司实际控制人就退出安排进行了初步沟通并取得一致意见，现提请投委会审议。具体如下："）。
- 导语只给结论，证据放到第二、三部分展开；简称首次出现时用"（简称'XX'）"紧跟全称，括号楷体。

### 一、项目基本情况

**（一）投资尽调和决策**：一段写完，按时间顺序用分号串联每个节点，每个节点带日期：

立项（总办会届次）→ 全面尽调＋聘请律师事务所、会计师事务所专项尽调并出具报告 → 内部研讨、综合研判、形成投资建议逐级报批 → 董事会（届次、同意票数、占出席董事比例）→ 上报报告（文号）→ 区政府批示 → 国资备案（通知文号）。

作用：向投委会证明当初的投资程序完整合规，为退出程序合规打底。

**（二）对赌回购条款**：先总述"本次投资约定了业绩目标、股权回购等投资者保护条款。其中，"，再分述"业绩目标条款约定：（逐年营收门槛）"和"股权回购条款约定：（触发条件、回购价格下限）"。照录条款，不评论。

### 二、XX发展情况

**引导段**两句定性：前一句客观肯定历史阶段（"在XX年之前，处于公司核心技术平台研发阶段和产品试验定制、小批量供应阶段，总体运作正常"），后一句用"但"转入问题（"但XX年以来，公司产品市场推广不力，发展速度显著低于投资预期"）。

**（一）经营业绩情况**：数字链一段写完，顺序固定：

1. 上一完整年度：营业收入、同比增幅（上年基数写在括号里）、净利润、期末总资产、所有者权益、负债、货币资金；
2. 合同执行：执行合同项数与总金额，新签合同明细写在括号里并给合计，继续执行合同金额；
3. 最新一期：先一句总述（"XX年上半年，公司经营出现明显下滑"），再写资产与权益、营业收入（负数照写，原因写在括号里，如"（存在收入冲回情形）"）、净利润（"较上年同期由盈转亏"）、经营活动现金流量净额、货币资金（"较年初XX万元下降XX%"）、应收账款与回款状态；
4. 结论句收段："按此发展趋势，公司完成《增资协议》约定的XX万元营业收入目标差距较大，存在极高的回购风险。"

**（二）经营情况分析**：三段，客观平衡：

- 成果段：研发推进方向、阶段性成果、应用场景、获得的资质称号；
- 问题段："XX年，公司开始推广产品，但受下游市场需求变化和行业竞争加剧等因素影响，相关产品推广落地不及预期，尤其是核心业务XX推进放缓。"
- 应对段：拟调整的业务方向和延展产品，写到当前所处阶段（"多处于样机验证或小批量交付阶段，标准化产品体系和规模化销售仍在培育过程中，收入转化和现金流贡献尚需较长时间"）。

成果写足、问题写实、应对写到阶段，不下"前景黯淡"一类评价。

### 三、退出原因

两条，二级标题本身就是结论，格式"现象，后果/对策"：

- **（一）核心业务发展不及预期，新产品研发转化不确定**：用"根据上述分析，"承接第二部分；写原核心业务放缓、新业务所处阶段、研发和商业化周期对收入的影响，以两期经营活动现金流量净额佐证（"分别为-XX万元和-XX万元"），收于"公司难以按原预期实现业绩目标"。
- **（二）业绩对赌预期触发回购，提前退出以防范风险**：协议约定的当年目标 → 最新一期实际数 → 按经营基础和订单储备测算的缺口 → 时间窗口（"现距XX年12月31日已不足X个月"）→ 访谈判断（"XX年X月，投后小组与实际控制人访谈判断公司全年业绩目标基本已无实现可能"）→ "届时将大概率触发平价回购条款。"

原因一讲经营基本面，原因二讲条款触发，前因后果，不重复第二部分的数字罗列，只取支撑结论的关键数。

### 四、退出安排

**引导段**用"因此，基于前述……"承上，直接陈述退出的必要性与沟通结果："因此，基于前述预期回购风险，为防范国有资金损失、把握退出主动权、提前锁定回购本金，我司已与实际控制人初步沟通退出事项，对方同意进行回购。"

**（一）回购价格确定原则**：三步——协议依据（"根据《增资协议》第X条'股权回购'约定……回购价格为投资者初始投资金额"）→ 国资要求（"根据区国资局X国资发〔XX〕X号通知要求……回购价格为投资者实际支付的原始投资金额或按公司最新的投资估值两者孰高"）→ 结论（"据此，本次回购价格按照'原始投资金额与最新估值孰高'原则确定，即以我司实际支付的原始投资金额XX万元为基准，并以经审计、评估确认的公司最新估值所对应的我司XX%股权价值为参照，两者孰高者为最终回购价格"）。

**（二）退出工作流程**：先写依据（"根据《企业国有资产交易监督管理办法》及投资退出审批流程，本次退出主要环节及安排为："），再用一段写完全部环节："先由……；随后……；在……基础上……；之后……；下一步……；……；最后……。"与附件流程表的环节一一对应。

### 五、请示事项

```
　　综上，现申请：一是同意XX项目启动退出，由实际控制人XX回购我司持有的XX XX%股权；按照"原始投资金额与最新估值孰高"原则确定回购价格，以我司实际支付的原始投资金额XX万元为基准，最终价格以审计、评估结论及国资备案结果为准；二是同意授权投管公司聘请审计机构和资产评估机构对XX开展审计与资产评估工作，总金额不超过XX万元。
　　提请投委会审议。
```

- 每项请求写满：动作＋主体＋标的＋比例＋定价规则＋金额上限。
- "提请投委会审议。"单独成段；审议机构称谓与导语一致。

### 附件说明、落款与附件方案

- 正文下空一行写附件说明（单份：`附件：XX有限公司项目退出方案`），空两行后署名单位、成文日期。
- 附件方案另起一页，`附件：`顶格，二号方正小标宋标题（`XX有限公司项目`／`退出方案`），空一行后：
  - 一、退出方式与定价原则：（一）退出方式（谁、以什么方式、回购多少股权、实现全额退出）；（二）定价原则（协议＋国资要求＋孰高）；（三）基准价格测算（第一基准为原始投资金额，第二基准为最新估值对应的股权价值，具体价格以审计报告、资产评估报告结论为准）。
  - 二、退出工作流程及时间安排：引导句"本次退出共分为X个环节，基本安排如下表："＋流程表（序号｜事项｜预计历时（工作日）｜备注），备注无内容填"—"。

## 四、沿用终稿时统一的细节

研读终稿时发现以下几处，沿用时统一：

- 审议机构称谓全文一致：导语写"现提请投委会审议"，末段同样写"提请投委会审议"，不在文中换成其他会议名称。
- 标的简称一经确定全文不变，不混用"XX"和"XX公司"。
- 正文和表格不用非正式称谓，统一写"实际控制人XX"。
- 导语中的原因写明主要因素（"受下游需求变化、行业竞争加剧等因素叠加影响"），与第二部分分析呼应，不写"因各种因素和原因叠加"。
- "经XX年X月，投后小组……判断"去掉"经"，写"XX年X月，投后小组……判断"。
- 引导句"本次退出共分大约为X个细分环节"写作"本次退出共分为X个环节"。
- "具体价格须以……报告结论结果为准"写作"具体价格以……报告结论为准"。
- 表格文字按现行规则用仿宋_GB2312五号、括号内楷体_GB2312五号（终稿表格为宋体）。

## 五、成稿自查

- 骨架五部分齐全，二级标题与本文件一致；退出原因两条的标题是结论句。
- 导语两段：第一段有背景、决策（届次、金额、股比）、备案交割；第二段有投后动作、变化、研判结论、目的、沟通结果和"现提请投委会审议。具体如下："。
- 投资决策链每个节点有日期，董事会写届次和票数，报告与通知写文号。
- 经营数据链完整：上年度营收、同比、净利润、资产负债、货币资金；合同；最新一期营收、净利润、现金流、货币资金变化、应收与回款；结论句。
- 定价原则写出协议条款、国资要求、孰高结论三步；流程段与附件流程表一一对应。
- 请示事项分"一是……；二是……"，每项有动作、主体、比例、定价规则或金额上限。
- 语气中性，段尾无悬置句，无"不是……而是"类对举句式；运行 `scripts/check_yiti_text.py` 无硬规则命中。
- 附件说明、落款、附件方案齐全，格式符合 `format-rules.md`。
