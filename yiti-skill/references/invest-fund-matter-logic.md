# 项目投资、基金组建、经营事项议题写作逻辑（C、D、E 类）

本文件规定三类议题的骨架和逐节写法：C 类项目投资议题、D 类基金组建（设立）议题、E 类采购等经营管理事项议题，并补充 A 类会议表决议题的三种变体（收益分配与份额调整、协议修订、建议反对）。骨架由维护者提供的本单位议题成稿研读得出，原件只读、不入库，例句中的主体和数字均为虚构。完整范文见 `gold-examples.md` 例七至例十，C 类可直接套用的 JSON 见 `assets/examples/invest-yiti-spec.json`。

句子写法见 `expression-style.md`，论证要求见 `logic-chain.md`，排版见 `format-rules.md`。

## C 类：项目投资议题

适用：我司拟以直接投资、设立 SPV 或通过基金等方式投资某一标的，报投委会（或经投委会后报董事会、党委会）审议。

### 动笔前的四个判断

1. **交易结构。** 增资还是受让老股；直接持股还是通过 SPV、基金；我方各主体分别出多少。结构决定"投资方案"一节的要素表怎么列。
2. **定价锚。** 评估值（基准日、评估结论）、上一轮融资估值、本次估值，三者的高低关系是"投资建议"的核心依据。
3. **保障与退出。** 有无回购、对赌、董事席位、反稀释；预期退出路径和时间。没有保障条款的，必须在风险揭示中写明。
4. **报送层级。** 同一项目逐级上会时，正文不变，只改三处：提交主体行、主送、提请句；上一级会议的纪要或决议列为附件第一项。

### 固定骨架

```
审议关于对XX有限公司
项目投资的议题
提交部门/子公司：投管公司
（空一行）
投委会：
　　导语：拟以什么方式投资谁，"具体情况如下："
　　一、项目基本情况
　　（一）项目概况
　　（二）交易对手介绍（受让老股时写；增资不写）
　　（三）风险揭示
　　（四）投资建议
　　二、投资方案
　　（要素表）
　　三、请示事项
　　（空一行）
　　附件：1.尽调报告  2.审计报告  3.法律尽调报告  4.评估报告  5.风控报告
```

推理链：拟投什么 → 标的怎样 → 风险在哪 → 综合判断 → 方案要素 → 请求。

### 逐节写法

**导语**一句：`我司拟＋方式（联合谁、设立什么）＋对＋标的全称（简称"XX"或"公司"）＋进行投资，具体情况如下：`。导语不写金额和理由，金额放在方案和请示事项。

**（一）项目概况**分五段，每段一个层面，段首用定位词：

1. **定位段**（不加定位词）：成立时间、主营业务一句话定位、聚焦的领域、资质称号；随后写与我方的关联——与本区产业的衔接、与我司已有基金或项目的协同。
   > 　　XX科技成立于2016年8月，是工业机器视觉检测设备提供商，聚焦新能源电池、半导体封装、汽车零部件等领域，具备完整的研发、制造与服务体系，是国家级专精特新"小巨人"企业。我区已形成较为完善的智能制造产业生态，机器视觉是我区机器人产业链的细分领域；同时，我司XX基金重点投资方向为智能制造，后期与XX科技具有合作空间。
2. **行业层面**：下游需求、市场规模的起止年份与数值、复合增长率、政策。规模数据写明年份和单位，注明来源口径。
3. **业务层面**：总括一句后分"产品技术端""市场端""客户资源端"三个分句，每个分句落在可核对的事实上（专利数量、装机数量、客户名称）。
4. **财务方面**：近三年资产规模、负债率（偏高的写原因和公司的应对）、营业收入及复合增长率、净利润及拐点；公司对未来三年的预测单独一句并写明"公司预计"。
5. **交易层面**：方式 → 投资总额及各方分摊 → 评估基准日与评估值 → 本次估值与对应股比 → 与评估值、上一轮估值的比较 → 标的的资本市场规划 → 假设条件下的预期收益 → 法律尽调关于重大诉讼和上市障碍的结论。

**（二）交易对手介绍**（受让老股时）：转让方是谁、与标的的历史关系、当前持股比例、转让原因；历次转让用表格列出（序号｜转让时间｜受让方及股权比例｜转让后持股比例｜备注），表前写"历史转让情况如下："。

**（三）风险揭示**一段写完，句式固定："本次投资主要面临X方面风险：一是经营层面，……；二是财务层面，……；三是法律层面，……；四是交易层面，……。"每项按"事实＋可能后果＋已有应对或保障缺失"写：

> 　　二是财务层面，公司经营性现金流连续三年净流出且规模扩大，资产负债率处于较高水平，公司已制定加强回款、增资等应对措施。

没有回购、对赌等保障条款的，在交易层面明确写出"本次受让老股未设置回购、对赌等退出保障条款，投资收益依赖经营业绩、上市进程及二级市场表现"。

**（四）投资建议**四句，顺序固定：

1. 优势概括（只用前文已写过的事实）；
2. 定价判断（"本次投资定价合理，较评估值略有折价"）；
3. 让步回应（"目前虽存在……等阶段性财务特征，但随着……，相关问题有望逐步改善"）；
4. 结论（"综合来看，XX科技具备较高的投资价值，建议对该项目进行投资。"）。

投资建议不引入新事实；第3句回应的不足必须是风险揭示里写过的。

**二、投资方案**用两列要素表（基本要素｜内容），常用要素依次为：投资主体（SPV 名称，注明"最终名称以工商注册为准"）、投资标的、投资金额（含预留费用）、投向标的金额（估值及对应股比）、注册地、执行事务合伙人、出资结构（定位｜出资主体｜总出资（万元）｜占比，末行合计）、出资进度、执行合伙事务报酬、合伙费用、存续期限、运营管理（决策机制）、收益分配机制。直接投资不设 SPV 的，要素改为：交易条款、治理条款、股权回购、其他保护性条款。

出资结构各行之和等于合计，占比之和为100%；投资金额等于投向标的金额加预留费用。

**三、请示事项**两段：

> 　　综上，我司拟申请按照上述投资方案，联合XX投资成立有限合伙企业（SPV），对XX科技有限公司进行股权投资，投资金额不超过1,600万元，其中投管公司出资100万元，产投公司出资不超过1,500万元。
> 　　现提请投委会审议。

请求中的金额是我方出资上限，与出资结构表中我方各主体的出资之和一致。

### 小额早期项目的简式

投资金额小、处于研发或小批量阶段的项目，骨架压缩为三节：`一、公司及核心创始团队简介`（公司一段：成立时间、注册资本、技术与产品、所处阶段、最新资产负债、资金用途、分年预测；团队一段：核心成员的来历和分工）、`二、投资方案`（交易条款、治理条款、股权回购、其他保护性条款四行表）、`三、请示事项`。导语引出句用"要点如下："。

## D 类：基金组建（设立）议题

适用：我司拟联合其他机构发起设立私募股权、创业投资基金，报投委会审议立项并授权开展对管理人的尽调和协议磋商。

### 动笔前的四个判断

1. **我方角色。** 普通合伙人（GP2、执行事务合伙人）还是有限合伙人，或两者兼有（不同主体分别担任）。角色写在导语里。
2. **合作方体系。** 管理人、其股东、出资主体之间的股权关系；需要按"合并口径"报出双方阵营各自的出资和占比。
3. **我方的控制点。** 投决会席位与表决机制（如"5票4过"）、我方能否否决、管理费与超额收益分成比例。这是审议人最关心的条款，逐项写出对我方的含义。
4. **本次请求到哪一步。** 立项阶段只请"同意立项并开展尽调和协议磋商"，写明后续"提交集团审议"；方案未定的要素标注"暂定""以……为准"。

### 固定骨架

```
审议关于与XX组建XX基金的议题
提交部门/子公司：投管公司
（空一行）
投委会：
　　导语：目的＋我方角色＋联合谁（全称及简称、相互关系）＋设立什么，"具体情况如下："
　　一、基金设立背景
　　二、基金管理人概况
　　三、基金概况
　　（一）基金基本要素
　　（二）基金出资结构
　　（三）基金管理机制
　　（四）基金治理架构
　　（五）基金投资
　　（六）基金托管
　　（七）基金管理费
　　（八）收益分配
　　（九）基金退出
　　四、请示事项
　　（空一行）
　　附件：XX基金管理有限公司简介
```

推理链：为什么设 → 与谁设、对方是否合格 → 怎么设 → 请同意立项。

### 逐节写法

**导语**一句写满："为＋目的（服务本区什么产业、借助什么平台资源、引导什么项目落地），我司拟作为＋角色，联合＋合作方（集团全称及简称、其下属出资主体及简称、其管理人及简称），与＋本方其他出资主体，共同发起设立＋基金全称（以下简称"XX基金"）。具体情况如下："。先写我方角色，再写合作方；各主体之间的隶属关系用"下属""全资子公司"交代清楚。

**一、基金设立背景**两段：

- 第一段写政策依据，由大到小：市级改革方向 → 具体文件（发文机关、文件全称、文号、原文引用）→ 文件明确的牵头单位和投向。引用原文加引号，不改写。
- 第二段写合作的必要性，四步：合作平台的能力 → 基金聚焦的领域 → 对本区的作用（拓宽项目来源、推动成果落地）→ 对我司的作用（承担的职责、分享的管理费和收益、能力提升）。

**二、基金管理人概况**一段：成立时间、注册资本、股东、中基协登记编号、业务范围、员工人数及从业资格、在管基金数量、所属集团的基金出资情况，末句"公司详细情况见附件"。只写可核对的事实，不写评价。

**三、基金概况**按九个二级标题展开：

- **（一）基金基本要素**：用"1.基金名称：""2.基金组织形式：""3.基金规模：""4.基金注册地：""5.基金管理人/执行事务合伙人：""6.基金期限："逐条列出。名称后注"（暂定名，以工商注册为准）"；规模写目标规模、分期及每期金额、后续出资的触发条件（"当基金对外投资金额达到首期实缴出资额的80%时，基金管理人可向有限合伙人发出第二期缴款通知"）；期限写投资期、退出期和延长规则。
- **（二）基金出资结构**：先逐个写各合伙人的定位、认缴额、占比；再写合作方内部的股权关系；再"按合并口径"报双方阵营合计出资与占比；再写分期实缴安排；最后"各合伙人出资情况如下："接表（出资人类型｜出资机构｜认缴出资额（万元）｜出资比例｜首期实缴（万元）｜二期实缴（万元），末行合计）。正文数字与表格逐一对应。
- **（三）基金管理机制**：双 GP 的，用"1.核心职责：""2.项目尽调：""3.投后管理："分写各方分工，明确谁是"基金运作第一责任主体"、谁负责信息披露。
- **（四）基金治理架构**：合伙人会议（组成、须一致同意的事项逐条列出）；投资决策委员会（人数、各方委派名额、通过票数），末句写对我方的含义："我司与产投公司合计委派2名委员，在'5票4过'机制下对基金投资事项具有否决作用。"
- **（五）基金投资**：投资领域、投资方向（每个领域后括注细分方向）、投资限额（单一企业不超过基金总规模的比例、持股比例上限、是否为第一大股东）。
- **（六）基金托管**：一句。
- **（七）基金管理费**：标准（投资期、退出期、延长期分别怎么收）；分配（各 GP 的分成比例）；"经测算，"给出每期到位后的年度管理费及各方金额。测算数与费率、规模、分成比例相乘的结果一致。
- **（八）收益分配**：先总括"在全体合伙人之间按照下列顺序进行分配："，再按"1.合伙人实缴出资返还 2.有限合伙人优先回报 3.普通合伙人优先回报 4.超额收益分成"逐级写，每级以"如有余额，则……"起句，写明比例和计算基准。
- **（九）基金退出**：IPO、股权转让、产业并购各一句，说明适用情形。

**四、请示事项**：

> 　　拟申请按照上述方案对XX基金进行立项，并据此开展对基金管理人XX公司的尽职调查工作及合伙协议磋商工作。待基金方案最终确定且尽调结果符合中国证券投资基金业协会及公司相关规定后，提交集团审议。
> 　　现提请投委会审议。

**附件**为管理人简介，另页排在文后，内容依次为：公司简介、所属集团基金业务概况（附基金一览表）、高级管理人员简历（姓名、现任职务、学历、从业年限、主要经历）、已投项目情况（表）。简历只写经历和职责，不写评价性语言。

## E 类：经营事项议题（采购等）

适用：数据终端、信息服务、中介服务等采购，以及其他需提交专题会审议的日常经营管理事项。

### 固定骨架

```
关于XXXX的议题
提交部门/子公司：投管公司
（空一行，不设主送行）
　　导语：业务需求 → 现状与缺口 → 拟办事项，"现将有关情况汇报如下："
　　一、采购背景
　　二、调研比选情况
　　（一）方案一  （二）方案二  （三）方案三
　　（结论段）
　　三、申请采购方案及费用
　　（一）……（二）……
　　四、提请审议事项
```

标题用"关于＋事项＋的议题"，事项写办什么事（"优化投资业务辅助工具""续购XX服务账号"）。推理链：需求和缺口 → 选项及优劣 → 选择及理由 → 方案和费用 → 请求。

### 逐节写法

**导语**一段四句：

1. 需求："随着公司投资业务持续推进，项目筛选、尽职调查、行业研究、风险核查等工作对信息获取的及时性、完整性和专业性提出了更高要求。"
2. 现状与缺口："目前，原XX服务已到期，现有免费公开渠道存在信息分散、检索效率不高、专业数据覆盖不足等问题，已难以满足业务开展需要。"
3. 拟办："为补齐……方面的工具缺口，投管公司拟采购……。"
4. 引出："现将有关情况汇报如下："

**一、采购背景**：既往采购情况（何时采购、何时续购、现状）＋本次做了什么（"对市场主流产品开展了专项调研比选，并同步梳理了……使用需求"）。

**二、调研比选情况**：每个备选方案一个二级标题，正文两句——第一句写方案内容和报价（账号数量、权限、期限、价格），第二句写一项优势和一项不足，句式"该产品……，但……"。各方案写法对称、要素相同，便于横向比较。比选结束后单独一段给出结论：

> 　　综合数据覆盖范围、功能实用性、账号数量、采购成本和服务响应等因素，XX终端整体性价比较高，能够覆盖投资研判、尽职调查、行业研究等主要业务场景，建议选用该产品。

功能定位不同、不存在替代关系的工具，分开写并说明互补关系（"金融数据终端主要提供标准化数据，XX主要用于文档处理和信息整合"），不放在一起比价。

**三、申请采购方案及费用**：每项采购一个二级标题，一句写满数量、规格、金额、服务期限："采购1个正式账号，另赠送5个与正式账号功能权限一致的终端账号，采购金额为28,000元，服务期限为一年。"金额未最终确定的写"不超过"。

**四、提请审议事项**：

> 　　申请同意投管公司按上述方案采购XX数据终端、XX及XX服务，采购总金额不超过30,500元，服务期限均为一年。
> 　　以上议题，提请专题会审议。

总金额等于各分项金额之和。

### 写法要点

- 只写功能、数量、报价和适用场景，不照抄供应商宣传语（"行业领先""第一家""强大的"）。
- 结论用"整体性价比较高""能够覆盖主要业务场景"，不用"最高""最符合"。
- 每个被比较的方案都有报价；被选中的方案也写明成本。

## A 类变体

`writing-logic.md` 的骨架适用于常规股东会和合伙人会议。遇到下列三种情形，按本节调整。

### 变体一：收益分配、份额缩减、合伙人层级调整

事项直接涉及我司的资金收回和权益变化，骨架改为 `一、表决内容`（每个事项一个二级标题）＋`二、请示事项`。每个事项按三步写：

1. **事项本身**：全体合伙人拟签署什么文件、把什么调整为什么、调整后的结构。
2. **调整原因**：用引导词"调整原因："起句，写清成本、顺位或基数的变化机理，以及文件对责任边界的约定（"前端门槛收益率仅为收益分配计算基准，不构成合伙企业、普通合伙人的保本、保收益或刚性兑付义务"）。
3. **我司分配情况及影响**：用引导词"我司分配情况及影响："起句，写我司持有份额、持有天数、本次分配的本金和收益、合计、分配后剩余份额及占比。

其他合伙人的明细、计算公式、管理费、税务承担放入附件统计表和决议草案，正文写"具体分配明细详见附件1"。请示事项先写核查结论（表决范围、表决比例、分配顺序和计算公式与协议一致、我司金额与附件相符），再写申请内容（同意签署什么、同意按哪个基准日分配、我司缩减份额和分配收益的金额、由执行事务合伙人办理相关事项），最后"现提请投委会审议。"

### 变体二：协议修订、补充协议

写清四件事：修订的起因（监管反馈、备案要求，引用反馈原文）；修订了什么（涉及的条款和内容范围）；依据（监管规定全称和条款）；没有改什么（"仅对原合伙协议相关条款进行细化完善，未调整基金核心权利义务与交易结构"）。最后一项是审议人判断风险的关键，必须写。会议要求豁免通知期限的，单列一项议案，写明协议约定的通知期、豁免的理由和出席即视为同意的规则。

### 变体三：建议反对或暂缓

我方对来文事项持不同意见时，把来文方观点和我方分析分开写，骨架为：

```
　　一、议案内容
　　（议案名称、会议方式、议案主要内容、协议依据及我方表决权）
　　二、议案分析
　　（一）XX观点概述
　　（二）项目分析
　　三、请示事项
```

- **议案内容**：用"议案名称：""会议方式：""议案主要内容：""协议依据："四个引导词逐条写；协议依据中写明我方的表决地位（"项目退出事项需经基金投资决策委员会审议，且我方对该类事项拥有一票否决权"）。
- **来文方观点概述**：客观转述，句首标明来源（"XX整体观点倾向实现退出，具体理由概述如下：一是……；二是……"），不夹带我方评价。
- **项目分析**：我方的意见，逐条写"论点句＋事实＋缺什么"，论点句本身说明问题所在：
  > 　　一是议案对基本面的论证不充分。……但关于产品竞争力、财务预测、市场竞争情况等关键信息披露不够详实，无法据此判定其长期竞争优势与投资价值。
  > 　　二是定价依据不足。本次方案拟按4%年化单利执行，但现有材料未说明测算依据、估值逻辑及评估程序；受让方的主体背景、资金来源及与相关主体是否存在关联关系，缺少核查材料。
  > 　　三是对基金整体收益的影响。经测算，若本次退出实施，基金公允价值将减少XX元，累计收益率将由XX%降至XX%。
- **请示事项**：结论明确，写"综上，建议对该议案投反对票，并要求基金管理人补充下列材料后重新提交审议：一是……；二是……；三是……。"随后"现提请投委会审议。"

需要对方补充的材料写进请求，成为表决意见的一部分；不在正文里写"待进一步沟通后再行判断"。

## 成稿自查

- 类型判断正确，骨架与本文件一致，一级标题序号连续。
- C 类：项目概况五个层面齐全；风险项数与总括句一致，每项有事实；投资建议未引入新事实并回应了主要不足；要素表数字闭合；请求金额与出资结构一致。
- D 类：导语写明我方角色和各主体关系；出资结构正文与表格一致、合并口径复算无误；投决会机制写出对我方的含义；管理费测算可复算；请求止于立项和尽调。
- E 类：各方案写法对称且均有报价；结论有比较维度；总金额等于分项之和。
- A 类变体：我司的金额和占比单独写出；修订类写明未调整的内容；反对类把来文观点与我方分析分开，结论明确。
