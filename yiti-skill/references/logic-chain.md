# 议题的论证逻辑

本文件规定议题怎样想、怎样排、怎样接，使全文从导语到请示事项成为一条走得通的推理链，审议人逐句追问都有答案。句子怎么写见 `expression-style.md`。规则由维护者提供的本单位历年议题成稿逐段研读得出，原件只读、不入库，例句中的主体和数字均为虚构。

## 一、合格标准

一份逻辑过关的议题同时满足五条：

1. **请求唯一且明确。** 读完能用一句话复述"请审议机构同意什么、金额或比例上限是多少"。
2. **请求中的每个要素前文都有来历。** 请示事项里出现的主体、标的、金额、比例、期限、定价规则，在前面的章节都已出现并有依据；请示事项不出现新事实、新数字。
3. **每个判断后面站着事实。** 全文任何一个带评价的词（合理、合规、较高、不及预期、极高）都能在同段或上一段找到支撑它的数据、条款或程序。
4. **前后不打架。** 同一数字、同一名称、同一口径、同一审议机构全篇一致；分项之和等于合计；正文与附件、表格一致。
5. **读者的追问已被回答。** 为什么是现在、为什么是这个价格、为什么是这个对手方、对我方有什么影响、最坏情况是什么、程序是否走完，文内都有对应的句子。

## 二、动笔前先回答六个问题

先在草稿上用一句话分别回答，答不出的回到材料里找，材料里没有的向用户要，不凭推测补：

1. **请什么。** 请审议机构同意的事项和上限（"同意以不超过1,600万元投资XX科技"）。
2. **为什么办。** 目的或触发原因（政策要求、协议约定、风险出现、合同到期、来文征询）。
3. **凭什么办。** 协议条款、制度规定、上级文件、已履行的程序。
4. **怎么办。** 方案的要素：主体、对象、金额、价格、方式、期限、步骤。
5. **对我方意味着什么。** 权益比例、收益、成本、风险、话语权的变化。
6. **还差什么。** 后续程序和以什么为准（审计评估、国资备案、工商核名、上级会议）。

六句话连起来就是全文的骨架：导语回答第1、2问，主体章节回答第3、4、5问，请示事项重述第1问并带上第6问的规则。

## 三、全文的推理链

五类议题的章节不同，推理的走向相同：**事由 → 事实 → 分析 → 结论 → 请求**。后一部分只使用前一部分已经给出的东西。

| 类型 | 推理链 |
|---|---|
| A 会议表决 | 谁来文、与我方什么关系 → 会议要素 → 各议案办什么事、依据是什么、对我方有何影响 → 核查结论 → 请同意并表决 |
| B 项目退出 | 为什么投、怎么投成的 → 约定了什么 → 现在怎样 → 为什么这样 → 所以要退 → 怎么退、什么价 → 请同意启动并授权 |
| C 项目投资 | 拟投什么 → 标的怎样（行业、业务、财务、交易）→ 风险在哪 → 综合判断值得投 → 方案要素 → 请同意按方案投资 |
| D 基金组建 | 为什么设 → 与谁设、管理人是否合格 → 基金怎么设（要素、出资、治理、费用、分配、退出）→ 请同意立项并开展尽调 |
| E 经营事项 | 需求是什么、现状缺什么 → 有哪些选项、各自优劣 → 选哪个、为什么 → 方案和费用 → 请同意按方案办理 |

检验方法：把每个一级标题下的结论各写成一句，按顺序读，能否读成一段通顺的话。读不通，说明章节之间缺环节或顺序错了。

> 　　我司拟联合XX投资设立SPV投资XX科技（导语）。XX科技是工业机器视觉检测设备供应商，行业处于增长期，近三年收入持续增长并于2025年扭亏，本次以低于评估值的价格受让老股（项目概况）。项目存在经营、财务、法律、交易四方面风险，其中财务风险公司已有应对措施（风险揭示）。综合来看具备较高投资价值（投资建议）。投资通过SPV实施，总额不超过1,700万元，我方出资不超过1,600万元（投资方案）。请同意按上述方案投资（请示事项）。

## 四、章节之间怎样接

### 上一节的结论是下一节的起点

每个一级标题下的最后一段给出本节结论，下一节第一句从这个结论出发，并用承接词把关系写明：

| 关系 | 承接词 | 例 |
|---|---|---|
| 由事实到分析 | 根据上述分析， | 根据上述分析，公司原核心业务放缓，新业务仍处于产品开发和市场拓展阶段。 |
| 由背景到动作 | 在此背景下，／在此基础上， | 在此背景下，我司拟与XX公司合作设立产业基金。 |
| 由原因到对策 | 因此，基于前述……， | 因此，基于前述预期回购风险，为防范国有资金损失，我司已与实际控制人初步沟通退出事项。 |
| 由依据到结论 | 据此， | 据此，本次回购价格按照"原始投资金额与最新估值孰高"原则确定。 |
| 由比选到选择 | 综合……等因素， | 综合数据覆盖范围、账号数量、采购成本等因素，XX终端整体性价比较高，建议选用该产品。 |
| 由全文到请求 | 综上， | 综上，我司拟申请按照上述投资方案…… |

承接词后面必须指向前文确实写过的内容。前文没有分析就不写"根据上述分析"，前文没有比选就不写"综合比较"。

### 标题本身承担逻辑

- 一级标题是推理链的节点，名称用名词短语，顺序即推理顺序：`一、项目基本情况` `二、XX发展情况` `三、退出原因` `四、退出安排` `五、请示事项`。
- 需要读者先接受结论的地方，把二级标题写成结论句："（一）核心业务发展不及预期，新产品研发转化不确定""（二）业绩对赌预期触发回购，提前退出以防范风险"。标题是结论，标题下的正文就只负责证明它。
- 并列的二级标题用同一种结构，不出现一个是名词、一个是句子的混排。

### 先总后分，项数对得上

凡分项展开，先写总括句并报出项数，再逐项写；总括句的项数、正文的项数、请示事项的项数三者一致：

> 　　本次股东会共计审议两项议案，具体内容如下：……（一）……（二）……经核查，本次两项议案均已履行……现提请投委会同意本次两项审议议案。

## 五、段落内部的推理

一个需要读者接受的判断，按"论点—依据—推理—对我方的含义"写成一个单元，四步可以在一句或一段内完成：

> 　　**议案办成什么事（论点）**：基金管理人提议由XX银行担任基金托管人，并按零费率开展托管业务合作。
> 　　**凭什么（依据）**：根据XX基金《合伙协议》12.1约定，托管机构由管理人按照合伙人会议决议选取。
> 　　**为什么是它（推理）**：经与四家银行沟通对比，该行提供零费率，且可在同一支行办理募集户及托管户开立。
> 　　**对我方意味着什么（含义）**：托管费由基金财产承担，零费率可降低基金运营成本，不影响我方出资比例及收益分配顺序。

常见的缺步和补法：

| 缺什么 | 表现 | 补法 |
|---|---|---|
| 缺依据 | "该议案合法合规。" | 写出核查了哪项程序、对照了哪份文件："已由XX第四届董事会第十五次会议审议通过，符合《公司章程》第X条。" |
| 缺推理 | "公司经营下滑，因此应当退出。" | 补上中间环节：下滑到什么程度 → 距协议目标差多少 → 回购条款何时触发 → 提前退出能锁定什么。 |
| 缺含义 | 只转述议案内容，不写对我方的影响 | 补一句持股比例、分红金额、成本或表决权的变化；确无影响的，写"不涉及我司出资及持股比例变化"。 |
| 缺论点 | 罗列一串事实，没有落点 | 段首或段尾加一句结论，说明这些事实证明了什么。 |

## 六、推理不跳步

从事实到请求之间的每一步都写出来，不让读者自己去猜。检查方法：在相邻两句之间问一句"所以呢"或"凭什么"，答案应当就是下一句或上一句。

退出议题中"为什么现在退"的完整链条：

> 　　协议约定2026年度营业收入应达到300万元（约定）→ 截至2026年6月30日上半年营业收入为-0.12万元（现状）→ 按现有订单储备测算全年收入距目标缺口超过290万元（测算）→ 现距2026年12月31日已不足4个月（时间）→ 2026年9月投后小组访谈判断全年目标基本已无实现可能（印证）→ 届时将大概率触发平价回购条款（结论）→ 为把握退出主动权、提前锁定回购本金，现在启动退出（对策）。

七步缺任何一步，结论的强度都要降一档。只有"现状"和"结论"两步的，属于跳步，补齐或改写为较弱的判断。

## 七、论点强度与证据强度相称

判断能说多重，取决于后面的证据有多硬：

| 证据 | 可以写 | 不可以写 |
|---|---|---|
| 审计数据、协议原文、会议决议、监管文件 | 已、均、符合、触发、未发现存在……情形 | — |
| 未经审计的报表、管理层口径、项目组测算 | 约、测算、预计、大概率、差距较大 | 必然、确定、肯定 |
| 公司预测、行业研究、访谈 | 公司预计、有望、可能、具备一定…… | 将实现、必将、确保 |
| 没有材料 | 不写 | 任何判断 |

- 预测数字写明是谁的预测："公司预计未来三年营业收入分别为……"，不把公司的预测写成我司的判断。
- 收益测算写明假设："假设2030年实现IPO退出，预期投资IRR可达……（对应退出时PE30—40倍）"。
- 判断和证据写在一起。证据在附件里的，正文点明"详见附件X"。

## 八、数字的逻辑

审议人最先核对的是数字。下列五项逐一过：

1. **来源一致。** 每个数字能在来文、协议、报表或测算表中找到；正文、表格、附件、请示事项里同一数字写法相同。
2. **口径一致。** 认缴与实缴、含税与不含税、合并与单体、投前与投后、年度与半年度不混用；换口径时写明"按合并口径""按实缴口径"。
3. **加总闭合。** 分项相加等于合计，比例相加等于100%，差额等于两数相减，占比等于分子除以分母。写完后逐个复算。

   > 　　基金总规模5,000万元。XX公司作为LP1认缴出资2,900万元，占58.00%；产投公司作为LP2认缴出资1,900万元，占38.00%；XX基金公司作为GP1认缴出资100万元，占2.00%；我司作为GP2认缴出资100万元，占2.00%。

   2,900＋1,900＋100＋100＝5,000；58.00%＋38.00%＋2.00%＋2.00%＝100.00%。

4. **比较有基数。** "增长""下降""折价""高于"后面有比较对象和幅度："较评估值6.50亿元折价7.69%"，不写"价格较低"。
5. **上限有余地。** 请求中的金额写"不超过"，并与方案中的测算数对得上：方案测算1,592万元，请求写"不超过1,600万元"，不写"约1,600万元"。

## 九、正反都写，结论不被稀释

议题不回避不利事实。不利事实写在它该在的位置，并交代应对或影响，结论句仍然明确：

- **项目投资**：风险单列一节，每项风险写"事实＋可能后果＋已有应对"；投资建议中用一句让步句回应最主要的不足，随后给出明确建议。
- **项目退出**：成果写足、问题写实。先写公司取得的阶段性成果和资质，再用"但"转入问题，退出的理由落在数据和条款上，不贬低企业。
- **会议表决**：议案对我方有不利影响的，写出影响的金额或比例，再写核查结论和表决建议；建议反对的，逐条写出来文论证不充分之处和对我方的测算影响，结论写"综上，建议予以反对"。
- **采购比选**：每个选项各写一句优势、一句不足，被选中的方案也写不足或成本。

结论句只有一个方向。不写"总体可行但仍存在较大不确定性，建议审慎决策"这种两头都占的句子；风险确实大到改变结论的，结论就改。

## 十、常见的逻辑问题

| 问题 | 例 | 改法 |
|---|---|---|
| 循环论证 | 本次交易定价合理，因为价格是公允的。 | 写出比较基准：较评估值、上一轮融资估值分别低多少。 |
| 以偏概全 | 公司获得一项省级资质，技术实力行业领先。 | 资质只证明资质；"领先"需要市场份额、专利数量或第三方排名。 |
| 偷换主体 | 前文写"基金管理人认为"，后文写成"我司认为"。 | 来文方的观点始终标明来源；我司的判断另起一句。 |
| 偷换口径 | 前文"实缴1,980万元"，后文按"认缴3,960万元"算比例。 | 全篇同一口径，或写明换算关系。 |
| 因果倒置或不成立 | 行业增长快，所以公司收入会增长。 | 写出公司在行业中的位置、订单和客户，行业只是背景。 |
| 请求超出论证 | 正文只论证了启动退出，请示事项同时请同意回购协议。 | 请求只请正文已论证的事项，其余留待下次上会。 |
| 请求小于论证 | 正文分析了三项议案，请示事项只提其中两项。 | 项数对齐，逐项表态。 |
| 条件遗漏 | "预期IRR可达50%"未写假设。 | 补上退出时间、退出方式、估值倍数等假设。 |
| 前后矛盾 | 风险揭示写"负债率较高"，投资建议写"财务状况稳健"。 | 建议中承认该特征并说明改善路径。 |
| 时间错位 | 用2024年度数据论证2026年的经营现状。 | 用最新一期数据，写明截止日。 |

## 十一、质询预演

成稿后站在审议人的位置，把下列问题逐个问一遍。每个问题在文中应有一句能直接回答；没有的，补上或在附件中备好。

通用：

- 这件事为什么需要本机构审议？依据是哪条制度或协议？
- 为什么是现在？晚一个月会怎样？
- 这个数字是谁出的、什么口径、哪天的？
- 对我方的权益比例、收益、成本各有什么影响？
- 最不利的情况是什么？有没有应对或保护条款？
- 前置程序走完了没有？后面还要过哪些会、报哪些部门？

分类型：

- **会议表决**：议案是否已过对方董事会或合伙人会议规定的程序？我方不同意会怎样、有没有否决权？表决截止时间是哪天？
- **项目退出**：价格怎么定、协议和国资要求哪个高？对方有没有回购能力和意愿？费用上限怎么测的？
- **项目投资**：估值依据是什么、与评估值和上一轮相比如何？转让方为什么卖？退出路径和保障条款是什么？出资在各主体之间怎么分？
- **基金组建**：管理人有没有资质和业绩？我方在投决会有几票、能否否决？管理费和超额收益怎么分？出资节奏和触发条件是什么？
- **经营事项**：为什么不继续用原方案？比了几家、差价多少？总金额和期限是多少？

## 十二、逻辑自查清单

- 六个问题都有答案，请求能用一句话复述。
- 各章结论连读成段，顺序即推理顺序。
- 每个承接词（根据上述分析、据此、综上）指向的内容前文确实存在。
- 总括句、分项、请示事项的项数一致；"一是、二是"连续且不少于两项。
- 每个判断词的同段或上段有事实支撑，强度与证据相称。
- 全部数字复算过：分项之和、比例之和、差额、占比、上限。
- 同一主体、同一事物、同一审议机构全篇一个叫法。
- 请示事项中没有新事实、新数字；金额带"不超过"，后续程序写成"以……为准"。
- 来文方观点与我司判断分开，预测与事实分开。
- 运行 `scripts/check_yiti_text.py`，逻辑结构类警告逐条复核。
