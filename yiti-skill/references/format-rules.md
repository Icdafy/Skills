# 议题文书格式规则

规则来源：`assets/templates/文件字体格式.doc`（西安未央城市建设集团《关于规范行文格式的通知》）与四份议题成稿的逐段格式实测。以下现行规则优先于历史成稿与原始格式样本；两者仅作为内容和结构参考。

## 页面设置

- A4 纵向。
- 页边距：上 3.7 厘米，下 3.5 厘米，左 2.8 厘米，右 2.6 厘米。
- 标题行距：主标题、提交部门行及各级标题均为固定值 30 磅。
- 正文及附件行距：固定值 28 磅，不因篇幅紧张而调整。
- 正文两端对齐。
- 页码：格式 `-1-`，左右两个半角短横线及数字全部为宋体四号（14 磅）；所有字体槽位 ascii/hAnsi/eastAsia/cs 均设为宋体，动态 PAGE 域及显示结果同样设置，位于版心外侧，奇偶页不同；一页以内的议题可不加页码。

## 字号对照

- 二号 = 22 磅。
- 三号 = 16 磅。
- 四号 = 14 磅。
- 五号 = 10.5 磅。

## 字体规则

字体优先级：中英文圆括号（含括号本身）及其内部所有文字、数字、西文统一为楷体_GB2312 三号（16 磅），适用于标题、正文、表格及附件，保留原有加粗；页脚完整 `-1-` 统一为宋体四号。两类特殊 run 的 ascii/hAnsi/eastAsia/cs 均设为指定字体，不能被 Times New Roman 覆盖。

其余 run 的西文字体（ascii/hAnsi/cs）设为 Times New Roman，中文字体（eastAsia）按段落角色设定。括号外数字与英文字母的字号随所在文字：正文中为三号，表格内为五号。下表的常规位置规则均服从上述特殊规则。

| 位置 | 中文字体 | 字号 | 加粗 | 对齐 |
|---|---|---|---|---|
| 主标题 | 方正小标宋简体 | 二号 | 否 | 居中 |
| 提交部门/子公司行 | 楷体_GB2312 | 三号 | 否 | 居中 |
| 主送（投委会：） | 仿宋_GB2312 | 三号 | 否 | 顶格，无首行缩进 |
| 正文段落 | 仿宋_GB2312 | 三号 | 否 | 两端对齐，首行缩进2字 |
| 一级标题（一、） | 黑体 | 三号 | 否 | 首行缩进2字 |
| 二级标题（（一）） | 楷体_GB2312 | 三号 | 是 | 首行缩进2字 |
| 三级标题（1.） | 仿宋_GB2312 | 三号 | 是 | 首行缩进2字 |
| 四级序号（（1）） | 楷体_GB2312 | 三号 | 否 | 首行缩进2字 |
| 核心结论句、引导词（主要内容：/审议依据：） | 仿宋_GB2312 | 三号 | 是 | 随所在段落 |
| 附件行 | 仿宋_GB2312 | 三号 | 否 | 见附件规则 |
| 表格内文字 | 仿宋_GB2312 | 五号 | 表头可加粗 | 水平居中、垂直居中 |
| 表格内数字与西文 | Times New Roman | 五号 | 否 | 水平居中、垂直居中 |
| 数字、英文字母、百分号、小数点（正文） | Times New Roman | 三号 | 随所在句 | 随所在段落 |

- 系统缺少 仿宋_GB2312 时用 `assets/fonts/simfang.ttf`；缺少 方正小标宋简体、楷体_GB2312 时用 `assets/fonts/` 内对应字体文件安装后再排版。
- 除核心结论句和引导词外，不加粗、不加下划线、不用颜色、不用斜体。

## 缩进规则

- 所有标题和所有正文段落一律首行缩进 2 个中文字符（三号字对应 32 磅）。
- 例外仅两处：居中的标题区（主标题、提交部门行）和顶格的主送行 `投委会：`。
- 纯文本输出时，标题与段落一律以两个全角空格 `　　` 开头。

## 文书结构（固定顺序）

1. 主标题（可折行，居中）。
2. `提交部门/子公司：投管公司`（居中；也可按实际写 `提交子公司：投管公司`）。
3. 空一行。
4. `投委会：`（顶格）。
5. 导语段（一段，以"具体如下："或"具体情况如下："收尾）。
6. `一、会议基本信息`。
7. 会议要素逐行列出，每行一段，首行缩进2字：会议名称、会议时间、会议地点、召集人、会议方式、表决方式、表决文件截止时间（按会议实际选用，见 writing-logic.md）。
8. `二、会议审议事项`。
9. 议案概述（单议案直接写；多议案先写"本次会议共审议X项议案，具体内容如下："再分（一）（二）逐项写）。
10. `三、请示事项`。
11. 合规核查结论段＋明确提请段。
12. 附件行。
13. 全文到附件行为止，不写落款单位、不写日期。

## 表格规则

- 表格内括号外的中文为仿宋_GB2312 五号，数字与西文为 Times New Roman 五号；括号及内部文字统一为楷体_GB2312 三号。
- 单元格内容水平居中、垂直居中；表头行可加粗。
- 表格自适应：按内容与窗口宽度自动调整列宽，不得溢出版心。
- 表格前必有一句引导句并以冒号收尾，如"XX近三年主要财务指标如下："。
- 金额类数字使用千分位分隔（如 245,766.75）；单位在表头注明（如 "净利润（万元）"）。
- 表格行距用单倍行距，不套用正文 28 磅固定行距。

## 附件规则

- 单个附件：`附件：关于召开XXXX会议的通知`，不加阿拉伯数字序号，附件名称不加书名号，名称后不加标点。
- 多个附件：
  - `附件1.XXXXX`
  - `附件2.XXXXX`
  - 每份各占一段，首行缩进2字；序号用阿拉伯数字和半角句点，不在“附件”与序号之间加冒号。附件名称不加书名号，名称后不加标点。
- 生成器的 `attachments` 数组只传附件名称，不传“附件”标签或序号；生成器自动编号、去除名称中的书名号及末尾标点。
- 附件按报送顺序编号：通知在前，议案次之，表决票最后。
- 附件行前空一行。

## 标点与数字

- 中文语境一律使用全角标点；连续书名号、引号之间不加顿号。
- 正文中的议案名称用书名号：《关于XXXX的议案》；附件名称不加书名号。
- 协议条款引用格式：`根据XX基金《合伙协议》12.1约定"……"`，条款编号用阿拉伯数字，引文用中文引号。
- 发文字号用六角括号：`中国人民银行中国证监会公告〔2025〕8号`。
- 日期格式：`2026年4月23日`；时间格式：`17:00`（冒号为半角，数字 Times New Roman）。
- 金额写法：`2亿元`、`40亿元`、`141583.56元`、`不超过20万元`，数字部分 Times New Roman。

## 成稿自查清单

- 标题为二号方正小标宋简体且居中，提交部门行为三号楷体_GB2312且居中。
- 提交部门行后空一行，`投委会：`顶格。
- 全部标题、全部段落首行缩进2字。
- 一级标题三号黑体不加粗；二级标题三号楷体_GB2312加粗。
- 正文三号仿宋_GB2312；括号外数字与西文为 Times New Roman；所有圆括号及内部字符为楷体_GB2312三号。
- 表格括号外内容仿宋_GB2312五号居中、数字 Times New Roman；括号内容楷体_GB2312三号，表格未超出版心。
- 多份附件格式为“附件1.XXX”，单份无序号；名称无书名号、无尾部标点，首行缩进2字。
- 页脚完整“-1-”（两个短横线、动态页码及其显示结果）全部为宋体四号。
- 文末无落款、无日期。
- 行距：标题30磅、正文28磅固定值。
