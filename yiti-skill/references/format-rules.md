# 议题文书格式规则

规则来源：`assets/templates/文件字体格式.doc`（西安未央城市建设集团《关于规范行文格式的通知》）、历次议题成稿与2026年9月项目退出议题终稿的逐段格式实测。以下现行规则优先于历史成稿与原始格式样本；两者仅作为内容和结构参考。

## 页面设置

- A4 纵向。
- 页边距：上 3.7 厘米，下 3.5 厘米，左 2.8 厘米，右 2.6 厘米。
- 标题行距：主标题、提交部门行及各级标题均为固定值 30 磅。
- 正文、附件说明、落款及附件正文行距：固定值 28 磅，不因篇幅紧张而调整。
- 正文两端对齐。
- 页码：固定加页码，格式 `-1-`，左右两个半角短横线及数字全部为宋体四号（14 磅），短横线与数字同为四号，不能只改数字；ascii/hAnsi/eastAsia/cs 均设为宋体，动态 PAGE 域及显示结果同样设置；页脚奇偶页不同，奇数页居右、偶数页居左。

## 字号对照

- 二号 = 22 磅。
- 三号 = 16 磅。
- 四号 = 14 磅。
- 五号 = 10.5 磅。

## 字体规则（按顺序设置）

字体按以下四步设置，与在 Word 中手工排版的顺序一致，后一步覆盖前一步：

1. **中文字体按角色设定**：方正小标宋简体（主标题、附件标题）、黑体（一级标题）、楷体_GB2312（提交部门行、二级标题）、仿宋_GB2312（正文、三级和四级标题、附件说明、落款、表格）。
2. **括号**：中英文圆括号（含括号本身）及其内部文字一律楷体_GB2312，字号与所在位置一致：主标题和附件标题中为二号（22 磅，与标题同大）；提交部门行、正文、各级标题、附件说明中为三号（16 磅）；表格内为五号（10.5 磅）；保留所在位置的加粗。四级标题开头的序号"（1）"不改楷体，随标题用仿宋_GB2312加粗；序号之后标题文字中的括号仍按本条改楷体。
3. **页脚**：完整 `-1-` 为四号宋体，四个字体槽位均为宋体。
4. **最后一步，全文 Times New Roman**：对正文全部内容（含标题、括号内、表格、附件说明、落款、附件正文）统一设置西文字体 Times New Roman。该操作只改变数字、英文字母和 `%` `.` `:` `-` `/` 等半角符号，不改变汉字和中文标点的字体。页脚不参与这一步，保持四号宋体。

补充要求：

- 全角数字（０—９）、全角字母和全角百分号（％）先转为半角，否则最后一步无法把它们设为 Times New Roman；生成器自动转换，文本稿手工改。
- 中文引号、破折号、省略号属中文标点，仍用所在位置的中文字体（生成器为每个 run 设置 `w:hint="eastAsia"` 与 `w:lang eastAsia="zh-CN"`）。
- 数字和西文的字号随所在位置：正文三号，表格五号，主标题二号。

| 位置 | 中文字体 | 字号 | 加粗 | 对齐 |
|---|---|---|---|---|
| 主标题（可折行） | 方正小标宋简体 | 二号 | 否 | 居中 |
| 提交部门/子公司行 | 楷体_GB2312 | 三号 | 否 | 居中 |
| 主送（投委会：），仅会议类 | 仿宋_GB2312 | 三号 | 否 | 顶格，无首行缩进 |
| 正文段落 | 仿宋_GB2312 | 三号 | 否 | 两端对齐，首行缩进2字 |
| 一级标题（一、） | 黑体 | 三号 | 否 | 首行缩进2字 |
| 二级标题（（一）） | 楷体_GB2312 | 三号 | 是 | 首行缩进2字 |
| 三级标题（1.） | 仿宋_GB2312 | 三号 | 是 | 首行缩进2字 |
| 四级标题（（1）），按需使用 | 仿宋_GB2312 | 三号 | 是 | 首行缩进2字 |
| 核心结论句、引导词（主要内容：/审议依据：） | 仿宋_GB2312 | 三号 | 是 | 随所在段落 |
| 主标题、附件标题内的括号及括号内文字 | 楷体_GB2312 | 二号 | 否 | 居中 |
| 括号及括号内文字（标题区和表格以外） | 楷体_GB2312 | 三号 | 随所在位置 | 随所在段落 |
| 附件说明、落款、成文日期 | 仿宋_GB2312 | 三号 | 否 | 见附件与落款规则 |
| 表格内文字（括号外） | 仿宋_GB2312 | 五号 | 表头加粗 | 水平居中、垂直居中 |
| 表格内括号及括号内文字 | 楷体_GB2312 | 五号 | 随所在位置 | 水平居中、垂直居中 |
| 数字、英文字母、%等半角符号（全文） | Times New Roman | 随所在位置 | 随所在句 | 随所在段落 |
| 页脚 `-1-` | 宋体 | 四号 | 否 | 奇数页居右、偶数页居左 |

- 三款公文字体随技能放在 `assets/fonts/`（simfang.ttf、楷体_GB2312.ttf、方正小标宋简体.ttf），运行 `scripts/ensure_fonts.py` 检测并做用户级安装（Windows 同时写入 HKCU 字体注册表，无需管理员权限，已打开的 Word 重启后生效）。
- 生成的 DOCX 嵌入仿宋_GB2312、楷体_GB2312；方正小标宋简体的许可（fsType=2）禁止嵌入，打开文档的电脑须已安装该字体。Word 另存 PDF 时该字体同样不能嵌入，PDF 字体列表里标题可能显示为 SimSun，属 Word 的命名方式，标题字形仍为方正小标宋。
- 除标题、核心结论句和引导词外，不加粗、不加下划线、不用颜色、不用斜体。

## 标题层级

一、→（一）→ 1. →（1）。四级标题只在三级标题下内容仍需分项时使用，不越级，不在（一）下直接用（1）。

## 缩进规则

- 所有标题和所有正文段落一律首行缩进 2 个中文字符（三号字对应 32 磅）。
- 例外：居中的标题区（主标题、提交部门行）、顶格的主送行 `投委会：`、附件正文页左上角的 `附件：`。
- 纯文本输出时，标题与段落一律以两个全角空格 `　　` 开头。

## 文书结构

会议参会表决议题（A 类）：

1. 主标题（可折行，居中）。
2. `提交部门/子公司：投管公司`（居中；也可按实际写 `提交子公司：投管公司`）。
3. 空一行。
4. `投委会：`（顶格）。
5. 导语段（一段，以"具体如下："或"具体情况如下："收尾）。
6. `一、会议基本信息`，会议要素逐行列出。
7. `二、会议审议事项`。
8. `三、请示事项`：合规核查结论段＋明确提请段。
9. 附件说明。全文到附件说明为止，不写落款单位、不写日期。

投资项目退出议题（B 类，详见 exit-writing-logic.md）：

1. 主标题 `审议关于XX有限公司投资项目退出的议题`（在主体名称后折行）。
2. `提交子公司：投管公司`。
3. 空一行，不设主送行。
4. 导语两段（投资背景与决策；投后变化、研判与提请），以"具体如下："收尾。
5. `一、项目基本情况` `二、XX发展情况` `三、退出原因` `四、退出安排` `五、请示事项`。
6. 附件说明、落款单位、成文日期。
7. 另页：附件正文（退出方案）。

## 表格规则

- 表格内所有文字固定为五号：括号外中文仿宋_GB2312，括号及括号内文字楷体_GB2312，数字与西文 Times New Roman。
- 单元格内容水平居中、垂直居中；表头行加粗并设为跨页重复，行不跨页拆开。
- 表格铺满版心宽度，列宽按内容分配：序号、历时等短列按内容定宽，事项等长文字列分得剩余宽度，不得溢出版心。
- 表格前必有一句引导句并以冒号收尾，如"本次退出共分为17个环节，基本安排如下表："；引导句与表格同页。
- 表头需要注明单位时另起一行写在括号内，如"预计历时（工作日）"；无内容的单元格填"—"。
- 金额类数字使用千分位分隔（如 245,766.75）；单位在表头注明（如 "净利润（万元）"）。
- 表格行距用单倍行距，不套用正文 28 磅固定行距。

## 附件说明规则

- 位置：正文（或请示事项末段）下空一行，另起一段，首行左空二字，三号仿宋_GB2312。
- 单个附件：`附件：XX有限公司项目退出方案`；名称过长回行时，回行与名称首字对齐（悬挂在"附件："之后），不顶格。
- 多个附件：

  ```
  　　附件：1.XX有限公司项目退出方案
  　　　　　2.XX有限公司2026年半年度财务报表及审计机构出具的专项审计报告（含附
  　　　　　　注及补充说明材料）
  　　　　　3.回购协议（草案）
  ```

  - 第一份写在"附件："之后，从第二份起每份另起一行，序号"2."与"1."左对齐。
  - 每份名称回行时，与本行序号之后的名称首字对齐，不回到"附件："下方，更不顶格。
  - 序号用阿拉伯数字加半角句点"1."，序号与名称之间不空格、不加标点。
- 附件名称不加书名号，名称后不加标点。
- 生成器的 `attachments` 数组只传附件名称，不传"附件"标签或序号；生成器自动编号、去除名称中的书名号及末尾标点，并按实际字宽计算悬挂缩进（"附件："占3字；"1."按 Times New Roman 实际宽度），同时关闭中西文自动间距，保证对齐。
- A 类附件为来文原件，按报送顺序编号：通知在前，议案次之，表决票最后。

## 落款规则（B 类）

- 附件说明下空两行。
- 署名单位右空四字；成文日期在署名下方、以署名为准居中；日期用阿拉伯数字 `2026年9月X日`，数字 Times New Roman。
- 落款不单独成页：正文末段、附件说明、落款排在同一页。

## 附件正文规则（B 类）

- 另起一页；左上角顶格写 `附件：`（多份时 `附件1：` `附件2：`），三号仿宋_GB2312。
- 附件标题二号方正小标宋简体居中，可折行；标题下空一行。
- 附件正文的标题层级、正文、表格规则与主文相同。

## 标点与数字

- 中文语境一律使用全角标点和全角括号；连续书名号、引号之间不加顿号。
- 数字、百分号、小数点一律半角并设 Times New Roman：`12.5%`、`-18.60万元`、`30.25%`。
- 正文中的议案名称、协议名称用书名号：《关于XXXX的议案》《增资协议》；附件名称不加书名号。
- 协议条款引用格式：`根据《增资协议》第X条“股权回购”约定` 或 `根据XX基金《合伙协议》12.1约定"……"`。
- 发文字号用六角括号：`X国资发〔2025〕X号`、`中国人民银行中国证监会公告〔2025〕8号`。
- 日期格式：`2026年4月23日`；时间格式：`17:00`（冒号为半角）；期间用一字线 `2026年1—6月`。
- 金额写法：`100万元`、`2亿元`、`141583.56元`、`不超过5万元`；负数直接写 `-0.35万元`。

## 成稿自查清单

- 标题为二号方正小标宋简体且居中，提交部门行为三号楷体_GB2312且居中。
- A 类提交部门行后空一行、`投委会：`顶格；B 类空一行后直接接导语。
- 全部标题、全部段落首行缩进2字；四级标题"（1）"为仿宋_GB2312加粗。
- 一级标题三号黑体不加粗；二级标题三号楷体_GB2312加粗；三级、四级标题三号仿宋_GB2312加粗。
- 所有圆括号及括号内汉字为楷体_GB2312：主标题和附件标题内二号，表格内五号，其余三号；四级标题序号"（1）"为仿宋_GB2312加粗。
- 表格内全部五号；括号外仿宋_GB2312，括号内楷体_GB2312；表格未超出版心。
- 全文数字、字母、%等符号为 Times New Roman（含括号内和表格内）；无全角数字和全角％。
- 页脚完整"-1-"（两个短横线、动态页码及其显示结果）全部为宋体四号，奇偶页不同。
- 附件说明左空二字；多份为"附件：1.XXX"，"2."与"1."对齐，回行悬挂对齐；名称无书名号、无尾部标点。
- A 类文末无落款、无日期；B 类落款右空四字、日期居中于署名下，落款不单独成页。
- 行距：标题30磅、正文28磅固定值。
